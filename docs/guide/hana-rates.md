# 하나은행 환율 연결

2026-11-17 사용자 확정 기준과 로컬 구현이다. 운영 활성화는 적용 전이다.

| 통화 | 채택 자료 | 달러당 현지통화 계산 |
| --- | --- | --- |
| BRL·MXN·CLP·COP | 하나은행 현재환율의 최초 고시 1회차 미화환산율 | 1 ÷ 미화환산율 |
| PEN·ARS | 하나은행 비고시환율의 Cross Rate | Cross Rate 그대로 |

표시 자릿수와 반올림, 휴일 보정은 기존 앱 규칙을 사용한다. 계산 단계는 원본의 역수를 보존한다. CLP·COP도 사용자가 같은 역산 방식으로 확정했다. 원본 네 자리 표기의 역산 결과에서 생기는 계단식 변화를 별도 평활하지 않는다.

수집기는 은행 공개 페이지의 조회 요청을 사용한다. 계약형 Open API 접속과는 별도 경로다. 최초 고시는 실제 응답 날짜·고시 시각·1회차·통화·표 구조를 검사한다. PEN·ARS에는 응답 날짜를 기록하며 고시 회차나 고시 시각을 추가하지 않는다. 은행이 직전 날짜를 응답하면 그 실제 날짜에만 연결하고 이후 날짜는 기존 FFILL로 표시한다.

은행 원본 숫자 문자열·단위·변환 방식·고시 회차, 정제 응답의 SHA-256과 수집 시각을 가격 출처에 함께 보존한다. 저장된 숫자를 역산 재검사하며 월별 집계·원화 환산·이동 비교는 기존 공통 계산을 사용한다.

## 실행 연결과 전환 준비

`scripts/generate-data.ts`는 `FX_HANA_EFFECTIVE_FROM=YYYY-MM-DD`가 있을 때 은행 값을 수집하여 기존 공통 병합 함수에 전달한다. 기본 설정은 기존 경로다. 적용일 이후에는 6통화에 은행 관측값을 우선 적용하며, 기존 은행 관측 이력도 다음 실행에서 재사용한다. 적용일 전 데이터와 이미 채택한 원고·숫자는 보존한다. 적용일 이후 다른 출처의 확정값이 이미 있으면 역사값 충돌을 보고한다.

적용 시작일은 2026-11-19로 준비했다. 기존 공개 리포트의 관측일과 같은 날짜에 조회한 하나은행 값을 별도 비교 기록으로 보존한다. 누적 2% 판단에는 이 하나은행 비교값을 사용하고, 정기 예정일은 원래 시장·정기 공개본의 기준일을 따른다. 전환 첫날 전일 대비도 이전 날짜의 하나은행 비교값을 사용한다. 과거 원고·조회 이력의 숫자는 보존한다. 구체적인 반영·복구·확인 항목은 [운영 반영안](hana-rollout-20261119.md)에 기록했다.

## 확인 결과

11월 17일 은행 공개 응답을 저장해 6통화를 실제 파싱했다. 최초 고시 네 통화는 08:24:06의 1회차였다. BRL은 0.1729의 역수, MXN은 0.0540의 역수, CLP는 0.0010의 역수, COP는 0.0003의 역수다. PEN Cross Rate는 3.40860, ARS는 1,549.87500이었다. 이는 은행 응답 대조이며 회사 시스템 전체의 동일성 확인은 포함하지 않는다.

로컬 모의 검사는 역수·직접값, 누락·0·형식 변경·최초 회차 위반, 응답일 보존, 적용일 전후 병합과 FFILL, 출처와 기존 이력 보존을 확인한다.
