# 앱 개요

상태: **로컬 2.0의 현재 기능**. 운영 배포 상태는 [운영 안내](operations.md)를 확인합니다.

## 독자가 하는 일

1. **대시보드:** 원달러 기준축, 통화별 기준환율·월평균·MoM·52주 위치, 일별·월별 차트를 읽습니다. 기존 카드 구성과 BRL/USD 표기는 유지합니다.
2. **환율 추이:** 일별 추이·월별 이력·상세 비교를 한 메뉴에서 봅니다. 기간과 통화는 URL에 반영되며 뒤로가기·새로고침을 지원합니다.
3. **환율 리포트:** 국가 목록에서 최신 원고 또는 해당 국가의 이력으로 이동합니다. 국가별 목록에서 국가를 바꾸면 다른 국가의 목록으로 갑니다. 상세에서는 근거·이전/다음 원고·링크 복사·인쇄를 사용합니다.

대시보드의 새 리포트 표시는 조회가 검증된 실제 공개 원고의 게시일을 사용합니다. 기사 날짜나 생성일로 새 원고를 꾸미지 않습니다. 시험본은 운영 발행본과 구분합니다.

## 관리자가 하는 일

상단 관리자 버튼으로 데이터·리포트 관리와 계획환율·변경 이력에 접근합니다. 같은 인증 상태를 쓰며 서버의 active admin 권한을 확인합니다. 공개 현재 계획값과 비공개 수정 이력은 접근 범위가 다릅니다.

리포트 생성, 자동 내용 검토, 관리자 승인, 실제 공개는 별도 단계입니다. 실패 초안을 기존 공개본 대신 노출하지 않습니다. 철회·정정 상태가 오래된 캐시보다 우선합니다.

## 메일과 앱

메일은 환율 요약과 마감 시점까지 승인된 새 리포트를 소개합니다. 리포트 읽기는 해당 원고 판본으로 앱에 연결됩니다. 새 원고가 없으면 기존 환율 메일의 역할을 유지합니다. SMTP 접수 성공과 수신함 도착은 다릅니다.

## 유지하는 방향

환율 변화와 이유가 리포트의 중심이며 영업 환경은 근거가 있을 때만 보조합니다. 화면마다 경고나 설명을 늘리는 대신 기준일·자료 상태를 필요한 위치에 표시합니다. 새 기능을 추가하는 평가가 아니라 현재 역할의 정확성과 사용성을 평가합니다.
