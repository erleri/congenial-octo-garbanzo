# 앱 개요·이용 안내

구현 기준: 운영 배포 `681de0c`, 2026-11-10. 독자 화면의 11월9일 구성은 유지하고 관리자 운영 확인에 저장·복원 장애를 연결했습니다. 활성화·실행 결과는 [운영 상태](operational-status.md), 정책은 [공통 규칙](rules.md)를 참조합니다.

## 목적과 역할

독자는 주요 통화의 기준환율과 추이를 확인하고, 관련 리포트에서 변화의 배경을 읽습니다. 관리자는 같은 로그인으로 리포트·출처 검토와 계획환율 변경·이력을 관리합니다. 환율 중심 설명이 주 목적이며, 소비·영업 환경은 근거가 있을 때 붙이는 보조 설명입니다.

## 세 메뉴와 이동

| 메뉴 | 첫 화면과 다음 행동 | 구현 근거 |
| --- | --- | --- |
| 대시보드 | 통화별 숫자·변화·비교를 훑고 추이 또는 새 리포트로 이동 | [App](../../src/App.tsx) |
| 환율 추이 | 일별 추이 / 월별 이력 / 상세 비교 중 선택 | [App](../../src/App.tsx), [월별 표](../../src/components/MonthlySummary.tsx) |
| 환율 리포트 | 국가별 최신 리포트 소개 → 리포트 읽기 또는 지난 리포트 | [목록](../../src/components/PublishedCurrencyReports.tsx) |

LATAM FX 로고는 대시보드로 돌아갑니다. 관리자 진입은 독자 메뉴와 분리돼 있습니다. 데이터 갱신·관리자 조작과 자료 기준 정보는 좁은 화면에서도 핵심 숫자를 밀어내지 않도록 정리했습니다. 자료 기준 표시를 열어 날짜·제공 정보를 확인합니다. 앱에서 자료를 다시 읽는 동작과 서버의 유료 생성 실행은 다릅니다.

## 환율 추이의 선택 상태

일별·월별 기본 통화는 BRL입니다. 어느 화면에서든 개별 통화를 새로 선택하면 양쪽에 공유합니다. 월별에서 ‘전체 통화’를 선택하면 일별의 마지막 개별 통화를 보존합니다. 일별로 갔다가 선택을 바꾸지 않고 돌아오면 월별은 전체를 유지합니다. 대시보드의 특정 통화 추이 진입은 새로운 개별 선택입니다.

주소에 `currency`와 `monthly`가 둘 다 있으면 각각 존중합니다. `currency`만 있으면 월별에도 적용합니다. 뒤로가기·앞으로가기·새로고침은 URL 상태를 복원합니다. 일별 조회 기간과 월별 연도 범위는 별도로 유지합니다.

일별 화면은 **그래프 → 관련 리포트 → 접힌 일별 환율표** 순서입니다. 숫자가 필요할 때 표를 펼칩니다. 표가 넓으면 표 안에서 가로 이동하며 페이지 전체가 밀리지 않게 했습니다.

## 월별 이력과 상세 비교

모바일 월별 표는 선택 범위의 최신 월부터 보입니다. 자료 기준일 이후 모든 선택 통화가 빈 미래 월은 숨기지만, 과거 결측은 `—`로 남깁니다. 유효한 값이 하나도 없으면 기간 선택을 유지하고 자료 없음으로 표시합니다. 연월은 `YYYY.MM`으로 함께 표시합니다. 통화·연도 변경은 내부 스크롤을 초기화하고, 단위 변경은 같은 월의 세로 위치를 유지합니다. PC·인쇄는 기존 시간순과 전체 기간을 유지합니다.

독자용 상세 비교는 평균·계획 대비 결과를 먼저 보여주고 일자별 상세를 접습니다. 여덟 요약 항목은 평균(실적), 누적, 선행, 선행 대비, 이동, 이동 대비, 전년 동월 누적, 전년 동월 대비입니다. 계산을 새로 만들지 않고 기존 결과를 분류합니다. 일자별 상세에는 실제 날짜를 표시하며 전부 빈 미래 날짜를 제외하고 과거 결측을 보존합니다. 관리자의 계획환율 편집은 기존 통합 표를 유지합니다. [공유 비교표](../../src/components/MovingComparisonTable.tsx).

## 리포트 읽기와 과거 조회

국가별 카드의 **‘리포트 읽기’는 소개된 최신 원고**, **‘지난 리포트’는 그 국가의 목록**으로 갑니다. 최신 원고가 바뀌어도 날짜가 지정된 직접 링크는 해당 날짜의 원고를 찾습니다. 목록에서 다른 국가로 바꾸면 목록 맥락을 유지합니다.

| 상태 | 독자가 보는 내용 | 관리자의 다음 행동 |
| --- | --- | --- |
| 미발행 | 원고 없음과 국가 선택 유지 | 발행 필요성·근거 상태 확인 |
| 정상 공개 | 승인 판본·기준일·출처·본문 | 필요 시 이력 확인 |
| 새 자료 부족 | 기존 공개 원고의 원래 날짜 유지 | 부족·실패·중복 사유 구분 |
| 조회 장애·캐시 | 캐시/확인 상태와 다시 확인 경로 | 원격 조회·권한 상태 확인 |
| 정정 검토 | 현행 판본과 정정 상태를 구분 | 대상 문장·새 근거 검토 |
| 철회 | 정상 추천에서 제외, 알려진 철회를 캐시가 되살리지 않음 | 사유·판본 이력 보존 |

상세에서는 기준일을 상단, 관측일·관측시각 미제공 여부를 숫자 부근에 표시합니다. 수집 시각·제공 경로·가격 정의는 접힌 ‘환율 자료 정보’에 모읍니다. 기사 출처와 해석의 한계는 별도입니다. 시간대가 있는 유효한 시각만 KST로 변환하며 날짜만 있는 값이나 시간대 없는 문자열은 추정하지 않습니다. 명확한 단위 토큰만 독자용 표현으로 바꿉니다. 저장 원고·근거·해시·다운로드는 바꾸지 않습니다. [표시 함수](../../src/lib/reports/reader-display.ts).

목록은 상단 새로고침, 정상 상세는 상세 도구의 ‘리포트 새로고침’ 하나를 사용합니다. 모바일 상세 도구는 더보기로 모읍니다. 실패·철회·미발행에서도 재확인 경로를 남깁니다. 갱신은 현재 통화·주소·목록 기간을 보존합니다.

## 관리자

한 번 로그인하면 데이터·리포트 관리와 계획환율·변경 이력을 함께 이용합니다. 화면이 보이는 것만으로 권한을 인정하지 않으며 서버가 현재 활성 관리자와 대상 버전을 다시 확인합니다. 리포트 승인·반려·철회, 출처 이용 범위 결정, 정정 검토는 각각 기록됩니다. 로그아웃·권한 해제 후 초안이나 비공개 원장을 공개 조회로 대신 제공하지 않습니다.

관리자 알림은 처리할 항목을 알려주는 수단입니다. 링크 자체가 승인권한을 부여하지 않습니다. [알림과 Dot](admin-review-notifications.md).

**데이터·리포트 관리 → 이용 현황**에서는 최근 7일/30일의 화면 조회·메일 유입·리포트 열기·30초 표시를 봅니다. 일별 추이, 메뉴·통화별 이용과 원고별 열람·근거 펼침도 확인할 수 있습니다. 합계는 기간 전체를 계산하고 원고 목록만 페이지로 나눕니다. 집계 꺼짐·활성화 후 기록 없음·정상·조회 장애를 구분합니다. 로그인한 관리자 이용은 독자 통계에서 제외됩니다. 횟수는 고유 독자 수나 정독률이 아닙니다. [지표 정의와 활성화 시각](report-followup-usage.md#익명-이용-집계-v2).

입력 저장·복원 문제가 있으면 검토함의 **운영 확인**에서 발생 단계와 사유를 봅니다. 이는 원고 승인 대상이 아니며 관리자가 원문 저장소를 직접 열거나 경고를 지워 해결하는 화면도 아닙니다. 후속 정상 검사로 해결 여부를 확인합니다. 이 장애가 기존 환율·공개 리포트를 삭제하거나 비공개 초안을 대신 공개하지는 않습니다.

## PC·모바일·인쇄

기존 색조·대시보드 정보·BRL/USD 표기를 유지했습니다. 의미 있는 보조 글자 최소 12px, 조작 문구 기본 13px, 주요 메뉴 터치 영역 44px, 조회 탭 36px·기간 버튼 34px를 기준으로 정리했습니다. 색상만으로 상태를 구분하지 않습니다. 인쇄 스타일은 접힌 상세·환율 자료 정보를 포함하도록 구현했습니다.

320·390·768·1440px 검사는 데스크톱 브라우저의 화면 폭 검사입니다. 실제 iPhone Safari, 최신 변경의 실제 A4 미리보기·200% 글자 확대는 별도 미확인입니다. 이전 사용자의 인쇄·메일 확인을 이번 변경 전체의 실제 기기 검증으로 확대하지 않습니다. [검증 범위](verification.md).
