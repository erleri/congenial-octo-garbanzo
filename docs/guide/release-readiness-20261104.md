## 고정한 코드의 의미

현재 개발 폴더의 변경을 그대로 main에 커밋하지 않는다. 기존 출시 조립 도구로 검증된 운영 main에서 별도 비공개 소스 사본을 만들고, 최신 코드·문서·테스트를 반영한다. 운영 환율·생성 플래그4파일은 upstream 바이트 그대로 유지한다. 원고·원문·비용·비밀 환경파일·시안·로컬 DB·의존성·빌드 결과는 신규 커밋에 포함하지 않는다. 기존 운영 저장소의 다른 데이터는 조립 도구의 보존 정책을 따른다.

로컬 출시 브랜치는 `codex/release-candidate-20261104`다. 원래 개발 브랜치와 index는 유지하며, 별도 index로 검증한 트리를 커밋한다. commit/tree SHA·파일 해시·검사 결과·보존한 운영 파일은 비공개 `.local-reports/private/release-freeze-20261104/receipt.json`에 연결한다. 이후 코드가 달라지면 같은 후보라고 부르지 않고 차이를 검사한다. push·배포·운영 설정 변경은 하지 않는다.

실제 배포 직전 main이 더 갱신됐으면 새로운 환율 데이터와 기준점을 확인하고 재조립해야 한다. 이번 고정본을 과거 데이터와 함께 무조건 덮어쓰는 절차가 아니다.
