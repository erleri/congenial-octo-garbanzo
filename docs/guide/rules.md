# 현재 공통 규칙

상태: **사용자 합의와 로컬 구현 기준**. 운영 활성화·반복 예산 승인과 별개입니다. 규칙 변경 시 코드·검사·이 문서를 함께 변경하고 과거 입력·승인을 덮어쓰지 않습니다.

## 국가별 차이가 허용되는 범위

출처와 사용 조건, 현지 달력·시간대, 가격 정의, 공식 지표의 단위·대상 기간·수정 시점입니다. 같은 나라라도 자료 판본과 거래일이 달라지면 새 검토가 필요합니다. 미확인 정보를 국가 기본값으로 보충하지 않습니다.

국가별 등록 자료는 [출처 계획](../2.0/six-currency-explanation-sources-20261027.json), [출처 등록부](../2.0/six-currency-source-register-20261027.json), [원문 처리 정책](../2.0/original-news-source-policy-20261028.json), [처리 규칙](../2.0/material-processing-rules.json)을 참조합니다. 날짜가 붙은 파일도 코드가 읽는 경우 현재 설정 자료이므로 청소 대상으로 취급하지 않습니다.

## 과거 규칙을 읽을 때

[기존 공통 규칙](../2.0/common-report-rules-history-20261104.md), [기존 편집 기준](../2.0/editorial-standard-history-20261104.md), [기존 발행 정책](../2.0/publication-policy-history-20261104.md)은 변경 과정의 기록입니다. 문서 안의 서로 다른 날짜·버전을 현재 규칙처럼 합쳐 적용하지 않습니다. 모델 입력의 실제 상세 지침은 코드와 저장된 요청 판본을 기준으로 확인합니다. 정비 과정에서 모델 프롬프트나 품질 합격선을 변경하지 않았습니다.
