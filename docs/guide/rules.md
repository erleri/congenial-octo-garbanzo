# 공통 규칙

구현 기준 `681de0c` / 2026-11-10. 발행·모델·예산 정책은 변경하지 않고 입력 보관·복원과 장애 표시를 보강했습니다. 운영 활성화·예산의 실제 값은 [운영 상태](operational-status.md), 국가별 차이는 [6통화 표](countries.md)에서 관리합니다. 여기서는 중복 없이 공통 의미를 정의합니다.

## 환율·시점·발행

| 항목 | 기준 | 구현 |

2%는 발행 보장이나 매일의 변화율만을 뜻하지 않습니다. 조용한 날에도 새 정책 설명을 조사할 수 있고, 임계값을 넘더라도 근거가 없으면 보류합니다. 5.5·5.6 같은 임의 가격 마디를 별도 발행 기준으로 추가하지 않았습니다. 과거 현재 역사값이 달라져도 공개본의 고정 분모를 사용하되 단위·정의·확인된 공급자 변경과 현재 자료 오류는 검사합니다.

기사의 현지 거래일, 발표일, 가격 관측일, 수집일, 보고서 기준일은 다른 필드입니다. 수집시각으로 미제공 관측시각을 채우지 않습니다. FIX·종가·장중·평균·호가를 혼용하지 않으며, 기사 가격은 자신의 시점·종류를 밝힌 보조 설명입니다.

## 조사·원문·카드·내용

자료 발견, 수집 성공, 이용 범위 적합, 날짜·가격 적합, 문장 지지, 집필 자격, 게시 승인을 별도로 기록합니다. 등록 출처는 조사 경로이며 모든 기사의 포괄 이용 허가가 아닙니다. [출처 선택](../../scripts/currency-report/research-source-selection.js).

허용된 공개 본문·URL·발표시각을 서버의 승인된 처리 설정에 따라 외부 모델로 보내 비공개 추출·대조할 수 있습니다. 원문 경로와 이미 검토된 사실·견해 카드 경로를 구분하고 카드 재검토를 원문 검증 성공으로 표시하지 않습니다. 유료벽·로그인 차단을 우회하지 않습니다. 수집 실패는 자료 없음과 다릅니다. 보류된 한 출처가 다른 적합 출처를 모두 차단하도록 취급하지 않습니다. 다만 입력 저장 용량·예산·실행 잠금 같은 전체 실행 조건은 여러 국가에 공통으로 영향을 줄 수 있습니다.

새 매체는 기술적으로 읽히는지와 사용 범위가 맞는지를 나눠 봅니다. 공통 기사 조건 또는 관리자가 결정한 매체·섹션 조건에 정확히 맞으면 재사용할 수 있습니다. 조건 변경·전재·범위 밖 기사는 별도 판단 대상으로 남깁니다. 단순 발견 링크는 근거 카드가 아니며, 미해결 출처를 기다리느라 기존 적합 출처를 멈추지 않습니다.

공식 통계는 지표 정의·범위·대상 기간·발표/수정·단위·판본·이용 범위를 확인한 뒤 보조 배경에 전달합니다. 월간 소매·물가 수치를 특정 거래일 환율 움직임의 직접 원인으로 대체하지 않습니다. 최신 조회가 곧 당시 이용 가능했던 판본을 의미하지 않습니다.

집필은 환율의 변화 → 새 정보 → 시장 반응과 해당 통화의 연결을 중심으로 합니다. 전문가 설명은 발언자에게 귀속하고, 독립적인 요인 기여율·우선순위를 계산한 것처럼 확대하지 않습니다. 하나의 사실을 여러 기사에서 재전재했다고 독립 증거 여러 건으로 세지 않습니다. 필요한 반대 조건은 문장에 담되 반복 경고·최소 글자 수로 품질을 대신하지 않습니다. 빈 영업 항목을 억지로 채우지 않습니다.

구조 검사는 항목·형식·개수·연결을, 내용 검토는 문장의 각 주장에 대한 출처 지지·시점·귀속·인과 범위를 봅니다. 필수 교정 오류와 제목·문체 개선을 분리합니다. AI 검토 결과만으로 객관적 사실이나 게시 허가를 확정하지 않습니다. [공통 집필](../../scripts/currency-report/shared-writer.js), [주장 검토](../../scripts/currency-report/claim-review.js), [전송 스키마](../../scripts/currency-report/generation-wire.js).

## 모델·전송·비용

[모델 정책](../../scripts/currency-report/writer-policy.js)은 Sol을 기본으로 하고 명시된 프로필 교체를 지원합니다. 현재 운영은 `sol-us`입니다. Sonnet·Argon 프로필이 존재해도 운영 정책 검증이 허용하는 writer는 별개이므로 단순 변수 변경만으로 교체 완료라고 보지 않습니다. 특히 [반복 운영 정책](../../scripts/currency-report/operating-policy.js)은 현재 sol/sol-us를 검증합니다. 다른 모델 운영 채택은 입력·출력·검토·경로·가격·품질 검증과 운영 정책 변경이 필요합니다.

전송 목적지는 OpenRouter의 `/api/v1/chat/completions`, 운영 제공 경로는 검증된 Azure입니다. 호출 전 제공 상태·필수 구조화 기능·가격·ZDR·데이터 수집 금지를 확인합니다. 백업 모델로 자동 전환하지 않습니다. 키·관리자 개인정보는 입력에 넣지 않습니다. ZDR/수집 금지 요청과 정책 검사를 수행한다는 뜻이며 제공자의 내부 이행을 이 문서가 독립 감사했다는 뜻은 아닙니다.

호출 전 최대 비용을 예약하고 실제 사용량·확정 비용을 별도로 기록합니다. 시간 초과·응답 유실 등 비용 미확인은 예약을 함부로 해제하지 않습니다. 실행 ID만 바꿔 예산·중복 차단을 우회하지 않습니다. 기본 120초·자동 재시도 0·백업 없음이며 과거 승인된 429 한정 추가 시도는 당시 시험 범위입니다. 반복 운영에 그 예외를 자동 승계하지 않습니다.

## 승인·공개·보존

자동 생성·자동 내용 검토·활성 관리자 승인·공개·메일 전달은 분리됩니다. 승인 시 대상 버전·권한·조건을 다시 확인하고 상태 변경과 공개 복사를 함께 처리합니다. 정정 후보는 관리자에게 연결하되 기존 공개 문장을 자동 수정하지 않습니다. 철회된 판본을 캐시가 정상 최신으로 복구하지 않게 합니다.

공개 빌드는 승인 원고와 허용 필드만 사용합니다. 원문·비공개 카드/검토·키·회계/발송 기록은 별도 보관합니다. 임시7일·반려원문30일·상세90일·감사24개월·경보70%·중단85%는 **dry-run 제안**입니다. 자동 삭제 정책으로 적용된 값이 아닙니다. 반면 공개 상태 재확인 15분·공개 캐시24시간은 조회 정책의 실제 값입니다. [데이터 정책](../../src/lib/report-data-policy.js), [보존 점검](../../scripts/currency-report/data-operations-policy.js).

## 실행 코드가 읽는 문서

입력 보관의 11월10일 배포 기준은 [저장·복원](frozen-input-storage.md#인터페이스와-보호-한도)에 모았습니다. 원문 무손실 압축·분리 저장이며 위 환율·발행·모델·비용 규칙을 수정하지 않습니다. 실제 운영 확인 범위는 [운영 상태](operational-status.md)에서 구분합니다.

[출처 계획](../2.0/six-currency-explanation-sources-20261027.json), [등록부](../2.0/six-currency-source-register-20261027.json), [원문 정책](../2.0/original-news-source-policy-20261028.json), [처리 규칙](../2.0/material-processing-rules.json)은 날짜가 오래돼도 실행 입력입니다. 일부 안의 `runtimeIntegrated:false`·`local_research_only`는 작성 당시 설명이며 현재 연결 상태는 코드 호출로 판정합니다. 이번 문서 정비에서는 이를 수정하지 않았습니다. 내용 변경이 필요하면 운영 입력 변경 작업으로 분리합니다.

과거 공통 규칙·편집 기준·모델 비교는 [색인](catalog.md)의 과거 기록입니다. 과거 실패와 비용을 현재 성공으로 재작성하지 않습니다.
