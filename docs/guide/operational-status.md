## 최근 자동 실행에서 확인된 보류

[예약 실행 #211](https://github.com/erleri/congenial-octo-garbanzo/actions/runs/42573958438)은 **11월9일 UI 배포보다 먼저 실행**됐습니다. 당시 전체 성공 표시와 달리 `currency-review-report` 작업은 실패했습니다. 당시의 `continue-on-error` 설정은 이번 `681de0c`에서 제거됐으며, 선행 환율·메일의 별도 작업은 유지합니다.

실제 결과는 `operating_payload_capacity_hold`, exit code 2, 모델 호출 0회입니다. [당시 배포 코드](https://github.com/erleri/congenial-octo-garbanzo/blob/fa9b58f7bc8c112879db037f181a7eca8c4c4e28/scripts/currency-report/operating-cycle.js)는 동결 입력의 JSON과 이스케이프된 JSON 합산 크기 및 여유분이 30,000,000바이트를 넘으면 DB의 32MB 한도 전에 멈춥니다. **원인을 자료 없음이나 모델 품질 실패로 바꿔 설명하지 않습니다.** 로그에는 실제 바이트 수가 없으므로 초과량은 미확인입니다.

BRL·MXN·COP·CLP는 당시 `no_report_due`, PEN·ARS는 조사 후보에서 각각 기사 3건·7건을 계획했습니다. 계획 비용 상한 $3.093675001·24회는 지출이 아닙니다. 이후 저장 수정 배포의 실제 왕복은 통과했지만 당시 실행 자체를 성공으로 바꾸지 않습니다.

11월10일 새 무료 수집에서는 6통화 모두 새 조사 후보가 있었고 입력 기사 20건·최대 52회·$6.988400001을 계획했습니다. 이는 이번 무료 수집 결과이며 이전 상한과 합산하지 않습니다. 누적 ±2%를 넘은 통화는 없고 정기 점검 예정일은 11월16일입니다. 기사 내용 검토 후 중요성이 인정돼야 후속 원고가 나올 수 있으며, 6개 발행을 강제하지 않습니다.
