# 자동 운영 공통 경로 보강·반복 검증 — 2026-11-08

범위: [독립 점검 A1–A3](unattended-operation-review-20261108.md)의 공통 코드 수정과 반복 시뮬레이션. **로컬 구현·검증 결과**이며 운영 배포·자동 생성 활성화·새 유료 호출·메일 발송은 포함하지 않는다. 기존 공개 원고·가격·승인·비용 기록을 수정하지 않았다.

일회 시험 설정은 기존 전체 입력·정확한 승인 예산 경계를 유지한다. 새 순차 배분을 근거로 일회 시험 예산을 자동으로 늘리거나 두 번째 묶음을 허가하지 않는다. 반복 운영도 월·회차·요청별 비용 한도와 DB의 원자적 예약을 그대로 사용한다. 수동 원고 교정이나 모델 교체는 사용하지 않았다.

## 반복 검증 범위

- 최종 코드의 `npm run check`(타입·린트·전체 1,340개 테스트·운영 빌드·번들 경계)가 통과했다. 별도 리포트 빌드도 통과했다. 기존 React title 및 리포트 정적/동적 import 경고는 이번 수정의 성과로 계산하지 않는다.
- 핵심 재발 방지: `scripts/currency-report/unattended-operation.test.ts`. 원래 세 문제의 실패 조건을 넣고 정상 복구·재실행·권한 차단·기사량 초과·목록 유실을 연결해 확인한다. 제품 테스트 수와 실제 원고 품질 표본은 구분한다.
- 관련 복구 검증: 국가별 준비 회복, 기존 묶음 재개, 검토 철회, 본문/공식 수치 수정, 비용·시간·제공 경로 보류, 원문 대조·구성 검사를 함께 실행했다.
- 저장된 실제 6개국 환율·기사 29건에는 **모두 첫 발행 대상이라는 합성 이력 조건**으로 계획기를 재생했다. 6통화 모두 계획 가능, 52회·$6.9463 상한, 전역 초과 보류 없음. 이는 실제 현재 발행 결정이나 과금 결과가 아니다. 날짜·가격·원문은 원래 그대로다.
- 기존 이력이 있는 격리 DB(56322): 새 대기 자료의 저장/재조회/멱등성/변조 거절/익명 접근 차단 등 8개 SQL 검사와 직렬화 왕복을 확인했다. 시험 쓰기는 롤백했고 기존 원고·비용 장부·제어·공개 원고 행 해시가 유지됐다.
- 전체 DB 회귀: 장기 사용 DB에 이력이 없다는 전제를 강요하지 않고, 구조·소유자·권한을 복사한 새 로컬 검증 DB를 사용했다. 최신 저장소의 설정 변경 보호 정의를 적용한 상태에서 21개 SQL 파일·368개 검사가 통과했다. 검증 후 새 DB의 접속을 닫았다. 기존 이력은 복사하거나 삭제하지 않았다.

DB 전체 검사 중 처음 확인한 두 차이는 앱 실행 오류와 구분한다. 기존 시험의 일회 예산 기준은 보존된 과거 비용·예약을 포함해야 했고, 장기 사용 격리 DB의 설정 변경 함수가 저장소의 최신 보호 정의와 달랐다. 기존 DB에서 비용 기록을 제거하거나 보호 기준을 낮추지 않았다. 새 검증 DB에서 최신 후보를 검사했으며, 운영 반영 점검 때도 실제 함수 정의가 현재 migration과 맞는지 확인해야 한다.

## 자료 상태의 의미

- `unreviewed_source_capture`: 다음 검토를 위한 비공개 원문. 사실 카드·근거 승인·모델 검토 결과가 아니다.
- `source_budget_deferred` / `source_dispatch_deferred`: 이번 회차 한도 때문에 남은 작업. 다음 정기 실행에서 저장된 검토와 대기 자료로 다시 계획한다. 자동 유료 재시도 승인이 아니다.
- `wait_for_country_storage`: 해당 국가의 이력/상태 기록을 다음 실행에서 다시 확인한다. 이 상태로 해당 국가를 집필하거나 게시하지 않는다.
- 실제 원문 비교의 보류·철회·충돌은 기존 검토 이력으로 유지한다. 미검토 자료를 추가했다고 해소되지 않는다.

원문은 계속 서비스 전용 저장소에만 보존하며 기존 보존·용량 정책의 대상이다. 같은 판본의 대기 자료를 매일 새 사본으로 쌓지 않는다. 실제 검토와 원문 대기는 별개이며, 제한을 초과한 자료를 공백·합격으로 숨기지 않는다.

## 증거와 남은 운영 경계

비공개 증거 위치: `.local-reports/private/operating-rollout-20261108/source-gap-review/`의 `unattended-release-check.log`, `unattended-completion-audit.log`, `unattended-recovery-suite.log`, `ready-materials-replay.json`, `clean-sql-result.json`, `final-boundaries.json`. 기존 데이터 DB 저장 검증은 별도 `.local-reports/private/unattended-db-*/result.json`에 있다. 브라우저 산출물의 비밀값 일치 0건, 보존 대상 6개국 수집 파일의 SHA-256 일치를 확인했다. 실제 원문·계정·키는 문서나 Git 변경에 포함하지 않는다.

이번에 수정한 코드의 CI·운영 반영과 실제 runner 확인은 별도 단계다. 그때 최신 설정 변경 보호 함수·원문/예산 처리 설정·제어·원고 보존을 대조하고 무과금 준비를 확인한 뒤 활성화를 판단한다. 실제 원고의 장기 품질이나 발행 빈도를 시뮬레이션 통과로 대체하지 않는다. 외부 사이트의 개편·유료화·인증 만료는 계속 발생할 수 있으며, 이번 보강은 그것을 정상 보류·대체 출처·다음 실행 복구로 처리하기 위한 것이다.
