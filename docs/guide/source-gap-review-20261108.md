## 공통 수집 경로의 실제 수정

1. **발견 단계 수에 맞춘 무료 요청 배분.** 모든 출처를 같은 2~3회로 나누면 robots → 목록 → RSS → 사이트맵 → 본문인 경로는 기사에 도달하지 못했다. 등록된 어댑터의 단계 수에 맞춰 첫 본문까지의 시도 예산을 배분한다. 국가·특정 기사 예외는 추가하지 않았다. 기본 16회, 국가별 뉴스 수집 상한 32회이며 명시적으로 낮은 한도를 지정한 호출은 그대로 유지한다. 필요한 최소 시도가 상한을 넘으면 미충족 상태를 표시한다. 이 수는 무료 HTTP 요청이며 유료 모델 횟수·예산은 바꾸지 않는다.
2. **응답 재사용 오류 수정.** 살아 있는 응답 복제본을 캐시하면 최초 요청의 제한 시간이 지난 뒤 다른 날짜 검색에서 다시 읽을 때 실패했다. 응답을 최대 4MB의 완료된 바이트로 저장해 같은 URL을 재조회 없이 읽는다. 리디렉션 차단·요청 제한·출처별 접근 조건은 유지한다.
3. **진단 분리.** 접근/추출 실패, 요청 예산 소진, 탐색에서 일치 후보를 찾지 못한 상태를 구분한다. 질문·날짜별 같은 오류는 합쳐 영향 기간을 보존한다. 후보 없음은 기사 부재의 입증이 아니다. 출처별 수집 건수는 내용 승인과 분리한다. 공식 발표문 조회 결과도 준비 결과에 포함한다.

PEN은 새 정책으로 21회 상한 중 실제 18회에 4건, CLP는 기존 16회 상한 중 실제 13회에 6건을 확보했다. CLP의 기존 8/4/4 배분처럼 이미 충분한 배분은 유지했다. 모두 등록된 공개 경로를 사용했고 유료벽·robots 실패를 우회하지 않았다.
