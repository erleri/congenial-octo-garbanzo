## 같은 기준과 국가별 차이

공통 기준은 원자료 해시, 허용 URL, 수집시각, 정의 버전, 실제 대상 월, 유한 값, 결측, 중복/상충 판본, 최신 검증 월, 기존 4개월 조사 범위, 수치 사용 정책, 자료 역할과 공개 승인 분리다. 등록 프로필에는 출처·계열·비교·단위·계절조정·기준년·대상 채널·파서만 둔다. 개별 뉴스나 날짜에 맞춘 예외 문구를 집필 지침에 추가하지 않았다.

- PDF는 표의 같은 지표 값과 서술의 값을 대조한다. DANE의 차량 포함 7.3%를 연료 제외 9.0%로 바꾸거나, 칠레 IACM을 IAC 전체로 바꾸지 않는다. 실제 두 표를 PNG로 렌더링해 확인했다.
- PDF 파서는 다음 발행 월에도 같은 제품 정의와 구조를 검사한다. 형식·범위·표 값이 달라지면 추측하지 않고 이유를 남긴다.
- API/CSV에 발표일이 없으면 비워 둔다. `availability`에 실제 원자료 확보시각만 별도로 보존한다. 이 경로는 등록 통계의 소비/금융 배경에만 허용하며, 날짜 없는 일반 뉴스나 환율 원인으로 우회할 수 없다.
- 최신 월이 결측이면 이전 유효 월을 최신 정상값으로 조용히 바꿔 끼우지 않는다. 재수집한 공백/들여쓰기/시각만 바뀌면 새 통계 판본으로 세지 않는다. 값·기간·정의가 바뀌면 재검토할 조사 후보로 분리한다.
- ARS는 같은 원계열의 당월 지수 79.46845968899339와 전년 동월 지수 82.55780826244025로 코드가 계산했다. 명목 매출이나 계절조정 지수와 혼합하지 않는다. 정부 API 메타데이터의 원 기관·단위·월 빈도·CSV 주소 및 겹치는 값이 맞아야 CSV를 쓴다.
- 소비 통계를 환율 원인으로 사용하면 기존 공통 검사에서 거부한다. 집필 모델에는 숫자 사실·범위·출처만 전달하고 PDF/CSV/JSON 원문은 비공개 증거에만 남긴다.

## 실제 문제와 수정

1. 기존 월간 PDF의 24쪽 제한에 DANE 33쪽 문서가 걸렸다. 기본 24쪽 제한은 유지하고, 등록 공식 통계 문서에만 `statistical-bulletin` 프로필을 추가했다. 최대 96쪽·2MB·쪽당 40,000자·20초 제한이며 자르지 않는다. 합성 33쪽/97쪽 문서로 허용·차단 경계를 실제 추출기에 확인했다.
2. 칠레 정상 통계 페이지의 숨김 문의 양식에도 `captcha`가 있었다. 단어만 보고 차단하는 오탐을 제거하고 실제 차단 화면의 제목·서버 표식·인증 요구 문장을 검사한다. 수정 후 같은 일반 수집 경로에서 칠레 실조회가 성공했다.
3. 페루는 실제 차단 화면이라 정상 JSON으로 처리하지 않았다. 명시적으로 제공한 저장 입력이 있으면 원래 수집시각으로 재검사하고 현재 조회 실패를 함께 남긴다. 저장 입력이 없으면 자료 미확보다. **운영 저장소에서 직전 원자료를 자동으로 찾아 로더에 주입하는 캐시 연결은 이번 범위에서 구현하지 않았다.** 현재 로컬 재생/매니페스트 경로와 완전한 운영 자동 캐시를 혼동하지 않는다.
4. 이미 연결된 등록 통계를 다시 일반 월별 수집기로 중복 요청하던 부분은 재사용으로 전환했다. 미등록 정책/급여 등 다른 항목의 미완료 상태는 숨기지 않았다.
5. 기존 캐시를 검사한 뒤 새 숫자 카드를 붙이는 순서에서는 최신 출처 제한이 새 카드에 빠질 수 있었다. 새 카드와 새 기사 연결 뒤에도 공통 제한을 다시 적용한다. 수치 사용 정책은 명시적 서버 제한을 덮어쓰지 않는다.

## 코드와 재현

- `official-country-statistics.js`: 다섯 등록 정의·파서·숫자 사용 범위.
- `official-country-input-loader.js`: 고정 API/공식 목록/공식 배포 주소, 20초·2MB 제한, 재시도 없음, 실제 실패와 저장 재사용 분리.
- `official-statistic-availability.js`: 발표일 없는 등록 배경 자료의 별도 확보시각 계약. 일반 뉴스에는 허용하지 않음.
- `official-statistic-admission.js`, `runtime-official-supply.js`: 기존 공통 채택·숫자 사실·출처 연결, 중복 수집 방지.
- `official-input-loader.js`: 기존 운영 진입점에서 같은 다섯 로더를 호출. PDF는 기존 Python/pypdf 추출기를 사용하고 실패는 보류로 반환.
- `operating-source-cache.js`: 안정된 계열 판본으로 수집시각/서식 변경과 실제 값 변경 분리.
- `runtime-supply.js`: 새 자료를 연결한 뒤 현재 출처 제한 재확인.
- `official-country-local.js`: 무료 수집/저장 재생 전용 명령. DB·모델·활성화 경로가 없음.

이번 입력은 `.local-reports/private/five-official-20261101/`에 원자료·수집 결과·집필 입력으로 별도 보존했다. 저장 대시보드 파일을 읽기 전후 대조했고 변경하지 않았다. 과거 AI 원고는 편집하지 않았다.

```powershell
# 저장 재생: 외부 호출 0, 키 접근 0
node scripts/currency-report/official-country-local.js --mode saved --input .local-reports/private/five-official-20261101/live-manifest.json

# 등록된 무료 공식 URL만 조회: 모델/DB/과금 없음
node scripts/currency-report/official-country-local.js --mode live --input .local-reports/private/five-official-20261101/live-manifest.json
```

매니페스트는 `official-background-replay/1`, `asOf`, `countries[{currency,officialInputsFile}]`다. 입력/결과는 Git 제외 비공개 폴더만 허용하고 매번 새 결과 폴더를 만든다. `asOf`는 해당 실행의 계획 시각으로 갱신해야 한다. 저장 재생에서 원자료 수집시각을 갱신하면 안 된다. 실제 운영 실행은 별도 준비/예산/승인 기준을 그대로 따른다.

## 검증과 다음 경계

새 회귀는 다섯 지표의 정의·결측·중복·범위·원자료 해시·현재 차단·누락된 발표일·환율 원인 혼용·출처 제한·판본 신규성·원고/가격 보존을 확인한다. 합성 테스트와 실제 공식 원자료 재생은 분리했다. 자동 테스트 개수는 실제 원고 품질 표본 수가 아니다.

실제 최신 수집 경로는 총 8회 무료 요청으로 BRL/COP/CLP/ARS 정상, PEN 차단+명시된 저장 입력 재사용을 확인했다. 저장 전용 재생은 외부 요청 0이다. 다섯 실제 입력 모두 `prepared_not_called`, 공개 사용 대기다.

최종 전체 159파일·1,171사례, 타입 검사·린트·운영 빌드·번들 경계 검사를 통과했다. 별도 앱/리포트 빌드도 통과했으며, 기존 리포트 빌드의 `dbClient` 정적/동적 import 병행 경고는 남는다. 브라우저 산출물/요약 105파일에서 실제 비밀값·비공개 실행 기록 노출 0건을 확인했다. 로컬 4176의 갱신 준비표 HTTP200, 비공개 원자료 HTTP403을 실제 확인했다. DB·권한 구조는 변경하지 않아 이번에 pgTAP은 재실행하지 않았다.

남은 것은 (1) PEN의 안정적인 무인 신규 수집 또는 운영 저장 원자료 자동 캐시, (2) 공개 출처/라이선스 고지 렌더링과 내용 검토, (3) 필요한 추가 지표별 정의·수집 확대, (4) 별도 범위/예산의 실제 집필·문장 검토 및 정정 후보 연결 검증이다. 6개국 전체 무인 운영·실제 리포트 품질·2.0 출시를 완료로 판정하지 않는다.
