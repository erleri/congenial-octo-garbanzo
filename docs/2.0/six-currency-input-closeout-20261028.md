# 6개 통화 자료·집필 입력 재검증

2026-10-28 · 로컬 준비 단계 · 추가 유료 호출/운영 변경 없음

후속 갱신: [COP·ARS 보도 가격 연결](cop-ars-reported-prices-20261028.md)에서 두 통화의 별도 리포트 가격 계약을 검증했다. 아래 표는 당시 저장 입력 재검증 결과로 보존한다. COP·ARS 가격 준비가 추가됐으며 전체 집필 보류는 남아 있다.

## 결과와 범위

**CLP·MXN·BRL의 저장 사례는 현재 공통 집필 입력으로 준비된다. COP·PEN·ARS는 서로 다른 이유로 보류한다. 여섯 통화의 무인 조사·집필·게시가 완성됐다는 뜻은 아니다.**

오래된 준비표의 BRL PTAX 보류를 최신 현물 종가 사례의 상태와 분리했다. CLP는 옛 9/10 사례 대신 10/27 거래일 입력을 사용하고, MXN은 영업 환경과 당일 달러 관측을 연결한 최신 입력을 사용한다. 기존 원고·수치·점수·비용·승인을 덮어쓰지 않는다.

| 통화 | 이번에 재검증한 거래일·가격 기준 | 집필 입력 | 영업 환경과 남은 작업 |
| --- | --- | --- | --- |
| BRL | 10/27, CNN Brasil 보도 현물 종가. 이전 거래일도 같은 보도 기준. PTAX와 분리 | 저장 사례 요청 준비 | 소비 배경 미확보. 기존 IBGE 소매의 외부 이용 범위와 실제 소비 설명 연결은 미완료. 재정·인선 기사를 소비 자료로 바꾸지 않음 |

| CLP | 10/27 실제 거래, 10/28 고시의 BCCh 거래 가중평균. 현물 종가로 부르지 않음 | 저장 사례 요청 준비 | 검토된 3분기 소비 평가 연결. 새 무인 원문 검토와 발행 자격·품질·게시 승인은 별도 |

COP의 기존 카드가 저장된 묶음 날짜는 10/28이지만 설명 대상 거래일은 **9/24**다. 재검증 날짜만 바꿔 최신 보고서로 만들지 않았다. PEN·ARS의 기존 입력도 10/26 사례로 남긴다.

## 새 무료 자료의 확인 결과

기존 등록 수집기에서 추가 공개 요청 **8회**, 원문 추출 **4건**(COP 1, PEN 2, ARS 1)을 보존했다. 조사용 합성 수치는 경로 선택 시험에만 사용하며 집필 자료로 전달하지 않았다. 첫 로컬 조사 입력의 날짜 불일치는 전송 전 중단됐고, 원래 기록을 보존한 별도 입력에서 수정했다.

- **COP:** [La República 10/27 기사](https://www.larepublica.co/finanzas/precios-del-dolar-y-del-petroleo-hoy-27-de-octubre-de-2026-4511869)의 마감판을 수집했다. 기사 가격과 당일 TRM의 차이는 전일 종가 대비 변화가 아니다. ING 견해는 달러 공통 배경이며 COP 하락의 직접 설명으로 바꾸지 않는다. 오전 최초 게시와 오후 수정 시각을 모두 보존한다.
- **PEN:** [RPP 10/27](https://rpp.pe/economia/economia/precio-del-dolar-peru-y-tipo-de-cambio-hoy-27-de-octubre-del-2026-noticia-1714624)과 [10/28](https://rpp.pe/economia/economia/precio-del-dolar-peru-y-tipo-de-cambio-hoy-28-de-octubre-del-2026-noticia-1714795)을 분리했다. 27일 수정판은 가격 관측과 일반적 영향 경로를 담지만 당일 원인까지 설명하지 않는다. 28일 자료를 27일 근거로 사용하지 않는다. Gestión 경로의 이번 수집 실패도 자료 부재와 구분했다.
- **ARS:** [Infobae 10/23 기사](https://www.infobae.com/economia/2026/10/23/el-dolar-termino-la-semana-con-nuevo-record-nominal-tras-seis-alzas-consecutivas/)에서 이전 도매 가격을 직접 확인했다. [기존 10/26 기사](https://www.infobae.com/economia/2026/10/26/dolar-riesgo-pais-y-acciones-uno-por-uno-cuales-fueron-los-efectos-del-ballotage-de-brasil-en-el-mercado-financiero-argentino/)와 각각의 명시적 관측을 연결할 수 있는 후보로 기록했다. 상승폭으로 이전 값을 역산하지 않았다. Ámbito 후보에는 구독 전용 안내가 있어 대체 본문으로 사용하지 않았다.

이는 개발 중 에이전트의 범위 확인이다. 새 기사 네 건은 자동 원문 대조를 통과한 카드가 아니며 이번 집필 입력에 자동 채택하지 않았다. 수집기의 검토 대기 상태와 출처별 외부 전송/공개 미확정 상태를 유지한다. 원문을 새 모델에 전송하지 않았고 사용자에게 수동 검토를 운영 절차로 맡기지 않았다.

## 반복 가능한 공통 준비 경로

```powershell
npm run report:prepare:six -- --input .local-reports/private/six-currency-input-closeout-20261028-BwhRnh/manifest-final.json
```

이 명령은 네트워크·키·모델·DB를 사용하지 않는다. 여섯 통화를 누락/중복 없이 검사하고, 국가 하나가 실패해도 나머지를 계속한다. 출력은 매번 새 비공개 폴더에 저장한다.

1. 최신 검토 입력은 기존 가격·인과·집필 검사에서 다시 확인한다. 저장된 점수·평가·이미 사용한 승인·실행 계획은 승계하지 않는다.
2. 나머지 국가는 기존 자료 준비·출처 표시·가격 연결 검사를 그대로 실행한다. 지원 통화 목록을 늘리는 것만으로 통과시키지 않는다.
3. 수집 결과와 저장된 검토 기록을 별도 재생한다. 접근 실패·다른 날짜·검토자 부재를 집필 가능 또는 ‘뉴스 없음’으로 바꾸지 않는다.
4. 원문 수집 상태, 저장 사례 집필 가능 여부, 영업 배경, 실제 품질, 게시 승인을 서로 구분한다. 요청 준비 상태도 실제 제공 경로의 가용성이나 호출 승인이 아니다.

## 다음 순서

현재는 원래 계획의 **국가별 자료 준비·공통 집필 연결 단계**다. 다음 순서를 유지한다.

1. **COP·ARS 가격/거래일 계약 마감 — Sol High.** COP는 TRM 적용일과 실제 거래·기사 종가를 분리하고, ARS는 새 도매 가격 후보를 엄격한 공통 검사에 연결한다. 기존 공식 환율을 기사 가격으로 대체하지 않는다.
2. **PEN 직접 설명과 BRL 소비 배경 보완 — Astra High 검토, Sol High 연결.** PEN 일반론을 원인으로 채우지 않고, BRL 통계는 실제 이용 범위·대상 월을 확인한 것만 연결한다. 막히면 구체적인 보류를 남긴다.
3. **자동 근거 대조의 이용 범위와 실행 경계 마감.** 저장 카드 재생과 새 원문 자동 검토를 구분한다. 실제 유료 시험은 별도 예산 승인 전 실행하지 않는다.
4. 여섯 통화 입력이 준비된 뒤 품질 시험 → 승인·공개·장애 흐름 → UI 2.0/메뉴 단순화 → 파일럿/출시·복구 순서로 진행한다. 출시 범위를 자동 축소하거나 운영에 반영하지 않는다.

대시보드 환율 API의 한국 오전 종가·현지 거래일 정합성 점검은 별도 후속 과제다. 이번 리포트 전용 가격 정리로 기존 대시보드 가격을 변경하지 않았다.
