# UI 검토 전 1·2단계 — 발행 정책과 화면 상태 확정

2026-10-30 · 저장 자료만 재생 · 정책 재확인/문서 정리 · 운영 미적용

## 결론과 기록 정정

**PEN·ARS도 기존 네 통화와 동일하게 누적 절대 2%와 유효 환율 점검본 발행 후 14일이 지난 첫 한국 월요일에 조사한다.** 임계값 도달은 집필·게시 승인이 아니다. 큰 변화가 없어도 정기 점검은 수행하지만, 자료 확인과 독자 가치가 없으면 새 원고를 강제로 만들지 않는다.

이는 새 국가별 예외를 추가하는 결정이 아니다. 10월 29일 [주기 설계의 최신 확정 기록](publication-cadence-design-20261027.md)과 `shared-price-contract.js`의 `six-currency-cadence/2`에 이미 여섯 통화가 같은 기준으로 연결되어 있었다. 10월 30일 설계도·운영 전환 인계와 최근 답변의 ‘PEN·ARS 미결정’ 표시는 오래된 정보를 다시 인용한 오류다. 이번에는 기존 정책을 저장 자료로 재확인하고 인계 표시를 바로잡는다. 과거 비교 결과·원고·승인 이력은 수정하지 않는다.

두 번째 결과물은 [독자·관리자 상태와 행동표](report-state-actions-20261030.md)다. 이 표는 UI2.0 설계의 공통 계약이며, 아직 없는 화면/운영 연결을 구현 완료로 표시하지 않는다.

## 1. PEN·ARS 재생 결과

입력은 `data/fx-full-history.json`의 저장 숫자다. 보간·잘못된 값·주말·충돌 날짜를 제외했다. 마지막 유효 관측은 **2026-09-11**이다. 오늘 시장, 실제 과거 발행 이력, 실제 현지 휴일 검증으로 읽지 않는다. 선택한 두 통화의 `.local-reports/reviewable` 원고는 0건이며 운영 DB를 조회하지 않았다.

모든 조사 후보가 곧바로 근거·예산·검토·공개 승인을 얻는다는 가정으로 계산했다. 따라서 아래는 **가상 발행 횟수**이며 실제 발행량·비용 예측 또는 상한이 아니다. 급변/정책 사건의 추가 경로는 횟수에 포함하지 않았다.

| 저장 구간 | 통화 | 누적 2%+정기 점검 | 누적만 | 정기만 | 동시 충족 | 3%일 때 | 4%일 때 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 최근 252관측 | PEN | 24 | 2 | 22 | 0 | 24 | 24 |
| 최근 252관측 | ARS | 36 | 23 | 13 | 0 | 27 | 27 |
| 최근 756관측 | PEN | 77 | 7 | 66 | 4 | 76 | 76 |
| 최근 756관측 | ARS | 99 | 46 | 52 | 1 | 88 | 83 |

252관측 구간은 PEN 2025-09-16~2026-09-11, ARS 2025-09-12~2026-09-11이다. 756관측은 각각 2023-09-20, 2023-09-19부터 시작한다. 공급자·실제 관측시각은 최근 756개 모두 미기록이다. `API` 태그를 특정 공급자나 공식 시장 가격의 인증으로 취급하지 않았다.

- **PEN:** 최근 구간의 정기 계기가 22/24건이다. 기준을 3~4%로 올려도 총 횟수는 같지만 2%는 일부 움직임을 앞서 포착한다. 2%를 유지하고, 조용한 시기에는 짧은 점검본을 검토하는 편이 일관적이다.
- **ARS:** 2%가 3%보다 최근 구간에서 가상 발행 9건 많다. 평균 간격 약 9.8일, 최소 1일이다. 후보가 많다고 임계값부터 높이지 않는다. 동일 사건·기존 설명·진행 중 조사를 합쳐 새 설명이 있는 경우만 집필한다. 새 중대 사건은 횟수 제한으로 숨기지 않는다.
- **검토 지연의 영향:** 추가 3개 관측 후 재확인·승인하는 가정에서는 PEN 24→17건, ARS 36→21건이다. 이것은 ‘3일 강제 대기’ 정책 제안이 아니다. 자료와 검토 소요시간에 따라 횟수가 달라짐을 확인한 민감도 분석이다.

### 누락·중복을 어디까지 확인했는가

| 질문 | 확인한 결과 | 남은 한계 |
| --- | --- | --- |
| 작은 변화가 쌓이면 잡히는가 | 현행 계약 검사에서 +0.3% 복리 6회는 2% 미만, 7회는 초과로 구분. 반대 방향과 반올림 직전 값도 구분 | 실제 사건의 중요성 판단은 별도 |
| 2%에 못 미치면 영원히 보고서가 없는가 | 저장 PEN 약 -0.95%, ARS 약 +0.60%와 가상의 전회 발행/달력을 연결했을 때 둘 다 정기 조사 반환 | 가상 시각·달력이며 실제 승인 이력 아님 |
| 같은 입력을 다시 돌리면 중복되는가 | 위 두 통화의 반복 실행 모두 `duplicate_check`, 조사 허용 false. 현행 계약에서 누적·정기·사건 이유를 한 조사 건으로 병합 | 서로 다른 기사에 담긴 같은 의미의 중복은 내용 검토 필요 |
| 승인 대기·실패가 기준점을 바꾸는가 | 현행 검사에서 바꾸지 않음. 철회 후 이전 유효 기준점 사용 | 실제 운영 이력/공유 조사 장부 연결은 남음 |
| 큰 왕복 움직임·정책 사건을 놓치지 않는가 | 순누적 변화만으로는 놓칠 수 있음을 확인. 독립 사건 조사 경로가 있음 | 과거 사건 정답 집합 없음. 기존 단기 변동 재생기는 PEN/ARS를 지원하지 않아 그 두 통화의 단기 누락률은 **미검증** |
| 휴일과 자료 실패를 구분하는가 | 기대 자료일 미확인/불일치·보간·수정본은 대기. 확인된 기대일이면 월요일에 직전 정상 자료 사용 가능 | 실제 국가·공급자 공표 달력 미연결. 이번 평일 가정의 지연을 실제 장애로 세지 않음 |

‘누락 0’이나 ‘2% 최적’을 입증한 결과는 아니다. 동일 기준으로 시작하기에 모순이 없고, ARS의 과잉 집필 위험과 PEN의 정기 점검 의존도를 확인한 결과다.

## 2. ARS 기준환율을 다루는 고정 원칙

이번 재생은 **대시보드와 같은 저장 기준환율**을 사용했다. 회사 환율과의 동일성은 기존 사용자 승인 작업 가정이며 확인 대기다. 저장 과거 값이 BCRA 공식 도매 기준환율, 은행 소매, MEP·CCL·blue 중 어느 계열과 같은지 이번 기록만으로 인증할 수 없다.

[기존 공식 자료 검토](six-currency-readiness-20261027.md)의 ARS 절은 도매 기준과 별도 금융·비공식 시장을 구분하고, BCRA A8359의 2026-01-02 산식 변경을 기록했다. 이는 저장된 **공식 출처 조사 결과**의 재사용이며 이번에 최신 제도·약관을 재조회한 것이 아니다. 공식 시리즈의 변경을 앱의 저장 시리즈에 그대로 적용하거나 과거 전체를 한 공식 계열로 인증하지 않는다.

| 경우 | 공통 정책 적용 |
| --- | --- |
| 같은 저장 기준환율의 비교 가능한 두 값 | 누적 2% 판정. `1 USD당 ARS` 상승은 ARS 약세 방향 |
| 동일 가격의 공급자·산식·시리즈 변경이 확인됨 | 연결 가능한지 검토. 불연속을 시장 변동으로 집필하지 않음 |
| 기준환율은 조용하지만 별도 시장·정책에 중요한 변화 | 독립 사건 후보로 조사. 다른 시장 가격으로 기준값·기준점을 교체하지 않음 |
| 기사에 MEP/CCL/blue 또는 장중/종가가 나옴 | 이름·시점·시장·출처를 붙인 보조 설명에만 사용 |
| 참고 가격 자체는 있으나 원인 근거가 없음 | 가격 사실 유지, 배경 확인 대기. 소비 통계를 당일 환율 원인으로 대신 사용하지 않음 |
| 자료 도착·현지 휴일을 확인할 수 없음 | 0%/변화 없음으로 처리하지 않음. 가격 점검 대기, 무관한 정책 자료 검토는 가능 |

## 3. 여섯 통화에 적용할 한 벌의 정책

1. 마지막 **유효한 시장/정기 점검 공개본**의 고정 가격과 최신 비교 가능한 저장 기준환율 사이 절대 변화율이 2% 이상이면 조사한다. 반올림 전 값으로 판정한다.
2. 유효 발행의 한국 날짜에 14일을 더한 후 첫 월요일에 점검한다. 최초 예정일까지 14~20일이다. 월요일 실행/자료 확보 실패는 다음 확인 때 같은 대기 건으로 이어간다.
3. 누적·정기·중요 사건·정정 계기를 병합하고, 기존 설명의 새 사실·변화 여부를 검토한다. 원인별 기여도를 추정하거나 날짜만 바꿔 반복 집필하지 않는다.
4. 공개 저장에 성공한 현재 환율 점검본만 가격/정기 기준점을 갱신한다. 실패·반려·검토 대기·과거 사례·문체 편집·정책만 다룬 글은 갱신하지 않는다.
5. 정정은 오류 원고를 우선 처리하되 주기를 다시 시작하는 수단으로 쓰지 않는다. 철회본은 제외하고 이전 유효 기준점으로 돌아간다.
6. 정상 점검·설명 변화·일부 근거 부족은 기존 정기 집필 계약으로 구분한다. 조회 실패는 정상 점검이 아니며, 핵심 확인 자체가 안 되면 발행을 보류한다.

정책 버전 `six-currency-cadence/2`, 판정 버전 `publication-cadence/2`를 유지한다. 코드의 새 임계값·국가별 예외·스케줄 변경은 없다.

## 4. 이번 검증과 재현

- 재생 명령: `node scripts/currency-report/replay-publication-cadence-local.mjs --pen-ars-study`
- 이번 결과: `.local-reports/private/cadence-replay-20261027-TEny80/result.json`.
- 현행 두 통화 계약 재생·해시 기록: `.local-reports/private/pre-ui-policy-20261030/audit.mjs`, `result.json`, `protected-hashes.json`. 보고용 요약은 [JSON](pre-ui-policy-review-20261030.json).
- 기존 3개 검사 파일, **19개 사례 통과**: `publication-cadence.test.ts`, `provider.test.ts`, `currencyReportAccess.test.ts`. 최초 실행은 임시 파일 rename 권한 오류로 테스트 시작 전 중단됐고, 임시 경로를 작업 폴더로 옮겨 재실행했다.
- 과거 연구용 규격 모델의 12개 합성 검사는 재통과했지만 3% 사례가 포함된다. 이를 전부 현행 2% 검증이나 실제 품질 표본으로 합산하지 않는다.
- 보호 615개 파일의 해시 동일: 앱·스크립트·환율·공개 파일·워크플로·DB migration·원고·패키지 설정. 제품 코드 변경 없음. 이번에는 전체 빌드·브라우저·실제 DB 권한 검증을 재실행하지 않았다.
- 신규 자료/API 수집·유료 모델 호출 0, 신규 비용 $0. 문서와 FigJam의 과거 미결정 표시만 정정한다.

## 5. 다음 고정 단계

요청한 **1·2단계 검토는 마감**한다. PEN/ARS 임계값을 다시 미결정으로 열지 않는다.

다음은 **기존 앱 주요 흐름 로컬 확인 — Sol High**다. [상태·행동표](report-state-actions-20261030.md)의 실제 구현/남은 항목을 기준으로 숫자 카드→목록/상세→근거/이력, 승인→공개, 로그아웃·철회·장애 화면을 확인한다. 그 결과를 들고 UI2.0 메뉴·동선 검토로 넘어간다. 국가별 원고 품질·실제 달력/이력·운영 저장/배포/파일럿은 별도 출시 조건으로 유지하며 이 두 단계에 다시 끼워 넣지 않는다.
