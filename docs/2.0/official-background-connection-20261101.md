# 공식 통계의 자동 검사와 집필 연결 — 2026-11-01

> **현재 상태 갱신 — 2026-11-01:** 아래는 당시 기록이다. 이후 6통화 공식 자료 입력·서비스 전용 원자료 캐시·공개 고지의 로컬 연결과 검증을 마쳤다. [1~3단계 마감과 남은 제한](report-operations-stage123-20261101.md)을 우선 확인한다. 실제 내용 검토·유료 생성·운영 전환은 별도다.

> 후속: [다른 5개국의 실제 무료 조회·공통 집필 입력 연결 결과](official-five-country-connection-20261101.md). 아래는 MXN을 먼저 연결했던 시점의 보존 기록이다. 현재 다섯 지표의 연결은 완료했으며 PEN 신규 조회 차단 등 남은 조건은 후속 문서를 기준으로 본다.

## 결과와 범위

사용자가 선택한 후속 1번을 로컬 구현했다. 새 모델 호출·새 공개 리포트·운영 변경은 없다. 기존 통계 수집기와 INEGI 지표 정의, 10월28일 기록된 수치 이용 검토를 재사용했다. 기사 원문 검사나 관리자 승인을 이 자동 검사로 대체하지 않는다.

공통 경로는 연결했으며 **실제 저장 원자료로 수치 채택과 집필 입력을 확인한 것은 MXN**이다. 다른 5개국의 공식 통계 자동 채택까지 완료했다고 표시하지 않는다. 이 미완료는 기존 기사·검토 카드 경로까지 사용할 수 없다는 뜻은 아니다.

`공식 출처 선택 → 기존 수집기 → 등록 지표 정의 대조 → 실제 대상 월·유한한 수치 → 발표 자료·판본 확인 → 수치 이용 조건 확인 → 중복/최신 검증 월 선택 → 소비 배경 카드 → 공통 집필 → 별도 문장 검토 → 관리자 승인`

## 공통 규칙

| 항목 | 자동 처리 | 자동으로 보장하지 않는 것 |
|---|---|---|
| 정의 | 계열 ID, 정의 버전, 단위, 비교, 명목/실질, 계절조정, 기준년, 지역·채널 대조 | 익숙한 지표 이름만 보고 같은 계열로 승인 |
| 대상 기간 | 요청한 월에 정확히 한 개의 유한 값. 기존 4개월 조사 범위에서 최신 검증 월 선별 | 수집일을 지표 대상 월로 대체, 결측을 0으로 처리 |
| 발표 | 등록 제품 PDF의 표제·발표일·대상 월을 해시로 고정한 추출과 대조. 기존 시점 검사 재사용 | API LASTUPDATE를 발표일로 사용, 시각 미상을 자정으로 인증 |
| 판본 | 같은 제품·월의 서로 다른 PDF 해시, 같은 계열·월의 상충 수치는 보류 | 수정본의 우선순위 자동 추정, 현재 API 수치가 최초 발표값이라는 주장 |
| 이용 | 이미 검토한 수치·메타데이터 범위와 정확한 약관 본문 해시 대조. 새 약관·누락은 보류 | 외부 문서나 모델이 스스로 이용 권한을 승인 |
| 설명 | 코드가 만든 수치 사실과 방향 요지만 소비 배경에 연결 | 회사 판매·당일 환율 원인·통계 간 파급 효과 승인 |
| 한도 | 같은 계열/월 중복 제거. 전체 8개 근거 한도 유지. 검증 통계를 뉴스 병합 전에 연결하고 남는 칸에 기존 시장 우선순위로 기사 연결 | 한도 때문에 빠진 자료를 실제 부재로 표현하거나 필수 인과 근거를 창작 |
| 실패 | 이번 어댑터의 이전 숫자 카드를 제거하고 원래 원고/감사 기록 보존. 다른 검증 기사 경로는 계속 검사 | 최신 실패를 이전 성공으로 덮어쓰기 |

공식 자료의 숫자와 기간은 코드가 표시한다. 집필·검토 모델에는 대상 범위와 정성적 사실을 전달하며, 수치 정리 검사를 새 경제 해석의 독립 승인으로 표시하지 않는다. 같은 EMEC/INPC 발표의 여러 계열은 하나의 발표 그룹으로 표시한다.

PDF·약관·추출 증거는 비공개 동결 배치에 보존하며, 집필과 공개 요약에서는 제외한다. 기존 DB의 32MB 제한을 늘리지 않았다. 원래 JSON과 보존용 직렬화가 함께 저장되는 실제 크기를 사전 계산하고 30MB를 넘으면 원문을 자르지 않고 모델 호출 전에 `operating_payload_capacity_hold`로 중단한다. 추출용 임시 PDF는 해당 명령이 만든 파일만 정리한다.

같은 발표와 값에서 수집시각만 달라지면 새 판본으로 세지 않는다. 새 공식 발표 또는 이미 사용한 발표의 값/판본 변경은 기존의 **조사 후보** 경로로 전달한다. 조사 후보는 중요성·내용 품질·발행 승인이 아니다. 기존 2%·정기 점검 규칙은 변경하지 않았다.

## 실제 저장 자료 재생

API·PDF·약관은 기존 10월27일 캡처다. 11월1일 분석 시점에 재생했으며 새 조회 성공이나 최신 기관 자료 확보로 표시하지 않는다. PDF에서는 발표 메타데이터만 파싱하고 수치표를 문장 추출로 추측하지 않았다.

| 통화 | 이번 실제 재생 | 공식 숫자 자동 채택의 남은 조건 |
|---|---|---|
| MXN | 4개 통계 채택·집필 입력 연결 확인 | 새 응답/약관/PDF 실조회, 공개 고지 렌더링 및 최종 승인 별도 |
| BRL | 해당 범위의 저장 공식 캡처 없음 | 기존 BCB/IBGE 수집 경로의 실제 응답, 정확한 정의·발표/수정·이용 프로필 |
| COP | 저장 SFC 질의가 이번 월 전체 범위를 충족하지 않음. 소매/정책 자동 계열 미연결 | 표본·단위·집계 정의, 발표 시점, 재사용 범위. 짧은 과거 질의를 월 전체 자료로 대체하지 않음 |
| PEN | BCRP 상품·만기별 금리 JSON 재수집 없이 재생 | 발표/수정 시점·정확한 계열별 사용 범위. 국가 소비자 평균이나 정책금리로 승격하지 않음 |
| CLP | 기존 INE 소매·급여 PDF를 원래 해시로 재생 | 새 판본에 적용할 수치표 파서·범위 검사. 과거 시각 검토를 다음 PDF에 복사하지 않음 |
| ARS | 등록된 경로는 있으나 해당 자동 공식 계열 미연결 | INDEC/BCRA 정의·발표·판본·이용 프로필과 자동 파서 |

소매의 계산값은 같은 API 계열의 전년 동월 지수로 계산했다. 보도자료 앞면의 계절조정 소매 변화율과 혼합하지 않았다. 서로 다른 월의 소매와 물가를 빼서 실질 소비를 다시 계산하지 않는다. 수치는 수집 당시의 현재 계열이며 최초 발표 당시 판본은 아니다.

API의 관측 상태 원코드와 계산에 사용한 전년 관측의 상태 코드를 보존한다. 코드 의미의 추가 정의 없이 잠정/확정 판정을 만들지 않는다. 발표 PDF의 수치표와 API 현재 값이 같다고 인증한 것도 아니다.

## 코드와 재현

- `runtime-official-supply.js`: 기존 수집기 재사용, INEGI 정확한 범위 지정, 정책·급여·활동 자료도 명시적으로 조사 상태 반환.
- `official-statistic-admission.js`: 공통 자동 검사와 등록된 INEGI 제품 파서, 소비 배경 연결. 자동 무결성 검사와 의미 검토를 분리.
- `official-input-loader.js`: 서버 전용 공식 API/PDF/약관 수집. saved에서는 토큰 파일과 네트워크에 접근하지 않는다. MXN live는 최대 API3·약관1·PDF4 요청이며 재시도 없다. 고정 INEGI 주소만 사용한다.
- `official-background-local.js`: DB 없이 저장 자료 재생. 원자료 변경을 검사하며 새 비공개 디렉터리에 결과를 보존한다.
- `runtime-supply.js` / `runtime-batch.js`: 공식 검토 결과가 원래 운영 집필 경로에 실제 전달됨. 단순 상태 표시에서 끝나지 않는다.
- `shared-writer.js` / `openrouter.js` / `claim-review.js`: 수치의 코드 표시, 영업 환경 연결, 같은 기준의 별도 문장 검토. 공개 사용 대기는 유지.
- `operating-source-cache.js` / `runtime.js`: 공식 발표 그룹·수치/판본 변경을 기록해 단순 재수집과 구분.

로컬 재현:

```powershell
node scripts/currency-report/official-background-local.js --input .local-reports/private/official-background-20261101/all-saved-manifest.json
```

실제 실행 명령은 사용하지 않았다. 기존 `report:operate -- --action plan --input ...` 로컬 입력에 `officialInputsByCurrency: {"MXN": "<private JSON>"}`를 지정할 수 있다. 원문/PDF/추출은 비공개 폴더와 비공개 배치 입력에만 남고 집필에는 숫자·정의·코드 작성 요지·출처만 보낸다.

live 경로는 기존 `.env.research.local`의 `INEGI_INDICATORS_TOKEN`을 재사용한다. PDF 추출을 실행할 Python 경로는 서버의 `FX_REPORT_PDF_PYTHON`으로 지정한다. 기존 `extract-monthly-pdf.py`와 pypdf를 사용한다. 경로가 없으면 설치나 다운로드를 자동 수행하지 않고 추출 미설정을 반환한다. 이번 작업에서는 실제 외부 조회와 운영 환경변수 변경을 하지 않았다.
