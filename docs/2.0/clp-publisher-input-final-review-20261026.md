## 기사 이용 범위 확인

공식 [Emol 일반 약관](https://www.emol.com/terminos/terminosycondiciones.aspx)과 그 페이지에서 연결한 El Mercurio의 `v2023` PDF를 확인했다. HTML 제2절과 PDF 2쪽은 개인·비상업적 이용 및 재전송·가공·게시 등에 대한 사전 서면 허가 조건을 명시한다. PDF 6쪽에는 내부 기사 링크에 관한 제한도 있다. 출처 표기만으로 서비스용 권한을 확보한 것으로 볼 수 없다.

이는 약관에 AI 추론을 명시적으로 금지한 문장을 발견했다는 뜻도, 개별 이용의 법적 위법 여부를 판정했다는 뜻도 아니다. **반복적인 서비스용 수집·외부 모델 입력·공개 표시를 허용할 근거가 확보되지 않았다**는 운영 판단이다. 별도 허가·적용 가능한 라이선스·이용 근거를 확인하거나 허용 범위가 명확한 자료로 대체해야 한다. 무료로 제공하는 서비스라는 이유로 자동 허용하지 않는다.

BCCh 통계의 BDE/API 이용 범위는 별도다. 이번 기사 권리 문제로 공식 환율 데이터 사용 검토나 공통 수집·검토 구조를 폐기할 필요는 없다. 다만 현재 `reuse:not_verified`를 확인 완료로 올릴 근거는 없다.

PDF는 `.local-reports/private/emol-terms-review-kjPXoQ/terms.pdf`에 보존했고 SHA-256은 `f132e145c3e7373a061d1fffe008a7aa4a18bbf244ee97c01a88a7a4db1c577a`다. 1쪽 적용 범위, 2쪽 이용 조건, 6쪽 링크 조건, 9쪽 권리 부여 여부를 읽고 2·6쪽 렌더링도 확인했다. 웹 도구의 PDF 열기는 실패했으나 공개 공식 URL 직접 조회는 HTTP 200이었다. 새로운 기사 수집은 하지 않았다.
