# 경제 리포트의 주장 범위와 근거 카드 검토

칠레 두 저장 원고를 대조한 결과, 개선 대상은 모델 문체만이 아니다. 입력 카드의 자료 부재 단정, 지수 기여에서 가계 부담으로 넓어진 설명, 제목과 본문에 다르게 적용한 검토 기준을 함께 바로잡아야 한다. 확인한 사실은 단정적으로 쓰되, 사실이 설명하는 대상과 비교 범위를 바꾸지 않는 것이 공통 기준이다.

검토 기준은 `economic-scope-review/1`이다. 기존 R03·R04·R06·R07·R10과 `claim-review/3`을 구체화하는 **오프라인 편집 기준**이며 새로운 자동 사실 판별기가 아니다. 생성 코드는 아직 `economic-update/2`를 사용한다. 이번 결과로 과거 원고·검토·점수·비용·게시 상태를 변경하지 않는다.

## 오류와 개선을 구분하는 기준

| 구분 | 판단과 처리 | 칠레 적용 |
| --- | --- | --- |
| 근거와 모순 | 확인한 원문이 주장을 반박하면 `conflicting`, 필수 교정 | 이번 순위 표현은 여기에 해당하지 않음 |
| 채택 범위 초과 | 읽은 자료가 일부만 지지하면 `limited`, 주장 축소 또는 추가 근거 확인 | 지수 기여를 실제 가계 부담의 상대적 크기로 확대 |
| 자료 미확인 | 원문·비교표·적용 조건 자체가 없으면 `unverified`; 사실이 틀렸다고 단정하지 않음 | 전체 분류 순위 확인에 필요한 표 없음 |
| 출처 연결 결함 | 내용 지지와 별도로 참조 계약을 교정 | 임금 문단의 기간 비교에 IPC 출처도 필요 |
| 문체 개선 | 의미가 지지되고 더 쉽게 읽을 수 있으면 `supported/refine` | ‘반대 맥락’이라는 추상적 표현 |

한 문장에 확인된 수치와 미확인 순위가 함께 있으면 수치까지 틀렸다고 처리하지 않는다. 세부 주장에는 각각의 상태를 기록하고, 문장 전체의 확정 표현은 축소하거나 확인 전까지 보류한다. `limited`와 `unverified`의 구분을 통과 우회로 사용하지 않는다. 어느 쪽이든 미확인 단정을 그대로 게시할 수 없다.

## 모든 통화에 적용할 편집 판단

| 검토 대상 | 필요한 근거와 허용 범위 | 보완 방법 |
| --- | --- | --- |
| 순위·주도 | 같은 지표·기간·단위·비교 집합의 순위표, 또는 출처가 명시한 순위를 귀속해서 설명 | ‘주목한 분류’를 ‘가장 큰 분류’로 번역하지 않음. ‘주도’도 독자가 읽을 선도·우선순위 주장을 검사 |
| 변화율과 기여도 | 해당 분류 자체의 변화율과 전체 지수에 대한 기여도를 분리 | 크게 하락한 분류라도 전체 지수에 미친 영향이 가장 큰 것으로 확대하지 않음 |
| 지수와 가계 | 물가지수 구성에 대한 설명은 가능. 실제 가계 부담의 크기·분포에는 지출 구성과 소득 등 별도 근거 필요 | ‘식품·교통 가격 상승이 IPC 상승에 기여했다’는 유지. ‘가계 부담이 이 두 부문에 집중됐다’는 별도 확인 |
| 조건부 원리 | 승인된 원리·대상 기간·적용 조건을 연결하고 실제 발생과 구분 | ‘명목소득이 물가를 따라가지 못한다면 구매력에 부담’은 조건 충족 검토 후 허용. 조건부라는 말만으로 실제 판매 감소를 추정하지 않음 |
| 실질보수와 소득 | 물가 조정된 보수 지수의 대상·기간·비교 기준을 유지 | 다른 달 CPI를 다시 빼지 않음. 전 가구 소득·가처분소득·판매로 확대하지 않음. 세부 조사 모집단은 방법론 확인 전 새로 특정하지 않음 |
| 자료 부재 | 입력에 없음, 확인하지 못함, 공식 미발표, 실제 없음은 서로 다른 상태 | ‘이번 입력에 판매 자료 미포함’으로 기록. 공식 미발표는 해당 통계·기간·확인 시점에 대한 근거가 있을 때만 |
| 제목·요약 | 본문과 같은 대상·강도·시점으로 읽히는지 독립 검사 | 본문에 제한을 달았다는 이유로 확정적인 제목을 통과시키지 않음 |
| 교차 자료 | 한 문장의 각각의 주장에 출처 연결 | 임금의 정의는 임금 출처, 다른 달 물가와의 비교는 물가 출처도 연결. 출처 ID 합집합은 의미 검토를 대신하지 않음 |

금지 단어 목록을 늘리는 방식은 사용하지 않는다. ‘크게’·‘주도’·‘부담’은 단어 자체로 불합격이 아니다. 문맥에서 주장하는 크기·대상·순위가 실제 근거를 갖는지 판단한다. 정량적 경계가 필요한 비교는 코드 계산과 단위 검증을 거친다.

경제 업데이트는 **새 지표 → 지표의 구성·반대 움직임 → 소비 환경을 읽을 때의 의미**로 설명한다. 환율 원인 보고서에 필요한 **사건 → 시장 반응 경로 → 통화**를 억지로 요구하지 않는다. 공식 물가·임금 발표만으로 당일 환율 원인을 설명하지 않는다. 두 목적 모두 설명할 것이 없으면 항목을 줄이며, 근거 없는 연결이나 반복 경고로 지면을 채우지 않는다.

## 칠레 원문과 입력의 확인 범위

저장된 INE 원문 두 건과 실제 전송 카드·응답·기존 문장 검토를 읽었다. 현재 웹페이지를 새로 수집하지 않았으며 이번 검토는 보존된 자료를 기준으로 한다. 발표일은 물가 10월 8일, 임금 10월 7일이고 대상 기간은 각각 9월과 8월이다. 10월 11일 수집·생성 결과를 10월 9일 실시간 발행물로 표시하지 않는다.

| 출처 | 실제 입력 문단 | 확인 내용 | 확인되지 않은 확대 |
| --- | --- | --- | --- |
| [INE 9월 IPC](https://www.ine.gob.cl/sala-de-prensa/prensa/general/noticia/2026/10/08/%C3%ADndice-de-precios-al-consumidor-(ipc)-de-septiembre-present%C3%B3-una-variaci%C3%B3n-mensual-de-0-4) | p0–p4 | 전월 +0.4%, 전년 +4.1%. 식품 +0.6%·기여 +0.133pp, 교통 +0.9%·+0.122pp. 다른 양의 기여 합계 +0.219pp. 보험·금융 -5.9%·-0.056pp | 전체 분류 순위, 가구별 부담·소비량·판매, 예상 대비 차이 |
| [INE 8월 보수](https://www.ine.gob.cl/sala-de-prensa/prensa/general/noticia/2026/10/07/%C3%ADndices-nominales-de-remuneraciones-y-de-costos-laborales-registraron-aumentos-interanuales-de-7-6-y-8-3-en-agosto-de-2026) | p1–p3 | p2의 물가 조정 정의와 실질보수 전년 +3.4%. 대상 월은 발표 메타데이터와 원문에서 확인 | 9월 구매력 측정, 모든 가구의 소득, 실제 내구재 수요 |

IPC는 두 분류를 `destacaron`으로 강조한다. 이는 완전한 순위표가 아니다. 다른 양의 기여 합계만으로 개별 분류 순위를 복원할 수도 없다. 따라서 “가장 컸다”는 **미확인 순위**이지 반대 순위가 증명된 오류가 아니다. 순위 자료를 확보하거나 “발표가 주요 상승 분류로 짚었다”처럼 귀속한다.

물가의 음의 기여가 전체 상승을 일부 상쇄한다는 설명은 같은 지수 안의 산술적 관계이므로 유지한다. 반면 별도 월 실질보수 증가가 9월 가계 부담을 실제 상쇄했다고 설명할 수는 없다. 두 경우를 모두 ‘반대 요인’으로 뭉뚱그리지 않는다.

입력 카드에도 “실제 내구재 수요 자료는 없다”가 남아 있었다. 이는 입력 준비자의 범위 오류다. /1의 유사 단정을 모델 문제만으로 설명할 수 없다. /2가 이 문장을 반복하지 않았어도 입력 결함이 해결된 것은 아니다.

## 저장 원고 재검토

총 24개 검토 단위는 **실제 원고 두 건의 제목·요약·소제목·문장**이다. 자동 테스트 24개나 품질 표본 24건이 아니다. 기존 평가를 덮어쓰지 않는 에이전트 재검토이며 사용자 독자 평가·게시 승인은 별개다. 숫자·위치 등 기존 출력 형식 실패는 그대로 유지한다.

| 원고와 기존 claim index | 판단 | 이유와 처리 |
| --- | --- | --- |
| /1 0 | 내용 유지 | 지수 상승·하락 기여. 제목 숫자 금지는 별도 출력 계약 |
| /1 1 | 내용 유지·형식 교정 | 물가 사실 지지. 요약 수치 위치·완성형 라벨 중복은 별도 |
| /1 2 | 유지·선택적 구체화 | 별도 월 실질보수를 함께 보자는 맥락. 가계 구매력 상승을 확정하지 않음 |
| /1 3 | 유지·선택적 축약 | 물가 구성 제목, 앞 제목 반복은 문체 |
| /1 4 | 유지 | INE가 상승 기여 분류로 꼽았다는 귀속이며 ‘가장 큰 두 분류’로 순위 확정하지 않음 |
| /1 5 | 유지 | 보험·금융 하락과 혼합된 방향 |
| /1 6 | 선택적 구체화 | 별도 월 보수 증가라는 범위 유지. ‘반대 맥락’은 추상적 |
| /1 7 | 유지·형식 교정 | 실질보수 정의·증가 지지. 완성형 수치 라벨 중복 |
| /1 8 | 출처 연결 교정 | 임금 정의와 IPC 대상 월을 함께 참조해야 함 |
| /1 9 | 유지 | 같은 기간 비교라는 관찰 목적. 실제 일정 단정 없음 |
| /1 10 | 유지 | 자료가 공개되면 비교한다는 조건. 가계별 효과 측정은 아님 |
| /1 11 | 필수 범위 교정 | 입력에 없는 것을 현실의 미발표·부재로 단정 |
| /2 0 | 선택적 구체화 | 제목 ‘반대 맥락’은 의미를 풀면 좋음. 새 인과·순위 주장은 없음 |
| /2 1 | 유지 | 품목별 가격 방향과 출처 일치 |
| /2 2 | 유지·선택적 구체화 | 물가만으로 구매력 판단을 끝내지 않는 취지. 별도 월·보수 지수 범위를 본문과 함께 유지 |
| /2 3 | 범위 교정 또는 순위 확인 | ‘주도’가 선도 기여를 암시. 앞 검토의 제목 통과는 일관되지 않았음. ‘식품·교통 가격 상승’으로 좁힐 수 있음 |
| /2 4 | 수치 유지·순위 보류 | 수치는 확인. ‘가장 컸다’의 전체 순위는 미확인 |
| /2 5 | 필수 범위 교정 | 실제 생활 부담의 비교로 읽힘. ‘두 분류가 IPC 상승에 기여했다’로 대상 한정 |
| /2 6 | 유지 | 같은 지수 안의 음의 기여가 일부 상쇄한다는 산술적 관계 |
| /2 7 | 유지·선택적 구체화 | 가격 하락과 음의 기여 지지. ‘크게’만으로 오류 판정하지 않음 |
| /2 8 | 유지·선택적 압축 | 품목별 혼합 방향 지지. 두 번째 경고를 붙이지 않고 앞 문장과 합칠 수 있음 |
| /2 9 | 선택적 구체화 | ‘별도 발표에서 실질보수 증가’처럼 실제 내용을 제목으로 |
| /2 10 | 유지 | 실질보수의 해당 월·연간 증가 |
| /2 11 | 출처 연결 교정 | 기간 비교의 IPC 출처 누락. 설명 자체는 타당 |

이 재검토에서는 /2의 본문 두 곳뿐 아니라 소제목 한 곳도 좁혀야 한다. 이는 새 사실 발견이 아니라 기존 R10의 일관된 적용이다. 과거 3.4/5·3.6/5를 바꾸거나 이번 검토만으로 새 점수를 부여하지 않는다.

## 근거 카드 보완안

[카드 제안](economic-evidence-card-proposal.json)은 생성에 자동 투입되지 않는 `proposal_not_wired` 자료다. 채택 가능 사실, 비교 범위, 미확인 정보, 허용 문장, 제외할 확대, 필요한 출처를 분리한다. 원본 `dossier.json`이나 과거 입력 해시는 수정하지 않는다.

필수 검토 질문은 다음과 같다.

1. 사실의 대상·단위·기간·비교 기준은 무엇인가? 순위라면 비교 집합은 완전한가?
2. 출처 직접 진술, 코드 계산 관계, 승인된 조건부 원리 중 어느 것인가?
3. 미포함 자료를 미발표로, 지수 평균을 모든 가구로, 서로 다른 달을 같은 시점으로 넓히지 않았는가?
4. 제목부터 각 문장의 모든 주장에 필요한 출처가 연결되는가?
5. 제한을 설명에 필요한 위치에 한 번만 남기고 새 사실을 먼저 전달하는가?

허용 예시는 정답 원고가 아니라 범위의 예다. “식품·교통 가격 상승과 보험·금융 가격 하락이 함께 나타났다. 전체 상승률만으로는 드러나지 않는 품목별 차이다.”는 두 자료를 보유한 것처럼 꾸미지 않으면서 구성 차이를 설명한다. “별도 발표에서는 물가 조정 후 실질보수 지수가 증가했다”는 정의를 독자 언어로 풀어 주며, 뒤에 대상 월 차이만 짧게 남길 수 있다. 여기에 판매·마진 전망을 붙이지 않는다.
