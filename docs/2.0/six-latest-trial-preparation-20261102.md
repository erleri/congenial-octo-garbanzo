## 실제 사용 경로·제공 조건

탐색/수집은 기존 `acquireRuntimeResearch`, 공식 입력 로더와 검증 캐시, `researchFeedback`, `reuseOperatingSources`를 사용했다. 과거 보류 이유를 실제 대체 탐색의 우선순위로 전달했다. 국가별 승인 예외나 수동 사실 카드를 추가하지 않았다.
