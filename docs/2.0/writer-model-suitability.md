# 칠레와 브라질 리포트 작성 모델 비교

기존 Gemini 두 결과와 같은 근거·새 BP 하네스 입력으로 GPT-5.4와 Claude Sonnet 5.5를 비교했다. 집필 규칙·출력 구조를 바꾸지 않고 모델 적합성을 먼저 분리했다. 사용자 승인 신규 $1.11 상한에서 **네 호출을 완료했고 실제 청구 합계는 $0.358687**이다. 미확인 비용과 재시도는 없다. 기존 Gemini를 재호출하지 않았으며 두 기존 생성 비용 $0.023594625는 이번 신규 지출과 구분한다.

이번 두 사례에서는 GPT가 더 구체적인 제목·출처 명칭·대외와 현지 요인의 구분을 보여 줬다. 하지만 근거 범위를 확장한 문장이 남고 평균 4/5 내용 기준에 도달하지 않았다. Claude는 설명이 자세한 대신 주의사항과 검토 조건을 반복했고, Gemini는 저렴하지만 추상적인 표현이 많았다. **모델 교체만으로 게시 가능한 원고가 완성되지는 않았다.** 이는 모델별 사례당 한 표본과 에이전트의 잠정 판단이지 Gemini 전체의 부적합이나 GPT의 일반 우월성을 입증하는 시험은 아니다.

## 원문 범위와 편집 개선

칠레 GPT는 공급 계획이 규모보다 신호로 읽혔다는 결론과 이름이 있는 출처를 명확히 제시했다. 다만 요약에서 BeFX와 XTB를 묶어 둘 모두 매각 규모보다 다른 배경을 더 중요하게 평가한 것처럼 귀속했다. 상대 중요성을 비교한 BeFX와 공급·구리를 설명한 XTB를 분리해야 한다. 브라질 GPT는 대외 동반 흐름과 현지 기대를 구체적으로 설명했지만, 제목의 당일 기대 재평가와 동조가 약할 때 특정 국내 요인의 비중을 높이는 관찰 문장은 원문 범위를 넘는다.

칠레 Claude는 정책 신호의 귀속이 자세하지만 시각 미상, 계획·집행 구분, 같은 기관 인용의 독립성, 원자재 일반화 금지 등의 검토 조건이 본문에 반복됐다. 포지션 변화가 없거나 매각 규모가 줄 때 정책 신호 해석 전반이 약해진다는 역추론도 원문이 지지하지 않는다. 브라질 Claude는 이전 두 거래일의 선거 반응과 당일 오전 조정을 잘 구분했지만, 가격 반응을 실제 헤알 매수 반응으로 확대했다.

Claude의 두 원고는 생성 계약에도 걸렸다. 칠레의 숫자 월 표기와 “확인해야”라는 인용 관찰, 브라질의 일차 투표 표기와 다른 통화 이름 때문이다. 해당 숫자는 허위 환율이 아니고 다른 통화들은 실제 기사에서 글로벌 비교에 사용됐으며, 관찰을 인용한 문장은 구체적인 가격·매매 업무 지시가 아니다. **계약 위반과 내용 오류를 별도로 기록**했고 검사를 통과시키려고 원고를 고치거나 판정을 완화하지 않았다.

기존 Gemini 평가도 별도로 보존했다. 칠레의 직접 심리 효과 및 비거주자 미변화의 역추론은 보완 대상이다. 브라질 본문은 원문 범위의 필수 교정이 없으나 구체성이 부족하고 내부 대응표의 근거 밖 전달 경로는 별도 보완 대상이다. 모든 모델에서 소비·판매 실적의 별도 자료 부재를 허구로 채우지 않았으며, 칠레의 달러 결제 환산은 같은 코드 소유 문장이다.

## 로컬 화면과 원격 이미지

[칠레 세 모델 비교](http://127.0.0.1:4175/artifacts/writer-comparison-CLP.html)와 [브라질 세 모델 비교](http://127.0.0.1:4175/artifacts/writer-comparison-BRL.html)는 왼쪽부터 Gemini, GPT, Claude다. 실제 제목·요약·배경·영업 의미·관찰 본문을 줄이거나 교정하지 않았다. 근거 없는 항목은 빈 상태로 표시한다. 실제 내용 검토의 지적은 원고와 다른 색의 하단 영역에 구분했다.

기존 A안 URL도 유지하며 여섯 미게시 비교본을 각각 열 수 있다. 생성 계약에 걸린 원고는 격리 열람으로 명시하고 기본 최신 리포트나 발행 이력에 넣지 않았다. 비교 원고의 콘텐츠 해시는 실제 모델 출력의 코드 조립본과 같으며, 실행·청구 파일은 덮어쓰지 않았다.

`artifacts/writer-comparison-CLP.jpg`와 `artifacts/writer-comparison-BRL.jpg`는 실제 로컬 비교 페이지의 전체 화면 이미지다. 브라우저 내용은 정제된 원고·공개 수치·모델명·비용·검토 메모로 한정하며, 원문 발췌·내부 대응표·키를 포함하지 않는다. 원격 사용자는 대화에 직접 표시되는 이미지로 비교할 수 있다.

## 고정 입력과 비용 상한

칠레는 2026년 10월 5일 과거 사례, 브라질은 저장 공개 데이터의 최신 기준일인 2026년 10월 7일 사례다. 이전 비교의 새 하네스 요청에 포함된 메시지·출력 스키마·medium 추론·16,384 출력 토큰 한도를 그대로 사용한다. 실제 환율·차트·근거·승인된 원리 적용 조건도 변경하지 않는다. Gemini를 재호출하지 않는다.

| 신규 호출 | 경로 | 최대 예약 비용 |
| --- | --- | --- |
| 칠레 GPT-5.4 | Azure | $0.333805 |
| 칠레 Claude Sonnet 5.5 | Google Vertex global | $0.234276 |
| 브라질 GPT-5.4 | Azure | $0.316600 |
| 브라질 Claude Sonnet 5.5 | Google Vertex global | $0.220512 |
| 합계 | 네 번, 재시도 없음 | **$1.105193** |

공개 제공 경로 목록에서 각 모델의 ZDR·구조화 출력·추론·컨텍스트·가격을 확인했다. 실제 요청에서는 ZDR, 데이터 수집 금지, 단일 경로, 자동 백업 금지를 요구하고 실행 직전에 다시 확인한다. Azure가 지원하는 출력 한도 필드로 전송 형태만 맞춘다. 전송 형식 변경을 집필 입력 변경으로 혼동하지 않는다.

상한은 UTF-8 입력 바이트와 별도 프레이밍 여유를 사용한 보수적 토큰 한계 및 최대 출력량으로 계산한 예약값이다. 실제 비용 예상이나 확정 청구가 아니다. 이번 비용은 각 응답의 usage.cost로 확인됐다. 응답 ID와 요청별 청구도 비공개 원문 기록에 남겼다. 검색·모델 변경·재작성 호출은 추가하지 않았다.

## 품질 평가

통화별 세 원고를 임의 순서의 표본 라벨로 정리하고 모델명·비용을 제외한 검토 자료에서 먼저 원문을 대조한다. 이전 Gemini 원고는 이미 보았으므로 에이전트 평가를 완전 맹검이라고 표시하지 않는다. 사용자에게는 모델 선택 전에 원고 자체를 비교할 수 있게 한다.

원인 설명, 변화 전달, 영업 관련성, 가독성, 근거 충실도를 각각 5점으로 평가한다. 근거 밖 매도 동기·심리·기여도·전망을 추가하면 필수 교정이며, 명료성을 높이는 표현 개선은 별도로 기록한다. 근거 부족으로 항목을 생략한 결과와 근거를 읽지 못해 놓친 결과를 구분한다. 원문 하나에서 세부 질문을 나눈 것을 독립 출처가 늘었다고 평가하지 않는다.

같은 환율·기사·원리로 더 구체적이고 읽을 가치 있는 설명을 만드는지, 사람이 수정해야 할 내용이 줄어드는지와 실제 비용을 함께 본다. 한 모델·한 사례당 한 표본으로 먼저 선별하며 안정성·통화 전체 우월성·출시 적합성을 확정하지 않는다. 유력 모델의 반복 시험은 별도 예산으로 정한다.

## 실행과 보존

사전 준비 명령은 `node scripts/currency-report/model-suitability-local.js --mode prepare`다. 준비된 파일은 `.local-reports/private/model-suitability-clp-brl-v1/`에 있다. 승인 후에만 `--mode run --budget-usd 1.11`로 실행하며, 영구 실행 잠금 때문에 같은 캠페인은 재실행되지 않는다. 이미 완료한 호출을 덮어쓰거나 새 호출로 자동 보완하지 않는다.

로컬 Node만 기존 키를 읽는다. 공개 환율·정제한 근거 외 관리자 정보·메일·이력은 전송하지 않는다. 실행·원문·비용은 `.local-reports/private/model-suitability-clp-brl-trial-v1/`에 저장한다. 그 뒤 `prepare-writer-review-local.js`가 모델명을 가린 자료와 별도의 비공개 대응표를 만든다. 브라우저에서는 원문 응답이나 키를 제공하지 않는다.

준비 경로의 동일 입력 보존·예산 부족 및 입력 변경 차단·무재시도·중단 비용 보존·모델 불일치 및 과금 초과 차단·ZDR와 Azure 출력 지원 검사가 통과했다. 비교 화면의 원고 보존·문자 이스케이프·비밀값 차단도 검사했다. 타입·린트·전체 59파일 427사례·운영 빌드·리포트 빌드·브라우저 번들 경계가 통과했다. 이 회귀 사례 수는 실제 리포트 품질 표본 수가 아니다. 기존 대형 묶음 경고는 남아 있다.

모델명·비용을 제외한 여섯 원고의 검토를 `evaluations-before-unmasking.json`에 먼저 고정한 뒤 대응표를 열었다. 이전 Gemini 원고는 이미 열람했으므로 완전 맹검이라고 보고하지 않았다. 문장별 근거 판단과 내용 점수는 별도 기록이고, 기존 원고·평가·비용·사용자 승인 기록을 교체하지 않았다.

이번 승인한 네 호출은 모두 사용했다. 남은 예산을 추가 호출 권한으로 취급하지 않는다. 유력 후보는 GPT지만 지금 운영 모델로 교체하지 않으며, 다음 판단은 사용자가 실제 원고를 읽고 느끼는 가치와 교정 부담을 포함한다. 기존 무료 모델 기본값, 운영·원격·DB·메일은 변경하지 않았다.
