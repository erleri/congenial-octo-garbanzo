# LATAM FX 2.0 경제 일정과 근거 출처 검토

후속 상태: [2026-10-11 원문·적용 검토](source-applicability-review-20261011.md)에서 BRL 공식 PDF 대체 경로, CL 물가·실질보수, MX INPC 본문·표, 연준의 이전 전망 대비 신규성을 확인했다. 아래 내용은 최초 출처 조사 기록이며 후속 채택 범위와 미해결 항목은 연결 문서를 우선한다.

경제 일정은 공식 발표를 확인할 시점을 알려주고, 발표 원문은 정책·지표의 변화를 설명한다. 시장 반응의 원인은 별도의 가격 기준과 시장 근거가 필요하다. 일정·수치 API를 연결하는 것만으로 환율 원인 리포트가 완성되지는 않는다.

2026년 10월 11일 공개 문서와 제한된 읽기 전용 응답을 확인했다. 초기에는 미국 공통 요인과 BRL·CLP·MXN의 핵심 발표를 선별하는 안이 적합하다. 브라질 IBGE와 미국 자료는 인증 없이 시작할 경로가 있다. 멕시코 수치 API와 칠레 BDE API는 등록·키가 필요하며 인증 호출은 아직 시험하지 않았다. 공개 재사용 조건, 실제 시각, 자료 최신성도 출처별로 구분한다.

이 검토는 [발행 정책](publication-policy.md)의 출처 계획 단계다. 수집 기능·계정 등록·키 변경·앱 코드·운영 일정·DB·메일·배포를 변경하지 않았고 유료 AI나 검색 API를 호출하지 않았다. 출처 채택과 구현 승인은 별도다.

## 확인 상태의 의미

- **공개 응답 확인:** 이 환경에서 키 없는 공개 GET의 상태와 응답 구조를 확인했다. 연속 운영 안정성이나 데이터 정확성의 합격을 뜻하지 않는다.
- **문서와 공개 자료 확인:** 공식 안내 또는 HTML·PDF에서 경로와 조건을 확인했다. API 인증·전체 파싱·수집 자동화는 미시험이다.
- **접근 또는 조건 미확인:** 실제 조회가 제한되거나 필요한 약관·시각·자료 선택이 남아 있다. 검색 제목만으로 사용 가능 판정을 내리지 않는다.

## 브라질 일정과 수치 연결

[IBGE API 목록](https://servicodados.ibge.gov.br/api/docs)은 집계 통계뿐 아니라 [일정 API](https://servicodados.ibge.gov.br/api/docs/calendario?versao=3)와 [뉴스 API](https://servicodados.ibge.gov.br/api/docs/noticias?versao=3)를 제공한다. 일정은 날짜 범위와 조사별 조회가 가능하고, 뉴스는 제품·기간·검색어 등으로 후보를 제한할 수 있다. 상세 원문 검토는 반환 링크의 본문에서 별도로 수행해야 한다.

이번 일정 표본의 첫 항목은 2027년 일정이었고 뉴스 첫 항목은 경제지표 발표가 아닌 도서 기증 뉴스였다. 최신 항목 하나를 읽는 방식으로 오늘의 경제 사건을 판정하면 안 된다. 대상 조사·기간을 선별하고 페이지 처리·중복·수정 여부를 확인하는 계획이 필요하다.

기존 코드의 소매판매 표 8880과 변수 11708은 메타데이터로 확인했다. 분류 11046의 항목 56734는 소매 판매량이며 명목 매출 항목과 구분된다. 변수는 계절조정 전월 대비 변화율이다. 응답의 마지막 대상 기간은 2026년 7월이므로 수집일이 10월 11일이라는 이유로 최신 월의 소비 상황이라고 표시하지 않는다. 공식 발표와 대상 기간을 연결하고 뒤늦은 수정값도 별도 버전으로 기록해야 한다. [집계 API 명세](https://servicodados.ibge.gov.br/api/docs/agregados?versao=3)

BCB의 SGS 정책금리 응답에는 `data`와 `valor`가 있다. 적용 날짜와 값만으로 Copom의 발표 시각·성명 변경·예상과의 차이를 확인할 수는 없다. 기존 [수집 코드](../../scripts/currency-report/sources.js)도 이를 검토용 자료로 분류한다. [BCB 공개 데이터 포털](https://dadosabertos.bcb.gov.br/)의 라이선스 메타데이터 조회는 이번에 403으로 실패했다. 검색에 나타난 라이선스 명칭만으로 재사용을 승인하지 않는다.

IBGE 일반 웹 페이지 일부는 이번 읽기에서 오류가 났지만 공개 데이터 API는 응답했다. 웹 페이지 장애를 API 장애로 합치거나 반대로 API 응답을 모든 발표 원문 확보의 성공으로 표시하지 않는다. 브라질 API 경로는 초기 계획의 우선 후보지만 원문·시각·재사용 조건의 남은 확인을 먼저 끝낸다.

## 멕시코 등록과 발표 원문

[Banxico SIE 명세](https://www.banxico.org.mx/SieAPIRest/service/v1/)는 토큰과 TLS 1.3을 요구한다. 공식 문서의 정책금리 목표 시계열은 SF61745이며 FIX 환율은 SF43718이다. FIX를 기존 시장 환율과 같은 시각·같은 가격으로 혼용하지 않는다. 키를 얻더라도 시계열 메타데이터와 발표 원문을 함께 확인해야 한다.

[호출 한도](https://www.banxico.org.mx/SieAPIRest/service/v1/doc/limiteConsultas)는 최신값·메타데이터에 분당 80회 및 일 40,000회, 역사 자료에 5분당 200회 및 일 10,000회를 명시한다. 브라우저에서 매번 요청하는 대신 수집 결과를 보관하라는 안내도 있다. [이용 정책](https://www.banxico.org.mx/footer-es/salvedad-politicas-uso-banco-.html)은 출처와 Banco de México 주소를 표시하는 재사용을 허용한다. 이번에는 토큰을 발급하거나 인증 호출하지 않았다.

[정책 일정 PDF](https://www.banxico.org.mx/politica-monetaria/d/%7B3B4BDA5B-E7E8-E414-2066-DA0CB3F7C36F%7D.pdf)는 2026년 금리 결정 발표를 현지 13시로 명시한다. [정책 발표 목록](https://www.banxico.org.mx/publicaciones-y-prensa/anuncios-de-las-decisiones-de-politica-monetaria/anuncios-politica-monetaria-t.html)에서 실제 발표 PDF도 확인했다. 예정 시각과 실제 공개 확인 시각은 별도 필드로 유지한다.

[INEGI 일정 PDF](https://www.inegi.org.mx/contenidos/saladeprensa/doc/cal_2026.pdf)는 발표 날짜와 지표 대상 기간, 기본 공개 시각 06시를 구분한다. [지표 API](https://www.inegi.org.mx/servicios/api_indicadores.html)는 토큰·지표 ID·지역·자료원과 버전을 요구한다. 응답의 `LASTUPDATE`는 지표 업데이트 날짜이며 개별 경제 사건의 발표 시각으로 대신하지 않는다.

[INEGI 자유이용 조건](https://www.inegi.org.mx/inegi/terminos.html)은 출처·제품·가능한 경우 갱신일을 표시하고, 가공 결과를 INEGI의 공식 분석이나 후원으로 보이지 않게 하는 조건을 포함한다. 복사 시 메타데이터를 유지한다. 지표 토큰을 얻기 전에도 일정과 공개 보도자료 검토를 계획할 수 있으므로 지금 사용자에게 키 등록을 요구할 단계는 아니다.

## 칠레의 웹 약관과 API 약관 구분

[칠레 중앙은행 일반 웹 약관](https://www.bcentral.cl/es/web/banco-central/condiciones-de-uso)은 개인·조직 내부 이용과 공개 유통의 조건을 다르게 규정한다. 반면 [BDE/API 별도 약관](https://si3.bcentral.cl/estadisticas/Principal1/Web_Services/terminos_condiciones.html)은 출처와 가공 책임을 표시하는 통계의 공개·변형을 허용하고 정보 사용 권한을 무상으로 명시한다. BDE 허용을 일반 웹의 모든 성명·문서에 자동 확대하지 않는다. 공개 보고서에서 사용할 자료별 약관 적용 범위는 출시 전 확인 대상이다.

[현재 API 접근 안내](https://si3.bcentral.cl/estadisticas/Principal1/Web_Services/acceso_api.html)는 계정·API 최초 활성화·개인 토큰을 요구하고 토큰 유효기간을 1년으로 안내한다. REST는 토큰 방식이 권장되며 예전 SOAP의 계정·비밀번호 방식은 신규 설계의 기본으로 삼지 않는다. 약관은 활성 계정당 초당 최대 5개 시계열 조회를 규정한다. 토큰 발급과 약관 동의는 사용자의 계정 행동이며 이번 조사에서 수행하지 않았다.

[정책 일정](https://www.bcentral.cl/es/web/banco-central/noticias-y-publicaciones/prensa/calendario-de-politica-monetaria-y-financiera)과 [통계 일정](https://www.bcentral.cl/es/calendario-estadistico)은 날짜·대상 기간을 확인할 시작점이다. 날짜만 있는 항목의 발표 시간을 추정해 채우지 않는다.

[INE Chile 일정](https://www.ine.gob.cl/inicio/agendaestadistica)에서 연결한 PDF는 본문상 2026년 일정이며 4월 10일 수정 표기가 있다. IPC는 08시, 상업활동 IAC와 고용 등은 09시로 구분된다. 링크 파일명이 매년 같으므로 검색에 남은 이전 연도 제목 대신 파일 본문의 연도와 수정일을 확인한다. [IPC 페이지](https://www.ine.gob.cl/estadisticas-por-tema/precios-e-inflacion/indice-de-precios-al-consumidor)와 [월간 상업활동 페이지](https://www.ine.gob.cl/estadisticas-por-tema/comercio-y-servicios/actividad-mensual-del-comercio)에는 실제 보도자료와 통계 파일 연결이 있다. 이번에는 모든 표 파일을 추출하지 않았다.

[INE Chile 라이선스](https://www.ine.gob.cl/terminos-de-uso-y-licencia-de-datos-abiertos)는 CC BY-SA 4.0을 명시한다. 출처·라이선스 링크·변경 표시와 동일조건 변경허락의 적용 범위를 공개 표·보고서 설계에서 확인해야 한다. 이는 앱 코드 전체의 라이선스를 자동 변경한다는 판단이 아니다. 미시자료의 재식별은 하지 않으며 초기 범위는 공개 집계 통계로 제한한다.

## 미국 공통 요인

[FOMC 일정](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)은 회의·성명·의사록을 구분하고 [연준 RSS 목록](https://www.federalreserve.gov/feeds/feeds.htm)은 정책 발표 탐지 경로를 제공한다. 정책 RSS에서 실제 XML과 발행 시각 필드를 확인했다. RSS 항목을 바로 승인된 본문 근거로 사용하지 않고 공식 원문과 연결한다. [연준 이용 안내](https://www.federalreserve.gov/disclaimer.htm)는 별도 표시가 없는 자료의 공개 이용과 출처 표기를 안내하며 외부 자료·로고 등을 예외로 둔다.

[BLS 일정](https://www.bls.gov/schedule/news_release/)은 시각을 미국 동부시간으로 명시하고 공식 ICS 구독 경로를 제공한다. CPI·고용 발표와 대상 월이 연결되며 일정이 수정될 수 있다. [BLS API 안내](https://www.bls.gov/developers/api_FAQs.htm)는 미등록 v1의 일 25회와 등록 v2의 일 500회를 구분한다. v2 등록은 키가 필요하고 매년 갱신해야 한다. 이번에 API 키 없이 쓸 수 있는 경로가 문서로 확인됐다는 의미이지 수치 응답을 실제 시험한 것은 아니다.

[BLS 저작권 안내](https://www.bls.gov/bls/linksite.htm)는 사진·그림의 일부 예외를 제외한 공개 자료의 재사용과 출처 표기를 안내한다. 미국 자료는 금리·물가·고용의 공통 배경에 사용하며 국가별 통화 반응이나 내구재 수요를 자동으로 설명하지 않는다.

## 기존 뉴스와 환율 공급자의 경계

Investing.com은 [공식 위젯](https://www.investing.com/webmaster-tools/economic-calendar)과 [일반 데이터 이용 조건](https://www.investing.com/about-us/terms-and-conditions)을 구분한다. 위젯을 표시할 수 있다는 사실은 내부 저장·AI 입력·예상치 재사용 권한을 뜻하지 않는다. 초기 계획은 별도 데이터 계약 없이 공식 일정 중심으로 두고 컨센서스는 선택 항목으로 유지한다.

[Alpha Vantage 현재 문서](https://www.alphavantage.co/documentation/#news-sentiment)는 NEWS_SENTIMENT를 프리미엄으로 표시한다. 기존 키의 계정 권한·예외·실제 이용 가능성은 이번에 확인하지 않았으므로 기존 운영의 장애나 구독 필요를 확정하지 않는다. 뉴스 발견의 보조 후보로 두되 무료 이용을 필수 경로로 가정하지 않고 자동 구독하지 않는다. 기사 발견과 원문 확보·재사용 권리는 별개다.

기존 [환율 코드](../../src/lib/api.ts)는 여러 공급자와 폴백을 사용한다. ExchangeRate-API의 갱신 시각을 날짜로 바꾸고 Alpha Vantage 일별 자료의 날짜와 close를 반환하는 경로가 있으며, 리포트에 실제 관측시각과 공급자별 가격 기준을 완전히 전달하지 않는다. [ExchangeRate-API 명세](https://www.exchangerate-api.com/docs/pair-conversion-requests)의 `time_last_update_utc`는 공급 자료 갱신 시각이다. 이를 거래소의 체결·종가 시각으로 승격하지 않는다.

공식 FIX·중앙은행 기준 환율·시장 일별 close·다중 공급자 환산값은 동일한 관측이 아니다. 원인 설명에 쓸 가격의 시각·시장·단위·확정 여부를 먼저 선택해야 한다. 기존 운영 계산은 바꾸지 않고 리포트용 비교 기준과 표시 메타데이터를 별도로 계획한다. DXY·구리·유가 등은 별도 공급자·계약·시각을 확보하기 전 필수 수치 입력으로 확정하지 않는다.

## 시간과 최신성의 설계 조건

일정의 예정 시각, 기관의 실제 공개 확인 시각, 원문의 최초 발행·수정 시각, 지표 대상 기간, API 갱신 시각과 환율 관측 시각을 따로 둔다. API 날짜 문자열에 시간대가 없으면 기관 문서 또는 공식 화면과 대조할 때까지 시점 미확인 상태다.

현지 시간 변환은 날짜별 시간대 규칙을 적용하는 계획으로 두고 국가별 고정 UTC 차이를 외우게 하지 않는다. BLS의 Eastern Time과 현지 기관의 공개 시각을 한국시간으로 표시하더라도 원래 시간대와 대상 날짜를 보존한다. 기관 홈의 수정 시각을 개별 발표 시각으로 복사하지 않는다.

일정은 발표 예정일에 가까워지면 다시 확인하고, 발표된 자료는 대상 기간·원문·수치·수정 여부가 맞아야 확보 완료다. 빈 응답·403·오래된 대상 월·정적 본문 부재를 변화 없음으로 처리하지 않는다. 현재 접근 가능성 시험은 일주일 이상 연속 수집의 안정성 시험을 대신하지 않는다.

## 계획에서 먼저 결정할 항목

1. **필수 지표 범위:** 각국 금리 결정·물가·소매판매와 미국 FOMC·CPI·고용을 우선 후보로 한다. 신용·실질소득·원자재는 출처가 준비된 뒤 추가한다. 개별 회사 실적은 제외한다.
2. **가격 비교 기준:** 기존 대시보드 값은 유지하되 리포트의 관측 기준을 명시한다. 시점이 맞지 않으면 발표 내용만 다루고 환율 반응은 보류한다.
3. **출처 채택 조건:** 인증·라이선스·시각·수정 처리와 실제 응답을 확인한 경로부터 채택한다. 브라질 API와 미국 공개 자료는 우선 검토 후보이며 미확인 조건을 면제하지 않는다.
4. **확인 시각과 예산:** 자료 도착을 조사해 하루 한 번 확인 시각을 정한다. 새 호출 예산은 여전히 미승인이다. 무료 공개 조회의 가능성과 검색·집필·검토·운영 비용을 구분한다.

다음은 이 후보 중 최소 범위를 선택하고 통화별 발행·보류 기준과 가격 시점을 결정하는 계획 단계다. 필요한 토큰 발급은 경로 채택 후 사용자가 직접 진행하며 키는 채팅·브라우저·AI 입력·로그에 전달하지 않는다. 현재 로컬 설정 파서는 새 기관 키를 허용하지 않으므로 키를 먼저 기존 파일에 넣으라고 안내하지 않는다. 토큰이 URL에 들어가는 API는 Node 측에서만 호출하고 요청 주소 로그를 가리는 별도 설계를 준비한다.

## 비용과 미완료 항목

이번 조회의 신규 유료 AI·유료 검색·데이터 구독 비용은 0이다. BDE의 무상 사용 조건과 그 외 공개 접근 가능성은 확인했지만, 모든 API·시장 데이터의 앞으로의 이용 비용이 0이라고 보장하지 않는다. Banxico·INEGI 토큰 발급 조건 및 BCB·IBGE의 선택 자료 재사용 조건은 추가 확인 대상이다.

미완료는 인증 API 호출, 실제 통계 표의 전체 추출, 출처별 시각·발표 버전 연결, 가격 관측 메타데이터, 지속 수집 안정성, 소비 지표의 통화별 범위, 공개 산출물의 라이선스 표시다. 이 상태에서 수집 자동화·실제 보고서 품질·운영 준비 완료를 선언하지 않는다.
