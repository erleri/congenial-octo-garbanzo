# UI 2.0 · 현재 구성의 세 가지 스타일 비교

2026-10-31 KST · 비교본 준비 / 실제 앱 스타일 미채택

## 열기와 비교 방법

http://127.0.0.1:4176/artifacts/ui2-style-comparison/index.html?theme=navy&view=dashboard&mode=compare&device=desktop

‘대시보드/리포트 본문’, ‘크게 보기/세 안 나란히’, ‘PC/모바일390’, ‘현재 스타일 보기’를 제공한다. 세 안의 크게 보기 버튼이나 위 스타일 카드를 누르면 해당 안을 크게 볼 수 있다. 큰 화면에서는 스타일만 바꿔 같은 앱의 색 차이를 비교한다. 선택 상태는 비교 주소에만 저장하며 현재 앱의 설정에 저장하지 않는다.

1. 웜 그레이·네이비: 따뜻한 회색 배경, 흰 카드, 깊은 네이비의 공통 UI. 리포트는 따뜻한 종이색 유지.
2. 아이보리·딥그린: 옅은 아이보리 배경과 종이색 카드, 짙은 녹색 UI.
3. 라이트 그레이·차콜: 중성 회색 배경과 흰 카드, 차콜 UI.

## 구성 보존 방식

실제4176앱을 iframe에서 불러온 뒤 비교 영역 안에만 스타일을 덧입힌다. 새 축약 대시보드나 가상 원고를 만들지 않았다. PC iframe은 모든 안에서1280px, 모바일은390px로 고정하고 부모 영역에 맞춰 전체를 축소한다. 나란히 보기의 글자가 작으면 크게 보기로 확인한다.

기존 카드/섹션 순서, 개수, 폭/높이, 간격, 글꼴 크기/행간, 수치·문장·차트 경로를 유지한다. 배경·일반 글자색·강조색·테두리색·모서리·그림자·반투명 효과만 바꾼다. 상승/하락 색과 통화별 차트 색은 보존했다. 원본의 USD/KRW MoM 중립색도 별도로 보존했다.

환율은 현재 로컬 앱에 저장된9월12일 자료, 리포트는 기존 승인된10월9일 칠레 과거 사례다. 새로운 환율이나 AI 원고를 생성하지 않는다. ‘과거 사례’ 표시도 유지한다.

비교 영역의 데이터 갱신·관리자 진입은 차단하고 안내한다. 실제 작업은 ‘현재 앱 열기’에서 이용한다. 공개 화면 조회와 스크롤·본문 열람을 위한 비교이며 운영 권한 경로를 새로 만들지 않는다.

## 검증

| 대상 | 현재 스타일 대비 세 안 모두 확인 |
|---|---|
| PC 대시보드 |6통화 카드·2차트 섹션, 전체 본문/숫자, 주요 요소 좌표·폭·높이, 차트 경로/색, 상승·하락 색 동일 |
| PC 리포트 | 원고·자료·과거 표시, 본문/영업 환경/관찰 변수 등의 좌표·폭·높이, 차트 경로/색 동일 |
| 모바일 대시보드 |390px viewport 안375px 실제 내용 폭, scroll375px,6카드, 본문과 배치 동일 |
| 모바일 리포트 |375px 내용 폭=가로 스크롤 폭, 본문과 주요 요소 배치 동일 |
| 현재 앱 | HTML에 비교 theme 속성 없음. 앱·원고 화면·스타일·설정·package/lock 등13파일 해시 동일 |
| 읽기 경계 | 비교 안 데이터 갱신/관리자 클릭이 실행 대신 안내로 끝나는 것 확인 |
| 비교 컨트롤 | 스타일 전환, 원본 복귀, 나란히/크게 보기, 화면 전환·모바일 동작 확인 |

세 팔레트의 일반/보조/옅은 글자와 공통 배경 간 대비를 계산했다. 최저값은1안4.66:1,2안4.61:1,3안4.68:1이다. 이는 새 팔레트의 세 텍스트 토큰 확인이며 전체 앱/기존 상태 배지의 접근성 인증은 아니다. 기존 의미색과 차트 색은 변경하지 않았다.

JS 구문 검사와 공백 검사를 수행했다. 앱 소스·산식·데이터는 변경하지 않아 새 단위 테스트나 DB 시험을 추가하지 않았다. 실제 화면 비교 결과는 `.local-reports/private/style-comparison-20261031/browser-verification.json`에 저장했다. 새 모델 호출·비용·운영 변경0.
