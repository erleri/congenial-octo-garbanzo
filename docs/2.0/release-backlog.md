2026-10-05 설명 근거 보강: 세 원문에서 사건·기대 차이·전달 경로·통화/소비 연결을 나눠 선택적으로 입력하는 카드와 검증을 추가했다. Codex 편집 기준 예시를 A안과 비교 패널에 연결했으나 새 API 생성물은 아니다. 추가 생성 비용0, 기존 AI 원고·기본 선택·운영은 유지한다. 전체231개 테스트 통과. 사용자 내용 검토와 보강 입력으로 실제 AI를 생성하는 시험은 남아 있다.

1. 사용자 선택에 따라 A안으로 진행한다. 내용 방향은 긍정적으로 검토됐지만, 급변일의 촉발 요인이 첫 화면에서 읽히는지 추가 검증한다. 단일 정책 발표만으로 작성한 두 시안은 실제 AI/발행 품질의 승인으로 간주하지 않는다. 상세 기준은 design-handoff.md의 급변일 읽기 흐름을 따른다.
2. 로컬 키 설정은 확인했다. 채팅·브라우저·Figma/Canva에 키를 전달하지 않는다.
3. 공개자료 전용 로컬 보관 허용은 사용자 승인 예외다. 기본 strict/무료 모델/내용 검증은 유지한다. BRL 응답 형식 실패 원인 진단과 재시험 예산을 정한 뒤 생성·문장별 근거 검토를 진행한다. 실패를 공개 리포트로 대체하지 않는다.
4. 발행 게이트의 상세 기준은 `evidence-quality.md`에 기록했다. 다음은 10개 후보 중 최근·급변 사례부터 당시 공개 근거를 확보하고, 이후 로컬 DB를 구현한다. 사용자 승인 없이 생산 DB나 기존 정기 작업으로 시험하지 않는다.

남은 npm audit 항목은 8건(low1/moderate2/high5). 이번 변경에서 강제 버전 업그레이드는 하지 않았다. 기존 의존성 보강 백로그와 별도로 관리하며 모든 취약점이 해결됐다고 보고하지 않는다.

## 출시/복구 경계

2026-10-05 테스트 재설계: [테스트 설계와 검증 책임](test-design.md)에 파일별 담당 기능과 단위/연결/고정 사례/실제 통합의 경계를 정리했다. 실패 원인 혼합·이전 스키마에서 먼저 거부되던 가짜 통과·자기 비교를 수정하고, 중복 감사와 미대체 fetch 차단을 기본 테스트 경로에 추가했다. 41개 파일·226개 선언·299개 실행 사례 통과이며, 합성 16건과 감사 장치 확인 4건은 이 수에 더하지 않는다. 기존 저장 원고 3건은 보류 상태다. 추가 API 비용과 운영 변경은 없다. 실제 AI 품질과 DB/화면 종합 검증은 여전히 남아 있다.

- 출시 전 원격 push/PR 생성/main 병합/Netlify 배포/운영 DB/정기 작업/메일 모두 보류.
- 로컬 실험 중지: 4175 리포트 서버만 종료. 기존 운영 서비스는 바뀌지 않는다.
- 실험 자료는 `.local-reports`에 보존한다. 원문·호출 기록 삭제, 기존 DB 이력 덮어쓰기는 하지 않는다.
- 이후 리포트 기능이 완성돼도 이 문서의 **전체2.0 출시 승인**을 별도로 받아야 한다.
