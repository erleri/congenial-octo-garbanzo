## 결론과 범위

출시 대상은 **BRL·MXN·COP·PEN·CLP·ARS**다. 아르헨티나 코드는 기존 앱과 동일한 ARS를 사용한다. 칠레에서 검증한 자료 카드·기간 구분·집필·검토 체계를 재사용하되, 국가마다 가격 기준과 기사 경로를 따로 확인한다.

현재 확장의 중심은 **기존 API의 환율을 설명할 뉴스·정책·시장 지표·소비·금융 자료와 발표 일정 확보**다. 대시보드의 환율 수집은 유지한다. 아래 PEN·ARS·COP 가격 검증은 기사와 숫자의 날짜·종류를 잘못 연결하지 않기 위한 보조 기록이며 운영 환율 교체 계획이 아니다. 질문별 무료 자료 경로는 [설명자료 등록부](six-currency-explanation-sources-20261027.json)에 모았다.

CLP는 기존 로컬 연결을 재사용할 수 있다. BRL·MXN은 공식 자료 조사와 일부 수집 기반이 있으며, COP·PEN·ARS는 새로 확인한 경로를 실제 수집·검토에 연결하는 작업이 남아 있다. **이번 조사는 6개 통화의 운영 준비 완료 또는 새 보고서의 근거 승인에 해당하지 않는다.**

이번 신규 유료 호출·구독 비용은 $0이다. 무료 공개 웹 열람과 제한된 공개 API GET만 수행했다. 기존 원고·비용 기록·환율 데이터·수집 코드·운영 설정은 변경하지 않았다. 이 문서와 [출처 등록부](six-currency-source-register-20261027.json)는 조사 기록이며 실행 설정이 아니다.

| PD04639PD / PD04640PD | SBS 은행권 매입 / 매도 | 은행권 가격 맥락. 위 시리즈와 혼용 금지 |

13:30은 시리즈의 가격 기준이며 개별 응답의 발표 시각을 뜻하지 않는다. 현지 시간대·거래일·휴일·수정 이력을 메타데이터로 확정해야 한다. 수집한 시각으로 관측 시각을 채우지 않는다.

**실제 읽기 결과:** PD04646PD의 2026-10-19~23 공개 요청은 HTTP 200이었으나, JSON 형태의 값 뒤에 서버 오류 HTML이 붙었다. 응답 전체는 정상 JSON이 아니었다. 일부 값을 잘라 정상 자료로 채택하지 않았다. 공식 문서·다른 공개 형식·재조회로 검증할 대상으로 남긴다. 기존 운영 데이터의 오류라는 뜻은 아니다.

[BCRP 이용 조건](https://estadisticas.bcrp.gob.pe/estadisticas/series/ayuda/condiciones-de-uso)은 출처를 표시한 재현을 허용하며 외부 원천 통계의 책임을 구분한다. 통계 수치·출처·정의를 사용하고 원천이 외부이면 함께 표시하는 경로를 제안한다. 이 약관에 모든 매체의 기사나 제3자 이미지 사용 권한까지 포함되는 것은 아니다.

## 4. ARS 환율 기준

**우선 후보는 BCRA의 도매 기준환율 변수 5다.** [공식 API 목록](https://www.bcra.gob.ar/apis-banco-central/)과 [v4 설명서](https://www.bcra.gob.ar/archivos/Catalogo/Content/files/pdf/principales-variables-v4.pdf)를 확인했다.

- 공개 GET에서 변수명, 일별 주기, ARS/USD 단위, 최신 관측일을 받았다.
- 방법론 응답도 정상 JSON이었다. 이번에는 역사 자료 전체나 휴일 범위를 수집하지 않았다.
- 인증 없는 접근 경로이며 호출 제한은 준수해야 한다. 기존 API v2/v3 예제를 새 연결의 기준으로 삼지 않는다.
- [A8359](https://www.bcra.gob.ar/Pdfs/comytexord/A8359.pdf)는 2026-01-02부터 기존 A3500 기준을 대체하는 산식을 정한다. 적격 거래의 거래액 가중평균과 거래 선정 조건이 있으므로 단순 종가로 표시하지 않는다.

| 가격 종류 | 리포트 처리 제안 |
| --- | --- |
| BCRA 도매 기준환율 | 누적 변화의 기본 후보. 산식 버전·단위·관측일 보존 |
| 은행 소매 환율 | 수입자·소비자 맥락을 확인할 별도 자료 |
| MEP / CCL | 해당 시장의 제도·거래 기준이 확인된 보조 자료 |
| blue | 별도 시장 자료. 공식 환율 장애 시 대신 사용하지 않음 |

뉴스의 도매 종가와 BCRA 가중평균이 다르다는 이유만으로 어느 쪽을 오류로 판단하지 않는다. 동일 기준의 두 관측을 비교해야 한다. 산식 변경 전후의 누적 변화와 가격 체계 변화는 별도로 표시한다.

[BCRA 이용 안내](https://www.bcra.gob.ar/aviso-legal/)는 출처·맥락을 유지한 정보·교육·학술 이용을 허용하고, 상업·광고 목적은 사전 허가 대상으로 구분한다. API 플랫폼에 별도 조건이 있는지와 LATAM FX의 서비스 목적에 적용되는 범위는 남은 확인 사항이다. **무료 공개 사이트라는 이유만으로 비상업 목적을 확정하지 않는다.** 이번 읽기 전용 조사와 운영 재배포 승인을 구분한다.

## 5. 다른 네 통화의 가격 기준도 재사용 전에 확인

- **BRL:** [BCB PTAX 자료](https://dadosabertos.bcb.gov.br/en/dataset/dolar-americano-usd-todos-os-boletins-diarios)에 ODbL 라이선스가 명시돼 있다. 일중 네 차례 조사에서 얻은 환율의 평균 구조이므로 기사 속 현물 마감가와 같은 값으로 취급하지 않는다. 출처 표시·가공·데이터베이스 배포 조건 적용이 남아 있다. 이번 확인은 이 PTAX 자료에 관한 것이며 모든 BCB 자료의 라이선스를 대체하지 않는다.
- **MXN:** 기존 조사에서 Banxico FIX SF43718, SIE 토큰·INEGI 토큰과 재사용 조건을 확인했다. 실제 인증 조회와 FIX의 적용일·조사일 연결은 별도 검증한다.
- **COP:** [SFC 공식 설명](https://www.superfinanciera.gov.co/publicaciones/10115773/market-representative-exchange-rate-trm/)은 적격 현물 거래의 거래액 가중평균과 SFC의 일별 계산·인증을 명시한다. [BanRep 조회 안내](https://www.banrep.gov.co/es/como-consultar-datos-historicos-tasa-representativa-mercado-trm-nuevo-portal-estadisticas)를 수집 후보로 둔다. TRM 적용일·기초 거래일·휴일 유효기간을 연결해야 한다.
- **CLP:** 기존 BDE 가격 정의와 날짜 구분을 유지한다. 이미 확인한 토큰·자료를 다시 발급하거나 현재 대시보드 값을 덮어쓰지 않는다.

현재 앱의 일별 자료는 여러 공급자와 보간 경로를 쓰며, 각 점에 `API` 등의 태그는 있지만 공급자·정확한 관측시각·가격 종류가 모두 남아 있지는 않다. 따라서 앱 PEN·ARS 값을 위 공식 기준과 같다고 가정할 수 없다. **대시보드는 유지하고 리포트용 가격 기준을 별도로 검증하는 방향**이다.

## 8. 일회성 조사에서 반복 가능한 수집으로 연결할 기준

다음은 구현 전 입력 계약 제안이다. 국가별 별도 집필 규칙을 늘리기보다 공통 자료 카드에 국가 설정을 붙인다.

1. **기존 환율 확인:** 기존 API 자료로 움직임과 전회 대비 누적 변화를 확인한다. 기사와 연결할 때 공급자·단위·거래일·가격 종류를 대조한다. 보조 가격 확인이 기존 운영 환율 교체로 이어지지 않게 한다.
2. **질문 선택:** 급변 이유, 전회 설명의 변화, 소비 환경 중 이번 발행 계기에 필요한 질문만 고른다.
3. **무료 탐색:** 현지어 통화·날짜·시장 단어로 승인된 탐색 경로에서 찾는다. 기사 두 건으로 고정하지 않고 필요한 질문의 근거 충족 여부로 멈춘다.
4. **자료 판정:** 실제 읽은 범위·발표/수정 시각·원 발행처·대상 기간·가격 기준·이용 조건을 확인한다. 구독 벽·추출 실패·오래된 캐시는 각각 별도 상태다.
5. **카드 정리:** 확인한 사실과 귀속된 견해를 분리해 자체 문장으로 요약한다. 이를 지지하는 범위와 배제한 목표환율·회사 실적 추정 등을 함께 남긴다. 같은 통신사 기사의 재전재는 독립 근거로 세지 않는다.
6. **생성 전 판정:** 자료·작성 자격·내용 검토·게시 승인을 따로 둔다. 가격 자료가 정상이어도 원인 근거가 없으면 원인 보고서 집필을 보류한다. 정기 점검의 일부 근거 부족 상태와 연결한다.

현지어 탐색어 예시: BRL `dólar real câmbio fechamento juros`, MXN `peso mexicano dólar cierre Banxico`, COP `dólar Colombia cierre TRM`, PEN `tipo de cambio Perú cierre sol BCRP`, CLP `dólar Chile cierre peso cobre`, ARS `dólar mayorista cierre BCRA MEP CCL`. 날짜와 가격 종류를 함께 넣고, 검색 제목만으로 근거를 채택하지 않는다. 탐색어는 특정 요인을 사실로 전제하는 집필 지시가 아니다.

이 단계까지 유료 모델 호출은 필요 없다. 조건 미확인 출처는 보류하고 확인된 국가의 로컬 작업은 계속한다. 잘못된 형식은 공식 대체 형식 또는 수동 검토로 진행하되 자동 수집 성공으로 기록하지 않는다. 시장 가격이 없는 날은 거래일을 새로 만들지 않는다. 유료 시험·운영 반영·지원 통화 축소는 별도 결정이다.
