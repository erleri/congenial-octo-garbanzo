## 4. 이용 범위

뉴스 세 카드에는 기존 **사실·아이디어와 표현을 구분하는 카드 기준**을 적용했다. 독자적으로 작성한 사실·귀속 견해만 로컬 분석 및 향후 외부 모델 입력 후보로 인정한다. 원문·번역·사진·기사의 고유한 구성은 보내지 않는다. 이번 모델 전송은 0회다.

[El Economista 약관](https://www.eleconomista.com.mx/terminos-servicio.html)은 확인한 범위에서 디지털 판매·구독·환불을 주로 다룬다. 여기서 AI 이용 허가나 일반 재배포 허가를 받았다고 주장하지 않는다. [WIPO의 아이디어·표현 구분](https://www.wipo.int/en/web/copyright/protection)을 참고한 프로젝트 차원의 제한된 실무 판단이며, 출처 표시만으로 모든 이용이 허용된다는 법적 보증이 아니다. 최종 공개 문구·출처 표시·게시 승인은 별도다.

Banxico 공개 표의 두 수치와 공식 정책 사실은 로컬 대조에 사용했다. 이번 검토로 전체 데이터 피드의 재배포 권한이나 Refinitiv 원자료 이용권을 승인하지 않는다. Banxico Educa·별도 노동 데이터베이스·조달 포털의 약관은 대상 서비스가 달라 대신 적용하지 않았다. 공식 가격의 향후 모델 입력·공개 사용은 그 가격 자료에 묶인 별도 범위 기록을 추가해야 한다.

## 5. 기존 도구 연결과 검증

- 저장 수집 결과 `collection-3uK5Uq`와 원본·검토 대기 카드의 해시를 재사용했다. 초기 질문 입력에 남아 있는 합성 소매형 차원은 실제 시장 조사 요구사항으로 승인하지 않았다.
- `reviewSelectedNewsMaterial` → `projectReviewedNewsNotes` → `projectEvidenceScopes`로 실제 기사 1건의 3개 요지를 검증했다. 새 검토 결과는 `selected-source-reviews/review-hvLD7n`에 별도로 저장했다.
- `inspectSourceUses`로 카드에 묶인 이용 판단을 따로 기록했다. 내용 검토 완료가 이용·집필·게시 승인을 대신하지 않는다.
- 공식 CA18의 두 날짜 행을 로컬 HTML에서 추출하고 기사 값·변화율·현지 게시시각을 계산해 대조했다. 이는 일반 수집기를 배포한 것이 아니라 해당 저장 원본의 재현 가능한 검토다.
- 실제 저장 사례와 합성 변형을 분리했다. 원본 변조, 없는 본문 위치, 귀속 없는 전문가 견해, MXN 수치를 CLP 전용 가격 계약에 넣는 시도, MXN을 CLP 전용 집필 가격 경로에 넣는 시도는 거부됐다. 카드 변경 시 기존 이용 승인은 보류로 돌아갔다.

기록 위치: `.local-reports/private/mxn-market-review-20261028/`의 `review.json`, `news-receipt.json`, `news-source-use.json`, `news-projection.json`, `public-captures-network.json`. 모두 기존 Git 제외 경로다. 첫 제한 환경의 원본 저장 실패 기록도 남기고, 승인된 공개 읽기 경로에서 확보한 6개 문서·표를 별도 기록했다. 기사 본문은 다시 저장하지 않고 기존 자료를 재사용했다.

검증 결과: 관련 5개 테스트 파일의 46사례 통과, 실제 자료 위 합성 오류 변형 6개는 거부 또는 보류를 확인했다. 시작 시 보존 목록 27,539개 중 의도한 진행표 1개 외 변경·누락은 없었다. 기존 운영 코드 수정이 없어 전체 빌드·DB·브라우저 회귀는 이번에 다시 실행하지 않았다. 이 수치를 실제 원고 품질 표본으로 세지 않는다. `verification.json`과 `tests.json`에 결과를 보존했다.
