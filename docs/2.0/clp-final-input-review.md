# 칠레 사례 최종 생성 입력 검토

2026-10-05 확정. 대상은 CLP 2026-09-11의 **사후 검토 초안**이다. 입력 준비는 완료했으며, 새 AI 호출과 공개 발행은 승인하지 않았다. 기존 원고·비용 기록·A안·운영 서비스는 변경하지 않았다.

## 최종 판단

원문을 확인한 세 출처로 미국 금리 해석, 칠레 현지 시장 배경, 구매력 맥락을 설명할 수 있다. 다만 대시보드 일간 변동 전체의 직접 원인을 확인한 자료는 아니다. 이 경계에서 역사 사례 초안 생성으로 진행할 수 있으며 추가 후보 수집을 선행 조건으로 두지 않는다. 완성 원고의 문장별 근거 검토와 실제 제공자 수락은 생성 이후 확인할 사항이다.

미국 금리·구리·구매력 관련 연결은 원문에 있는 귀속 해석을 사용한다. 별도의 공통 원리 적용을 사람이 승인한 것으로 만들지 않는다. 이번 입력의 `applicableMechanisms`는 빈 배열이다. 상대 금리 차이·위험회피의 당일 자료와 달러 결제 노출 조건은 확인되지 않아 추가하지 않았다. 일반 원리 목록 자체를 삭제하거나 공통 규칙을 완화한 것은 아니다.

본문은 새 정보와 전달 경로를 설명하고 공통 한계 네 항목은 별도 영역에서 한 번 표시한다. 출처의 구체적 반대 가능성은 관련 설명에 남긴다. 제목·요약·소제목까지 문장별 근거 대응표를 요구하며 기존 공통 검사 경로를 사용한다. 사람이 작성한 완성 원고나 칠레 전용 설명 카드는 입력하지 않았다.

## 고정 결과와 재현

- 준비 명령: `node scripts/currency-report/final-clp-input.js`. 네트워크·키 로딩·유료 호출·화면 투영 기능이 없다.
- 저장: Git 제외 `.local-reports/private/clp-20260911-final-input-v1/input.json`. 패킷, 실제 전송 예정 요청, 원문 채택 범위, 비용 상태를 함께 보관한다.
- 동일 입력 재실행은 저장본과 일치하는지 확인한다. 내용이 달라지면 덮어쓰지 않고 중단한다.
- 입력 해시: `39c2572d538812e2ef05d4eca0cda3e0113e055c9ad67463cce4c8b17c7515f0`.
- 시장 자료 해시: `cccd09114ea783f50a1794cd9bd0fd289d0796c757eb44fd541405015b825a3d`.
- 이번 호출 0회, 신규 비용·예약 $0. 과거 확인 지출 $0.07933225와 미확인 예약 $0.37118550를 유지한다. 미확인 비용을 0으로 계산하지 않았다.
- 준비된 GPT-5.4 medium 요청의 기존 가격 상한 기준 최대액은 **$0.17170750**. 입력의 보수적 상한 19,531토큰, 추론 포함 출력 상한 8,192토큰이다. 실제 예상 토큰이나 확정 청구액은 아니다.
- 다음 유료 실행에는 별도 승인이 필요하다. 승인 후에도 이 고정 입력의 해시, Azure의 현재 지원·ZDR·데이터 수집 금지·가격을 호출 직전에 확인한다. 기존 실패 캠페인을 재실행하지 않는다.

이번 준비는 원문·입력 검토 완료다. AI 설명 품질 합격, 사용자 내용 승인, 자동 발행 가능, 2.0 출시 완료를 의미하지 않는다.
