# 칠레 편집본의 로컬 승인과 조회 확인

사용자가 채택한 칠레 2026년 10월 9일 경제·소비 환경 편집본을 기존 앱의 관리 화면에서 승인했다. 격리 DB의 승인 결과만 기존 앱에서 읽으며, 운영 게시와 추가 모델 호출은 하지 않았다. 이 사례는 환율 급변의 원인을 설명하는 보고서나 전체 2.0 출시 승인이 아니다.

## 보존과 검토

기존 AI 원고, 출처 보완본, 수동 편집본의 파일은 바꾸지 않았다. 편집본 ID는 `CLP-2026-10-09-1791893507884`다. 별도 DB 시도에 원본 해시와 수동 편집 여부를 연결하고, 승인 기록은 한 건 남았다. 이전 3.8점과 모델 생성 비용 $0.024868은 과거 기록으로 유지한다. 이번 신규 호출과 비용은 0이다.

편집본의 새 수동 평가는 설명·변화·영업 관련성·가독성·근거 각 4/5, 평균 4/5다. 이는 에이전트의 제한된 경제 맥락 브리프 평가이고, 독립적인 모델 평가나 여러 사례의 품질 합격률이 아니다. 사용자는 편집본을 채택했다. 공식 원문의 IPC 상승과 분류별 상쇄, 물가 조정 실질보수 증가, 8월과 9월의 기간 구별을 확인했다. 실제 가계소득·판매·환율 원인으로 범위를 확대하지 않았다.

## 조회와 접근 경계

- `http://127.0.0.1:4176/#report/CLP/2026-10-09`에서 승인본을 읽는다. 관측일·관측시각 미제공·수집시각·두 대상 월·수동 편집·과거 사례 표시를 유지한다.
- 로컬 앱의 관리 탭은 격리 DB 관리자 검토 화면이다. 운영 빌드는 이 경로를 사용하지 않는다. 로그인은 기존 로컬 시험 계정으로 확인했고 로그아웃 후 비공개 원고를 제거했다.
- 공개 복사는 생성·검토·비용 원문을 포함하지 않는다. `authorship`은 승인된 고정 문자열만 복사하고 과거 사례 여부는 불리언으로 전달한다. 새 후속 migration은 로컬에서만 시험했으며 기존 migration과 권한은 바꾸지 않았다.
- 미래 날짜의 합성 자료는 DB에 보존한다. 같은 통화에 실제 승인본이 있으면 제품의 최신 목록·이력에서 합성 자료를 제외한다.

## 재현과 검증 기록

`node scripts/currency-report/stage-editorial-local.js`는 지정된 편집본만 로컬 API 56321에 등록하며 동일 ID의 재등록을 차단한다. 승인 자체는 관리 화면의 RPC를 사용한다. `node scripts/currency-report/verify-editorial-approval-local.js`는 승인 후 내용 일치·원본 해시·공개 메타데이터·단일 감사 기록·중복 승인 차단·일반 사용자 권한 차단을 확인한다.

개별 기록은 Git에서 제외한 `.local-reports/private/local-approval-aJ3zMb/`에 저장한다. 기존 생성 원고와 비용 기록은 그대로 보존한다. 테스트 DB의 함수는 SQL로 반복 검증했으며 migration 이력에 운영 적용 기록을 만들지 않았다. 출시 때에는 후속 migration의 별도 적용 승인이 필요하다.

전체 자동 검사 480개, 타입·린트·운영 빌드·시안 빌드·로컬 앱 빌드가 통과했다. DB pgTAP 4파일 58항목과 HTTP·비밀값 검사 15항목도 통과했다. 기존 큰 번들 경고는 남아 있다. 이 수치는 실제 원고 품질 표본 수가 아니다.

브라우저에서 관리 화면 승인, 로그아웃 시 원고 제거, 익명 목록·상세 조회, 직접 주소 새로고침, 8월 출처 펼침, 대시보드 복귀와 CLP 숫자 카드 재진입을 확인했다. 390px 모바일의 문서 폭은 375px로 가로 넘침이 없었다. A안 PC·모바일 이미지는 같은 비공개 검증 디렉터리에 저장했다. 검토 기록에는 사용자 채택과 에이전트의 수동 평가를 구분했으며 새 유료 생성으로 표기하지 않았다.

운영 DB·배포·원격 push·정기 작업·메일·Excel 업로드는 수행하지 않았다. 전체 파일럿, 다른 통화의 실제 원고, 운영 복구 검증과 출시 승인은 별도 단계다.
