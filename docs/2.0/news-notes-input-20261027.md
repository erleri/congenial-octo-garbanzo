# 사실·귀속 견해 카드 입력 연결 — 2026-10-27

## 결과와 범위

2026-09-10 칠레 급변일을 대상으로 DF·Pulso·Emol·Yahoo/Reuters의 **6개 카드(보도 사실 1개, 귀속 견해 5개)**를 기존 환율 원인 입력·범위·출처 이용·집필 요청에 연결했다. 새 원고·AI 품질 평가·게시 승인은 아니다. 모델·유료 데이터·DB·운영·메일 호출 및 원격 push는 없었다.

이전 [무료 기사 검토](clp-free-news-case-20260910-review-20261027.json)는 당시 판단으로 보존한다. 이번 자료는 기사 원문 재이용을 승인한 것이 아니라 **검토자가 작성한 사실과 해석 요지라는 별도 자원**에 대한 이용 범위 판단이다. 기존 원문 입력과 그 보류 상태를 바꾸지 않는다.

## 기사 내용 확인과 매체의 취재 검증을 구분

Yahoo나 Reuters가 한 취재를 에이전트가 다시 수행하거나, 기사 전체를 별도로 내려받아야 한다는 기준을 두지 않는다. 필요한 주장을 뒷받침하는 기사 내용과 발행처·저자·날짜·귀속을 확인하면 된다. 매체 페이지, 매체 피드, 출처가 확인되는 기사 본문 제공 부분을 허용한다. 제목만 확인되거나 검색 서비스가 새로 만든 요약만 있는 경우에는 그 내용에 없는 원인을 만들지 않는다.

Yahoo 직접 페이지 요청의 429 이력은 보존했다. 후속 무료 검색에서 Yahoo 원주소로 귀속된 Reuters의 Jamie McGeever 칼럼 내용과 저자 개인 의견 표시를 확인했다. 그 내용의 유가·물가·세계 채권금리·달러 배경만 카드로 정리했다. 해당 칼럼은 칠레 평균 집계 마감 후의 해설이며, 사전 관측 자료나 칠레 요인별 기여도의 독립 입증으로 쓰지 않는다.

## 연결 구조

1. [사례 카드와 명시적 검토 기록](clp-news-notes-20260910.json)을 읽는다.
2. 저장된 BCCh 환율 캡처의 원래 HTML과 산정 문서 해시를 다시 확인하고 기존 파서·거래일 변환·수치 계산을 재사용한다.
3. 카드의 내용 확인 방식, 독자적 표현, 발언자, 수치 기준과 검토 기록을 결합한다.
4. 기존 dossier·범위 카드·정확한 자원별 이용 판단·환율 목적 검사를 실행한다.
5. 기존 집필 요청을 로컬에서 조립한다. 출처 문맥은 `reviewer_authored_notes`로 표시하며 원문 발췌와 구분한다.
6. 원문과 카드 혼합, 카드·발언자 변조, 잘못된 가격 산술, 보류된 이용 범위는 차단한다. 유료 호출에는 별도의 결합된 예산 승인이 계속 필요하다.

입력 버전은 `currency-input/6`, 카드 문맥은 `reviewed-news-notes/2`다. `notes-reference/1`에서는 요지 문장을 한 번만 전달하고 목차·채택표는 ID로 참조한다. 귀속·기간·한계는 유지한다. 입력 중복을 줄여 기존 요청 크기·비용 상한을 통과했으며 예산 상한을 올리지 않았다.

## 가격과 날짜

- 실제 거래일 및 과거 사례 표시 기준일: 2026-09-10. 공식 평균의 고시 적용일 2026-09-11은 별도 가격 메타데이터로 유지한다. 앞선 준비본은 원래 날짜와 함께 비공개에 보존했다.
- BCCh 거래가중평균: 이전 거래일 925.97 → 937.17 CLP/USD, +1.2095424258%.
- DF 보도 마감값: 927.8 → 941.9, +14.1페소. 보도된 가격 기준으로 카드 안에 별도 보존한다.
- 두 값은 같은 거래일에 관한 다른 가격 기준이다. 기사 원인 해석을 평균값의 정확한 일중 인과·기여도로 바꾸지 않는다.
- 최신 수집 스냅샷으로 과거 사례를 재구성했다. 당시 발행이나 당시 자료 가용성을 재현한 백테스트로 표시하지 않는다.
- 구리의 거래소·현물·선물별 표기가 엇갈려 정확한 구리 수치와 목표환율은 입력에서 제외했다.

## 이용 범위 판단

사실·아이디어와 보호되는 표현을 구분하는 실무 검토에 따라, 이번에 독자적으로 작성하고 귀속한 카드만 향후 모델 입력 후보로 인정했다. 이것은 매체가 발급한 이용 허가, 국가별 법률 분쟁의 결론, 자동 수집 허가 또는 모든 기사의 포괄 승인과 다르다.

참고: [WIPO의 표현과 아이디어 구분](https://www.wipo.int/en/web/copyright/protection), [한국 저작권법 제7조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033063839), [제28조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025517657). 약관·계약·자동 수집·제3자 시세의 별도 문제는 이 판단으로 없애지 않는다. 길이 제한과 검토 플래그도 표현의 독립성이나 법적 적합성을 자동 증명하지 않는다.

외부 모델 입력 범위는 이 카드에 한정한 기록이며 실제 호출 승인은 없다. 공개 리포트의 최종 표현·출처 표시·게시 승인은 계속 보류다. 검토자 원고·비용·기존 출처 승인 기록은 덮어쓰지 않는다.

## 9월 10일 실제 생성 준비

사용자의 실제 생성 요청에 따라 거래일로 보고서 날짜를 맞췄다. 기사 카드를 붙인 뒤 가격만 있던 시점의 `official_price_local_review_only` 판정이 남지 않도록 기존 `assessEvidencePacket`을 다시 실행한다. 무변화·급변 근거 부족 차단은 그대로 적용하며, 외부 입력 이용 범위 및 공개 승인도 별도로 유지한다. 이전 가격 패킷과 저장 원고는 수정하지 않는다.
