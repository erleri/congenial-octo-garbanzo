## 2026-10-29 판단 — 원문 전송과 사실 카드 경로를 구분

이번은 **출처 조건·DF 처리 판단과 저장 자료 검증**이다. 제품 코드·출처 허용 정책·기존 원고는 변경하지 않았고, 별도 유료/독립 모델 호출도 하지 않았다. 상세 판단은 [9개 매체·12개 기사 사례별 기록](original-scope-and-df-decision-20261029.json)에 보존했다. 아래 이전 원문 시험 준비와 이 판단을 구분한다.

### DF: 유지할 것과 바꿀 것

정상 공개 열람으로 [해당 기사](https://www.df.cl/mercados/bolsa-monedas/dolar-hoy-p5xh6)의 본문과 Bci/Jorge Concha 발언을 확인했다. 외국인 달러 매도와 브라질 포지션 해소 자금 유입 가능성이라는 기존 최소 카드의 귀속·조건은 지지된다. 이는 한 전문가의 해석이며 측정된 자금 기여도나 확정된 인과는 아니다. 원래 발행 시점의 전체 판본/공개성까지 인증한 것은 아니다.

- **현재 저장 사례:** 검토된 짧은 귀속 카드를 보존한다. 원고를 다시 쓰거나 새 점수/승인을 부여하지 않는다.
- **오류 분류:** 현재 결과는 `article_body_not_identified`다. `articleFree`가 초기에 숨겨진 DOM이라는 점만으로 유료벽이나 기사 부재라고 단정하면 안 된다. 실제 로그인/유료 제한을 우회하지 않으며, 공개 본문 경계와 재현 조건을 따로 검증한다.
- **반복 자동 처리:** DF를 모든 CLP 리포트의 필수 출처로 고정하지 않는다. 공개 추출이 검증되면 사용할 수 있지만, 실패 시 DF에만 의존하는 주장·인용·출처·연결을 함께 제거한다. 다른 매체에 DF의 해석을 옮겨 붙이지 않는다.
- **이 사례에서 DF가 빠지는 경우:** 남는 것은 Emol 기사2건의 시장 관측1·귀속 설명2·반대 조건2, 총5개 주장이다. 차익실현·구리/유가·달러/지정학/금리 조건은 남는다. 외국인 자금 유입 설명은 남는 기사로 뒷받침되지 않으므로 뺀다. 두 기사는 같은 매체이며 독립 매체 둘로 계산하지 않는다.
- **공통 코드의 수정 과제:** 현재 선택기는 다른 충분한 근거가 있어도 시장 역할 출처를 제거하면 `required_material_cannot_be_excluded`로 막는다. 저장 재생으로 확인했다. 다음 구현은 국가 예외가 아니라 **명시적 제외 이유·잔여 최소 근거·모든 의존성·기간/용도 재검사**를 갖춘 공통 선택 규칙이어야 한다. 단독 필수 근거가 사라지면 계속 보류한다. 과거의 풍부한 입력을 문자열로 잘라 새 입력으로 쓰지 않는다.

위 DF 제외안은 **가능성 분석**이며 실제 입력/원고에서 DF를 삭제한 결과가 아니다. 같은 기준환율 스냅샷과 원래 자료를 보존했다. 주장 개수 충족을 새 리포트 품질 합격으로 부르지 않는다.

## 코드 연결

기존 `collectSelectedResearch`와 원문 파이프라인을 그대로 사용한다.

1. 출처 프로필은 정확한 호스트와 `/radio/programas/숫자-제목/`만 허용한다.
2. 프로그램 본문 영역만 읽는다. 중첩된 진행자 표시를 보존하고 별도 저작권 안내·옆 기사·음성 플레이어는 근거 본문에서 제외한다. 본문 영역이 여러 개로 모호해지면 중단한다.
3. 전용 발표일 라벨만 읽는다. 옆 기사 날짜를 사용하지 않으며 기존 명시 메타데이터와 충돌하면 보류한다.
4. 확인한 단일 프로그램 경로에만 원문 정책을 적용한다. 다른 프로그램이 같은 매체에 있다는 이유만으로 자동 허용하지 않는다.
5. 출처 정책에 선언된 attribution을 모델 입력의 실제 `sourceCredits`에 전달한다. 링크만 붙이고 필요한 출처명을 빠뜨리는 문제를 막는다.
6. 준비 결과의 본문·원문 해시·정책·요청 바인딩을 기존 두 단계 실행 경로에 연결한다. 준비 명령은 API 키를 읽지 않는다.

합성 허용 정책을 실제 자료에 적용하지 않았다. 실제 원문에 대해 새 추출·대조 응답이나 카드가 생성됐다고 기록하지 않는다.

1. 원문 처리 경로의 실제 모델 품질 시험은 준비됐지만 아직 실행되지 않았다. 이 과거 자료의 시험 결과만으로 현재 뉴스 수집 문제를 해결했다고 보지 않는다.
2. 최신 국가별 시장 기사에 적용할 원문 사용 범위와 직접 원인 근거를 마감한다. COP/PEN 직접 원인, BRL/ARS 같은 기준의 전후 가격 등 기존 공백은 유지한다.
3. 이 조건이 충족된 국가부터 공통 집필 자격을 재평가하고 원래 5단계의 실제 원고 품질·비용 시험으로 넘어간다. 사용자의 수동 기사 확인이나 소비 통계로 원인 설명을 대체하지 않는다.
