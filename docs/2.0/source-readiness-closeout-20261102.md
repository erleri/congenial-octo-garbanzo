# 공통 날짜·근거 연결 및 6통화 저장 응답 검증 — 2026-11-02

## 결론과 작업 범위

1·2단계의 공통 코드 보강과 저장 응답 재생을 마쳤다. **6개 통화의 실제 집필 준비가 모두 끝났다는 뜻은 아니다.** BRL·CLP는 집필 입력 준비, MXN은 입력 연결은 통과했으나 기사 내부 가격 불일치를 내용 검토 대상으로 남겼다. COP·PEN·ARS는 아래 이유로 보류한다.

11월 1일 대시보드 스냅샷과 실제 수집 기사 21건·실제 모델 응답 28건을 사용했다. 이는 저장된 실제 기록이다. 신규 탐색·외부 API·유료 모델·DB 쓰기·게시·메일·배포를 하지 않았다. 소프트웨어 회귀용 합성 사례는 실제 근거/품질 표본에 합산하지 않는다. 과거 원고, 원응답, 실제 결과와 비용 기록을 덮어쓰지 않았다.

|---|---|---|

| 기사 발표일 | 출처 표시, 상대 날짜의 현지 달력 기준 | 발표일만으로 거래일을 확정하지 않는다 |

| 월간 지표·채권 등 비교기간 | 명시한 기간의 배경 | 해당 기간의 끝을 당일 환율 사건으로 바꾸지 않는다 |
| 수집·검토 시각 | 입력 버전과 이용 가능성 기록 | 발표·관측 시각을 대신하지 않는다 |

국가별 하드코딩이나 특정 기사 승인 예외는 추가하지 않았다. 출처·현지 시간대·가격 정의는 기존 등록값을 사용한다. 이용 범위도 기존 처리 규칙을 재검사했으며 새 이용 허가를 만들지 않았다.

## 공통 경로에 반영한 변경

1. **날짜 형식 오탐 수정.** 명시 날짜가 원문에 있고 현지 발표일과도 맞으면 `explicit + same_day`처럼 중복된 정보만으로 반려하지 않는다. `previous_day`도 달력이 실제로 맞아야 한다. 모델 응답은 수정하지 않는다. 앞으로의 지침은 명시 날짜에 `explicit + none`을 우선하도록 분명히 했다.
2. **상대 표현 보완.** 스페인어 ‘오늘 아침/오후/밤’, 포르투갈어 대응 표현을 지원한다. ‘내일’ 단독 표현은 당일로 바꾸지 않는다. 구절이 정말 환율 세션을 지칭하는지는 별도 원문 대조가 계속 담당한다.
3. **사건 선택 지침 정리.** 한 후보는 하나의 사건/세션을 중심으로 작성한다. 전일 가격과 당일 예정회의를 같은 사건일로 묶지 않는다. 정책 배경은 같은 날의 예정 사건이라는 이유만으로 반려하지 않되 시장 원인 자격을 얻지 않는다. 기준일 이후의 미래 일정은 현재 사건 카드와 분리한다.
4. **발언 문맥 연결.** 후속 문단의 성·대명사를 사용할 때 발언자와 기관 소개 블록도 연결하도록 했다. 프로그램이 이름을 추측하거나 블록을 자동 덧붙여 승인하지 않는다.
5. **가격 모순 검토.** 후보가 인용한 가격과 동일 기준의 장중 범위가 충돌하면 `price_basis`의 필수 보류로 판단하도록 독립 대조 지침에 명시했다. 정확한 관측시각이 없다는 일반적 한계와 구별한다. 지침의 실제 모델 준수는 아직 시험하지 않았다.
6. **탐색 기간 보완.** 대시보드 기준일 이전의 두 평일 후보부터 현지 현재일까지, 기존 최대 4개 날짜 안에서 탐색한다. 오전 기사에 나오는 전일 세션을 조사할 수 있게 했다. 이것은 휴장 확인이나 무제한 오래된 자료 사용 허가가 아니다. 4일 밖은 공백으로 기록한다.
7. **세션 선택 수정.** 관측과 귀속 FX 설명이 같은 날짜에 함께 있는 가장 최근 검토 세션을 선택한다. 더 최신의 가격 나열·글로벌 기사·정책 예정만으로 이 설명을 밀어내지 않는다. 날짜가 다른 자료를 합쳐 통과시키지 않는다.
8. **기존 기록·캐시 보존.** 새 요청은 `original-news-pipeline/3`, 날짜 정책은 `news-event-date/2`다. 과거 `/2` 요청은 원래 지침으로 결합값을 검증한다. 새 지침으로 생성한 응답인 것처럼 재표시하지 않는다. 성공한 원문 대조 캐시는 유지하고, 구버전 날짜 형식/기간 검사 보류만 재평가 대상으로 분리한다. 실제 원문 지지 실패는 그대로 유지한다. 재평가 대상 지정은 재호출 승인이 아니다.

확인된 정상 카드 4건을 유지했다. 나머지는 날짜 미상, 옛 탐색 범위 밖, 귀속 문맥 누락, 미실행 독립 대조, 실제 원문 지지 실패, 내용 부족/무관으로 구분했다. ‘형식 오류 해결’과 ‘해당 기사 채택’을 같은 상태로 처리하지 않는다.

MXN 가격 모순은 이번 독립 점검의 추가 발견 사항이다. 기존 대조 모델의 `blocking=false` 기록은 그대로 보존했다. 따라서 `input_staged`라는 기술 결과만 보고 MXN의 내용상 준비 완료를 선언하지 않는다. 공통 지침을 강화했다는 사실만으로 새 모델이 이 오류를 잡았다고 주장하지 않는다.

## 집필·검토 크기 사전 점검

BRL·MXN·CLP의 공통 집필 입력을 메모리에서 준비한 후 비공개 파일로 저장했다. DB에는 등록하지 않았다. 세 통화 모두 원고를 제외한 최소 검토 입력은 기존 요청당 상한에 들어간다. **최종 원고가 추가된 검토 입력의 크기까지 보장한 결과는 아니다.** 특히 MXN은 최소 검토 요청 예약액이 약 $0.24149여서 $0.25 상한까지 여유가 작다. 실제 시험 계획에는 최종 입력 크기와 예산을 다시 반영해야 하며 근거를 잘라 맞추거나 승인 없이 상한을 높이지 않는다.

이번 추가 비용은 **$0**, 실제 집필·새 원고·게시도 0건이다. 앞선 실제 시험 $0.3265525와 미확인 비용 $0 기록은 보존한다. 이전 예산 잔액을 새 시험 승인으로 이월하지 않는다.

## 재현과 검증

```powershell
node scripts/currency-report/replay-source-readiness-local.mjs --input .local-reports/private/stage6-20261102/live-qXNDNm/continuation-1
```

명령은 지정한 비공개 저장 입력만 읽고 `.local-reports/private/source-readiness-*`의 새 폴더에 결과를 쓴다. 키·DB 연결을 읽거나 외부 호출을 하지 않는다. `result.json`은 실제 응답 재검증, `prospective-source-plans.json`은 **새 지침으로 준비만 한 요청**, 통화별 `*-writer-input.json`은 **집필 전 입력**이다. 예상 탐색 기간 진단도 별도 기록하며 새 범위로 원문 승인 영수증을 만들지 않는다.

실제 기록 4개(작업 응답, 고정 입력, 실제 실행 결과, 비용 종료 기록)의 SHA-256이 재검증 전후 같았다. 과거 요청 결합 검증도 통과했다. 새 폴더는 Git 제외 경로다.

검증: 전체 자동 테스트 1,201건 통과. 신규 테스트는 버전 호환과 6통화 공통 세션 선택의 2건이며 기존 날짜·캐시 테스트도 확장했다. 타입 검사·린트·운영용/로컬 앱/리포트 빌드·브라우저 번들 경계 검사 통과. 기존 `dbClient.ts` 정적/동적 import 혼용 경고는 남아 있다. 화면 자체는 수정하지 않았으며 새 원고 시각 검증은 수행하지 않았다.

## 다음 단계와 완료 경계

이 작업의 완료는 **공통 코드와 오프라인 검증의 마감**이다. 6통화 실제 생성이나 2.0 출시 완료가 아니다.

- 준비된 BRL·CLP는 기존 검증 카드로 집필·문장 검토 시험을 준비할 수 있다.
- MXN은 문제 가격 주장의 자동 대조 처리와 최종 검토 입력 용량을 먼저 확인한다.
- PEN은 확보된 10월 29일 후보의 독립 대조가 우선이며, COP·ARS는 세션에 맞는 원인 후보를 확보해야 한다. 구체적인 문제를 해결하지 않은 전체 원문 재호출은 하지 않는다.
- 다음 유료 시험은 재사용 자료/새 대조/집필/최종 검토를 나누어 비용을 계산하고 별도 승인받는다. 권장: 준비·실행 Sol High, 내용 판단 Astra High.
- 승인·조회·UI·이메일·출시는 실제 원고 검증 뒤 원래 계획대로 진행한다.
