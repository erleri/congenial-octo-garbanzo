# 6개 통화 직접 원인 근거·출처 이용 범위 검토

2026-10-28 · 저장 자료 재사용 · 기존 원고·환율·집필 입력 보존

## 결론과 검토 범위

**COP·PEN은 가격 보도와 국제 배경은 있지만, 저장된 기사만으로 해당 통화 움직임의 직접 설명을 채울 수 없다. BRL·ARS는 해당 통화를 연결한 보도·귀속 해석이 있으며, 가격 연결과 이용 조건이 남는다. CLP·MXN은 기존 사례 준비 상태를 유지한다.**

이번에는 원고를 생성하거나 기존 카드를 수정하지 않았다. 기존 기사 본문·수집 영수증·가격 검증·이용 판단을 다시 읽어 내용과 남은 조건을 분리했다. 같은 대화의 에이전트 검토이며 독립 맹검, 별도 Astra API 호출 또는 법률 자문으로 표시하지 않는다. 실제 새 원고가 없으므로 품질 점수도 매기지 않는다.

새 약관이나 오늘 시장을 조회하지 않았다. 아래 이용 검토는 **저장한 조건의 적용 범위와 기존 판단의 빈칸에 대한 검토**다. 새로운 포괄적 이용 허가, 약관 최신성, 운영 공개 승인을 선언하지 않는다. 제한된 자체 사실·귀속 견해 카드라는 기존 실무 방침을 유지한다.

대상: COP·PEN·BRL·ARS·MXN의 2026-10-26 사례, CLP의 2026-09-10 사례. BRL 후속 해설은 10/27, 수집·검토는 그 이후다. 당시 실시간 수집본이나 현재 시장 리포트와 구분한다.

**새로 확인한 주의점:** RPP의 소비자 편익 설명은 그대로 카드로 옮기면 일반 원리를 실제 결과로 바꾸게 된다. 가격 하락만으로 판매가격 전가·소비 진작이 관측됐다고 쓸 수 없다. RPP는 기존 집필 패킷에 채택되지 않았으므로 기존 원고 교정이나 운영 차단이 필요한 문제는 아니다.

Gestión 목록의 다른 날짜·전망·의견 링크는 후속 탐색 후보다. 원문이 없는 목록을 검토 완료로 바꾸지 않는다. RPP의 마감 내용도 수정 시각 20:05:39Z에 연결해야 하며 오전 최초 시각에 이미 있었다고 간주하지 않는다.

**종료 판단:** PEN 직접 원인 집필 보류. 다음에는 해당 거래 구간의 PEN에 연결되는 현지 수급·정책·위험 요인 설명을 찾는다. 없으면 ‘원인 확인 중’ 상태로 끝내며 소비 통계나 조건부 경제 원리로 원인 칸을 채우지 않는다. 공식 당일 결측과 자료 접근 실패는 별도 상태로 유지한다.

## 이용 범위 검토: 세 가지 상태를 분리

**무료 열람, 자체 카드의 제한된 이용 판단, 공개 서비스 적용은 서로 다른 상태다.** 기사 URL이 `terms.url`에 들어간 기존 기록은 실제 약관 허가를 뜻하지 않는다. `scoped_fact_notes_local_judgment/1`이라는 기존 버전명이 표시하듯, 원문·번역·구성 복제를 제외한 최소 사실·귀속 견해의 프로젝트 판단이다. 이를 ‘출판사가 AI 이용을 승인함’으로 표시하지 않는다. 반대로 명시적 AI 허가 문구가 없다는 이유만으로 모든 자체 사실 카드를 금지로 바꾸지도 않는다.

### 구현 전 필수 보완 U01: 설명문에만 있는 조건

새 네 통화의 이용 기록은 `conditions=[]`, `conditionIds=[]`다. DANE 등의 필수 출처 표시는 문서에만 있고 구조화된 검사에는 없다. 기존 검사기는 조건을 등록하면 보류/충족을 구분할 수 있으므로 새 허가 엔진은 필요 없다.

- 영향: 현재 public_display는 모두 pending이어서 이번 검토로 공개되는 자료는 없다. 다만 외부 입력 allowed를 ‘출처 표시 구현 확인 완료’로 오독하거나 나중에 공개 상태만 바꾸면 필수 조건을 놓칠 수 있다.
- 다음 조치: 새 사본에 출처·귀속·링크·기간·가공 표시 등 **실제로 요구되는 조건**을 기록하고, 외부 입력과 공개 표시 중 해당되는 용도에 연결한다. 충족 여부는 최종 투영 자료·화면으로 확인한다.
- 불필요한 확대 금지: 조건이 없던 기록을 일괄 불법으로 판정하지 않으며, 공개 화면이 아직 없다는 이유로 모든 로컬 사실 검토를 막지 않는다. 법적 판단·자료 내용·표시 구현·유료 호출 승인을 계속 분리한다.

이번에는 검토 기록만 추가했다. 기존 이용 승인이나 모델 입력을 소급 변경하지 않았다.

이 표는 국가의 영구적인 지원 불가 판정이 아니다. 같은 사례의 근거가 부족하면 해당 사례를 보류할 뿐이며, 국가별 지원 범위를 줄이지 않았다. 최신 근거 없는 새 원고를 만들거나 기존 발행일을 갱신하지 않는다.

다음은 여전히 **4단계 자료 연결 마감**이다. Sol High 작업으로 U01을 기존 조건 검사에 연결하고, 남은 자료 요청을 COP/PEN 직접 설명·BRL 발표/이용·ARS API 적용/수집으로 제한한다. 이 검토에서 못 찾은 근거를 프롬프트 추가로 해결하지 않는다. 준비된 국가만 5단계 실제 품질 시험의 예산 검토로 넘어갈 수 있으며 이번에는 그 호출을 승인하지 않는다. 이후 6단계 공개·권한·UI, 7단계 파일럿·출시 순서를 유지한다.
