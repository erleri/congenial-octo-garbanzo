# LATAM FX 2.0 리포트 발행 정책과 사례 판정표

> 최신 주기: 여섯 통화의 누적±2%·유효 발행 후14일이 지난 첫 한국 월요일 점검을 확정했다. [정책 재확인](pre-ui-policy-review-20261030.md) · [독자/관리자 상태표](report-state-actions-20261030.md). 아래 초기 임계값/일정 제안은 설계 이력이며 운영 적용을 뜻하지 않는다.

> 2026-10-27 후속 결정: CLP·MXN·BRL·COP의 누적 2%와 한국 날짜 14일 경과 후 첫 월요일 정기 점검을 채택했다. 현재 기준은 [발행 주기 상세 설계](publication-cadence-design-20261027.md)를 따른다. 아래 원래 설계·검토 기록은 이력으로 보존하며, 운영 설정은 변경하지 않았다.


매일 정보를 확인하되 독자가 새로 이해할 내용이 있을 때만 통화별 리포트를 발행한다. 대상은 공개 정보로 환율과 소비 환경을 이해하려는 영업·손익·가격 관리 담당자다. 환율 숫자의 변화, 기사 재배포, 보고서의 경과 일수만으로 새 원고를 만들지 않는다.

2026년 10월 11일 기준으로 하루 한 번 확인·사건 중심 발행·초기 관리자 승인이라는 계획 방향은 사용자와 합의했다. 아래 세부 판정은 검토용 정책이다. 정확한 변동 기준, 수집 경로, 확인 시각, 작성 모델과 비용 한도는 아직 확정하지 않았다. 이 정책은 구현·유료 호출·운영 반영 승인을 포함하지 않는다.

## 초기 범위와 리포트 목적

BRL·CLP·MXN과 미국 공통 요인으로 시작한다. 기존 A안, 환율 화면, 계획환율, 데이터 갱신과 이메일은 유지한다. 새 정책은 기존 비교 원고·비용·검토 기록을 덮어쓰지 않는다.

리포트 목적은 다음 두 가지로 나눈다. 목적 구분은 화면에 표시할 발행 계기와 설명의 허용 범위를 정하는 것이며 새로운 화면 디자인을 확정하는 것은 아니다.

- **환율 변화 해석:** 의미 있는 움직임과 해당 움직임을 설명할 수 있는 근거를 연결한다. 시간 순서만으로 인과를 확정하지 않는다.
- **정책과 소비 환경 업데이트:** 공개된 정책·물가·소매판매·고용·신용 정보가 기존 설명을 바꿀 때 제공한다. 이후 환율 관측값이 없으면 시장 반응을 주장하지 않는다. 월간 자료를 당일 변동 원인으로 바꾸거나 특정 회사의 셀아웃·마진을 추정하지 않는다.

변화 설명, 배경, 영업 의미와 관찰 변수의 기존 편집 원칙은 [공통 규칙](common-report-rules.md)을 따른다. 새 발행 정책이 생성·근거·내용 검사를 면제하지 않는다.

## 조사와 생성과 발행의 분리

일정 또는 변동 감지는 **조사할 이유**다. 원문과 새 정보가 확보되어야 **초안을 만들 이유**가 되고, 내용 검토와 관리자 승인을 거쳐야 **발행할 이유**가 된다. 세 판단을 하나의 통과 표시로 합치지 않는다.

| 판단 단계 | 필요한 조건 | 조건을 충족하지 못했을 때 |
| --- | --- | --- |
| 자료 상태 확인 | 시점·단위·출처·갱신 여부가 비교에 적합하다 | 확인 실패 또는 자료 대기. 변화 없음으로 표시하지 않음 |
| 조사 후보 선정 | 이례적 또는 누적 움직임, 중요한 발표, 소비 맥락 변화, 기존 해석의 수정 필요 중 하나가 있다 | 기존 보고서 유지. 새 초안 없음 |
| 새 정보 확인 | 이전 보고서 및 이전 시도와 비교해 설명을 추가·수정할 정보가 있다 | 중복 또는 추가 해석 없음. AI 호출 없음 |
| 근거와 설명 범위 확인 | 원문·대상 기간·통화 관련성·귀속이 확인되고 주장에 필요한 시점이 충족된다 | 근거 확인 중. 확인 가능한 사실만 별도로 표시 |
| 비용과 호출 권한 확인 | 별도 승인된 호출 범위와 예약 예산이 남아 있다 | 비용 또는 승인 대기. 기존 보고서 유지 |
| 초안 검토 | 기존 구조·안전·수치·문장별 근거·독자 가치 검사를 충족한다 | 미채택 초안 보존. 자동 재작성·모델 교체 없음 |
| 발행 승인 | 초기에는 관리자가 해당 원고를 승인한다 | 검토 대기. 공개 최신 보고서를 교체하지 않음 |

경제 발표가 있어도 별다른 새 정보가 없으면 생성하지 않는다. 금리 동결처럼 수치가 같아도 공개 성명에 중요한 새 내용이 있으면 검토할 수 있다. 무엇이 달라졌는지 원문으로 확인해야 하며, 예상과의 차이는 발표 전에 확보한 같은 기준의 예상 자료가 있을 때만 쓴다.

## 새 정보와 중복의 기준

중복은 입력 파일의 해시와 별개로 판단한다. 같은 사건의 다른 기사, URL 변경, 수집시각 변경, 환율 소폭 갱신은 그 자체로 새로운 설명이 아니다.

비교 단위는 통화·사건 종류·대상 기간·공식 발표 또는 정책 결정·발표 버전과 설명 범위다. 같은 사건이라도 실제 집행, 유의미한 수정, 새로운 반대 근거가 확인되면 다시 조사할 수 있다. 같은 통신사나 기관의 재인용을 독립된 근거로 세지 않는다.

마지막 공개 보고서와 함께 이전 생성·보류·실패한 시도도 비교한다. 기존 실패 원고를 같은 자료로 계속 생성하지 않는다. 의미적 중요성 판단과 원문 지지 검토는 해시 일치 검사로 대체할 수 없다.

첫 보고서는 비교할 이전 발행본이 없으므로 별도 초기화 검토가 필요하다. 이것을 매일 생성의 예외나 자동 발행 허가로 사용하지 않는다. 현재 모델 비교본은 초기 공개 보고서로 승인된 원고가 아니다.

## 변동과 시간 관계의 기준

기존 [변동 검사](../../scripts/currency-report/evidence-quality.js)는 과거 관측값의 상대적인 변동 폭과 절대 하한을 함께 사용한다. 현재 일간 주목 기준은 0.75%와 과거 절대 변동의 80분위 중 큰 값, 급변 기준은 1.5%와 95분위 중 큰 값이다. 이 수치는 기존 코드의 상태이며 이번에 승인된 운영 임계값이 아니다.

누적 변화는 5관측일 및 이전 보고서 이후 변화를 별도로 살핀다. 관측 수가 적거나 휴장 이월값·보간값이 섞이면 의미 있는 움직임으로 확정하지 않는다. 누적 변화의 숫자 기준은 통화별 자료와 대조 사례를 검토한 뒤 정한다. 기사 수와 감정적인 제목은 중요도 판단 근거로 사용하지 않는다.

발표 시각, 사건 시각, 가격 관측 시각, 자료 수집 시각을 분리한다. 수집 시각을 실제 가격 관측 시각으로 대신하지 않는다. 발표 이후 가격이 있어도 단위·시장·비교 구간이 맞지 않으면 직접 연결하지 않는다.

- 시간과 근거가 맞으면 검토한 출처의 설명 범위 안에서 환율 반응을 다룬다.
- 정책 내용은 확인됐지만 이후 가격이 없으면 정책 업데이트만 검토한다. 환율 반응은 대기한다.
- 기사 장중 가격과 저장 환율의 기준이 다르면 별도 관측으로 표시한다. 동일 움직임으로 합치지 않는다.
- 휴장·주말에는 가격 변화로 생성하지 않는다. 실제 정책 발표가 있으면 그 발표 자체는 별도로 확인할 수 있다.

기존 급변 원인 차단을 풀어 정책 업데이트를 만드는 방식은 사용하지 않는다. 구현 시 목적별 자격 판단을 분리하고, 기존 원인 설명의 시점·근거 보호를 유지하는 설계가 필요하다.

## 경제 일정과 출처 계획

내부 일정은 국가·관련 통화·발표 예정 시각·시간대·대상 기간·공식 URL·일정 수정 여부를 기록한다. 발표 후 실제값·이전값·수정값을 연결하며 예상치는 출처와 이용 조건을 확보한 경우에만 저장한다. 일정이 지났다는 사실만으로 발표 완료로 바꾸지 않는다.

공식 일정과 발표 원문을 우선하고 시장 보도는 실제 반응과 출처 귀속 해석에 사용한다. 캘린더의 존재, 기계 수집 가능성, 실제 발표 원문 확보는 별도의 확인 항목이다. 다음 단계에서 출처별 지원 상태·접근 방식·시각 정확도·이용 조건·비용을 조사한다.

Investing.com은 캘린더 화면과 보조 확인의 후보로 유지한다. [공식 위젯](https://www.investing.com/webmaster-tools/economic-calendar)은 화면 표시 경로이며, 데이터의 수집·저장·AI 입력 재사용 허가를 대신하지 않는다. [이용 조건](https://www.investing.com/about-us/terms-and-conditions)에 데이터 재사용의 사전 허가 요구가 있으므로 내부 수집 경로로 확정하지 않는다. 이 단계에서 위젯을 설치하거나 새 데이터 계약을 체결하지 않는다.

## 확인 주기와 독자 상태

하루 한 번 최신 자료가 준비된 뒤 판단하는 안을 유지한다. 실시간 생성, 발표 직후 자동 호출, 주간 정기 리포트의 강제 발행은 초기 범위에서 제외한다. 계획 수립과 별개로 실제 스케줄은 만들지 않는다.

현재 [기존 작업 일정](../../.github/workflows/generate-data.yml)은 한국시간 오전 9시 15분에 설정되어 있다. 이는 실행 완료나 실제 관측값 도착 시각의 보장이 아니다. 보고서 확인 시간은 환율 자료와 현지 발표가 도착하는 시점을 조사한 뒤 확정하며, 기존 데이터 갱신·이메일을 보고서 생성 때문에 기다리게 하지 않는다.

| 독자 상태 | 의미 |
| --- | --- |
| 새로 발행됨 | 검토와 승인을 거친 새 보고서가 있음 |
| 추가 해석 없음 | 정상적으로 확인했으나 기존 보고서에 보탤 새 설명이 없음 |
| 배경 확인 중 | 움직임이나 사건은 확인했으나 설명 근거를 확인 중 |
| 자료 확인 실패 또는 지연 | 정상적으로 확인하지 못함. 변화 없음과 다름 |
| 기존 해석 재검토 중 | 새 자료가 이전 설명과 충돌하거나 오류 가능성이 확인됨 |
| 검토 대기 | 새 초안이 있으나 발행 승인이 없음 |

보고서의 기준일·본문·수치·차트는 발행 당시 상태로 고정한다. 최근 확인 시각만 갱신했다고 보고서가 새로 발행된 것처럼 표시하지 않는다. 실제 오류가 확인된 원고는 단순히 오래된 보고서로 계속 권하지 않고 오류 안내·접근 처리와 감사 이력 보존을 별도 승인 절차에서 다룬다.

## 실제 저장 사례의 정책 검토

아래 두 건은 저장 자료에 대한 오프라인 정책 판단이다. 새 정책 실행 결과나 당시 실시간 발행 시험이 아니며 과거 비용·원고·승인·점수를 바꾸지 않는다. 신규성 비교에 필요한 이전 발행본과 당시 자료 버전이 완전하지 않으므로 자동 생성 자격 통과로 표시하지 않는다.

| 저장 사례 | 확인된 사항 | 기존 제한과 계획상 처리 |
| --- | --- | --- |
| CLP 2026년 10월 5일 | 검토한 기사에 정부 달러 공급 계획·시장 해석이 있음. 저장 가격의 실제 관측시각은 없음 | 정책 사건은 조사 후보. 저장 일간 변동의 직접 원인으로 합치지 않음. 정책 내용과 출처 귀속 해석에 한정한 초안은 신규성·근거·비용 확인 후 별도 검토. 기존 비교본의 발행 보류 유지 |
| BRL 2026년 10월 7일 | 저장 일간 변화 +0.24%, 5관측일 변화 -4.27%. 기사에는 이전 두 거래일 선거 반응과 당일 오전 조정이 구분됨. 저장 가격의 실제 관측시각은 없음 | 기존 일간 calm 차단과 별개로 누적 변화 조사 필요. 기사 장중 가격을 저장값의 직접 원인으로 연결하지 않음. 이전 설명과의 신규성 및 원고 품질 미통과이므로 생성·발행 승인 없음 |

근거 기록은 [칠레 하네스 비교](harness-comparison-results.md), [브라질 하네스 비교](brazil-harness-comparison-results.md), [작성 모델 비교](writer-model-suitability.md)에 보존되어 있다. 두 날짜만으로 적정 발행 빈도나 모델의 운영 적합성을 결론 내리지 않는다.

## 비용과 승인 경계

현 단계의 실제 AI 호출 허용 건수는 0이다. 모델 비교에서 승인했던 호출 횟수는 이미 사용했으며 남은 예산액을 새 호출 권한으로 재사용하지 않는다.

초기 실제 생성 시험은 별도 예산 승인 후 통화별 하루 최대 한 번이라는 상한안을 검토한다. 생성 실패·내용 미통과에 대한 자동 재작성과 자동 모델 교체는 하지 않는다. 검색·생성·검토 비용을 합산하며 미확인 비용의 예약을 유지한다. 시장이 중요한 날이라고 비용 한도를 자동 초과하지 않는다.

예산이 부족하면 기존 보고서를 유지하고 조사·확인 가능한 상태만 제공한다. 월 예산, 호출당 상한, 장애 재시도와 검토 호출 포함 여부는 가격·자료 확보 비용과 필요한 원고 수를 확인한 뒤 별도 결정한다. 모델별 실제 비교 비용은 운영비 보장이 아니다.

## 다음 계획 단계의 완료 조건

2026년 10월 11일 [경제 일정과 공식 출처 검토](source-feasibility.md)에서 공개 응답·명세·시각·재사용 조건을 구분했다. 인증 API, 일부 자료의 이용 조건, 실제 관측시각과 지속 수집은 아직 미확인이므로 수집 준비 완료로 표시하지 않는다.

같은 날짜의 [필수 지표와 환율 비교 기준안](indicator-price-plan.md)은 초기 지표 후보와 저장값·기사 관측의 구분을 제안한다. [생성과 보류 기준안](generation-decision-plan.md)은 일간·5관측일·20관측일의 초기 조사 임계값과 신규성·근거 대기·정정 처리의 권장안을 구체화했다. 숫자는 로컬 평가용이며 운영 확정값이 아니다. 정확한 확인 시각·작성 모델·호출 예산은 아직 확정하지 않았다.

그 조사 결과와 통화별 판정 사례로 임계값·확인 시간·예산을 제안하고 사용자 검토를 받는다. 계획이 확정된 뒤 로컬에서 호출 없이 조사 후보와 보류 판단을 구현·평가한다. 실제 생성 품질 시험 및 운영 반영은 각각 별도 승인 단계다.
