후속 분류: [필수 교정과 편집 권고 기준](review-error-and-style-policy.md). 아래는 당시 평가 기록을 보존한다. ‘동일한 외화’는 단어 자체의 오류가 아니라 문맥과 적용 범위를 확인할 표현으로 좁혔으며, ‘장부상 환산’의 범위 확대는 필수 교정으로 유지한다.

2026년 10월 7일 실행. 칠레 2026년 10월 5일의 고정 환율과 새 원문 문맥으로 실제 네 단계 호출을 완료했다. 신규 비용은 **$0.044439750**, 미확인 비용은 $0이다. 자동 형식·안전 검사와 모델 재검토는 통과했으나, 별도 에이전트 내용 검토에서 표현 범위 문제가 남아 결과를 미채택 비교본으로 보존한다.

## 실제 호출과 비용

사용자가 승인한 신규 예산은 $0.38, 호출 최대 네 번, 교정 최대 한 번, 재시도 없음이다. 동일한 달러 금액·미헤지 조건의 환산 설명을 허용하고 헤지·선결제·계약 환율 예외를 보존했다. 이 승인은 원리 적용과 시험 실행에 대한 것이며 생성된 원고의 내용 승인이나 운영 게시 승인은 아니다.

모델은 전 단계 `google/gemini-3.8-flash`, 추론 medium이다. 최초 사전 검사에서 일반 Vertex 경로의 상태가 정상값이 아니어서, 실제 결제 호출 전에 동일 모델의 정상 ZDR 경로 `google-vertex/global/flex`를 선택했다. 네 단계 모두 이 경로에 고정했다. 수집 금지·ZDR·가격 상한을 유지했으며 전송 실패 후 제공자 변경이나 모델 재시도는 하지 않았다.

## 교정 결과와 별도 판단

첫 원고의 관찰 항목에 직접 업무 지시가 있어 안전 검사가 보류했다. 원고와 보류 기록을 그대로 보존한 뒤 검토 단계로 이어갔다. 새로운 생성 호출은 없었다. 모델 검토가 같은 문장을 교정 대상으로 지정했고, 교정 모델은 한 문장을 관찰 변수 설명으로 바꾸었다. 지정하지 않은 본문은 그대로다. 모델 재검토 결과는 `reviewed_revision`이고 교정 후 안전 검사에는 오류가 없다.

제공자용 단순 스키마뿐 아니라 생성·검토·교정·재검토의 원래 전체 JSON 계약도 오프라인에서 대조하여 네 단계 모두 통과했다. 이것은 문장의 의미를 확인했다는 증거가 아니다. 수정 후 기존 ledger와 승인 해시는 무효화된 상태를 유지하며 과거 내용 승인이나 점수를 복사하지 않는다.

별도 에이전트 검토에서 다음 문제가 남았다.

- 요약의 **공식 관측 이후**는 저장 데이터에 없는 공식성을 부여한다. 실제 관측시각은 미상이고 확인한 것은 수집시각이다. 저장 자료와 이후 장중 보도라는 구분으로 좁혀야 한다.
- 영업 의미의 **동일한 외화·장부상 환산**은 승인된 같은 달러 대금의 조건부 환산보다 범위가 넓다. 다른 외화의 결제나 장부 평가 효과를 추정하지 말고 달러 결제 환산액으로 명시해야 한다.
- **원자재·대외 통화 여건** 대신 구리·글로벌 달러를 명명해야 설명이 구체적이다. 요인 나열형 제목도 독자가 기억할 핵심 해석을 전달하는 데 부족하다.

에이전트 잠정 평가는 원인 설명 3, 변화 전달 3, 영업 관련성 3, 가독성 4, 근거 충실도 3으로 평균 **3.2/5**다. 같은 에이전트가 당시 평가한 이전 원고의 평균도 3.2였다. 근거·입력·제공 경로가 바뀐 단일 사례의 잠정 판단이며 사용자 평가 또는 통계적으로 입증된 품질 비교가 아니다. 기준인 평균 4점·근거 4점·중대한 오류 없음에는 미달한다.

이번 시험은 **네 단계가 동작하고 비용을 확인할 수 있음**을 보여 주었다. 같은 모델의 검토가 범위 확대 표현을 놓친 사례도 보여 주므로, 모델 검토 통과만으로 게시할 수 없다. 이 원고를 임의로 추가 수정하거나 유료 재생성하지 않았다.

## 구현과 보존

공통 규칙은 `currency-rules/3`이다. 환산 원리는 기사 ID를 억지로 붙이지 않고 계산된 사실과 명시적 조건부 가정을 연결할 수 있게 했다. 이 형식은 `usd-payment-conversion`에 한정되며 사람 적용 승인·패킷/레지스트리 해시·달러 표시 방향·예외를 계속 요구한다. 다른 원리의 기사 근거 요건은 유지한다. 이전 원리 목록·원고·비용 기록과 규칙 버전은 변경하지 않았다.

`scripts/currency-report/run-clp-editorial-trial.js`는 단계별 요청·사전 확인·미확인 비용 예약을 전송 전에 저장하고 중복 단계·입력 초과·총예산 초과를 차단한다. `resume-review`는 이번 저장 원고의 업무 지시 오류에 대한 단 한 번의 검토 재개다. 원문 JSON과 응답 해시를 대조하며 생성 결제를 반복하지 않는다. 비밀값·구조·참조·ledger 오류는 이 예외로 넘기지 않는다.

private 실행 폴더: `.local-reports/private/clp-20261005-editorial-trial-v1/`. 최초 `result.json`과 이후 `result-after-review.json`을 별도로 보존한다. 정제 결과만 로컬 화면에 제공한다.

[실제 결과 A안](http://127.0.0.1:4175/local-experience.html?mode=live-local&design=a&run=CLP-2026-10-05-1791378393983#report/CLP/2026-10-05)은 `rejected`, `publishedAt=null`, `preferred=false`다. 환율·차트는 보존했고 원문 발췌·실행 원문·검토 기록·키를 공개 응답에 넣지 않았다. RBA 일반 원리 링크는 시장 기사와 구분해 표시한다.

## 검증과 다음 개선

전체 54개 파일·290개 정의·374개 실행 사례가 통과했다. 정확한 중복 이름·동일 본문·자기 비교 감사는 검출 0건이다. 타입·린트·운영/리포트 빌드·번들 경계가 통과했고 기존 804,454바이트 경고는 유지한다. 의미적 테스트 중복 전체를 증명한 것은 아니다.

A안의 실제 실행 URL과 기준일·수치·출처 펼침·원리 링크를 브라우저에서 확인했다. 모바일 폭 390px 설정의 유효 콘텐츠 폭은 375px이며 문서 폭도 375px로 수평 넘침은 없었다. PC·모바일 전체 화면 JPEG를 `artifacts/clp-20261005-editorial-trial-desktop.jpg`, `artifacts/clp-20261005-editorial-trial-mobile.jpg`에 저장했다. 화면 새로고침은 AI를 호출하지 않는다.

다음 개선은 **원고의 출처 범위와 주장 종류를 검토자가 실제로 구분하는지**에 집중해야 한다. 공식성·관측/수집 시각 혼동, 달러/일반 외화 확대, 결제 환산/장부 평가 확대를 고정 실패 사례로 추가하고 검토 프롬프트·판별 기준을 보완한다. 실제 추가 모델 호출에는 새 실행 범위와 예산이 필요하다. 이번 호출 예산이 남았다는 이유로 새 요청을 만들지 않는다.
