# 선택 출처 수집 → 근거 카드 검토 연결

2026-10-27 · 로컬 구현·실제 무료 조회와 저장 응답 재생 · 새 리포트 생성 없음

후속: [INEGI 지표 연결](mexico-api-verification-20261027.md#inegi-리포트-지표-연결--2026-10-27-후속). 일반 수집기의 무인증 기본값은 유지하고 전용 로컬 인증 경계에서 소매·월간 물가·연간 물가의 안전한 응답 투영을 받아 같은 수집·카드 검토 경로를 재사용한다. 4개 실제 수치 카드를 검토했으며 이용·집필·게시 승인은 별도다. 아래 최초 국가별 상태를 이력으로 남긴다.

## 연결한 흐름

**6개국 질문·출처 선택 → 선택한 조회만 실행 → 원본·해시·실제 수집시각 보존 → 추출 결과와 실패 상태 분리 → 근거 카드 검토 대기 → 명시적 검토 기록으로 기존 자료·범위 카드 생성**

질문 계획기와 등록부, 브라질 `normalizeSnapshot`, 공개 기사 `readPublicText`·`collectOriginal`, 칠레 월간 PDF 발견·저장·검토 도구, 기존 사실·견해 요지 및 범위 카드 검사를 재사용했다. 국가별 집필 지침이나 별도 모델 호출을 만들지 않았다.

실행은 로컬에서 명시적으로 선택한 출처만 대상으로 한다. 기본은 저장 자료 모드다. 실제 조회는 `live`를 지정하고 무료 공개 GET만 허용한다. 키·환경 파일·운영 DB는 읽지 않는다. 선택한 출처의 설명문을 임의의 실행 URL로 쓰지 않는다. 최대 8개 선택 조회, 기본 실제 요청 8회·설정 상한 16회, 요청별 기본 15초, 자동 재시도 0회다. 등록된 뉴스 목록에서 같은 호스트의 후보를 최대 2개 읽으며 후보 제목은 근거로 승인하지 않는다.

## 국가별 실제 결과

아래의 질문·대상 범위는 로컬 연결 시험을 위해 명시한 입력이다. 실제 발행 판단이나 새 보고서가 아니다.

| 통화 | 실제 사용한 자료 | 결과와 남은 검토 |
| --- | --- | --- |
| BRL | BCB 정책금리·IBGE 소매 API 새 조회 | 연결 실패로 기록. BCB는 실행 제한 밖 진단도 시간 초과. 정상 수치·변화 없음으로 처리하지 않음 |
| MXN | El Economista 목록·공개 기사 2건 새 수집 | 기사 검토 대기 2개. Banxico·INEGI 지표는 인증/시리즈 설정 필요. 금·달러 기사와 멕시코 환율 기사의 관련성을 같은 수준으로 승인하지 않음 |
| COP | 기존 SFC 원자료의 10월 1~26일·3행 제한 정상 빈 응답 | `empty_result`. 해당 조회 범위의 빈 결과이며 국가 전체 금융 자료 부재나 최신성 확인이 아님 |
| PEN | 기존 BCRP 금리 3시리즈·6~9월 원본 | 12개 관측 보존, 9월 소비자금리 요청과 연결. 1개 검토 대기 카드. 신용카드 상품의 9월 값만 별도 명시적 범위 검토로 연결 |
| CLP | 기존 INE 8월 소매 PDF 원본 | 해시·바이트 대조 후 기존 PDF 검토 계약에 연결. 10월 소매 실적이나 환율 원인으로 바꾸지 않음 |
| ARS | Infobae 목록·공개 기사 2건 새 수집 | 기사 검토 대기 2개. 27일 게시물을 26일의 당일 기사로 승인하지 않음. 도매·금융·소매 달러의 가격 기준 검토 필요 |

수집 명령의 실제 요청은 뉴스 6회와 브라질 실패 2회다. 브라질 연결 진단 2회는 별도로 실패했다. 저장 자료 최종 재생은 네트워크 0회다. 모든 단계에서 모델 호출과 새 유료 비용은 0이다.

같은 기사에 대한 여러 질문은 다운로드·원본·카드를 공유하고 질문 연결은 유지한다. 자료 하나의 여러 링크를 독립 원인 근거 여러 건으로 세지 않는다.

## 반환 상태

| 상태 | 의미 |
| --- | --- |
| `collected_pending_review` | 읽기·추출이 끝났으며 내용·기간·사용 범위 검토 대기 |
| `partial_pending_review` | 확보 자료와 실패/미조회 후보가 함께 있음 |
| `empty_result` | 정상 구조의 응답에 행이 없음. 조회 범위 밖 부재는 입증하지 않음 |
| `period_mismatch` | 원본은 확보했으나 요청 대상 기간의 관측이 없음 |
| `values_missing` | 해당 기간의 값이 결측. 빈 문자열·n.d. 등을 0으로 바꾸지 않음 |
| `access_failed` | 전송·HTTP·접근·유료 벽 실패 |
| `extraction_failed` | 본문 경계·JSON·스키마 추출 실패 |
| `no_candidates_in_listing` / `no_candidates_in_index` | 확인한 목록에서 후보를 못 찾음. 자료가 어디에도 없다는 뜻이 아님 |
| `not_attempted` | 저장 응답 없음 또는 요청 예산 소진. 실패·부재와 구분 |
| `configuration_required` | 토큰·시리즈·정확한 발표 경로 연결 필요 |
| `revision_conflict` | 같은 대상의 서로 다른 원본이 있어 버전 선택·수정본 검토 필요 |

발표일·수집일·요청 기간·실제 관측 기간을 따로 유지한다. 기사에는 발표일 일치 여부와 현재 페이지/수정시각을, PDF에는 본문 대상 기간 미검증 상태를 표시한다. 수집이 과거 보고서 기준시각 뒤라면 그 사실도 기록한다. 정상 추출은 당시 이용 가능성 증명이 아니다.

## 카드 검토와 입력 경계

검토 카드는 원본·출처·질문·기간·내용 해시에 묶는다. 기간·모집단·비교·발표/관측 시각·귀속·가격 기준·수정본·자료 사용 범위를 확인하도록 기존 범위 검사 항목을 사용한다. 원본이나 선택 내용을 바꾸면 예전 검토 기록을 재사용하지 못한다.

- **뉴스:** 검토자가 새로 작성한 사실·귀속 견해 요지와 그 요지를 지지하는 본문 위치·판단 이유를 받는다. 기존 `createReviewedNewsEvidence`와 `bindEvidenceScope` 검사를 사용한다. COP·PEN·ARS도 동일한 요지 카드 계약을 사용한다. 가격 숫자 계약을 임의로 다른 통화로 확장하지 않았다.
- **통계:** 검토자가 선택한 관측 행·단위·대상 기간·허용 문장을 기존 범위 카드로 만든다. 원본 JSON 해시와 정규화 변환을 보존한다. 단위가 미검증인 SFC 행, 다른 기간, 결측은 통계 카드 검토 완료로 통과시키지 않는다.
- **칠레 PDF:** 기존 저장 manifest·원문 PDF·추출·검토 도구를 그대로 사용한다. 새로 받은 PDF도 같은 저장 형식으로 넘긴다. PDF를 받았다는 이유로 본문 확인을 완료하지 않는다.

실제 PEN 저장 원본에서 9월 신용카드 시리즈 PN07845NM의 실효 연율 64.77%(원값 반올림)를 확인해 제한된 범위 카드 1개로 연결했다. 같은 에이전트의 수치·범위 대조이며 독립 품질 평가가 아니다. 정확한 발표시각은 원본 응답에서 확인하지 못했으므로 null을 유지했다. 사용 범위·집필 자격·게시 승인은 자동으로 통과시키지 않았다.

기사 본문은 비공개 수집 자료에만 저장하고 모델이나 브라우저로 전달하지 않았다. 새 기사 4건의 사실·견해 사용 승인과 독립 내용 검토는 아직 대기다. 수집 코드가 문장의 의미적 지지를 자동 확정한다고 주장하지 않는다.

## 실제 저장 자료에서 발견해 수정한 부분

1. COP의 기존 `between … and …` 날짜 조건도 같은 범위를 검증해 재사용한다. 선택 필드·기간·행 제한이 맞지 않으면 재사용하지 않는다. 기존의 빈 응답이 저장 파일 없음으로 잘못 분류되던 것을 고쳤다.
2. 기사 JSON-LD와 메타 태그가 같은 시각을 `-0600`/`-06:00`으로 적거나 초/밀리초 정밀도로 적은 경우를 구분했다. 같은 순간의 표기는 정상화하고 초 단위 공통 정밀도를 보존한다. 두 정밀한 시각이 실제로 다르면 계속 충돌로 남긴다. 관측시각을 기사 발표시각으로 채우지 않는다.

모두 저장 응답을 재생해 검증했으며 기존 원본·이전 판정은 덮어쓰지 않았다.

## 재현 명령과 결과 위치

```powershell
npm.cmd run report:research:collect-selected -- --input .local-reports/private/selected-source-collection-20261027/input-PEN.json --sources pen-financing --saved .local-reports/private/selected-source-collection-20261027/cache-PEN.json --mode saved
```

실제 새 읽기는 `--mode live`로 명시한다. 저장된 호환 응답이 있으면 먼저 재사용한다. 서로 다른 수정본을 자동 선택하지 않는다. 새 결과는 `.local-reports/private/selected-source-runs/collection-*/`에 생성하며 원본 캡처·검토 대기·수집 상태를 분리해 보존한다.

```powershell
npm.cmd run report:research:review-selected -- --collection <비공개 result.json> --card <검토 카드 ID> --receipt <명시적 검토 JSON>
```

검토 명령은 새 디렉터리 `.local-reports/private/selected-source-reviews/review-*/`에 자료·범위 카드만 만든다. 원고·DB·메일·모델·배포로 자동 전달하지 않는다. 실제 로컬 확인 요약은 `.local-reports/private/selected-source-collection-20261027/final-replay-summary.json`에 있다. [국가별 API와 토큰 준비 안내](research-api-access-20261027.md)를 별도로 제공한다.

## 검증과 남은 범위

전체 회귀 100파일·715사례, 타입·린트·운영 빌드·리포트 빌드·번들 경계 검사를 통과했다. 마지막 PDF 요청 예산 상태 보완 뒤 관련 3파일·34사례를 재확인했다. 테스트 목록의 완전 중복 이름·본문·자기 비교 신호는 없으며 의미상 중복 전수 증명이나 실제 원고 715개 평가라는 뜻이 아니다. 기존 500 kB 진입 번들 경고는 유지한다.

보존 목록 27,061개 대조에서 이번에 의도한 기존 코드·명령·문서 7개 외 27,054개 내용은 유지됐고 예상 밖 변경·누락은 없었다. 새 파일은 별도 추가했다. 기존 환율·원고·원본 응답·비용 기록과 운영 설정을 보존했다. 새로운 자료는 기존 제외 정책에 따라 비공개 로컬 경로에만 저장했다.

합성 검사는 잘못된 해시·다른 등록 버전·수정본 충돌·기간 불일치·결측·잘못된 JSON·HTTP 실패·유료 벽·실제 요청 상한·근거 위치 누락·원본 변경·표시 시각 정밀도를 확인한다. 실제 자료는 PEN·COP·CLP 저장 원본과 MXN·ARS 새 기사이며 합성 자료와 구분해 기록했다.

남은 범위는 브라질 새 응답 확인, 멕시코 인증/지표 연결, COP 최신 기간·단위/집계 확인, INDEC·INEI 등 미연결 본문, 새 기사별 내용·사용 범위 검토다. 이 결과는 **수집과 카드 검토 연결**이며 6개국 자동 집필·발행 또는 2.0 출시 완료가 아니다.
