# 리포트 화면 이름과 국가 이동 정리

2026-10-31 KST · 사용자 화면 검토 반영 · 로컬 변경

## 바뀐 기준

기존에는 국가 탭이 최신 본문을 열고, ‘지난 리포트’만 목록을 열었다. 국가별 목록끼리 비교하려는 동작과 최신 본문 바로 읽기가 같은 국가 선택에 섞여 있었다. 국가별 목록의 이름도 최신 글까지 포함하는 화면과 맞지 않았다.

| 화면/버튼 | 이름과 도착점 |
|---|---|
| 리포트 메뉴 첫 화면 | ‘국가별 리포트’. 전체 국가의 최신 요약과 각 국가 목록 진입 |
| 국가 탭 앞의 항목 | ‘전체 국가’ → 국가별 요약 화면 |
| 브라질·멕시코 등 국가 탭 | 항상 해당 국가의 리포트 목록. 본문에서 눌러도 같음 |
| 국가별 목록 제목 | ‘브라질 리포트’, ‘칠레 리포트’ 등. ‘지난’ 표현 제거 |
| 목록의 제목 | 해당 날짜 리포트 본문 |
| 본문의 복귀 버튼 | ‘← 칠레 리포트 목록’ 등. 해당 국가의 선택 기간/목록으로 복귀 |
| 최신 본문 바로가기 | ‘최신 리포트 읽기’ 또는 대시보드/추이의 ‘CLP 최신 리포트’처럼 목적을 명시 |

리포트 안에는 환율 추이/대시보드로 돌아가는 전용 버튼을 두지 않는다. 다른 메뉴로 이동할 때는 상단의 공통 메뉴를 사용한다. 환율 추이에서 리포트로 들어오는 기존 진입은 유지한다.

국가 탭을 바꾸면 새 국가의 전체 기간 목록을 보여준다. 기존 국가의 연도/월 때문에 다른 나라 자료가 없다고 오해하지 않도록 기간을 자동 승계하지 않는다. 같은 국가에서 본문을 읽고 목록으로 돌아올 때는 기존 기간과 불러온 범위를 복원한다.

## 주소 호환

- 국가 탭은 기존 `#report/BRL/history` 등 목록 주소를 사용한다.
- `#report/BRL`은 기존 최신 본문 바로가기 주소로 유지한다. 국가 탭에서는 이 주소를 사용하지 않는다.
- 날짜·공개 ID 주소, 정정·철회·캐시·조회 경로는 변경하지 않았다.
- 환율 추이 복귀용 내부 상태 연결은 제거했다. 브라우저 자체의 뒤로가기와 추이의 선택 상태는 그대로 사용할 수 있다.

이 문서가 이전 이력 계획/구현 결과의 ‘지난 리포트’ 표시명과 ‘원래 추이 복귀 버튼’에 대한 최신 기준이다. 해당 문서의 이전 검증은 당시 동작 기록으로 보존한다.

## 확인 결과

후속 시각 검토: 독자 화면에 남아 있던 ‘게시 상태 다시 확인’ 박스 버튼을 국가 탭 우측의 작은 아이콘·텍스트 ‘새로고침’ 보조 동작으로 정리했다. PC 높이36px,390px 화면 터치 높이44px·가로 넘침 없음·실제 재조회 확인. 타입/린트·로컬 앱 빌드와 기존 탐색2사례 통과. 자동 확인과 오류 시 다시 시도는 유지하며 새 유료/운영 호출은 없다.

- 6개 국가 탭을 실제로 눌러 각 국가 목록 주소·제목을 확인했다.
- 칠레 본문에서 브라질을 누르면 브라질 목록으로 이동한다.
- 칠레 본문의 복귀 버튼이 칠레 목록으로 돌아가며 연도2026 조건도 복원한다. 새로고침 후 목록을 유지한다.
- 리포트 영역에 환율 추이로 돌아가는 버튼이 없다.
- 관련4파일9사례, 타입·해당 린트, 운영/기존 앱 로컬 빌드와 번들 경계 검사 통과. 신규2사례는 국가 탭 목적지와 국가 목록 이름/복귀 경계를 확인한다.
- 기존 SVG title의 서버 렌더링 경고와 >500kB 번들 경고는 남아 있다. 이번 메뉴 연결에서 새로 생긴 실패로 분류하지 않았다.
- 원고·환율·DB 변경, 추가 유료 호출, 운영 반영은 없다. 소스 사본은 기존 비공개 제외 영역 `report-navigation-20261031`에 보관했다.
