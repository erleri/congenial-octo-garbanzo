# 6통화 근거의 공통 기준환율 정책 재연결

2026-10-28 · Sol 로컬 구현·저장 자료 재생 · 새 조사/모델 호출/운영 변경 없음

## 완료한 작업과 검토 대상

**기존 근거를 여섯 통화에 같은 규칙으로 다시 연결했다.** 대시보드 기준환율의 숫자는 그대로 두고 시장 관측·귀속된 원인 해석·글로벌 맥락·반대 조건·소비 배경·정책 배경·관찰 항목을 분리한다. 국가별로 느슨한 예외를 새로 만들지 않았다.

대상 가격은 이전에 저장한 10/28 배포 정적 JSON이다. 뉴스 검토 대상 거래일은 **10/27로 명시적으로 선정**했다. 기준환율 날짜에서 전일을 계산해 현지 거래일로 인증한 것이 아니다. 기존 9/24·10/26 자료는 원래 날짜를 유지하며 10/27 설명으로 승격하지 않는다.

새 연결은 `reference-materials/1`, 공통 가격은 `shared-dashboard-report/3`·`dashboard-reference-policy/1`이다. 회사 환율과 현재 API 값의 동일성은 사용자 확인 전 작업 가정이라는 상태를 유지한다.

‘최종 내용 검토 준비’는 저장된 근거의 구조·기간·기존 용도 판단을 연결했다는 뜻이다. 새 독립 내용 심사·새 모델 품질 시험·게시 승인이 아니다. 원인 자료가 부족한 세 통화도 지원 불가 국가로 처리하지 않는다.

## 먼저 확인한 COP·PEN·ARS 조건

### COP

기존 9/24 La República 카드에는 Corficolombiana의 Mauricio Acevedo가 현지 달러 잔고·결제 수요를 설명한 귀속 견해가 있다. 이 세 주장은 **9/24 역사 검토**로 남겼다. 10/27 설명의 근거로 복사하지 않았다.

공통 인계에는 더 최근의 저장 10/26 La República 자료와 8월 DANE 소매 자료를 선택했다. 10/26 보도도 10/27의 당일 원인으로는 사용하지 않는다. 선택 이유는 비공개 `input-selection.json`에 기록했다. 새 기사를 조사하거나 오래된 자료를 새로 검토했다고 표시하지 않았다.

DANE의 정확한 출처 표기 `Fuente: Departamento Administrativo Nacional de Estadística: www.dane.gov.co`가 기존 조건과 실제 인계의 출처 표시 양쪽에 있는지 재검사했다. 저장된 제한적 외부 입력 판단은 유지하고 공개 표시는 pending이다. 기관 약관의 새로운 법적 해석을 추가하지 않았다.

### PEN

Gestión 10/26 카드와 INEI 보고서를 분리했다. INEI 자료의 **발표일 10/15 / 대상 8월**, 생산·상업활동의 범위와 외부 모델 이용 pending 상태를 보존했다. 이를 10월 소매·가전 셀아웃 또는 당일 환율 원인으로 바꾸지 않았다.

기존 Revista Economía 10/27 후보의 검토 카드 바인딩과 두 요지를 재확인했다. 같은 날 시가→종가 비교와 Felipe Mendoza의 달러·금리 경계감 해석은 후보에 남아 있다. 다음 상태를 구분했다.

- 과거의 `PEN_price_pair_and_shared_price_adapter_missing` 조건은 현재 기준환율 정책으로 해소된 범주다. 기사에서 전일 종가를 더 구하는 과제로 돌아가지 않는다.
- 매체 수집 경로·이용 범위 및 다른 시장자료와의 시점 대조는 남아 있다.
- 후보에는 새 공통 집필용 범위/역할·이용 검토가 없으므로 임의 생성하지 않고 **집필 입력 미채택**을 유지했다.

이 결론은 원문 접근이 불가능하다거나 사실 카드 사용이 전부 금지됐다는 판정이 아니다. 저장된 자료만으로 이번 단계에서 확정할 수 있는 범위다.

### ARS

Infobae의 10/26 도매시장 설명과 INDEC의 8월 슈퍼마켓 지표를 분리했다. 슈퍼마켓 실질 매출 전년동월비 -3.7%·계절조정 전월비 -0.8%라는 기존 범위와 10/22 발표일을 유지했다. 회사·가전 판매 추정으로 확대하지 않았다.

현재 숫자는 공통 대시보드 기준환율이므로 이전 별도 BCRA 가격 쌍/API 이용 조건을 새 숫자의 필수 조건으로 계속 요구하지 않는다. **BCRA 자료를 실제 추가 인용하거나 전송할 경우의 조건은 여전히 별도**다. Infobae/INDEC의 기존 이용 판단을 BCRA에 확대하지 않았다. INDEC의 과거 수동 원문 확인 기록은 자동 반복 수집 성공으로 바뀌지 않는다.

10/27에 맞는 귀속 해설이 없다는 공백은 남긴다. 기존 10/26 도매 약세 설명으로 새 기준환율의 다른 방향 변화를 설명하지 않는다.

## 공통 코드에서 달라진 것

기존의 `projectEvidenceScopes`, `inspectDossier`, `projectFxWritingBackground`, `prepareCountryMaterials`, `inspectSourceUses`, 출처 표시 검사기를 재사용하는 `reference-materials.js`를 추가했다.

1. 기존 검토 해시와 역할·주장을 확인한다. 기록 ID가 존재하는 것만으로 내용의 지지를 새로 승인하지 않는다.
2. 시장 설명일을 명시적으로 받는다. 일치하지 않는 시장 주장은 archive로 보내며 대상일이나 숫자를 바꾸지 않는다.
3. 소비·정책·관찰 배경은 별도 역할로 연결한다. 발표일·실제 대상 월/분기·기존 검토의 기준일을 각각 보존한다. 소비 항목에 현지 거래일을 새로 만들지 않는다.
4. 외부 입력 allowed/pending/denied와 공개 표시 상태·필수 출처 조건을 유지한다. 공개 허가를 외부 입력 판단에서 자동 승계하지 않는다.
5. 연결물에는 채택된 주장과 그 근거 메타데이터만 투영한다. 이전 가격 facts·series·프롬프트·모델 원문 응답·사용한 호출 승인·평가 점수는 가져오지 않는다.
6. archive·held는 로컬 검토 기록이며 집필 전송 대상이 아니다. 향후 집필은 내용 검토와 이용 조건을 확인한 current sections만 사용해야 한다. 실제 요청은 이번에도 `null`이다.
7. 한 국가 자료가 잘못됐으면 그 국가의 `saved_material_invalid`로 기록한다. 가격 연결 실패로 오인하거나 다른 다섯 국가의 처리를 중단하지 않는다.

`six-currency-preparation/2` 파일 형식에는 선택적 `commentaryDate`를 추가했다. 지정하지 않은 기존 입력은 설명 대상일 선택 대기로 남으며 저장 날짜에서 전일을 추정하지 않는다. 과거 `historical_replay`와 기존 원고는 그대로 보존한다.

### 검증 중 수정한 기간 오류

월간/분기 표기를 날짜 문자열과 직접 비교하면 `2026-Q3`가 10/28보다 미래인 것처럼 판정될 수 있었다. `referencePeriodStart`를 공통으로 사용해 기존 국가 자료 검사와 새 연결에서 같은 방식으로 해석한다. 표기 원문은 유지하며 이 함수가 분기 전체의 완료·정확성까지 인증하는 것은 아니다. 실제 자료의 대상·비교 기준은 내용 검토에서 확인한다.

## 재현과 남은 검토

자료·검증 폴더: `.local-reports/private/reference-material-reconnection-20261028/`.

- `input-selection.json`: COP 자료 선택 이유. 기존 입력을 수정하지 않음.
- `manifest-*.json`, `replay-*.json`: 실행마다 새 파일과 새 공통 인계 폴더를 생성. 최초 및 후속 결과 보존.
- `replay.mjs`: 저장 JSON만 사용하는 재현 실행. 네트워크·키·유료 모델에 접근하지 않음.
- `supplementaryReview`: PEN 후보의 남은 조건과 COP 9/24 역사 자료 검토.
- `before.json`, `before-extended.json`: 원고·환율·비용·사용 입력/후보의 보존 기준.

최종 인계는 `.local-reports/private/six-currency-preparation-Mn9Bno/`다. `final-verification.json`에서 **6통화 숫자/계산 동일·채택 주장/발표일/사건일 보존·시장 설명일 유지·소비에 거래일 미생성·원문/이전 가격/승인 미복사**를 확인했다. 보호 104파일 변경/누락 0, 새 외부 요청·모델 호출·비용·운영 변경 0이다.

타입·린트·전체 **127파일/957실행 사례**와 운영/로컬 앱/리포트 빌드·번들 검사를 통과했다. 새 7사례는 6통화 공통 역할, 다른 거래일 보존, 소비 월/분기, 출처 용도/정확한 표시, 잘못된 역할/변경된 검토, 기준시각 및 명시적 설명일 경계를 확인한다. 기존 준비 검사에는 한 국가 자료 오류가 가격 오류로 바뀌거나 다른 나라를 막지 않는 검증을 추가했다. 테스트 이름/완전히 같은 본문/자기 비교 감사도 통과했으며 의미상 모든 중복 부재나 실제 AI 품질의 증거는 아니다. 기존 번들 경고와 진입 615,654바이트는 유지됐다. UI/DB를 바꾸지 않아 별도 화면·권한 시험은 새로 실행하지 않았다.

다음은 **Astra High 최종 내용 검토**다. 준비된 BRL·CLP·MXN은 해석이 원문 범위를 지키는지, 특히 BRL의 뉴스상 달러 하락을 기준환율의 다른 방향 변화에 연결하지 않는지 확인한다. COP·PEN·ARS는 원인 자료/이용의 미완료 사유를 함께 판단하며, 자료 부족을 통계 해설이나 일반 원리로 채우지 않는다. 이번 단계에서 새 원고·새 유료 호출·운영 적용 승인을 만들지 않았다.
