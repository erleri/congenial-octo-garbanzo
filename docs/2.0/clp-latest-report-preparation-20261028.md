# 칠레 최신 완료 거래일 리포트 집필 준비

2026-10-28 기준, 칠레 현지 10월 27일 거래를 설명할 Sol 집필 입력을 준비했다. 원문 추출 기능 시험용인 2024년 브라질 자료는 이번 입력에 사용하지 않았다. 실제 모델 생성은 별도 예산 승인 대기이며 운영 게시 승인이 아니다.

## 가격과 기사 판본

## 이용 범위와 자동화 경계

이전의 자체 작성 사실·귀속 견해 카드와 동일한 자원 구분을 적용했다. 짧은 사실·아이디어 요지를 새로 작성하고 귀속·기간을 보존하는 이번 카드만 로컬 분석과 외부 모델 입력 후보로 판단했다. 단순 번역·기사 대체 구성·제목의 연속 요약을 사용하지 않는다. 분량만으로 이용 적합성을 판정한 것도 아니다.

기사 원문 전체의 외부 전송·반복 서비스 수집·공개 본문 이용에 대한 기존 보류는 변경하지 않았다. 이 기록은 게시자의 원문 라이선스나 국가별 법률 결론이 아니다. 최종 생성 문장과 출처 표시·공개 승인은 별도로 검토한다. 원문용 2회 추출/대조 시험과 이전 $0.46의 카드 검토 승인은 이번 집필 승인에 사용하지 않는다.

이번 최신 한 건은 에이전트가 내용을 검토해 기존 집필 도구에 연결한 준비 결과다. 사용자에게 기사 수동 확인 작업을 넘기지는 않지만, 무인 서비스 전체의 원문 의미 검토가 완료됐다는 뜻은 아니다.

## 공통 연결 보완

`prepareNewsNotesInput`의 기본 역사 사례 동작을 보존하면서 `historicalCase=false`인 최신 거래일 준비를 구분했다. 과거 원고·비용·승인 기록을 다시 표시하거나 변경하지 않는다.

또한 이미 존재하던 `assessFxCauseInput`의 background 역할에 정책·소비 카드를 연결했다. consumer/watch 질문의 카드만 background로 들어가며, 이 카드를 그대로 driver로 지정하면 거부한다. 같은 거래일 설명과 이전/별도 발표 맥락을 구분해 공통 생성 입력에 넘긴다. 공개 리포트 구조와 URL, Sol 기본·모델 교체 경로는 유지한다.
