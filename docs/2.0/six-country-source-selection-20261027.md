# 6개국 질문·출처 선택 연결과 로컬 검증

2026-10-27 · 로컬 구현 · 신규 외부 조회·모델 호출 없음

## 완료한 범위

BRL·MXN·COP·PEN·CLP·ARS가 같은 질문 계획기와 출처 선택 경로를 사용한다. 기존 [질문별 출처](six-currency-explanation-sources-20261027.json) 24개와 [국가별 뉴스 경로](six-currency-source-register-20261027.json) 11개를 재사용한다. 35개는 등록 경로 수이며 자동 수집기 수나 승인된 근거 수가 아니다.

기존 질문 계획의 자료 기간·단위·출처 사용 범위·검토 상태 검사를 유지했다. 여기에 국가와 질문에 맞는 출처, 동일 조회의 공유, 이전 조회 결과를 연결했다. 기존 환율·원고·발행 판단·집필·운영 설정은 바꾸지 않았다.

흐름은 **국가·질문·대상 기간 → 기존 자료 점검 → 필요한 출처 선택 → 이전 조회 상태 결합 → 자료 상태와 조회 상태를 따로 반환**이다. 이번 경로는 여기서 끝난다. 새 자료 수집, 사실·견해 카드 작성, 내용 검토, 집필 자격, 게시 승인은 후속 단계다.

## 선택 기준과 호환성

- 환율 원인·반대 근거는 해당 국가 시장 기사 경로를 선택한다. 공식 통계만으로 당일 환율 원인을 대신 설명하지 않는다.
- 정책·소비·실질 보수·소비자금융은 등록된 자료 역할과 명시적인 지표 이름으로 고른다. 등록되지 않은 지표를 비슷한 자료로 자동 치환하지 않는다.
- 미국 공통 요인은 기존 공통 시장 지표 경로에서 선택한다. 연준 광의 달러지수를 DXY로 바꾸어 표시하지 않는다.
- ARS 분기 자료는 `2026-Q3`처럼 분기를 유지한다. 수집일을 지표 대상 기간으로 쓰지 않는다.
- 같은 공식 출처·대상 기간·통계 범위를 두 질문이 필요로 하면 조회 대상 하나를 공유한다. 질문별 자료 적합성 판단은 유지한다. 뉴스의 서로 다른 질문 의도는 임의로 합치지 않는다.
- 기존 자료 목록이 사용 가능 또는 충돌 상태이면 새 조회를 자동 추가하지 않는다. 검토된 자료 재사용과 불일치 확인은 기존 계획기에 맡긴다.
- 기존 세 통화의 월별 기본 입력은 기존 계획 버전과 식별을 유지한다. 새 세 통화 또는 분기 입력만 확장된 계획 버전을 사용한다.
- 기존 계획기의 조회 예산은 유지한다. 출처 후보 목록이 실제 조회 실행 또는 예산 증액을 허가하지 않는다.

출처 선택은 명시적으로 켜는 로컬 기능이다. 기존 CLI에 두 등록부를 함께 지정한다. 기존 명령은 그대로 작동하며 칠레 전용 범위 프로필과 새 출처 모드는 동시에 적용하지 않는다.

```powershell
npm.cmd run report:research:plan -- --input .local-reports/private/six-country-source-selection-20261027/input-PEN.json --source-plan docs/2.0/six-currency-explanation-sources-20261027.json --source-register docs/2.0/six-currency-source-register-20261027.json
```

명령은 명시한 로컬 JSON만 읽고 결과를 출력한다. 환경 파일·API 키를 읽거나 네트워크를 호출하거나 파일을 덮어쓰지 않는다. 예시 입력은 로컬 검증용이며 운영 입력이 아니다.

## 자료 부족과 조회 실패의 구분

| 반환 상태 | 의미 | 잘못 해석하면 안 되는 결론 |
| --- | --- | --- |
| `pending` + `not_attempted` | 출처는 선택했지만 조회하지 않음 | 자료 없음 |
| `no_registered_source` | 필요한 범위의 등록 경로가 없음 | 해당 국가에 자료가 존재하지 않음 |
| `missing_in_checked_sources` | 선택한 조회 대상 모두 빈 결과·미발표·해당 시리즈 없음으로 기록 | 모든 외부 출처에 자료 없음 |
| `stored_unreviewed` | 응답을 저장했지만 내용·사용 범위 검토가 필요 | 집필·게시 승인 |
| `metadata_compatible` | 기존 계획기의 자료 적합성 검사를 통과한 기존 목록 | 문장별 원문 지지·최신 수집 성공 |
| `conflict` | 기존 목록에 충돌이 있어 별도 판단 필요 | 임의 선택 후 자동 집필 |
| `lookupState=failed` | 접근·추출 실패가 있어 확인 불가 | 변화 없음·수치 없음 |
| `partial_failure` / `partially_checked` | 일부 성공·일부 실패 또는 미조회 대안 존재 | 조사 완료 |
| `scopeRequired` | 질문에 필요한 기간·통계 범위를 먼저 정해야 함 | 빈 요구사항으로 통과 |

출처 선택이 안 된 이유도 반환한다. 지표 매핑 미등록(`metric_mapping_required`)과 해당 범위의 경로 부재(`no_route_registered_for_scope`)를 구분한다.

조회 기록은 국가·기간·범위·출처 등록 내용·계획 식별에 묶는다. 다른 국가나 이전 출처 버전의 성공 기록을 붙일 수 없다. 중복 시도 ID, 기준시점 이후 기록, 잘못된 날짜, 저장 해시 없는 성공 기록을 거부한다. 이후 정상 응답이 생겨도 이전 실패를 삭제하지 않는다. 저장 해시는 응답의 식별값이며 내용 검토를 대신하지 않는다.
