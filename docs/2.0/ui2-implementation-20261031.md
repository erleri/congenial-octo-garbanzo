## 코드와 데이터 경계

- `src/ui2.css`: 기존 레이아웃 위의 공통 규칙. Dashboard/CurrencyDetail의 수치 계산은 유지.
- `src/lib/reports/`: 공개 표시·조회·캐시·연결. 로컬 DB 설정은 compile guard 뒤 동적 import. 생산 번들에 로컬 DB 설정/비공개 파일/서비스 키가 없음을 검사.
- `CurrencyReportReview`: 기존 운영 로그인/로그아웃 callback, 기존 active admin/RPC를 재사용. 신규 로그인 방식이나 권한 정책으로 교체하지 않았다. 로컬 계정 로그인은 기존 비밀번호 방식.
- 관리자 원고는 기본 실제 자료만 조회. 대기 전체 건수를 별도 확인하며 대기 최근20 + 이력 최근20 범위. 20개를 초과한 대기는 전체 수와 표시 제한을 알린다. 비용은 조회 범위에서 확인된 금액이고 누락 비용을 0으로 확정하지 않는다.
- 창을 벗어나거나 권한 확인이 실패하면 검토 자료를 지운다. 늦게 돌아오는 요청도 epoch로 차단한다. 서버 검증이 최종 권한 판단이다.
- `supabase/migrations/20261031095929_ui2_usage_daily.sql`: CLI 2.122.0으로 생성한 파일에 승인된 추가 SQL을 보존. 로컬에는 SQL로 시험했고 운영 적용 없음.
- `vite.ui2-preview.config.ts`: 운영 경로·로컬 공개 키만 사용하는 별도 프리뷰. 실제 기능 플래그를 변경하지 않는다.

## 이용 집계 운영 기준

수집 필드: UTC 일자, local/production 구분, 정해진 행동/화면, 6통화, 유효한 공개 리포트 ID, 횟수. 원시 이벤트 로그·사용자 ID·이메일·IP·전체 URL·에이전트 문자열은 집계 테이블에 저장하지 않는다. 플랫폼의 기존 접속 로그와 이 집계는 별개다.

동일 페이지 생애의 같은 행동은 중복 전송을 합친다(메모리 최대256키). 새로고침/다른 탭은 다시 셀 수 있으므로 고유 독자 수가 아니다. 30초는 화면이 보이는 연속 시간이며 정독 보증이 아니다. DNT, 로그인, 관리자, 비교용 iframe, 운영 코드의 localhost 시험을 제외한다. 합성 리포트 ID는 서버도 거부한다.

익명은 제한된 카운터 함수만 실행 가능하고 집계를 읽을 수 없다. 로그인 사용자는 직접 쓸 수 없으며, 활성 관리자만 집계를 읽는다. 서버 설정은 기본 off, 운영 빌드도 `VITE_USAGE_ENABLED` 미설정 시 off다. 로컬 시험만 명시 승인 뒤 scope=local로 켰다. 운영 전환 때 두 설정을 별도 승인 범위에서 검토한다. 봇으로 인한 횟수 부풀림까지 막는 계량 시스템은 아니며 청구/보안 결정에 사용하지 않는다.

조회는 최근30일, 최대1,000개 묶음이며 한도 도달 시 부분 집계를 알린다. 자동 삭제는 이번에 켜지 않았다. 기존 보존 정책의 승인·점검 절차를 따른다.

## 검증 결과

- 타입·린트·전체 테스트: **144파일 / 1,059 실행 사례 통과**. 테스트 수는 실제 원고 품질 표본 수가 아니다. 중복 이름/동일 본문/동어반복 탐지 결과 없음(의미적 중복까지 보증하지 않음).
- DB pgTAP: 기존99 + 새 이용 집계14 = **113검사 통과**. 트랜잭션 롤백. anon/일반 로그인/활성 및 비활성 관리자/서비스 역할.
- 기존 이력 REST: 65개 합성 이력의 30/30/6 페이지·정확 조회·기간·이웃·비공개 차단 통과. **기존 원고와 관련 기록70개의 해시 보존**.
- Supabase local security advisors: **No issues found**. 운영 advisors는 실행하지 않음.
- 운영·로컬 앱·보고서·운영 경로 프리뷰 4종 빌드 통과. 생산 번들 private/local marker와 서비스 키 미포함. 기본 기능 플래그 false 유지.
- 초기 HTML JS: 직전 저장 기록816,858bytes → **462,068bytes**(약43% 감소). 현재 진단 중 첫 빌드826,837bytes에서도 감소. 차트를 분리하고 대시보드에서는 환율과 병렬로 미리 받는다. 실제 회선의 LCP/INP 수치를 측정한 것은 아니다.
- 실제 화면: 대시보드→국가 목록→과거 본문→근거→복귀, 국가 목록끼리 이동, 최근 기간·월별·뒤로가기·제목/초점, 관리자 로그인·집계·로그아웃 확인.
- 320/375/1265px 내용 폭: 대시보드·칠레 리포트 가로 넘침 없음. 모바일은 데스크톱 iframe 검증이며 실제 iPhone으로 부르지 않음.
- 초기 샌드박스에서 임시 파일 rename/hard-link 및 localhost 접근 제한이 있었다. 같은 검사를 호스트에서 재실행해 통과했고 검사를 완화하지 않음.
- 보고서 저작용 로컬 빌드에만 기존 provider의 static/dynamic import 중복 경고가 남음. 빌드는 통과하며 생산 빌드에는 해당 경고/로컬 DB 모듈이 없음.

## 출시 전 남은 확인

실제 iPhone/Safari·VoiceOver, A4 출력, 실제 독자 사용성, 국가별 휴일·공급 기준시각·회사 환율 정의, 운영 제공 경로/집계 연결, 프리뷰에서 실제 운영 설정으로의 최종 비교와 배포·복구 승인. 새 AI 호출이나 원고 재시험은 이 작업의 선행 조건으로 추가하지 않는다.

문제 시 리포트·이용 집계 기능을 끄고 검증된 코드로 복구한다. 새 집계·감사 이력은 삭제하지 않는다. 코드 기준점은 `.local-reports/private/ui2-implementation-20261031/baseline/`에 보존했다. 실행 로그·측정 JSON·이미지와 SQL은 재현 가능하게 남겼으며 push·운영 DB·배포·메일·유료 호출은 0이다.
