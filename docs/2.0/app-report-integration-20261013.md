# 통화별 A안 리포트의 로컬 앱 연결

기존 환율 앱에 숫자 카드와 리포트 탭을 통해 A안 목록·상세·근거·이력을 읽는 경로를 연결했다. 제품 화면은 격리 DB의 승인본만 읽는다. 칠레 실제 원고의 누락된 출처 연결은 별도 사본에서 보완했으며, 원문·본문·수치·차트·비용·이전 평가와 승인 상태는 보존했다. 신규 모델 호출과 비용은 0이다.

## 출처 연결 규칙

공통 규칙은 `economic-scope-review/2`다. 서로 다른 자료의 관계를 쓰는 문장은 필요한 모든 출처를 문장 대응표와 본문 블록 양쪽에 연결한다. 검토자는 정확한 문장·대상·이유·필수 출처를 지정한다. 자동 검사는 연결 누락·없는 ID·중복·오래된 문장 바인딩을 확인하며, 출처가 실제로 주장을 지지하는지는 별도 원문 검토다. 키워드만으로 관계를 추정하거나 모든 출처를 붙여 통과시키지 않는다.

`reviseClaimReferences`는 출처 목록만 바꾼 별도 결과를 반환한다. 본문과 이전 원고를 수정하지 않고 기존 검토 바인딩을 새 결과에 재사용하지 않는다. 제목·요약에도 같은 검사를 적용할 수 있으며 단일 출처의 안전한 조건부 설명에는 추가 출처를 강제하지 않는다.

칠레 사례의 기간 관계에는 8월 보수와 9월 IPC를 연결했다. 보수 원문의 `agosto de 2026`, IPC 원문의 9월, 지표 정의와 기존 범위 구별을 대조했다. 필수 출처 지적은 해소됐으나 이전 품질 3.8/5·독자 평가 대기·게시 미승인은 유지한다. 이 결과를 새 AI 생성 성공이나 품질 합격으로 바꾸지 않는다.

## 제품 화면과 검토 화면

| 화면 | 조회 경계 |
| --- | --- |
| 기존 앱의 A안 연결 | `http://127.0.0.1:4176/#report`에서 격리 DB 승인본만 표시. BRL·MXN·CLP 카드와 탭, 날짜별 이력·직접 링크·새로고침 지원 |
| 칠레 출처 보완 사본 | 기존 4175 검토 화면의 명시적 실행 주소에서만 확인. 검토 초안이며 제품 목록에 추천하지 않음 |
| 기본 운영 빌드 | 로컬 전용 플래그가 false. 기존 보고서 기능 설정도 false로 보존. 새 A안 진입 링크·탭이 나타나지 않음 |

A안 본문·차트·근거 렌더러와 CSS를 시안 및 제품 화면이 공유한다. CSS는 리포트 영역에 한정해 이전 화면에 번지지 않도록 했다. 제품 화면에는 디자인 선택·초안 모드·원문 응답·비용 이력·생성 버튼이 없다. 실패한 리포트를 초안으로 대체하지 않으며 화면 오류도 리포트 영역에서 처리한다.

현재 격리 DB에는 이전의 승인된 BRL 합성 연결 시험 한 건이 있다. 미래의 시험 날짜와 AI 미사용 표시를 유지하며 실제 시장 보고서로 취급하지 않는다. CLP·MXN 승인본은 없어 미발행 상태다. 실제 칠레 원고는 승인하지 않았고 기존 DB 자료를 초기화하거나 새 공개 행을 쓰지 않았다.

## 검증

- 전체 자동 검사: 70파일·384개 선언·478개 실행 사례. 매개변수 확장 94개와 테스트 감사 자체 검사 4개는 별도로 구분한다. 정확히 같은 이름·본문·자기 비교 감사는 0이며 의미적 중복이나 원고 품질 합격의 증명이 아니다.
- 타입·린트·운영 빌드·시안 빌드·기존 앱 로컬 연결 빌드·번들 경계 통과. 큰 entry 경고는 남아 있다. 의존성은 변경하지 않았고 이번에는 clean install을 다시 하지 않았다.
- 격리 DB pgTAP 4파일·54항목 통과. 익명 승인본 조회·비공개 runs 차단·실제 미채택 원고의 공개 부재를 별도 읽기 전용 검사로 확인했다.
- HTTP·비밀값 검사 15항목 통과. 설정은 loopback URL과 공개 키만 반환한다. private 및 reviewable 원고 파일·키 파일·메일링 API 접근과 변경 요청을 차단했다. 브라우저 산출물 38개에 실제 비밀키가 없음을 값 출력 없이 확인했다.
- 숫자 카드 진입·목록·승인된 합성 상세·근거 펼침·이력 날짜 선택·새로고침·대시보드 복귀 확인. 실제 미채택 실행 주소는 제품 화면에서 차단된다. 390px에서 문서 폭 375px·리포트 폭 351px로 가로 넘침이 없었다. 실제 칠레 보완 사본도 390px에서 가로 넘침이 없고, Enter 키로 해당 근거를 펼치는 동작을 확인했다.
- 기본 빌드의 리포트 버튼 0개를 로컬 미리보기에서 확인했다. 이전 월별 표 2개·일별 표 1개·계획 대비·관리 화면 표시도 확인했다. Excel 업로드·계획환율 저장·메일 발송은 하지 않았다.

DB가 처음 꺼져 있어 오류 안내와 기존 환율 조회 유지가 먼저 확인됐다. Docker를 시작해 기존 격리 DB를 재사용했다. 초기화·migration 변경·운영 연결은 없었다. 캐시 실패 경로의 자동 검사는 통과했지만 이번 브라우저 검증에서 새 네트워크 장애를 주입하지는 않았다. A4 출력·전체 접근성·실제 AI 원고 승인·실시간 파일럿·운영 복구는 남아 있다.
