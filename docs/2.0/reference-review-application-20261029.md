## 반복 적용 방식

기존 `material-selection/1` 검증을 재사용했다. 준비 파일에 선택적 `materialReviewFile`을 명시하면 기존 로컬 명령 `npm run report:prepare:six -- --input <비공개 manifest.json>`이 이를 읽는다. 검토 파일도 기존과 같은 비공개 JSON 경계 안에서만 읽는다.

검토는 원본 입력·기준환율 스냅샷·해설 대상일·기존 자료 연결 전체의 해시에 묶인다. 하나라도 달라지면 옛 판단을 조용히 재사용하지 않는다. 기존 검토 파일이 없거나 읽히지 않으면 해당 통화는 `saved_material_invalid`로 남기고 다른 통화는 계속한다. 지정한 검토 파일이 실패했을 때 미수정 자료로 돌아가는 폴백은 없다. 이전 형식의 역사 재생은 그대로 보존한다.

선택 제외는 소비·정책·관찰 배경에만 적용할 수 있다. 시장 관측이나 귀속 원인 설명을 `optional`로 표시해 없애는 것은 거부한다. 남은 주장이 제외 자료를 필요로 하면 제외를 거부한다. 제외된 요지가 본문 외 경로로 섞이지 않도록 현재 섹션·보존 섹션·보류 항목·출처 용도 목록·외부 입력용 출처 표시에서도 해당 자료를 제거한다. 제외 기록에는 자료 ID와 이유만 남긴다.

역할 수정은 `countercontext`, `watch_context`, `policy_background` 사이의 제한된 재분류다. 소비·글로벌 자료를 당일 현지 원인으로 승격하거나 다른 거래일 자료를 현재 섹션으로 옮기는 용도로 사용할 수 없다. 본문·수치·실제 대상 월·주장의 귀속과 기존 이용 판단은 수정하지 않는다.

`writingContext`에는 **해설 기간의 의미·관측 구간·지켜야 할 설명 범위**를 전달한다. `sourceVersion`에는 최초 게시·확인된 수정·수집 시점을 구분한다. `bodyAvailableBy`는 보수적으로 본문 수집시각을 사용한다. 이것으로 실제 최초 공개시각이나 현지 가격 관측시각을 인증하지 않는다. 수정시각 미확인은 ‘수정 없음’으로 표현하지 않는다.

공통 집필 안내는 이 제약을 내부 기준으로 사용하고, 독자 본문에 경고 문장으로 반복 복사하지 않도록 한다. 의미를 바꾸는 ‘오전·최근·가능성·가구/가전 결합 업종’은 본문에서 유지한다. 선택 배경 제외는 이번 입력 미포함이지 현실의 통계 미발표나 부재가 아니다.

## 다음 고정 순서

현재 7단계 중 4단계 자료·내용 준비를 진행 중이다. 이번 공통 반영 묶음은 완료했다. 같은 문제의 검토를 다시 다음 과제로 제안하지 않는다.

다음은 **COP·PEN·ARS 자료 공백 마감**이다. COP·ARS는 해설 대상일에 맞는 시장 설명, PEN은 기존 후보의 수집/이용/시점 조건을 정리한다. 판단은 Astra High, 확인한 범위의 연결은 Sol High를 권장한다. 기존 저장 자료를 우선 쓰고 미해결 사유는 그대로 남긴다. 기사 가격 확보를 대표값의 필수 조건으로 되돌리지 않는다.

이후 5단계에서 준비된 입력만 별도 비용 승인으로 실제 품질을 시험하고, 6단계 승인·공개·UI 2.0, 7단계 파일럿·출시·복구로 이어간다. PEN·ARS 발행 기준의 미확정 부분과 공개 출처 표시 확인도 기존 계획에 유지한다. 이번 검토 파일은 로컬 개발자의 판단 기록이며 운영 관리자 인증이나 게시 승인으로 사용하지 않는다.
