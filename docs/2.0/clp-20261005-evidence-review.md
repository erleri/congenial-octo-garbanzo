## 원문 검토 결과

### 정부 발표와 정책 신호

[DF 원문](https://www.df.cl/mercados/bolsa-monedas/dolar-hoy-n75vd)의 본문 첫 부분과 Rodrigo Castillo 발언을 함께 읽어야 한다. 기존 입력은 Castillo의 정책 신호 해석을 빠뜨렸다. 발표 이후 전환은 보도됐지만 실제 집행 물량이나 비거주자 포지션 청산은 확인된 결과로 제시하지 않는다. 주간 한도는 확정 집행액이 아니다.

[La Tercera 원문](https://www.latercera.com/pulso/noticia/el-valor-del-dolar-en-chile-el-5-de-octubre-de-2026/)의 정부 조치 부분에는 자금 조달 필요와 시장 여건에 따라 금액이 바뀔 수 있다는 조건이 있다. 정부 계획은 매체가 전한 내용으로 귀속한다. 이번 검토에서 Dipres의 별도 원문 공고를 확인한 것으로 표시하지 않는다.

작성 방향은 발표된 공급 계획과 정책 신호가 달러 부족 우려·시장 기대에 영향을 주었다는 출처 귀속 해석이다. 대규모 물량이 쏟아졌다는 표현은 제외한다. 정부 계획과 정책 신호를 두 개의 독립 원인으로 부풀리지 않고 한 항목 안에서 설명한다.

### 구리와 글로벌 달러

DF의 구리 부분은 두 거래일 연속 상승을 설명한다. 이를 지속적인 상승 추세로 확대하지 않는다. La Tercera의 현물·선물 수치와 DF의 선물 수치는 상품·관측 기준이 달라 하나의 구리 수익률로 합치지 않는다.

기사의 전문가 해석에 귀속하여 구리 반등을 페소 지지 배경으로 설명할 수 있다. 실제 수출대금 유입이나 원인별 기여도는 추가하지 않는다. 글로벌 달러 강세 속 현지 달러 하락은 현지 요인이 부각됐다는 해석을 돕지만 그 자체로 인과를 증명하지 않는다.

두 매체의 XTB 발언은 서로 다른 매체에 실렸어도 같은 기관의 해석이다. 독립적인 두 번의 검증으로 세지 않는다. BeFX의 정책 신호 해석은 다른 기관의 의견이며, 의견이라는 성격을 유지한다.

| 원리 | 판단 | 적용 조건과 설명 범위 |

| 위험회피 | 필요한 경우 귀속 배경으로만 사용 | 현지 반전의 원인으로 덧붙이지 않음. 글로벌 달러 배경과 중복되면 생략 |
| 물가와 구매력 | 제외 | 이번 두 기사에는 칠레 소비자 물가·소득·판매를 연결할 자료가 없음 |

[RBA의 환율 정의](https://www.rba.gov.au/education/resources/explainers/exchange-rates-and-their-measurement.html)를 바탕으로 달러 결제금액 × CLP/USD = 페소 환산액이라는 산술 관계를 확인했다. RBA 예시의 AUD/USD와 이 프로젝트의 CLP/USD는 표시 방향이 다르므로 공식에 단위를 명시한다. 미헤지 조건과 헤지·선결제·계약 환율의 예외는 이 산술 관계를 기업 노출에 확대하지 않기 위한 적용 조건이다.

[RBA의 원자재와 환율 설명](https://www.rba.gov.au/education/resources/explainers/drivers-of-the-aud-exchange-rate.html)은 호주 사례의 일반 경로다. 칠레 수출 비중이나 당일 자금 흐름의 증거로 대신 사용하지 않는다.

영업 의미는 조건부 환산 부담 한 항목이면 충분하다. 실제 판매 증가·마진 개선·판매가격 인하·효과의 크기는 추가하지 않는다. 두 번째 영업 의미를 채우기 위해 같은 환산 관계를 다시 쓰지 않는다.

## 다음 생성 입력에 반영할 사항

1. DF의 빠진 정책 신호 발언과 이웃 문맥을 새 원문 선택본으로 확보한다. 기존 추천 템플릿 조각을 제거한다. 검토 요약을 원문 구절로 등록하지 않는다.
2. La Tercera의 계획 변경 조건, 출처 귀속, 서로 다른 가격 기준을 유지한다.
3. 기존 환율·차트는 고정하고 새 원문 선택본과 별도로 해시를 남긴다. 바뀐 입력은 과거 결과의 입력으로 소급하지 않는다.
4. 일반 원리 적용 기록은 `origin=agent`인 검토 제안으로 남긴다. 현재 공통 검사기는 사람의 적용 승인을 요구하므로 `origin=human`으로 바꾸거나 승인된 것으로 주입하지 않는다. 검토 후 생성할 때 이 상태를 명시적으로 처리해야 한다.
5. 생성·검토·교정·재검토에 동일한 시간 구분과 채택 범위를 전달한다. 모델이 제한을 지켰는지는 실제 출력에서 다시 확인한다.

새 원문 선택본의 생성 입력 연결과 실제 모델 검토는 다음 단계다. 이번 결과는 근거와 원리의 내용 검토이며 전송 가능한 최종 패킷 또는 생성 품질 합격을 의미하지 않는다.
