# 출처 표시 검사 연결과 국가별 자료 공백 후속 결과

2026-10-28 · Sol High 로컬 구현 · 새 원고·유료 호출·운영 반영 없음

## 완료한 범위

[이전 검토의 U01](six-currency-cause-use-review-20261028.md)을 기존 출처 이용 검사에 연결했다. BRL·COP·PEN·ARS의 저장 입력을 **새 사본**으로 만들고, 실제 집필 인계 자료에 출처·귀속·기간·가공 표시를 붙였다. BRL 소매 발표일과 ARS API 고지 위치도 확인했다. COP·PEN의 직접 원인 근거는 추가 확인 후에도 부족해 보류를 유지했다.

기존 원고·환율·가격 원본·과거 이용 판단·비용 기록은 덮어쓰지 않았다. CLP·MXN 기존 저장 사례의 준비 상태는 유지했다. 여섯 통화 집필 서비스나 공개 화면이 완성됐다는 의미는 아니다.

## 한 번의 수동 표시로 끝나지 않도록 연결한 코드

`source-attributions.js`의 `connectSourceAttributionConditions`가 검토된 출처 메타데이터를 받아 새 이용 기록에 필요한 표시 조건을 연결한다. 국가명을 나열한 예외나 새 허가 엔진을 만들지 않았다.

- `sourceUrl`, `publisher`, `publishedAt`, `referencePeriod`, `attribution`, `transformation` 중 실제 확인된 필드만 요구한다. 발표일 미상은 빈칸을 임의 날짜로 채우지 않는다.
- 출처 메타데이터는 자료 바인딩·URL·발표일·대상 기간과 대조한다. 다른 기사·다른 월의 출처 표시를 재사용하면 거부한다.
- 기존 검사 `inspectSourceUses`가 조건의 실제 텍스트 전달을 용도별로 확인한다. `satisfied`라는 기록만 있고 전달 문구가 없으면 보류다. 문구 누락·대체·자료 변경도 보류된다.
- 조건 자체에 적용 용도를 기록한다. 중복 참조인 `conditionIds`를 실수로 빠뜨려도 필수 표시가 사라지지 않는다. 같은 연결을 다시 해도 조건 수가 중복 증가하지 않는다.
- `prepareCountryMaterials`는 **출력에 실제 포함하는** `externalSourceAttributions`를 검사에 전달한다. 내부 검토자 정보·기사 본문·PDF 원문은 그 출처 표시 자료에 복사하지 않는다.
- 외부 입력과 공개 표시를 구분한다. 집필 인계에 표시가 있다고 공개 화면까지 확인됐다고 처리하지 않는다. 이번에는 공개 렌더링을 제공하지 않아 계속 보류다.
- 기존 `allowed / pending / denied` 이용 범위 판단은 유지한다. 표기가 완성돼도 IBGE·INEI의 이용 범위 미확인을 허가로 바꾸지 않는다.

새 네 통화의 자료 10건에 표시 조건 59개가 연결됐다. 이는 메타데이터 필드 검사 수이며 독립 근거나 원고 품질 표본 수가 아니다. DANE에는 저장 조건에서 요구한 `Fuente: Departamento Administrativo Nacional de Estadística: www.dane.gov.co`를 넣었다. 뉴스에는 매체와 해당 견해의 발언자·기관을 보존했고, Agência Brasil의 Reuters 정보 출처도 표시했다.

**연결 경계:** 현재 새 네 통화는 가격·원인 자격 때문에 실제 집필 이전 단계다. 후속 집필 경로도 이 출처 자료를 실제 입력에 포함해야 한다. 표시 자료 없이 새 조건 기록만 넘기면 기존 검사에서 보류됨을 재생했다. 아직 구현하지 않은 공개 UI가 이 조건을 만족한다고 표시하지 않는다. CLP·MXN의 과거 기록은 구 계약으로 보존했고 자동 소급 변경하지 않았다.

## 국가별 조사 결과

### BRL — 공식 발표일 공백 해소, 이용 범위 보류 유지

기존 공식 페이지는 다시 403이었으나, IBGE 공식 FTP의 [8월 PMC 보고서](https://ftp.ibge.gov.br/Comercio_e_Servicos/Pesquisa_Mensal_de_Comercio/Fasciculo_Indicadores_IBGE/pmc_202608caderno.pdf)를 정상 확보했다. 공식 파일명 규칙으로 찾은 후보를 실제 HTTP 응답·PDF 표지로 검증한 뒤 채택했다.

표지에 **8월 대상, 2026-10-15 발표, 09시**가 명시돼 있다. 추출문과 표지 이미지를 대조했다. 시간대와 실제 업로드 시각은 미확인이어서 UTC 시각을 만들지 않았다. PDF 생성 메타데이터를 발표일로 쓰지 않았다.

새 사본의 기존 SIDRA 8월 소매 카드에 `publishedAt=2026-10-15`와 공식 문서 URL·해시·확인 쪽을 연결하고, 바뀐 출처/범위/자료 역할 바인딩을 명시적으로 다시 검토했다. 소매 값·단위·비교·환율은 보존했다. 과거 입력의 `publishedAt=null`도 그대로 남겼다. 새 사본에서는 소매 `publication_not_verified`가 해소된다.

해당 PDF의 텍스트 확인만으로 재사용 허가를 확정하지 않았다. 기존 등록 이용 안내는 여전히 403이다. IBGE 외부 이용 범위, 현물 종가/PTAX의 같은 기준 전후 가격은 남는다. SGS 적용 날짜를 정책 발표일로 바꾸지 않아 기존 정책 배경의 발표 미확인도 유지한다.

이 PDF는 이번에 받은 현재 파일이다. 표지의 발표일이 당시 보존된 빈티지 수치나 10/26 실시간 수집 성공을 입증하지 않는다.

### COP — 새 기사 원문 확인, 직접 설명으로는 미채택

기존 목록에 있던 [Portafolio 해당 주초 기사](https://www.portafolio.co/economia/finanzas/precio-del-dolar-en-colombia-divisa-inicia-la-semana-cerca-de-los-3-505113)의 HTML은 확보했다. 기존 추출기는 본문을 식별하지 못했다. 제목·목록으로 원인을 승인하지 않았다. 페이지에 재현·AI 개발 관련 제한 문구도 있어 원문 전송·차단 우회·임의 전체 페이지 추출을 하지 않았다. 그 문구만으로 모든 자체 사실 카드의 법적 이용 가능성까지 일괄 판정한 것은 아니다.

추가 [Infobae 10/26 기사](https://www.infobae.com/colombia/2026/10/26/dolar-hoy-en-colombia-cotizacion-de-cierre-del-26-de-octubre/)는 실제 원문을 추출했다. Bancolombia 귀속 설명은 명시적으로 DXY 흐름을 설명한다. COP의 주간 시황·향후 시나리오·브라질 제목을 당일 COP 원인으로 합치지 않았다. 새 기사도 평균값 3157.57과 당일 TRM의 비교를 담아, 동일 숫자가 최종 체결 종가라는 증거로 사용하지 않는다.

수정 시각은 10/27 01:21:33Z다. 게시 시각 10/26 20:15:52Z에 현재 본문 전체가 이미 있었다고 소급하지 않는다. 새 기사는 발견·검토 기록으로 보존하고 기존 원인 패킷에는 자동 채택하지 않았다.

결과는 `직접 원인 근거 부족`이다. 추가 근거를 찾지 못한 사실과 조회·추출 실패를 구분한다. 공식 소비통계나 일반 원리로 빈 원인 칸을 채우지 않는다.

### PEN — 공개 브리프 확인, 원인과 이용 범위는 미해결

[Macroconsult 10/26 공개 일일 브리프](https://sim.macroconsult.pe/reporte-diario-del-26-de-octubre-de-2026/)는 무료 공개 본문에 해당일 가격과 BCRP 비개입 설명이 있다. 그러나 PEN 하락 이유까지 설명하지 않는다. 3.4435를 기존 기사 3.443이나 BCRP 매수/매도 값과 같은 시각·같은 가격으로 합치지 않는다.

기존 추출기는 본문 목록 항목을 누락해 `partial_extraction`으로 기록했다. 자동 정상 수집으로 표시하지 않는다. 원문 읽기와 비교하면 차이가 확인되며, 이 출처를 자동 채택하려면 목록 추출을 보완하고 그 범위를 다시 검토해야 한다. 이번에는 없는 원인까지 얻을 수 없으므로 새 어댑터 개발로 확대하지 않았다.

브리프 자체도 원출처 확인을 안내한다. Bloomberg/SBS 표 이미지나 원문을 재사용 가능한 자체 데이터 피드로 승인하지 않았다. 저장 INEI 공식 PDF의 본문·이용 문구도 재검토했지만 재사용 허용 조항은 확인하지 못했다. `derechos de importación`은 수입관세이며 저작권 허용 문구로 해석하지 않았다. 이용 금지로 확정하지 않고 외부 입력·공개 보류를 유지했다.

### ARS — API 고지 연결 위치 확인, 용도와 수집 장애는 유지

[BCRA 공식 API 안내](https://www.bcra.gob.ar/apis-banco-central/)의 통계 v4 영역에 있는 법적 고지가 [기존 Aviso legal](https://www.bcra.gob.ar/aviso-legal/)로 연결되는 것을 웹 원문과 저장 HTML에서 확인했다. 이전의 ‘API 고지 위치 미확인’은 이 확인으로 좁혔다.

API 안내는 기업·사이트 연동을 소개하지만 그 사실만으로 모든 상업 재사용을 허가한 것은 아니다. 연결 고지의 용도별 조건과 LATAM FX 적용 판단은 남긴다. 다른 기관의 조건을 대입하거나 무료 사이트라는 이유로 서비스 용도를 임의 확정하지 않았다. 기관에 메시지·허가 요청을 보내지 않았다.

기존 INDEC 공식 PDF의 새 바이트 확보를 한 번 더 시도했으나 전송 단계에서 실패했다. 이전 수동 원문 확인은 보존했고 자동 수집 성공으로 바꾸지 않았다. 도매시장 귀속 해석은 있으나 같은 기준 가격 쌍·BCRA 용도·INDEC 반복 수집의 남은 조건은 유지한다.
