# 집필 입력 보완과 반복 출처 경로

## 완료한 입력 보완

10월 26일 입력(실제 환율 거래일 10월 23일)의 세 보완을 **새 검토 기록과 새 입력**에 반영했다. 날짜를 오늘로 바꾸거나 최신 보고서를 작성하지 않았다. 같은 에이전트의 후속 작업이며 별도 Astra 실행·독립 평가로 기록하지 않는다.

| 항목 | 새 입력 |
| --- | --- |
| F01 가격 비교 범위 | ‘달러 상승 마감 보도와 최종 호가 제공’으로 좁혔다. 양방향 호가 각각의 전일 상승과 BCCh 방법 설명을 기사 주장에 넣지 않는다. BCCh 가격 메타데이터는 유지한다. |
| F02 시각 | ‘23일 오전 보도에서 분석가는…’으로 바꿨다. 기술주 조정 자체의 발생시각은 특정하지 않는다. |
| F03 귀속 | PKF Héctor Osorio의 이름·소속을 명시한 p18을 추가했다. 인접 문단은 문맥으로만 남기고 별도 주장으로 채택하지 않았다. |

기존 다섯 주장과 반대 요인, 채택·보류·제외 결정, 기사 이용 조건 미확인 상태를 유지했다. 유가 압력과 구리 상쇄를 함께 읽고, 오전 글로벌 달러 약세를 CLP 약세의 직접 원인으로 나열하지 않는 편집 기준도 유지한다.

- 이전 입력: `.local-reports/private/publisher-admission-cJEoyg/review-input.json`
- 새 검토 기록: `.local-reports/private/publisher-input-revision-EeaY0j/receipt.json`
- 새 입력: `.local-reports/private/publisher-admission-nFVplW/review-input.json`
- 재현 명령·검증: `.local-reports/private/publisher-input-revision-EeaY0j/revise.mjs`, `verification.json`
- 새 입력 SHA-256: `35d5a79c5a46fd24d2a9c49f286db5d0adda1a094474ce060acd4ab930a8dd66`

입력은 내용 보완용 사본이다. 기존 공통 컴파일러는 여전히 이용 범위·작성 가치·독립 내용 검토·게시 승인을 보류한다. 이번 문서나 사본은 그 상태를 자동 해제하지 않는다.

## 앞으로 반복 사용할 출처 경로

[구조화된 경로 기록](report-source-routes-20261027.json)을 만들었다. 현재 수집기 설정에 주입한 실행 파일은 아니다. ‘접근 가능’, ‘이용 조건’, ‘날짜 적합’, ‘주장 지지’, ‘새 작성 필요’를 별도로 기록한다.

| 질문 | 우선 경로 | 확인 상태와 제한 |
| --- | --- | --- |
| 실제 환율은 어떻게 변했나 | 기존 BCCh BDE API 어댑터 | 통계 공개·가공 허용 조건을 재확인했다. 적용일·거래일·가중평균·출처·가공 책임을 표시한다. 다른 기관 원천에는 별도 조건이 적용된다. |
| 소비·판매 환경은 어떠한가 | 기존 INE 월간 수집기 | CC-BY-SA-4.0을 재확인했다. 지표 대상 월을 명시하고 공개 파생물의 출처·변경·라이선스 표시를 정리한다. 월간 지표를 당일 환율 원인으로 쓰지 않는다. |
| 유가에 새 변화가 있는가 | EIA의 항목별 원천을 확인한 자료 | 자체 작성 자료의 이용 허용과 제3자 예외를 구분한다. 검토한 Brent spot의 원천은 Refinitiv/LSEG이며 이번에 이용 승인하지 않았다. 해당 페이지는 10월 20일 값까지만 있어 23일 기사 유가를 대조할 수 없다. |
| 구리는 어떤 배경인가 | Cochilco 원 보고서 후보 | 19~23일 주간 보고서의 소개 페이지는 확인했다. 원 보고서·자료 원천·재사용 조건은 미확인이다. URL은 6월 경로여서 제목·본문·수정 이력 확인이 필요하다. |
| 그날 시장은 무엇을 배경으로 해석했나 | 이용 근거가 확인된 시장 해설 | Emol 저장 자료는 로컬 검토로 보존한다. 이용 근거가 해결되기 전 외부 모델 전달·공개를 승인하지 않는다. 공식 수치의 동행만으로 기존 매체 해석을 재작성해 출처를 바꾸지 않는다. |

이는 BCCh·INE만으로 모든 원인 설명을 대체할 수 있다는 뜻이 아니다. 원인 설명은 해당 시점·시장과 연결된 근거가 필요하다. 핵심 설명을 지지할 허용 자료가 없으면 그 설명을 빼거나 작성을 보류한다. 준비된 소비 배경·가격 검증은 계속한다.

## 반복 기준

1. 출처를 처음 연결할 때 자료 범위·원 소유자·제3자 원천·약관 버전·로컬 분석/모델 전송/공개 표시의 이용 범위와 조건을 기록한다.
2. 같은 범위와 조건을 유지하는 출처는 매 원고마다 허가 검토를 처음부터 반복하지 않는다. 약관·원천·수집 방식·이용 목적이 바뀌면 다시 검토한다.
3. 매 실행에서는 발표일·대상 기간·가격 종류·수정본·추출 무결성을 확인한다. 수집시각으로 발표시각을 채우거나 누락값을 새 관측으로 만들지 않는다.
4. 통계 사실, 검증된 일반 원리, 당일 시장 해석을 분리한다. ‘유가와 환율이 함께 올랐다’만으로 인과를 확정하지 않는다.
5. 미확인 출처의 주장만 보류한다. 해당 자료를 쓰지 않는 다른 로컬 작업까지 중단하지 않는다. 새로운 설명이 없으면 이전 발행일을 유지한다.

## 검증과 다음 작업

기존 공통 명령으로 저장 HTML을 재추출하고 새 검토 기록을 입력으로 변환했다. 컴파일 재현·p18 전달·미채택 인접 주장 배제·원래 자료 결정/이용 상태·운영 JSON/기존 원고 해시 보존을 확인했다. 새 테스트나 생성 규칙을 추가하지 않았다. 자동 재현은 내용의 독립 승인이나 새 리포트 품질 점수를 의미하지 않는다.

기존 채택 경계 테스트 9개도 통과했다. 첫 실행은 테스트 시작 전 시스템 임시 폴더의 파일 이동 권한 오류로 중단됐고, 작업 폴더 안의 기존 임시 경로를 사용한 두 번째 실행에서 9개가 수행됐다. 테스트 실패를 내용 오류나 모델 실패로 계산하지 않는다. [검증 요약](publisher-input-revision-20261027.json)에 결과를 남겼다.

다음은 기존 BCCh·INE 수집 출력을 이 출처 계약에 맞게 연결해 **모델에 보낼 수 있는 자료와 부족한 질문**을 먼저 산출하는 로컬 작업이다. EIA·Cochilco 후보를 자동 채택하지 않으며, 유가·구리·시장 해석에 필요한 나머지 자료는 항목별로 검증한다. 실제 모델 생성과 게시 결정은 별개다.

추가 모델·유료 검색 비용 $0. 웹 공개 열람은 수행했다. 키 파일·운영 DB·메일·배포·원격 저장소는 변경하지 않았다. 운영/리포트 빌드 전체는 이번에 다시 실행하지 않았으며 문서·비공개 입력 작업의 검증을 보고한다.
