# 언론 원문을 리포트 입력으로 채택하는 공통 기준

버전: `publisher-admission/1` · 2026-10-26 · 로컬 검토 전용

후속 적용: [10월 27일 입력 보완·반복 출처 경로](publisher-input-revision-20261027.md). 자료 원 소유자·제3자 원천과 로컬 분석/외부 모델 전송/공개 표시의 조건을 구분하고, 동일 범위의 허용 조건은 재사용한다. 약관·원천·수집 방식·이용 목적 변경 시 재검토하며 날짜·수정본·추출 무결성은 매 실행 확인한다. 아래 칠레 사례는 최초 채택 당시 기록이며 세 입력 보완은 별도 사본에 반영했다.

이 기준은 칠레 한 건의 원고를 손으로 고치는 절차가 아니다. 다음 날짜·다른 통화에서도 원문 수집 결과에 같은 검사를 적용하고, 검토자가 사용할 주장과 제외 이유를 명시하도록 하는 계약이다. 칠레 실제 원문으로 재현했으며 BRL·MXN은 합성 계약 검사만 했다. 해당 국가의 수집기·가격 산정법·자료 이용 조건까지 검증했다는 뜻은 아니다.

## 반복 흐름

`질문과 가격 기준 고정 → 등록 출처 수집 → 원문 보존·추출 → 주장별 검토 기록 → 자동 무결성 검사 → 기존 근거 카드·조사 요약으로 변환 → 내용·이용 범위 재검토 → 별도 생성 결정`

기존 `source-context`, `evidence-scope`, `research-harness`를 재사용한다. 새 연결부는 `publisher-admission.js`, 저장 명령은 `report:research:admit`다. 생성기나 공개 앱의 기본 경로를 변경하지 않는다.

## 검토자가 판단할 것과 코드가 확인할 것

| 기준 | 검토자의 판단 | 코드의 확인 및 실패 처리 |
| --- | --- | --- |
| 원문 동일성 | 제목·본문·인용 주체·문맥을 실제로 읽었는가 | 저장 HTML 해시를 대조하고 다시 추출한다. 추출·본문·발표 정보가 바뀌면 재검토 |
| 가격 비교 | 평균·호가·종가·소매 환전 가격을 구별했는가 | 가격 입력 해시를 고정하고 기사 가격은 별도 범위로 기록. 기사 발표시각을 관측시각으로 복사하지 않음 |
| 기간 | 발표일·사건일·자료 대상 기간을 구별했는가 | 질문별 허용 기간 밖 사건을 거부. 집계 마감 전후 표시는 다시 계산 |
| 주장 지지 | 문장의 **모든 주장**을 해당 원문 구절이 지지하는가 | 명시적 검토 항목·문단 참조·귀속을 요구. 출처 ID가 있다는 이유로 의미를 자동 승인하지 않음 |
| 반대 근거 | 설명을 바꾸는 반대 요인과 조건을 남겼는가 | 필수 동반 주장 누락을 거부. 실제 충돌은 `conflict`로 보존하고 집필 보류 |
| 중복·독립성 | 동일 분석가·기관·통신사를 다시 인용한 것인가 | 사건·인용 기관 키로 기존 요약기에 연결. 기사 수를 독립 확인 수로 사용하지 않음 |
| 사용 범위 | 사실·귀속 해석·확인하지 못한 수치를 구별했는가 | 허용 주장과 제외 사유를 기존 범위 카드에 함께 전달. 이웃 원문을 읽었다고 그 내용 전체를 채택하지 않음 |
| 이용 조건 | 로컬 검토, 외부 모델 전송, 공개 발췌·표시를 각각 확인했는가 | 미확인은 별도 보류 사유. BCCh 통계 이용 조건을 기사·사진에 적용하지 않음 |

해시·체크리스트는 **동일한 자료를 검토했다는 기록을 검사**한다. 내용의 진실성, 사람의 신원, 해석의 타당성을 증명하는 서명이나 인증이 아니다. 자동 검사를 통과해도 별도 내용 검토는 남는다.

## 세 가지 자료 결정

- **채택(`admit`)**: 원문 전체를 승인하는 것이 아니라 명시한 주장·문단·기간·귀속 범위만 로컬 입력에 포함한다.
- **보류(`hold`)**: 산술 모순, 추출 실패, 미확인 가격 기준 등 해결 조건과 이유를 남긴다. 사용 가능한 다른 자료는 계속 검토한다.
- **이번 입력에서 제외(`exclude`)**: 중복, 무관한 기간, 목표환율 등 때문에 사용하지 않는다. 원문과 제외 기록을 삭제하지 않는다.

원문마다 하나의 결정을 반드시 기록한다. 누락된 원문, 보류 자료의 주장 삽입, 선택 문단 누락을 조용히 무시하지 않는다. 수치가 의심스러워도 값을 바꾸거나 매수·매도 표기를 자동으로 뒤집지 않는다.

## 시각·원인·소비 설명

- 기사 발표시각은 가격 관측시각이나 사건 발생시각이 아니다. 집계 마감 전에 나온 기사도 중앙은행 평균의 직접 원인을 자동 입증하지 않는다.
- 마감 뒤 해설은 사후 맥락으로 표시한다. 현재 페이지를 나중에 수집한 자료는 당시 원문이 보존된 역사 아카이브로 표시하지 않는다.
- 오전과 저녁의 상이한 시장 설명은 먼저 시점·가격 기준을 비교한다. 바로 모순으로 처리하거나 하나의 종일 추세로 합치지 않는다.
- 금리·원유·구리에 대한 분석가 해석은 기관과 시점을 붙인다. 매체가 공식 통계를 인용해도 공식 원자료로 바꾸지 않는다.
- 소비 자료가 없으면 실제 판매·소득·가전 수요를 추정해 채우지 않는다. 시장 설명의 준비와 영업 환경 설명의 준비를 따로 기록한다.
- 제목·요약도 허용 범위 밖의 인과·확신·순위로 강화하지 않는다. 새 설명의 가치가 없으면 작성하지 않는다.

## 결과 상태를 합치지 않는다

| 결과 | 의미 |
| --- | --- |
| `sourceReview: reviewer_checked` | 작성 에이전트 또는 사람이 범위를 검토했다고 기록함 |
| 기존 요약기의 `ready_for_draft` | 필수 질문에 카드가 있음. 의미·품질·이용 권한 합격이 아님 |
| `writingEligibility: false` | 이번 연결부는 독립 내용 검토·작성 가치·이용 범위 확인을 대신하지 않음 |
| `contentQuality: not_assessed` | 실제 새 원고를 작성하거나 점수 평가하지 않음 |
| `publicationApproved: false` | 로컬 입력 생성은 게시·운영 승인이 아님 |

이번 명령에는 네트워크, 모델, 토큰 로딩, DB, 승인, 공개 복사 기능이 없다. 모든 출력은 Git에서 제외된 비공개 폴더에 새 파일로 저장한다. 실패한 검토나 과거 입력을 덮어쓰지 않는다.

## 재현 방법

Node 20.19.0을 사용하고 다음 세 파일은 `.local-reports/private` 안에 둔다.

1. `report:price:api` 등의 경로로 준비한 환율 입력 JSON(`packet` 포함).
2. `report:research:publishers`로 추출한 원문 결과 JSON.
3. 수집 URL·시각·SHA-256·`NNN.body` 파일을 연결한 원본 수집 장부 JSON.

```powershell
npm run report:research:admit -- --input <환율입력.json> --research <원문결과.json> --ledger <수집장부.json>
```

검토 전에는 빈 검토 서식만 만든다. 검토자가 이유·기간·허용 주장·문단·반대 근거·제외 사유를 작성하고 아래처럼 실행한다.

```powershell
npm run report:research:admit -- --input <환율입력.json> --research <원문결과.json> --ledger <수집장부.json> --receipt <검토기록.json>
```

매 실행에서 저장 HTML의 해시와 본문 추출을 다시 확인한다. 변경된 자료에 검토 상태만 복사하지 않는다. 새로 수집한 원문에는 새 검토 기록이 필요하다.

## 이번 실제 칠레 사례

보고서 입력 기준일은 2026-10-26, 환율 거래일은 10월 23일이며 직전 비교 거래일은 22일이다. 원문 5건 중 3건의 **주장 5개**를 제한적으로 채택했고, 1건은 수치 불일치로 보류, 1건은 전일 중복 설명으로 제외했다.

| 채택 주장 | 허용 범위 | 남기는 조건 |
| --- | --- | --- |
| Emol의 23일 마감 호가 상승 보도 | 보조 시장 보도 | 대표 숫자·차트는 BCCh 평균. 기사 증감액과 혼합 금지 |
| Capitaria의 유가·에너지 수입 설명 | 칠레 연결에 대한 귀속 해석 | 환율 기여도·수입 비율·판매 효과 미확인 |
| XTB의 오전 국채 수요·달러 설명 | 오전 보도에 귀속한 해석 | 별도 국채·달러 지수 대조 없음. 종일 추세 아님 |
| XTB의 구리 상승·페소 지지 설명 | 유가 설명의 상쇄 요인 | 상쇄 크기 미확인 |
| PKF Chile의 유가 신규성에 대한 이견 | 마감 뒤 반대 견해 | 실제 수출 제한을 독립 확인한 사실이나 향후 전망으로 사용하지 않음 |

선택된 기사 세 개는 모두 Emol이다. 기관이 다르더라도 다섯 개의 독립 출처로 확인했다는 의미가 아니다. 정량 소비 근거와 구체적인 향후 관찰 조건은 이번 입력에서 확보되지 않았으므로 추가하지 않았다.

추가 유료 호출·실제 원고 생성·운영 변경은 하지 않는다. 다음 검토는 **작성 입력의 주장 지지·작성 가치와 이용 범위**이며, 실제 생성 여부·예산 결정은 그 뒤다.
