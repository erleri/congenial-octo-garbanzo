# 리포트 필수 교정과 편집 권고 기준

관측·출처·설명 범위가 독자의 판단을 바꾸는 문제는 필수 교정한다. 뜻이 정확한 문장의 제목·표현 개선은 편집 권고로 남긴다. 확인할 자료가 부족한 경우는 미확인으로 기록한다. 이 기준은 `claim-review/2`에서 도입했다. 현재 `claim-review/3`은 같은 분류를 유지하고 [문장 내 세부 주장 검토](generation-review-structure.md)를 추가한다.

## 판정 순서

1. 문장을 실제로 주장하는 내용으로 나눈다. ‘공식 관측 이후’에는 공식성, 실제 관측의 존재, 사건의 선후관계가 들어 있다.
2. 각 주장을 원문·환율 메타데이터·승인된 원리의 적용 조건과 대조한다. 한 부분의 인용으로 문장 전체를 승인하지 않는다.
3. 근거의 단위·기간·대상·조건·귀속과 달라지는 부분이 독자의 이해를 바꾸면 필수 교정한다. 이유에는 **원고의 주장 → 확인된 근거 범위 → 해석에 생기는 차이**를 남긴다.
4. 의미가 정확하고 더 읽기 쉽게만 바꿀 수 있으면 편집 권고다. 원문 자체나 필요한 조건을 확인하지 못했다면 미확인이다.

단어 검색만으로 판정하지 않는다. ‘공식’, ‘외화’, ‘장부’는 금지어가 아니다. 근거가 충분하면 사용할 수 있다. 미확인은 거짓이라는 뜻이 아니며, 근거 미지원도 반드시 현실에서 거짓이라는 뜻은 아니다. 원고가 확보된 근거보다 강하게 단정한 부분을 교정한다.

## 분류와 처리

| 분류 | 판정 근거와 예 | 처리 |
| --- | --- | --- |
| 관측시점 오류 `observation_time` | 수집시각으로 실제 관측의 선후관계나 뉴스의 인과를 단정 | 필수 교정 |
| 출처 속성 확대 `source_authority` | 환율 자료의 공식성이 확인되지 않았는데 공식 관측이라고 표현하거나, 언론의 정부 발표 인용을 직접 확인한 정부 원문으로 표시 | 필수 교정 |
| 설명 범위 확대 `claim_scope` | 계획을 집행으로, 가격 변화를 거래량으로, 달러 결제 환산을 장부 평가·판매 효과로 확장 | 필수 교정 |
| 근거와 모순 `evidence_conflict` | 원문이 명시한 방향·조건과 원고가 반대 | 필수 교정 |
| 금지된 권고 `advice` | 가격·판촉·투자 등의 구체 행동을 독자에게 지시 | 필수 교정 |
| 편집 권고 `style` | 정확하지만 추상적인 제목, 문맥상 정확한 상위어, 길거나 덜 매끄러운 표현 | 선택적 다듬기 |
| 미확인 `verification_gap` | 원문·대상 기간·적용 조건을 아직 대조하지 못함 | 확인 대기. 사실 오류로 단정하거나 자동 교정하지 않음 |

근거를 확인했으나 일부 주장만 지지하면 `limited`, 지지가 없으면 `unsupported`, 명시적으로 모순되면 `conflicting`이다. 모두 `rewrite`와 필수 교정 사유를 요구한다. 근거가 지지하는 문체 개선은 `supported/refine/style`, 지적 없음은 `supported/keep/none`, 자료 확인 대기는 `unverified/keep/verification_gap`이다. 내용이 사실이어도 금지된 업무 지시라면 `supported/rewrite/advice`일 수 있다.

제목도 같은 기준을 따른다. ‘정부 외환 매각 계획과 대외 여건의 상충’은 추상적이라는 이유만으로 게시 차단하지 않는다. ‘정부가 달러를 대량 매각해 페소 급등을 확정했다’처럼 미확인 집행·규모·인과를 새로 넣는 제목은 필수 교정한다.

## 과도하게 차단하지 않는 경계

| 허용하거나 편집 권고로 남길 설명 | 필수 교정 또는 확인이 필요한 설명 |
| --- | --- |
| ‘보도에 따르면 예산 당국은 달러 매각 계획을 발표했다’처럼 언론에 귀속 | 정부 원문을 직접 확인했다는 잘못된 표시 |
| ‘기사의 장중 반응’과 저장 환율을 구분 | 기사 시각만으로 저장 환율의 실제 관측시각과 인과를 확정 |
| 앞 문장이 동일한 달러 대금을 명시한 뒤 ‘이 외화 대금’으로 지칭 | 달러 표시 환율만으로 모든 외화 결제액의 같은 방향 변화를 단정 |
| 동일 USD 금액·미헤지 조건의 현지통화 환산과 계약·선결제 예외 | 장부 평가손익·실제 마진·판매 변화를 확인한 듯 확장 |
| 구리만 논하는 문맥에서 ‘원자재’라고 표현하되 구체 명칭을 권고 | 구리 하나의 움직임을 원자재 전반의 추세로 일반화 |
| 중요한 조건을 이미 밝힌 짧은 설명 | 문장을 강하게 만들기 위해 원문의 중요한 반대 조건을 삭제 |

## 저장된 칠레 원고의 재분류

2026년 10월 7일 에이전트 검토. 대상은 `CLP-2026-10-05-1791378393983`의 저장 원고와 해당 시험의 원문 문맥이다. 새로운 모델 평가나 사용자 내용 승인이 아니다. 과거 점수·본문·검토 결과·비용은 덮어쓰지 않는다.

| 위치와 원고 표현 | 이번 분류 | 근거와 교정 범위 |
| --- | --- | --- |
| 요약 첫 문장 ‘공식 관측 이후’ | 필수 교정: 공식성 및 관측시점 | 고정 패킷의 `observationAt`은 null이다. 수집시각이 있어도 실제 관측시각을 대신하지 못한다. 공식성을 입증한 기록도 없다. 저장 환율과 보도의 범위를 분리하고 해당 수식어를 좁혀야 한다. 자료가 비공식임을 입증했다는 뜻은 아니다. |
| 영업 의미 첫 문장 ‘장부상 현지통화 환산 부담’ | 필수 교정: 설명 범위 | 승인된 원리는 같은 USD 결제대금의 조건부 환산이다. 회계상 장부 평가를 확인한 자료가 없다. 결제대금의 현지통화 환산액으로 한정한다. |
| 같은 문장의 ‘동일한 외화 금액’ | 구체화 권고. 단어 자체로 별도 오류를 세지 않음 | ‘외화’가 달러를 지칭하는지 문맥으로 판단한다. 이번 입력의 단위를 명확히 하려면 USD로 쓰는 편이 좋다. 다른 외화 전반에 같은 결론을 적용하면 그때는 범위 오류다. |
| 제목 ‘정부 외환 매각 계획과 대외 여건의 상충’ | 편집 권고 | 본문의 현지 정책 신호와 글로벌 달러 배경을 더 쉽게 전달할 수 있다. 추상성 자체는 사실 오류가 아니다. |
| 배경 제목 ‘대외 통화 여건과 원자재 가격 흐름’ | 편집 권고 | 해당 원문은 글로벌 달러와 구리를 다룬다. 구체 명칭으로 바꾸면 이해하기 쉽다. 본문의 ‘주요 원자재’가 시장 전반을 뜻하는지까지 확인해야 하며 일반화가 있다면 범위 오류로 처리한다. |
| 관찰 변수의 집행·포지션 조정 여부 | 유지할 조건부 설명 | DF의 전문가 발언은 비거주자가 앞으로 포지션을 조정할지 관찰하는 내용이고, La Tercera는 매각 규모의 변경 조건을 전한다. 미래 관찰을 집행 완료나 관측된 청산으로 바꾸지 않는다. |

원문 위치는 저장된 DF 문맥의 `p0/p2/p3/p5`(발표·신호·전문가 해석), La Tercera의 `p9/p10/p13/p14`(발표·변경 조건·글로벌 달러 대비·구리)다. 두 기사에 동일 기관 XTB가 인용된 사실은 독립 확인 횟수로 늘리지 않는다. 원문은 당시 최초 판본을 보장하는 아카이브가 아니라 수집 당시 공개 페이지다.

필수 교정은 **두 문장**이며 요약 문장에는 두 종류의 문제가 함께 있다. 나머지 구체화 권고를 오류 수에 합산하지 않는다. 이 표는 앞서 지적한 쟁점의 재분류이며 모든 문장에 대한 신규 합격 판정은 아니다. 기존 평균 3.2점과 미채택 상태는 유지한다.

## 코드 적용과 한계

`claim-review/2`는 검토 문장마다 `issue`를 요구하고 `requiredCorrections`, `optionalRefinements`, `verificationPending`을 별도로 반환한다. 사유·지지 여부·처리 방식이 모순되면 교정을 실행하지 않는다. 선택적 편집만 있으면 기본 경로에서는 추가 교정 호출이 없다. 미확인 항목은 확인 대기로 남긴다.

기존 `claim-review/1` 기록은 과거 계약으로 보존한다. 새 검토에 이전 승인 기록을 재사용하지 않는다. 이 변경은 기존 최소 품질 점수·의미 검토·발행 승인을 완화하지 않는다. 문체 권고가 없어도 설명 자체가 부실하면 별도의 독자 품질 평가에서 미달할 수 있으며, 그 사유를 사실 오류라고 부르지 않는다.

분류 코드는 검토자의 판단이 일관되게 처리되는지 검사한다. 모델이 정확한 분류를 선택하거나 원문 전체를 이해한다는 증명은 아니다. 실제 모델의 새 기준 판별력은 아직 시험하지 않았다. 이번에는 API 호출·본문 교정·화면 변경 없이 분류 기준과 저장 원고의 쟁점 검토를 완료한다.

로컬 검증: 타입·린트·전체 54개 파일의 293개 테스트 정의, 387개 실행 사례와 운영/리포트 빌드가 통과했다. 정확한 중복 이름·동일 테스트 본문·자기 비교 감사는 검출 0건이다. 기존 운영 번들 804,454바이트 경고는 유지된다. 위 원고·입력·비용 파일 해시가 작업 전후 동일함을 확인했다. UI를 수정하지 않아 브라우저 시각 검사는 재실행하지 않았다. 신규 API 호출과 비용은 0이다.
