# 멕시코 자료의 공통 집필 입력 연결

2026-10-28 · 저장 자료 재생 · 로컬 구현 · 모델·유료 호출 0회

## 결과와 경계

**10월 26일 멕시코 시장 보도와 공식 종가, 이전 정책 결정, INEGI 소비 자료를 공통 집필 입력에 연결했다.** 검토 기준일은 10월 28일이며 최신 시장 리포트나 당시 실시간 발행물로 표시하지 않는다. 실제 원고를 만들거나 발행 후보를 임의로 생성하지 않았다.

현재 결과는 `prepared_input_not_called`다. 입력 조립과 역할·기간·수치 검사가 통과했다는 의미이며, 실제 모델의 설명 품질·사람의 게시 승인·운영 반영과 구분한다. `decision`, `generationRequest`는 null이고 유료 호출·게시 권한도 false다. 모델 설정과 예산·호출 경로는 이번에 변경하지 않았다.

## 재사용한 자료와 흐름

1. [이전 시장·정책 검토](mxn-market-policy-review-20261028.md)의 Banxico CA18 HTML·산정법 PDF·정책 PDF와 El Economista 저장 기사·검토 요지를 재사용했다.
2. `mxn-official-price`가 공식 표에서 열·은행 영업일 행·종가 값을 읽고 코드로 변화율을 계산한다. 공개 페이지를 다시 읽거나 토큰을 사용하지 않는다.
3. 기존 `reviewSelectedNewsMaterial`이 원본과 묶인 사실·귀속 견해 카드를 재검사한다. 기사 두 종가와 공식 가격 기준의 연결은 별도 검토 기록으로 묶는다.
4. [INEGI 기존 검토](mexico-api-verification-20261027.md)의 통계·발표일·이용 기록을 재검증해 소비 환경 입력을 조립한다. 정책은 확인한 이전 결정의 사실만 제한된 배경으로 넣는다.
5. 기존 범위·이용·시점·조사 자료 검사를 통과한 뒤 `harnessRequest`의 공통 집필 지침·출력 스키마로 미리보기를 만든다. 실제 발행 판단이나 모델 전송 요청은 만들지 않는다.

## 가격·거래일 검사

- 공식 종가 식별자는 `CA18:closing_reference`다. API 계열 ID를 추측해 부여하지 않았다. `SF43718` FIX로 바꾸면 거부한다.
- 멕시코 은행 영업일을 그대로 거래 기준일로 사용한다. 칠레 평균환율처럼 고시일을 하루 옮기지 않는다. 결제일·적용일은 확인되지 않은 상태의 null이다.
- 공식 표의 직전 은행 영업일 5행과 최신 행의 구조를 확인한다. 행이 빠지거나 종가 열 순서가 바뀌면 보류한다. 주말을 독립 관측으로 채우지 않는다.
- 현지 산정 구간은 13:55~14:05이며 실제 선택된 연속 3분과 개별 관측시각은 미상이다. 14:10은 정해진 발표 안내이지 실제 역사적 업로드 시각의 증거가 아니다.
- 표의 수치 행·차트 값·일간·5관측일·전월 말 대비 값을 다시 대조한다. 저장된 변화율만 믿지 않는다.
- CA18은 요약 기준일 모음이다. 전체 일별 이력·3개월/52주 범위를 확보한 것으로 표시하지 않는다. `coverage.dailyHistoryComplete=false`를 유지한다.
- 기사 게시일은 `America/Mexico_City`로 판정한다. UTC 날짜가 다음 날이어도 현지 같은 날일 수 있다. 기사 발행시각은 사건 발생시각이 아니다.
- 현재 확보한 스냅샷보다 이른 기준시각으로 조립할 수 없다. 이번 입력은 과거 사례 재검토이지 당시 자료 가용성의 재현이 아니다.

## 공통 집필·검토·조립 보완

기존 기사 카드와 통계 자료의 혼합 차단은 유지한다. 새 연결에서는 재검증한 소비 맥락·등록된 정책 배경만 별도 `fxWritingBackground`로 허용한다. 임의의 이웃 자료를 추가하거나 검토 후 본문·범위를 바꾸면 거부한다. 원문·비공개 검토 영수증·환경 값·로컬 경로를 집필 미리보기에 보내지 않는다.

`drivers`는 당일 환율 설명, `implications`는 검토된 소비·정책 배경으로 구분한다. 배경 자료를 drivers의 근거로 연결하면 보류한다. implications에 시장 기사만 붙이거나 미검토 근거를 연결하는 것도 차단한다. 배경의 문장별 출처 연결은 기존 writer-links와 내용 검토에 포함한다. 제목·요약의 지지 여부와 인과 해석의 타당성은 계속 내용 검토 대상이다. 참조 위치 검사만으로 문장의 의미적 정확성을 보장하지 않는다.

종전의 ‘implications는 빈 배열’ 지침은 이 경로에 맞는 배경 작성 지침으로 바꾸어 전달한다. 서로 충돌하는 지시를 덧붙이지 않는다. 환율 변화 요약에는 spot·day·five·mtd만 넣고 소매·CPI·정책 수치가 같은 문장에 섞이지 않게 했다. 새 배경 문장은 코드가 작성한 달러 환산 원리로 잘못 분류하지 않는다. 기존 CLP 등 배경 연결이 없는 입력은 종전 계약을 유지한다.

## 이용 판단과 실행 범위

기사 요지는 이전의 제한된 사실·귀속 견해 이용 판단을 재사용했다. 공식 가격과 정책에도 소수의 확인한 사실·날짜·메타데이터에 한정한 명시적 로컬 검토 기록을 묶었다. 원문·번역·시장 원자료 피드·문서의 고유 구성·로고를 전달하는 허가로 확대하지 않는다. 공개 사이트의 일반 재배포 라이선스를 확보했다고 주장하지 않는다.

이용 조건이 미완료이거나 자료·검토 기록의 연결이 달라지면 집필 미리보기를 만들지 않는다. 외부 모델 입력 후보라는 판단과 실제 API 호출 승인은 별도다. 최종 공개 표현·출처 표시와 게시 승인은 pending 상태로 유지한다.

## 재현과 실제 검증 기록

```powershell
npm.cmd run report:research:prepare-mxn -- --input .local-reports/private/mxn-writing-integration-20261028/verified/input.json
```

새 실행은 `.local-reports/private/mxn-writing-runs/prepare-*/`에 `result.json`과 `writer-input-preview.json`을 별도로 저장한다. 입력 경로는 기존 비공개 로컬 폴더 내부만 허용하고 문서·표의 실제 바이트 해시를 확인한다. 기존 결과는 덮어쓰지 않는다.

최종 저장 미리보기: `prepare-oVu1nH`. 실제 입력은 시장 기사 1건·통계 관측 4개·정책문 1건이다. 저장 자료 재생 8항목에서는 정상 입력과 FIX 대입·기사 날짜 이동·스냅샷 전 기준시각·정책문 교체·가격 이용 보류·소매의 원인 대체·검토 후 내용 변경을 구분했다. 네트워크 시도는 0회다.

추가로 실제 저장 입력에 **합성 출력**을 넣어 소비 배경의 문장별 근거 연결, 환율 변화 요약의 수치 분리, 배경을 환율 원인에 넣은 출력의 거부를 확인했다. 이는 AI가 새 원고를 잘 썼다는 품질 시험이 아니며 기존 원고로 등록하지 않았다. 기록은 `.local-reports/private/mxn-writing-integration-20261028/`의 `saved-replay.json`, `synthetic-output-replay.json`, `final-summary.json`에 보존했다.

최종 자동 검사 108파일·766사례, 타입 검사, 린트, 운영/로컬앱/리포트 빌드와 번들 경계가 통과했다. 새 합성 계약 검사는 가격 9사례·배경 3사례다. 테스트 수를 실제 모델 원고 품질 표본으로 세지 않는다. 빌드와 린트가 겹쳐 생성 파일 교체 중 린트가 한 번 중단됐으나, 빌드 종료 후 타입·린트를 순서대로 재실행해 통과했다. 기존 500 kB 번들 경고는 유지하며 진입 번들 610,348바이트·지연 xlsx 경계도 유지됐다.

직전 시장 검토 시작 시 만든 누적 보존 목록 27,539개와 대조해 의도한 기존 코드·진행표 8개 외 변경·누락 0을 확인했다. 이 목록에 없는 신규 파일과 package 명령은 별도 추가했다. 원고·환율·비용 기록을 덮어쓰지 않았다. 코드·문서·브라우저 산출물·새 로컬 입력/미리보기 615파일을 실제 두 연구 키와 대조한 결과 노출 0이었다. 입력 경로의 비공개 폴더 이탈과 다른 산정법 문서도 별도로 거부했다. 실제 브라우저 화면·DB·메일·모델 원고 품질 검증은 이번 입력 연결 단계에서 수행하지 않았다.

## 다음 단계

내용 판단은 **Astra High**로 최종 입력을 검토하는 것이 적절하다. 확인할 것은 카드가 실제 설명을 지지하는지, 당일 기사와 정책·소비 배경의 역할이 타당한지다. 그 뒤 새 실제 원고 시험은 별도 모델·가격·예산 승인 범위에서 진행한다.

이번 단계는 저장 자료의 공통 집필 입력 연결이다. 최신 자료의 반복 수집·전체 국가 지원·실제 모델 품질·관리자 게시·운영 배포는 완료로 표시하지 않는다. 기존 원고·환율·비용 기록과 운영 설정은 보존한다.
