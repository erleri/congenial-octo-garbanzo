## 수정 효과와 남은 한계

### 페루 선택 개선은 실제 수집에서도 확인

RPP 원인 해설 `1715079`가 새 공통 선택 규칙으로 우선 선택되어 본문까지 수집됐다. 원문 선택을 사람이 지정하거나 사실 카드를 손으로 작성하지 않았다. 원실행에서 시세 기사에 밀리던 선택 문제는 저장 재현에 이어 실제 무료 수집에서도 개선됐다.

그러나 해당 기사는 10월29일 발표 자료이며 현재 검색 구간은 10월30일~11월2일이다. 발행 시점 선별은 이를 `publication_before_session_window`로 제외했다. 최신 구간의 RPP `1715142`는 가격과 일반 소비 영향 설명이 중심이다. 이 가격 기사만으로 환율 원인을 채우면 안 된다.

이는 ‘페루에 설명 기사가 없다’는 의미가 아니다. 현재 구간의 해설 확보와 첫 점검에서 사용할 과거 설명의 허용 범위가 남아 있다는 뜻이다. 과거 설명을 사용하려면 실제 설명 날짜를 유지하고 현재 가격의 직접 원인으로 소급하지 않는 공통 기준으로 검토해야 한다.
