## 오류와 보류의 구분

첫 CLP 응답은 `currency_mismatch`와 R09 발행 정책으로 보류됐다. 원문·입력·출력을 대조한 결과, 환율 단위를 바꾼 것이 아니라 **DF에 인용된 브라질 자산 포지션 해소 자금의 칠레 유입 가능성**을 설명한 문장에서 국가 이름을 잡은 오탐이었다. 인용된 검토 카드에 해당 국가가 있고 본문이 해당 통화와의 연결을 명시한 경우에만 허용하도록 좁게 보완했다. 출처 없는 국가명·다른 통화 단위·호가 혼용은 계속 거부한다. 최초 응답과 보류 기록은 수정하지 않고 저장 응답의 재평가를 따로 보존했다. 재호출은 없었다.

BRL·MXN도 구조·수치 검사에는 통과했지만 R09의 `review_required` 또는 `no_material_change`가 원고 실패와 묶여 `output_hold`로 남았다. 이 기록은 보존한다. 후속 공통 실행 경로는 **별도 승인된, 환율 설명 근거에 결합된 로컬 초안**의 내용 검사와 R09 자동 발행 보류를 구분한다. R11 등 내용·수치·보안 문제나 편집 차단을 무시하지 않으며, 내용 검사를 통과해도 `contentReview=unverified`, 공개 승인 false와 발행 보류를 그대로 반환한다.

CLP 다음에는 기존 BRL→CLP 품질 합격 뒤 MXN 진행 규칙과 타 국가의 보류 원고 때문에 실행이 막혔다. 이 시점에 BRL/MXN 예약이나 POST는 없었다. 이번에 명시적으로 승인된 **세 나라의 정확한 요청·모델·최대 비용·각 최초 1회**에만 결합한 비교 승인을 추가해 남은 두 건을 진행했다. 기존 실패 원고나 비용을 지우거나 캠페인을 갈아타지 않았다. 같은 국가 재호출·미확인 비용·예산 초과·승인 외 요청은 계속 차단한다.
