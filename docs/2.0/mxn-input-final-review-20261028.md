## 판정

**2026-10-26 페소 움직임을 제한된 범위에서 설명할 근거는 있다. 가격·거래일과 소비 배경 분리는 타당하다. 다만 실제 집필 전 공통 지침 충돌 F01을 해소해야 한다.** A안에 결과를 붙이기 전에는 요약 표를 연속 차트로 오해시키는 F02도 처리해야 한다.

이는 같은 대화의 에이전트가 원문과 입력을 다시 대조한 최종 검토다. 독립 맹검 또는 별도 유료 모델 평가로 표시하지 않는다. `prepared_input_not_called`는 기존 구조 조립 결과로 보존하며, 이 별도 내용 검토의 `writerDispatch=hold_F01`과 구분한다. 실제 새 AI 원고가 없으므로 원고 품질 점수는 부여하지 않는다.

검토 대상은 `prepare-oVu1nH/writer-input-preview.json` 및 그 원본 자료다. 10/28은 검토 기준일, 10/26은 환율 거래일이다. 오늘 시장 리포트나 10/26 당시에 확보된 빈티지 자료가 아니다.

## 수정 필요와 선택 개선을 구분

### F01 — 실제 호출 전 필수: 숫자·기간·자리표시자 계약 충돌

- 공통 지침: `본문·제목·요약에 숫자·날짜·URL·placeholder를 직접 쓰지 않는다.`
- 소비 지침: `본문 수치는 코드의 {{fact_id}}만 사용한다.`
- 실제 출력 스키마의 문자열 정규식은 중괄호를 금지한다. 소비 지침을 따라 `{{mxn_retail_yoy}}`를 넣은 합성 응답은 `draft_schema`로 거부됐다.
- 대상 월을 유지하라는 지침에 따라 `8월`을 직접 쓴 합성 응답도 `untrusted_text`로 거부됐다. 기간은 출처 메타데이터에 있으므로 잃어진 것은 아니지만, 모델이 무엇을 써야 하는지는 일관되지 않다.

**권장 해결:** 기존 공통 계약을 유지해 모델은 정성적 설명과 근거 ID를 작성하고, 수치·대상 월·비교 기준은 코드가 붙이도록 역할을 하나로 정한다. 독립 경제 업데이트 경로는 자리표시자를 쓰므로 공유 지침을 통째로 삭제하지 말고 목적별 계약에서 정확히 분리한다. 본문에 근거 없는 숫자를 허용하도록 검사를 풀지 않는다. 날짜 표시와 수치 연결까지 저장 자료의 정상/실패 출력으로 확인하면 종료한다.

원고를 고치는 일이 아니라 공통 생성 계약을 한 번 수정할 사안이다. 이번 검토에서는 코드·지침을 수정하지 않았다.

### F02 — 화면 연결 전 필수: 요약 관측을 연속 이력처럼 표시할 가능성

가격 입력은 `dailyHistoryComplete=false`이고, 최근 6개 은행 영업일 및 월말 등 일부 기준일만 담는다. 기존 `CurrencyReportDetail.Chart`는 점을 시간 간격 대신 배열 순서로 동일 간격 연결하며 1·3·12개월 버튼을 표시한다. 9/30~10/19의 긴 공백과 하루 간격을 같은 길이로 그릴 수 있다.

숫자 계산의 오류는 아니지만 추세를 오해시킬 수 있다. 확보 구간만 표시하고 간격을 보존하거나, 요약 기준일 표로 제시해야 한다. 이를 위한 대규모 가격 재수집은 이번 입력 검토의 필수 조건이 아니다. 실제 MXN 화면을 생성·등록하지 않았으므로 이번에는 **코드 정적 확인**으로 기록하며 화면 검증 완료로 세지 않는다. 원래 계획의 6단계 표시 계약에 배정한다.

### E01 — 공통 연결 정리 때 함께 처리할 편집 상태 불일치

별도 `fxWritingBackground.consumerContext`에는 두 소비 주제가 있는데 `researchBrief.unresolved`는 consumer를 missing으로 표시한다. 기존 시장 조사 하위 계획에는 없다는 뜻이지만 최종 입력 전체의 부재로 오독할 수 있다. 출처를 다시 수집할 필요 없이, 하위 계획의 범위와 배경 첨부 완료를 명확히 표시한다. 근거 자체의 오류나 새 정보 누락은 아니다.

### 유지할 조건 — 새 차단 사유로 늘리지 않음

- 단일 시장 기사의 전문가 해석도 귀속·범위를 지키면 쓸 수 있다. 무조건 두 매체를 강제하지 않는다.
- 발표가 종가 이후라는 사실만으로 당일 회고 보도를 배제하지 않는다.
- 원계열 3.3%와 계절조정 3.2%는 구분할 값이다. 더 보기 좋은 수치를 선택하지 않는다.
- 기간·출처 메타데이터는 이미 있으며 공개 화면에서도 출처 링크의 대상 기간을 표시한다. 이를 데이터 유실로 과장하지 않는다.
- 이용 판단은 기존 제한된 사실·귀속 견해 범위를 재사용했다. 이번에는 새로운 법률/라이선스 판단이나 공개 이용 승인, 최신 약관 확인을 하지 않았다.

## 검증 기록

새 비공개 기록: `.local-reports/private/mxn-input-final-review-20261028/verification.json`.

- 저장 입력 재조립 결과와 기존 미리보기의 완전 일치 확인.
- 실제 입력 위 합성 출력으로 정상 구조, F01의 자리표시자·대상 월 충돌, 소비 근거의 원인 위치 거부를 확인.
- 올바른 뉴스 ID를 붙인 인과 과장은 구조 검사만 통과할 수 있음을 확인. 구조 통과를 내용 승인으로 쓰지 않는 기존 검토 경계가 필요하다. 이를 새 의미 자동검출 성공으로 보고하지 않음.
- 요약 표 coverage와 차트의 정적 구현, 소비 배경/하위 조사 상태 불일치 확인.
- 총 8개 검토 재생 항목. 실제 AI 원고 품질 표본 8건이라는 뜻이 아님.
- 관련 코드·입력·기존 원고·환율 등 11,999파일 전후 해시 동일. 원고·기존 평가·비용·입력 상태는 덮어쓰지 않음.
- 네트워크 시도 0, 모델 호출 0, 신규 비용 $0. 자격증명 파일은 열지 않음. 새 문서와 별도 검토 기록만 추가.
- 제품 코드 변경이 없으므로 전체 766사례·빌드는 이번에 재실행하지 않음. 직전 성공 기록을 이번 실행 결과로 부르지 않음.

## 원래 순서로 복귀

추가 기사 조사나 멕시코 원고 반복 제작으로 확장하지 않는다. **내용 검토는 여기서 종료**한다. F01/E01을 공통 집필 경로의 제한된 마감 작업으로 묶고, F02는 화면 단계에 둔다. 다음은 [6개 통화 실행 순서](six-currency-work-sequence-20261028.md)의 3단계 공통 경로 마감과 4단계 나머지 국가 연결이다. 실제 유료 시험은 그 뒤 별도 승인한다.
