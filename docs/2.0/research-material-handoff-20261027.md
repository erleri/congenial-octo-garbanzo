# 수집 자료에서 집필 재료·부족한 질문으로 연결

2026-10-27 · 로컬 전용 · 신규 외부 요청·모델 호출·비용 $0

## 이번에 연결한 흐름

`기존 수집·원문 검토 결과 → 자료별 사용 범위 검사 → 기존 기간·통계 범위·질문 검사 → 검토에 쓸 자료와 부족한 질문 반환`

새 검색기·원고 생성기를 만들지 않았다. 기존 BCCh 입력, 언론 원문 채택 결과, INE 월별 근거 카드를 받는 연결 명령 `report:research:materials`를 추가했다. [출처 경로 조사 기록](report-source-routes-20261027.json)은 여전히 조사 문서이며, 그 상태 문구를 자동 승인 규칙으로 읽지 않는다. 이번 연결은 별도의 명시적 사용 범위 기록을 검사한다.

| 부분 | 역할 |
| --- | --- |
| `source-use.js` | 로컬 분석·외부 모델 입력·공개 표시의 상태와 조건을 각각 확인한다. 미확인, 거절, 조건 미충족, 자료 변경을 구별한다. |
| 기존 `research-needs.js` | 선택적으로 사용 범위 기록을 받아 기존 날짜·기간·모집단·단위 검사를 유지한다. 사용 범위 문제는 원문을 다시 검색하기 전에 저장 자료 검토로 돌린다. 이전 호출 방식과 판단은 그대로 유지한다. |
| `research-materials.js` | 기존 `inspectDossier`, `projectEvidenceScopes`, 시간 검사, `planChileConsumptionNeeds`를 연결한다. 사용할 가격·근거의 제한된 사본과 미해결 질문을 만든다. |
| `research-materials-local.js` | Git 제외된 비공개 파일만 읽고 결과를 새 폴더에 저장한다. 키·네트워크·DB·집필·승인 경로를 호출하지 않는다. |

## 반복 적용하는 사용 범위 기록

각 자료에는 `source-use/1` 기록을 연결한다.

- 원자료 식별자와 전체 자료 해시, 확인한 약관 URL·버전 표기·검토일·허용 범위.
- `local_analysis`, `external_model`, `public_display` 각각 `allowed`, `pending`, `denied`.
- 각 이용 범위에서 필요한 조건과 충족·미충족 상태.
- 명시적인 검토자의 판단 이유. 이 기록은 신원 인증이나 법적 허가 증명이 아니다.

정책 검토 결과는 동일한 자료 범위·조건에서 재사용할 수 있다. 새 수집물의 해시와 범위를 연결하지 않은 과거 기록을 자동 복사하지 않는다. 자료·기간·메타데이터가 바뀌면 `source_use_binding_changed`로 보류한다. 출처명이나 ‘공식기관’ 문자열만으로 이용을 허용하지 않는다. 미확인 기록을 `allowed`로 만드는 기능은 없다.

외부 모델 이용이 허용된 범위 기록이 있어도 수정본·대상 기간·발표시각·모집단 검사는 계속 수행한다. 오래된 단일 `reuse` 플래그는 수정하지 않는다. 새 기록은 이번 계획의 이용 범위 판단에만 적용한다. 공개 표시 조건은 모델 입력 조건과 별개로 반환하며 실제 게시 승인으로 연결하지 않는다.

## 실제 칠레 저장 자료 적용

이번 재생 기준일은 **10월 26일**, 환율 거래일은 **10월 23일**이다. 10월 27일의 최신 자료를 새로 수집하거나 오늘 보고서를 만든 것이 아니다. 기간과 이용 조건을 판단한 시점도 별도로 기록했다.

| 자료·질문 | 결과 | 남은 판단 |
| --- | --- | --- |
| BCCh 공식 환율 | 고정된 990.35 CLP/USD, 계산 사실·차트 표본·가격 기준을 검토 사본에 포함 | 공식 평균과 기사 호가의 차이, 관측시각 미상, 원인 설명 및 새 작성 가치 |
| INE 통계 3개 | 2026-08 실질 시간당 보수·전체 소매·가전/전자 관련 상품군의 검토된 범위와 출처·라이선스·변경 표시를 포함 | 최신 통계 여부는 미확인. 해당 월의 배경 자료이며 회사 판매·당일 FX 원인 아님 |
| 소비·상품군 비교 질문 | 기존 판정기가 명시적으로 선택한 2026-08 범위에 `available` 반환 | 의미적 주장 검토와 최신 기간 선정은 별개 |
| 기사 기반 시장·현지·글로벌·반대 요인 | 저장된 검토 기록은 유지하되 이용 미확인으로 집필 재료 사본에서 제외 | 적합한 이용 근거 확보 또는 허용 출처로 동일 주장을 다시 검증 |
| 향후 관찰 변수 | 별도 근거 없음 | 개수를 채워 생성하지 않음. 선택 항목의 미확보를 필수 질문과 혼동하지 않음 |

결과는 `materialStatus: incomplete`, `writingEligibility.eligible: false`다. 자료 준비, 의미 검토, 새 작성 필요성, 원고 품질, 게시 승인을 별도로 유지한다. INE가 사용 가능하다고 기사 설명까지 허용하거나, 기사 이용 문제가 있다고 준비된 통계 작업까지 중단하지 않는다.

집필 검토용 사본은 필요한 수치·시계열·출처·기간·발췌·범위만 포함한다. 비공개 검토 기록·검토자 정보·원 응답·임의 provenance 필드는 전달하지 않는다. 이름이 같은 출처 여러 개를 독립 확인 횟수로 승격하지 않는다.

## 재현 명령

Node 20.19.0에서 실행한다. 세 입력은 `.local-reports/private` 안의 파일이어야 한다.

```powershell
npm run report:research:materials -- --input .local-reports/private/publisher-admission-nFVplW/review-input.json --monthly .local-reports/private/official-statistics-review/pdf-9257XG/evidence.json --uses .local-reports/private/research-materials-review-BDKmSQ/source-use-reviews.json --asOf 2026-10-26T23:59:59Z --period 2026-08
```

매 실행은 새 `.local-reports/private/research-materials-*/result.json`에 저장한다. 이전 결과·원고·비용 기록을 덮어쓰지 않는다. 외부 경로, 큰 파일, 자료 식별 중복, 오래된 근거 카드 등 잘못된 입력은 거부한다. 이 명령은 실제 최신 수집이나 유료 집필을 수행하지 않는다.

- 사용 범위 검토 기록: `.local-reports/private/research-materials-review-BDKmSQ/source-use-reviews.json`
- 실제 최종 결과: `.local-reports/private/research-materials-9fzxaW/result.json`
- 실행 요약: `.local-reports/private/research-materials-review-BDKmSQ/final-replay.json`
- 원본 보존 검사: `.local-reports/private/research-materials-review-BDKmSQ/verification.json`
- [구조화 검증 결과](research-material-handoff-20261027.json)

## 검사 범위와 남은 작업

새 검사 6개는 이용 범위별 상태·조건, 변경된 자료 바인딩, 기존 판정기 연결, 일부 자료만 보류, 기간/수정본 보존, 비공개 경로/새 출력 책임을 나눠 확인한다. 실제 시장·라이선스 허가·새 원고 품질 표본은 아니다. 처음 작성한 합성 데이터가 문서 묶음 제한을 초과해 연결 검사 4개가 실패했고, 실제 형식처럼 두 문서·세 지표로 수정한 뒤 통과했다. 제품의 제한을 완화하지 않았다.

전체 88개 파일·613개 실행 사례(509개 선언, 매개변수 확장 104개), 타입 검사, 린트, 운영용·리포트용 빌드와 번들 경계가 통과했다. 정확히 같은 검사 이름·본문·자기 비교는 발견되지 않았다. 의미적 중복이 없다는 보장은 아니다. 마지막에는 새 검사의 비공개 필드 제외·소비 상태 표시 확인도 재실행했다. 기존 610,348바이트 entry의 500KB 초과 경고는 유지된다.

이번에는 DB·화면을 변경하지 않아 pgTAP과 시각 검증은 다시 수행하지 않았다. 키를 읽지 않았고 추가 외부 수집·유료 호출·생성·운영 반영·원격 push도 하지 않았다.

다음은 **어떤 기간의 자료를 조사할지 선택하는 규칙과, 실제 새 수집 결과를 이 판정에 넘기는 연결**이다. 이번 선택 월 2026-08은 고정 재현용이며 최신 월을 자동 선택한 결과가 아니다. 기사 대체 자료를 채택하려면 실제 원문·이용 범위·주장 지지 검토가 필요하다. 집필 자격을 얻은 뒤에도 새 유료 호출과 게시 결정은 따로 둔다.
