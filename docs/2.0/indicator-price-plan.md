# LATAM FX 2.0 필수 지표와 환율 비교 기준안

초기 캘린더는 BRL·CLP·MXN의 금리 결정·물가·소비 지표와 미국의 FOMC·물가·고용으로 제한한다. 환율 변화는 기존 대시보드와 같은 저장 자료로 보여주되, 기사 속 장중 가격이나 공식 기준 환율과 같은 관측으로 합치지 않는다. 설명할 정보가 없으면 항목을 채우거나 새 보고서를 발행하지 않는다.

2026년 10월 11일 기준의 검토용 계획안이다. 하루 한 번 확인·사건 중심 발행·초기 관리자 승인이라는 합의 방향을 구체화하며, 지표별 시계열과 관측 기준은 아래 채택 조건을 충족한 뒤 확정한다. 자료 접근 조사 상태는 [출처 검토](source-feasibility.md), 조사·생성·발행의 구분은 [발행 정책](publication-policy.md)을 따른다. 이번 단계는 문서 정리이며 코드·키·운영 설정·AI 호출 승인을 포함하지 않는다.

## 필수 지표 범위

| 범위 | 초기 후보 | 독자에게 설명할 질문 | 선택 시 확인할 조건 |
| --- | --- | --- | --- |
| BRL | Copom 결정·성명, IBGE IPCA, PMC 소매 판매량 | 정책의 새 내용, 물가 변화, 실제 소비 흐름이 이전 설명과 어떻게 다른가 | 정책금리 적용일과 발표일 분리. 소매 명목 매출과 판매량, 계절조정·전년 대비 구분 |
| MXN | Banxico 결정·성명, INEGI INPC, 소매 부문 지표 | 정책·물가·소비의 새 정보가 있는가 | INPC 월간과 반월 자료 구분. 전국 소매 시계열 ID·단위·조정 방식 선택 |
| CLP | RPM 결정·성명, INE IPC, IAC 및 소매 세부 후보 | 정책·물가·상업활동 변화가 어떤 맥락을 추가하는가 | IAC 전체를 소매판매만으로 부르지 않음. 적합한 소매 세부표 확보 전에는 범위를 상업활동으로 표시 |
| 미국 공통 | FOMC 결정·성명, CPI, Employment Situation | 미국 정책·물가·고용의 새 내용과 출처가 설명한 달러 배경은 무엇인가 | 고용·물가 발표의 대상 월과 발표일 분리. 공통 배경을 모든 통화의 실제 원인으로 자동 배정하지 않음 |

처음부터 각국의 모든 경제지표를 수집하지 않는다. 같은 결정에 딸린 성명과 결정 수치는 하나의 사건 묶음이며 별도 원인 두 개로 세지 않는다. 정례 의사록은 기존 설명을 바꾸는 새 내용이 있을 때 같은 정책 범주의 후속 사건으로 검토한다. 전문이나 발언이 나왔다는 사실만으로 재생성하지 않는다.

초기 소비 맥락은 확보한 공개 집계에 한정한다. 전국 소매 전체, 상업활동 전체, 가전 세부 지표와 개별 회사 셀아웃은 서로 다른 범위다. 실질소득·가계 신용·현지 고용과 내구재 세부 항목은 관련 시계열과 이용 조건이 확인된 뒤 확장한다. 금리 결정 하나로 실제 할부 부담이나 판매 효과를 수치화하지 않는다.

구리·유가·DXY·국채 금리의 새 수치 공급자는 초기 필수 계약으로 추가하지 않는다. 검토한 시장 원문이 해당 자료와 통화의 연결을 설명할 때 출처·시장·관측 구간을 표시해 보조 근거로 사용할 수 있다. 새 수치나 전달 경로를 모델이 만들어 채우지 않는다. 중요한 반대 근거를 확보했다면 선택 범위가 작다는 이유로 숨기지 않는다.

## 캘린더와 발표의 분리

화면에 표시할 일정은 국가·관련 통화·발표명·대상 기간·현지 예정 시각·한국시간·출처·수정 여부를 갖춘다. 정확한 시각이 없는 경우 날짜만 표시한다. 국가로 시간대를 추정해 확인되지 않은 시각을 확정하지 않는다.

예정 일정, 실제 원문 확보, 수치 확인, 내용 검토는 다른 상태다. 일정이 지났거나 API 값이 바뀌었다는 이유만으로 발표를 확보한 것으로 표시하지 않는다. 처음 공개된 자료와 수정본을 따로 남기고, 수정 때문에 기존 설명이 달라지는지 검토한다.

예상치는 초기 필수 입력이 아니다. 적법한 출처에서 발표 전에 확보한 같은 지표·기간·단위의 컨센서스가 있을 때만 예상과의 차이를 다룬다. 전월과 달랐다는 사실을 시장 예상과 달랐다는 표현으로 바꾸지 않는다. 기사에 분석가의 예상 비교가 있으면 그 출처에 귀속하고, 서비스가 별도 컨센서스 수치를 확보한 것처럼 표시하지 않는다.

공식 발표 원문이 핵심 지표의 결과를 뒷받침한다면 자료가 몇 개 없다는 이유로 무조건 배제하지 않는다. 다만 시장 원인, 소비 전달 경로, 반대 근거 등 서로 다른 주장은 각자 필요한 근거를 요구한다. 기사 수나 출처 개수만으로 충분성을 판정하지 않는다.

## 리포트 가격의 기본 기준

### 대시보드와 공유하는 변화 수치

초기 권장안은 기존 환율 계산과 자료 파일을 유지하는 것이다. 리포트 숫자와 차트는 발행 당시 자료 스냅샷에 고정하고 `1 USD = 현지통화` 단위로 표시한다. 이 값이 상승하면 현지통화 약세, 하락하면 강세 방향이다. 전 관측일·5관측일·전월 마지막 관측일 대비의 기존 계산 정의를 유지한다.

데이터 기준일, 해당 통화의 마지막 유효 관측일, 실제 관측시각, 공급자 자료 갱신 시각, 시스템 수집 시각을 구분한다. 실제 관측시각이 없으면 미상으로 둔다. 전체 파일 기준일을 해당 통화의 마지막 관측일로 복사하지 않는다. 주말·보간·휴장 이월 의심값을 독립된 새 시장 움직임으로 세지 않는다.

현재 [환율 병합 코드](../../src/lib/merger.ts)는 여러 공급자의 날짜별 값을 결합해 `source: API`로 저장한다. [API 코드](../../src/lib/api.ts)는 공급자의 갱신 시각을 날짜로 줄이거나 일별 close만 반환하는 경로가 있다. API라는 표시만으로 개별 날짜의 공급자·체결 시각·확정 종가를 알 수 없다. 과거 값을 추정한 공급자로 다시 라벨링하지 않는다.

이 자료를 공식 시장 종가라고 부르지 않고 서비스 저장 기준의 일별 환율로 표시하는 안을 택한다. 대시보드와 맞춘 숫자는 유지하되, 실제 사건 반응을 확인할 가격 자료의 별도 기준이 필요하다. 향후 수집에서는 확인된 공급자·가격 종류·관측 구간·확정 여부를 보존하는 설계를 검토한다. 지금 기존 자료를 재작성하지 않는다.

### 사건 설명에 사용하는 별도 관측

시장 원문에 장중 가격과 관측시각이 있으면 별도 관측으로 다룬다. 출처·단위·시장·비교 기준·시각을 확인하고, 발표와의 연결도 원문에서 설명하는 범위로 제한한다. 그 기사 가격으로 대시보드 KPI나 공통 차트를 덮어쓰지 않는다.

| 자료 조합 | 설명할 수 있는 범위 | 허용하지 않는 연결 |
| --- | --- | --- |
| 저장 환율의 시각과 사건 선후·가격 기준·원문 귀속을 확인 | 해당 비교 구간의 움직임과 출처가 설명한 배경을 연결 | 시간상 먼저였다는 이유만으로 유일한 원인 확정 |
| 저장 환율 시각은 없지만 기사에 특정 시각·기준의 시장 반응이 있음 | 저장 수치와 기사 관측을 분리하고 기사 기준의 반응을 출처에 귀속 | 기사 장중 변동률을 저장값의 변동률로 치환 |
| 정책 원문은 있고 발표 이후 가격은 없음 | 정책의 새 내용·공개 사실과 확인된 일반 경로 | 발표가 당일 저장 환율을 움직였다는 주장 |
| FIX·중앙은행 기준값과 다른 시장 자료가 함께 있음 | 각 기준을 명시한 별도 참고값 | FIX·기준값·장중 가격·저장 일별 값을 같은 관측으로 병합 |
| 가격 또는 사건의 시각·비교 구간이 불명확 | 확인 가능한 변화 사실 또는 정책 내용만 표시 | 수집 시각·예정 시각·날짜만으로 선후 관계 확정 |

대시보드 값과 시장 기사가 다른 가격·변동률을 보여도 곧바로 어느 한쪽의 오류라고 판단하지 않는다. 우선 시각·시장·단위·비교 구간을 대조한다. 동일 기준인데 충돌이 남으면 해당 주장을 보류하고 신뢰하는 숫자 하나를 임의 선택하지 않는다.

## 저장 사례에 적용한 범위

[BRL 2026년 10월 7일 기록](brazil-harness-comparison-results.md)의 저장 일간 +0.24%는 현지통화 약세 방향이고, 5관측일 -4.27%는 강세 방향이다. 하나의 방향으로 합치지 않는다. 기사에는 이전 두 거래일 선거 반응과 당일 오전 조정이 구분되어 있다. 저장 가격의 실제 관측시각이 없으므로 기사 장중 반응을 +0.24%의 직접 원인으로 연결하지 않는다. 누적 변화는 조사 후보지만 기존 비교 원고의 품질 보류와 신규성 미확인을 해제하지 않는다.

[CLP 2026년 10월 5일 기록](harness-comparison-results.md)에는 정책 신호·정부 공급 계획과 시장 해석이 있지만 저장 가격의 실제 관측시각이 없다. 서로 다른 기사 가격 기준도 유지한다. 설명은 정책 사실과 각 출처의 시장 관측 범위로 제한하며 저장 일간 수치 전체의 직접 원인을 확정하지 않는다. 이를 합격한 발행 사례로 재분류하지 않는다.

## 초기 화면과 확인 주기

캘린더는 기존 대시보드에 핵심 예정 발표와 최근 확인된 발표를 요약하는 방향으로 계획한다. 전체 국가·전체 일정 위젯이나 새 디자인을 먼저 확정하지 않는다. 목록은 관련 통화·발표명·대상 기간·확인 상태를 보여주고 공식 자료로 이동할 수 있게 한다. Investing.com은 보조 링크 또는 허용 조건을 확인한 위젯 후보이며 내부 데이터 공급자로 채택된 것이 아니다.

리포트 상단에는 보고서 기준일·가격 관측일·발행 계기를 표시한다. 실제 시각이 확인되지 않으면 필요한 비교에 한해 설명 범위를 제한하고 공통 한계 영역에 모은다. 같은 경고를 원인 문단마다 반복하지 않는다. 최근 확인일이 바뀌어도 본문·차트·발행 기준일은 유지한다.

하루 한 번 기존 데이터 갱신이 끝난 뒤 조사 후보를 판단하는 안을 유지한다. 한국시간 오전 9시 15분의 기존 작업 시작 설정을 보고서 완성 시각으로 보장하지 않는다. 정확한 확인 시각은 자료 도착과 필요한 발표의 선후를 확인한 뒤 정한다. 새 보고서가 없어도 기존 환율 갱신·메일은 정상 경로로 진행해야 한다. 이 계획으로 스케줄을 생성하거나 운영 작업을 변경하지 않는다.

## 세부 결정과 검증 경계

| 상태 | 항목 |
| --- | --- |
| 합의 방향 유지 | 로컬 우선, 하루 한 번 확인, 사건 중심 발행, 관리자 승인, A안 유지, 운영과 유료 호출 별도 승인 |
| 이번 권장 초안 | 국가별 핵심 세 지표 범주와 미국 공통 세 범주, 예상치 선택 사항, 저장값과 기사 관측 분리, 가격 시각 부재를 억지로 채우지 않음 |
| 자료 확인 뒤 결정 | 소매 세부 시계열 ID·단위·조정 방식, 라이선스 표시, 사건 비교용 가격의 공급자·시장·관측 구간 |
| 아직 미정 | 누적 변동·새 정보 중요도 기준, 확인 시각, 작성 모델, 월 예산과 호출별 상한, 실제 검토 인력·운영 승인 절차 |

다음 판단은 숫자 임계값·중복·자료 부족에 따른 생성·보류를 어떻게 구분할지다. 저장된 두 실제 사례와 별도 합성 대조 사례를 먼저 사용한다. 합성 검사는 실제 모델 품질이나 실제 발행 합격률로 계산하지 않는다. 시점·근거 제한을 충족한 정상 설명을 과도하게 막지 않는지도 함께 확인한다.

이번 기준안은 기존 계산·원고·점수·비용을 바꾸지 않는다. 조사 범위가 정해졌다는 이유로 새 기관 키를 요청하거나 모델을 호출하지 않는다. 전체 코드 테스트·브라우저 검증은 구현 이후 변경에 맞춰 수행하며, 이 문서 단계는 내용·연결·경계 검토만 수행한다.
