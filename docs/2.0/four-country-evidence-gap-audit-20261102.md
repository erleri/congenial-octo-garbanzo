## 공통 보완 순서와 완료 기준

1. **부족 상태를 분리한다.** 탐색 미완료, 원문 접근 실패, 검토 실패, 기간 불일치, 검토한 기사에 설명 없음, 예산 부족을 각각 표시한다. `collected_pending_review`를 자료 충분으로 세지 않는다.
2. **선택 피드백을 보완한다.** 처리 실패로 보류된 해설이 영구적으로 시세 기사보다 밀리지 않게 한다. 동일 본문·동일 규칙의 유료 반복은 계속 막고, 규칙 변경/새 판본/새 기간에서는 비용 승인 전 무료 재선정이 가능해야 한다. 페루 저장 목록을 실패 재현으로 사용한다.
3. **설명 기간을 구분한다.** 일간·주간·월간·전망과 가격 종류를 보존한다. 첫 정기·누적 변동 리포트에 기간이 맞는 FX 설명을 검토할 수 있어야 한다. 기간을 넓히더라도 소비 통계로 환율 원인을 대신하지 않는다.
4. **미충족 질문에 맞춰 대체 탐색한다.** 기존 출처의 시세 후보를 받았다는 이유로 탐색을 끝내지 않는다. 마감 해설·수급·전문가 해석 후보를 찾되 제한·실패를 기록한다. 국가별 고정 기사 URL을 예외로 심지 않는다.
5. **같은 6통화로 무과금 재생한다.** 설명 기사 선택 여부, 기간 혼용 방지, 과거 실패 무한 반복 방지, 한 나라 실패 시 나머지 진행을 함께 확인한다. 이 결과 이후에만 필요한 유료 추출·대조의 범위와 비용을 다시 계산한다.
