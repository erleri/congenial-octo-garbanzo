# 반복 경고를 줄이는 경제 리포트 입력 설계

2026-10-11, `a9d3cef`를 보존한 로컬 후속 작업. 추가 API 호출·비용은 0이다. 기존 A안, 실제 원고 3건, 근거 범위 카드, 문장 검토와 비용 기록은 변경하지 않는다. 이 문서는 실제 AI 품질 합격이나 게시 승인이 아니다.

## 원인과 변경 범위

기존 경제 업데이트 입력은 `cards`와 `scopeCards` 양쪽에서 `allowedUse`·`countercontext`를 전달하면서 앞쪽 새 정보는 첫 승인 주장 하나로 축소했다. 실제 세 번째 원고는 같은 IPC의 상승·상쇄를 둘로 나눴고, 문단 끝에 측정 범위 경고를 반복했다. 대상 월이 다르다는 독해 규칙을 관찰 변수로 쓰기도 했다.

새 `economic-editorial/1`은 금지 문구를 더 늘리는 대신 입력의 역할을 나눈다. 경제·소비 업데이트 어댑터의 통화 공통 구조이며 CLP 이름이나 해당 기사의 문장을 생성 규칙에 넣지 않는다. 환율 원인 설명용 별도 writer 경로는 이번에 바꾸지 않았다.

| 입력 | 역할 | 본문에서의 처리 |
| --- | --- | --- |
| `storyBeats` | 출처별 승인 주장 ID 전체 | 새 사실 → 구성·대조 → 확인된 의미. 같은 발표의 상승·상쇄는 묶고 항목 수를 채우지 않음 |
| 원문 `cards` | 발표·기간·원문 구절 | 사실 확인용. 사용 제한을 이곳에 중복 복사하지 않음 |
| `scopeCards` | 기존 단위·모집단·범위·반대 맥락 계약 | 모두 유지. 제외 주장을 문단 끝의 경고 문장으로 나열하지 않음 |
| `placement` | 본문·검토 정보의 배치 | 실제 반대 사실과 해석을 바꾸는 조건은 해당 문장에 남김 |
| `codeOwnedLimitations` | 공통 한계 | 코드가 기존 한계 영역에 한 번 표시. 서로 다른 대상 기간은 직접 차감·같은 달 합산 금지로 정확히 제한 |
| `watchCandidates` | 검토된 관찰 신호와 판단 목적 | 후보가 없으면 `watch: []`. 독해 규칙을 대신 쓰지 않음 |

분량을 늘릴 근거가 없으면 짧게 끝낸다. 새 사실만으로 얻을 수 없는 소비·판매 인사이트를 만들어 빈자리를 채우지 않는다. ‘비교할 수 없다’는 광범위한 금지로 서로 다른 자료의 병렬 설명까지 막지 않는다.

## 조건을 숨기지 않는 기준

- **본문 유지:** 보험·금융의 음의 기여가 같은 IPC 상승을 일부 상쇄했다는 사실. 이는 경고가 아니라 결과를 이해하는 데 필요한 반대 움직임이다.
- **표현에 내재화:** ‘실질보수 지수’와 ‘지수 기여’라고 정확히 쓰면, 주장하지 않은 ‘전 가구 소득·실제 판매·가계 부담’을 매번 부정할 필요가 없다.
- **공통 한계:** 지표의 대상 월이 다르다는 사실과 직접 차감·같은 달 합산 금지는 한 곳에 둔다. 본문은 ‘별도 임금 발표’로 구분한다.
- **예외:** 어떤 구체적인 해석이 기간 차이나 반대 근거 때문에 달라진다면 그 조건은 본문에도 필요하다. 부정 표현 비율이나 정규식으로 일괄 삭제하지 않는다.

자동 검사는 경고 반복의 의미를 판정하지 않는다. 같은 주의사항을 여러 번 썼는지, 생략해도 독자가 오해하지 않는지, 새로운 설명이 있는지는 문장별 내용 검토 책임으로 남긴다.

## 관찰 변수 계약

새 후보는 근거 범위 카드에 포함된 주장 ID, 확인할 신호, 그 신호를 확인하는 목적과 로컬 검토 기록을 요구한다. 후보와 출처·기준일을 결합해 수정 후 검토 재사용을 막는다. 이 결합은 무결성 검사이며 관리자 인증이나 자동 의미 승인이 아니다.

집필 결과는 선택한 `candidateId`를 반환해야 한다. 전체 로컬 스키마는 후보가 없으면 항목 수 0, 후보가 있으면 해당 ID만 허용한다. 선택된 출처를 블록에 포함해야 하며 같은 후보를 반복할 수 없다. 공개 콘텐츠에는 내부 후보 ID를 넣지 않는다.

제공자용 스키마에서 개수 제한이 단순화되어도 로컬 최종 검사는 원래 제약을 적용한다. ID가 맞는다는 이유만으로 문장 의미를 승인하지 않는다. 신호가 실제 미래 관찰 항목인지, 판단 목적이 원문을 넘지 않는지는 별도 검토한다. 이번 칠레 입력에는 검토된 후보가 없으므로 0개다. 후속 발표를 임의로 만들지 않았다.

새 요청·실행 계획·응답 검사가 동일 편집 계약을 사용한다. 계약을 삭제하거나 바꾸면 API 접속 전에 중단한다. 구 원고는 원래 계약으로 보존하고, 새 규칙 재평가 결과를 별도로 기록한다. 기존 유료 승인·시도 제한을 재사용하거나 완화하지 않는다.

기존 공통 한계도 버리지 않는다. 공개 타입의 4개 슬롯 안에서 정확히 같은 문구를 한 번만 남기고 필요한 경우 마지막 슬롯에 합친다. 길이 한도를 넘으면 집필 전 보류한다.

## 저장 원고 대조

실제 원고: `CLP-2026-10-09-1791718402206`, Claude Sonnet 5.5, 당시 비용 $0.030218. 기존 세 시험 합계 $0.091992와 미채택 기록은 유지한다.

수동 대조 예시의 본문은 다음과 같다. **AI 재생성본이 아니라 입력 설계를 검증하기 위한 편집 예시다.**

> **전체 상승률 안의 서로 다른 움직임**
>
> 9월 IPC 전월 대비 +0.4%, 9월 IPC 전년 대비 +4.1%이다. 원문은 식품·교통을 상승 분류로 강조했고, 보험·금융의 음의 기여는 전체 상승을 일부 상쇄했다.
>
> **물가를 반영한 실질보수 지수도 증가**
>
> 8월 실질보수 지수 전년 대비 +3.4%이다. 실질보수는 이미 물가 변동을 반영해 조정한 지표로, 이번 발표는 그 조정 이후의 증가를 보여준다.

편집 예시는 기존 3개 설명을 2개로 합치고 독해 규칙뿐인 관찰 항목을 제거한다. 실제 지급여력·셀아웃·수요 증가를 추가하지 않는다. 환율 수치 블록은 기존 원고와 동일하다. 대상 기간의 제한은 공통 한계에 한 번 표시한다.

원문 대조: 보관된 INE IPC 원문의 p0·p1·p2·p4와 실질보수 원문의 p2. 제목·요약·본문 총 9개 문장/소제목에 출처 구절과 검토 이유를 연결했다. 이 결과는 에이전트의 명시적 원문 대조이며 사용자 승인이나 실제 모델 품질 점수가 아니다.
