## 공통 회계 변경

기존에는 명확히 거절된429와 아직 실행 중일 수 있는 응답 유실을 모두 미확정 비용으로 전체 차단했다. 명확한 거절은 원본 비용 상태를 바꾸지 않고 전액 예약을 별도 에스크로에 보존할 수 있게 했다.

- 비용 상태는 계속unknown, 실제 비용은null이다. 404를 무과금으로 취급하지 않는다.
- 에스크로는 service 전용 함수로 명시적으로 등록한다. 받은 응답이 invalid·429·본문0자·usage미확인이며 작업 상태received인 경우만 허용한다.
- 응답 ID·원본 응답 해시·예약액이 달라지면 에스크로 자격이 사라진다.
- 예산 계산은 에스크로 예약 전액을 계속 합산한다. 월 경계를 넘은 미확정 예약도 빠뜨리지 않는다.
- 통신 단절, calling/reserved 작업, 부분 응답, 알려진 예산 초과는 계속 전역 차단한다.
- 나중에 공식 비용이 확인되면 기존 대조 함수로 실제 청구액을 기록한다. 새 원문/원고의 의미를 승인하지 않는다.

## 제한된 재시도

서비스가 `FX_REPORT_RETRY_TRANSIENT=bounded`로 명시한 경우만 동작한다. 기본 실행은 계속 기존 무재시도 경로다. 같은 요청의 실패 확정429만 최대 두 번 추가 시도하며, 직전 실패가 실제 비용 확정 또는 전액 에스크로로 자금 확보되어야 한다.

각 시도는 별도 작업·비용 행으로 저장하고 원래 실패 행은 덮어쓰지 않는다. DB의 검토자 단일 행 제약도 시도별로 구분하되, 같은 시도의 중복·다른 요청으로의 변경·3번째 추가 시도는 차단한다. 입력/스키마/원고 품질 실패를429로 취급하지 않는다.
