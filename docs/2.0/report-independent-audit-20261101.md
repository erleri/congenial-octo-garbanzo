# 5단계 — 공통 운영 흐름 독립 점검

2026-11-01 · 저장 자료·로컬 모의 실행·격리 DB · 유료 호출/운영 변경 없음

## 판단

기존 테스트 합격을 근거로 연결을 승인하지 않고, **준비 결과와 실제 실행 결과가 일치하는지** 별도 실패 조건으로 대조했다. 준비 보류의 실행 누락, 보류 해소 후 재진입, 캐시 비용 중복 계산, 공식 자료 순서에 따른 잘못된 신규성, 같은 날 발표자료 누락을 보완했다. 국가별 예외를 추가하지 않고 6통화 공통 경로를 수정했다.

이번 점검은 **로컬 공통 실행 경로를 다음 실제 시험의 준비 대상으로 넘기는 판단**이다. 무인 운영 출시, 경제 원고 품질, 모든 과거 원고의 정정 탐지 합격을 의미하지 않는다. 새 유료 호출은 하지 않았다.

## 발견한 문제와 조치

| ID / 중요도 | 재현한 문제 | 공통 수정 | 확인한 경계 |
|---|---|---|---|
| A1 / 필수 | 준비 단계에서 자료 오류로 보류된 BRL이 저장된 검토 카드로 집필까지 진행. 수정 전 모의 실행에서 집필/검토 2단계가 실행됨 | 국가별 준비 상태·보류 사유를 고정 입력에 포함하고 실행 직전 적용. 이전 형식의 동결 입력도 준비 행을 다시 확인 | 6통화 각각 같은 오류를 주입. 해당 국가는 0호출·0초안·사건 선점 없음, 다른 5통화는 계속 진행 |
| A2 / 필수 | 보류가 해결돼도 가격·기사 내용이 같으면 완료된 배치로 간주할 수 있음 | 배치 식별에 준비 상태·보류 사유 포함. 국가별 사건 잠금은 유지 | 실패 국가만 복구 후 집필. 이미 처리한 다른 5통화의 추가 호출 0. 실제 DB가 아닌 메모리 저장소에서 운영용 사건 식별 사용 |
| A3 / 비용·가용성 | 검토가 끝난 기사도 새 추출·대조 비용으로 계산. 합성 6기사 캐시에 예상 원문비 $0.913·12호출이 다시 잡힘 | 준비/실행이 같은 캐시 조회 기준 사용. 정확히 일치하는 저장 검토·저장 보류에는 새 원문 호출 예약 제외 | 같은 합성 자료의 원문비 상한 0, 전체 호출 상한 24→12. 집필·검토 6쌍의 보수적 상한 $3는 유지. 잘못된/중복 캐시는 보류하며 승인으로 바꾸지 않음 |
| A4 / 중복 | 동일한 공식 통계가 다른 배열 순서로 오면 자료 해시가 달라짐 | 지표별 항목을 정렬하고 정의 버전을 포함 | 순서만 바뀌면 같은 식별. 실제 수치·정의 버전·판본 변경은 다른 식별 |
| A5 / 누락 | 발행일과 같은 날짜의 새 공식 발표가 시각 미제공이면 조사 후보에서 누락 | 같은 날짜의 미사용 판본을 조사 후보로 유지 | 이미 사용한 판본·전날의 미확인 자료는 반복 사건으로 만들지 않음. 날짜만으로 발표 순서나 중요성을 확정하지 않음 |

원고 수동 편집·규칙 완화로 해결하지 않았다. A3는 비용 계산의 개선이며 실제 지출 절감 실측이 아니다. 해당 자료는 모의 원문과 모의 응답이다.

## 연결별 검토

| 연결 | 확인한 내용 | 남은 검증 |
|---|---|---|
| 가격 → 발행 후보 | 모든 통화가 대시보드 스냅샷·누적 2%·2주 미발행 후 월요일 점검을 공유. 이어받은 가격과 새 자료 시각 분리 | 회사 기준환율과의 동일성은 기존 사용자 확인 대기 가정. 현지 종가를 임의 인증하지 않음 |
| 무료 수집 → 새 자료 | 완료 배치라도 새 기사·공식 자료를 먼저 확인. 수집시각만으로 새 원고를 만들지 않음 | 실제 새 사이트의 가용성, 4일 탐색 범위 밖 과거 자료는 완전 탐색이 아님 |
| 국가별 차이 | 공식 API/PDF/HTML, 시간대, 지표 정의·발표/사용 범위는 등록 어댑터 차이. 준비·예산·집필·검토·게시 기준은 공통 | PEN 신규 접속 차단, MXN 일부 발표자료 확보 공백 유지 |
| 공식 통계 → 집필 | 최신 검증 대상 월·정의·계산·판본을 보존. 현재 수치의 배경 사용과 환율 원인 구분. 없는 소비 질문을 다른 지표로 대체하지 않음 | 9수치는 소비 전체나 6개국 실제 원고 품질 표본이 아님 |
| 원문 → 카드 → 집필 | 원문 추출·별도 대조를 통과한 카드만 집필 경로로 연결. 저장 결과에도 현재 사용 범위·내용 연결 검사 유지 | 실제 모델의 누락·과잉 해석·귀속 정확성은 실제 생성 시험에서 판단 |
| 예산·복구 | 전송 전 예약, 비용 미확인 시 후속 과금 중단, 자동 재시도/백업 없음. 보류 복구와 같은 사건 재생성 차단 구분 | 현재 모델 제공 경로·가격·ZDR와 실제 예산 잔여분은 다음 시험 직전 재확인 |
| 변경 → 정정 후보 | 같은 관측 수정/같은 URL 판본 변경을 문장에 연결. 공개 원고 자동 변경 없음 | 다른 기사 간 의미상 반박, 입력에 없는 과거 월 수정, 연결이 없는 제목·요약은 자동 의미 검증 완료가 아님 |
| 검토 → 공개 | 기존 active admin·동시 승인·철회/캐시·역할 분리 유지. 후보 확인은 게시 승인과 별도 | 실제 관리자 브라우저 로그인·클릭을 이번에 새로 수행하지 않음. DB 권한 검사는 별도로 실행 |
| Actions → 기존 서비스 | 리포트 경로는 환율·메일 뒤 별도 읽기 권한 작업. 실행 변수·서버 설정·예산이 모두 필요 | 실제 GitHub secrets·Ubuntu 실행·운영 migration 적용은 미실시. 워크플로 파일도 이번 미수정 |

기존 COP 귀속 보정이나 과거 CLP 실험 입력은 보존했으나, 현재 자동 경로의 필수 수동 입력으로 요구하지 않는다. 자동 경로에서 국가별 임시 글을 끼워 넣거나 역사 시험 원고를 새 승인본으로 만들지 않는다.

외부 요청을 금지한 `operatingEntry(action: plan)`과 격리 DB를 연결했다. 기존 원고/검토/공개본/활성화/예산/처리 설정의 전후 해시는 동일했다.

| MXN | 8 | 4 | 첫 점검 입력 준비 | 일부 발표자료 미확보; 채택한 4수치와 분리 |

총 24기사·9수치다. 무료 준비에서는 국가별 보류가 없고, 실행 차단은 기존 **미활성·미승인 반복예산·미확정 처리 설정**이다. 이를 해제하지 않았다. 저장 설정으로 계산한 60호출/$6.992525는 과거 입력의 준비 상한이며 **이번 실행 승인이나 최신 가격 견적이 아니다**.

정정 검사 대상인 실제 운영 발행본은 0건이다. 따라서 후보 0건을 ‘오류 없음’이나 실제 탐지율로 보고하지 않는다. 자료가 충분한지·독자에게 도움이 되는지는 다음 실제 내용 검토에서 통화별로 판정한다.

## 다음 고정 순서

**6단계: 실제 6통화 시험 준비 → 실행 → 내용/비용 평가.** 먼저 현재 제공 경로·요청 상한·기존 비용 기록·입력 판본을 다시 고정한다. 합성 통과를 원고 품질 승인으로 대체하지 않는다. 승인 범위가 정해진 실제 호출 후, 원문→카드와 카드→원고를 각각 평가하고 보류한 통화도 그대로 보고한다. 수동 교정·무료 백업·숨은 재시도로 성공 숫자를 만들지 않는다.

다른 기사 간 의미 정정은 아직 별도의 실행 검증이 필요한 범위다. 신규 원고의 내용 검토가 과거 모든 공개 원고의 모순까지 자동 검사한다고 표시하지 않는다. **7단계 운영 출시에서는 이 범위와 운영 감시·담당자·복구를 확인해야 하며, 이번 점검으로 출시 승인하지 않는다.**
