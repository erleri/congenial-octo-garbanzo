INEGI의 [공식 API 안내](https://www.inegi.org.mx/servicios/api_indicadores.html)는 유효 토큰·지표·지역·자료원·버전을 요구한다. Banxico [공식 시작 안내](https://www.banxico.org.mx/SieAPIRest/service/v1/)의 SIE 시리즈·인증 방식을 재사용했다. INEGI의 소비·물가·EMEC 정확한 지표 선정과 카드 검토는 이번 인증 확인과 별도다. 새 환율·리포트 원고를 생성하거나 기존 자료에 합치지 않았다.

## 비밀값과 실패 처리

- 전용 Node 명령이 로컬 토큰 파일을 명시적으로 읽는다. 브라우저나 Vite 환경으로 전달하지 않는다.
- Banxico 토큰은 `Bmx-Token` 헤더로 보낸다. INEGI는 공식 방식상 요청 경로에 토큰이 들어가므로 인증 요청 주소·헤더·원본 응답·오류 문자열을 저장하거나 출력하지 않는다.
- 응답의 토큰 재노출을 검사한 다음 날짜·숫자·허용된 상태만 추린다. 두 실제 키가 브라우저 빌드에 포함되지 않았음을 값 출력 없이 대조했다.
- 오류는 인증 거부(401), 접근 차단(403), 한도(429), 기관 오류, 연결·시간 초과, JSON/스키마 오류, 빈 자료·결측, 리다이렉트·응답 용량·민감정보 응답 차단으로 나눈다. 403을 곧바로 잘못된 토큰이라고 단정하지 않는다.
- 단순 HTTP 200·빈 자료·알 수 없는 구조를 인증 성공으로 표시하지 않는다. 유효한 시리즈·자료를 확인한 경우에만 인증 표본 정상으로 기록한다.
- 각 실행은 새 비공개 디렉터리에 보존한다. 이전 성공·실패를 덮어쓰지 않는다. 이번 결과는 `.local-reports/private/mexico-api-checks/check-X5xdWc/result.json`에 있다.

## 로컬 관리화면에 추가한 기능

[로컬 앱](http://127.0.0.1:4176/)의 **관리** 탭에서 `API·자료 연결 상태`를 확인한다. 기존 로컬 리포트 검토 화면 위에 별도 영역으로 배치했다. 원래 관리·리포트 URL 및 운영 화면은 유지한다.

코드에서 확인한 연결을 16개 항목으로 정리했다. 환율 API(ExchangeRate-API·Frankfurter·Open ER·Currency API·Alpha Vantage FX), 뉴스 API(Alpha Vantage), 저장·조회(Supabase), 설명자료(BCCh·BCB·IBGE·Banxico·INEGI·BCRP·SFC), 공개 페이지, AI(OpenRouter)로 구분한다. 같은 Alpha Vantage라도 환율과 뉴스는 별도 항목이다. 공개 문서 수집을 API 인증 성공이라고 표시하지 않는다.

상태판은 연결 이름·용도·로컬 준비 단계·표본 정상/실패/설정 필요/미점검·최근 점검·최근 성공·실패 종류를 보여준다. 이번에 점검 기록을 연결한 기관은 Banxico와 INEGI 두 곳이다. 나머지 14개는 미점검이며, 이 화면의 미점검을 실제 운영 장애로 해석하지 않는다. 코드 목록에 있다는 사실만으로 현재 운영 설정에서 활성 선택된 경로라고 단정하지 않는다.

- 종류별 필터를 제공한다. PC와 390px 모바일에서 확인했다.
- `점검 결과 다시 읽기`는 저장 기록만 다시 읽는다. 외부 API·AI·유료 검색을 호출하지 않는다.
- 새 실패 뒤에도 과거 성공시각은 유지하지만 현재 결과를 정상으로 숨기지 않는다. 로컬 점검 후 24시간이 지나면 재확인 안내를 붙인다. 이는 통계 발표 지연이나 월간 데이터의 부재 판정 기준이 아니다.
- 상태 조회 자체가 실패하면 이전 녹색 결과를 제거하고 API 장애 여부는 미확인이라고 표시한다.
- 토큰·계정·인증 주소·원본 오류·비공개 원고·실행 파일 경로는 화면에 전달하지 않는다.

이 기능은 **저장된 로컬 점검 결과를 보는 초기 관리 기능**이다. 운영용 실시간 감시·모든 수집기의 상태 자동 기록·서버 관리자 인증은 미완료다. 운영에서는 별도 승인과 권한 설계를 거쳐야 한다.

## 접근 경계와 검증

로컬 서버는 127.0.0.1:4176에만 열었다. 상태 경로는 GET만 허용하고 로컬 호스트·접속 주소·Origin을 검사한다. 실제 확인에서 다른 Origin 403, POST 405, `.env.research.local`·기존 키 파일·비공개 결과 경로 403을 확인했다. 비밀 파일 응답 본문은 읽지 않았다.

운영 빌드에는 상태판 모듈을 넣지 않는다. 로컬 리포트 앱 빌드에서만 활성화한다. 실제 빌드 산출물에서 두 토큰이 노출되지 않으며 운영 산출물에 `ApiStatusPanel`이 없음을 확인했다. 로컬 브라우저 검증 중 외부 요청은 차단했고, 엑셀 업로드·메일 저장·DB 승인·생성 호출은 실행하지 않았다.

전체 회귀 103파일·729사례, 타입·린트·운영·로컬 앱·리포트 빌드와 번들 경계 검사를 통과했다. 마지막 상태 검증 보완 후 관련 11사례를 재실행했다. 동일 이름·동일 테스트 본문·자기 비교 신호는 없었다. 의미상 중복 전수 증명이나 실제 원고 품질 729건이라는 뜻은 아니다. 기존 500 kB 진입 번들 경고는 유지한다.

실제 PC·모바일 상태판, 종류 필터 7행, 2개 정상 표본, 조회 실패 시 과거 녹색 제거, 새로 읽기의 외부 호출 없음, 화면 오류 0건을 확인했다. 로컬 접속 권한 환경과 관리 탭의 기존 분기를 확인해 실제 로컬 화면에 연결했으며, 이전 화면 확인 실패를 API 인증 실패로 기록하지 않았다. 검증 자료는 `.local-reports/private/mexico-api-verification-20261027/`에 보존했다.

보존 목록 27,072개를 대조했다. 의도한 기존 파일 5개(App·로컬 Vite 설정·명령·문서) 외 27,067개 내용은 유지됐으며 예상 밖 변경·누락은 없었다. 새 모듈·화면·문서는 별도 추가했다. 기존 환율·원고·비용 기록·다른 키 설정을 보존했고, 새 키도 수정하지 않았다. 브라우저 산출물 41개와 저장 조회 결과에서 두 토큰이 포함되지 않았음을 값을 출력하지 않고 확인했다.

## 다음 연결 범위

1. INEGI의 리포트용 소매·물가 지표와 메타데이터·시리즈 버전을 선정한다. 인구 예제로 대체하지 않는다.
2. 새로 확인한 인증 수집 결과를 기존 질문·출처 선택 → 카드 검토 경로에 연결한다. 현재 일반 공개 수집기의 멕시코 `configuration_required`를 성급히 성공으로 바꾸지 않는다.
3. 각 실제 수집기가 같은 상태 기록을 남기도록 확장한다. 무료 한도·월간/일간 주기·기관별 재시도 정책을 구분한다.
4. 운영 관리화면은 active admin 권한, 비공개 상태 저장, 정기 기록과 경보 범위를 설계한 뒤 별도 반영한다. 브라우저에 키를 보관하거나 화면 새로고침마다 외부 API를 점검하지 않는다.

권장 개발 모델은 수집·상태 기록 연결 **Sol High**, 지표 의미·자료 범위 판단 **Astra High**다. 이번에는 운영 배포·원격 push·운영 DB·정기 작업·메일 변경을 하지 않았다.

## INEGI 리포트 지표 연결 — 2026-10-27 후속

### 실제 확인한 계열과 의미

| 코드 | 전국 지표 | 실제 최신 대상 월·값 | 비교·단위 |
| --- | --- | --- | --- |
| 718506 | EMEC 소매업 전체의 실질 매출 | 2026-08 · 121.90334727 | 비계절조정 지수, 2018=100 |
| 910399 | INPC 전체 소비자물가 | 2026-09 · 0.42% | 전월 대비, 비계절조정 |
| 910406 | INPC 전체 소비자물가 | 2026-09 · 3.45% | 전년 동월 대비, 비계절조정 |

사용한 경제 자료원은 공식 조회 생성기의 현재 **BIE-BISE**다. 인구 예제의 BISE, 이전 경제 자료원 BIE와 구분한다. 공식 `CL_INDICATOR`는 잎 항목 이름만 반환한다. 같은 ‘46 Comercio al por menor’가 GDP·고용·보수 등 여러 계열에 쓰이므로 이름만 보고 매출로 채택하지 않았다.

[공식 지표 대응표](https://www.inegi.org.mx/app/indicadores/BIE_tabla_equivalencias.xlsx)에서 718506의 전체 경로를 확인했다. EMEC Base 2018 → Ingresos totales por suministro de bienes y servicios → Comercio al por menor → 전국 전체이며, 이전 전국 키 720064·719605가 현재 키 718506에 연결된다. API 단위 1051은 `Índice base 2018=100`, 출처 3209는 EMEC 2018이다. 물가의 단위 302는 변화율이며 출처 3371은 INPC 2018이다. 응답 주기 8과 월별 관측 형식을 함께 확인했다.

소매 지수에서 같은 전년 월의 지수를 사용해 `100 × (현재 / 전년 동월 - 1)`을 계산한다. 실제 2025-08 지수 117.99385878와 비교한 결과는 3.313298…%이며, [10월 21일 EMEC 발표문](https://www.inegi.org.mx/contenidos/saladeprensa/boletines/2026/emec/emec2026_10.pdf)의 **원계열 연간 3.3%**와 반올림 일치한다. 같은 발표문의 **계절조정 전월 1.2%·연간 3.2%**와 섞지 않는다. 전년 월이 없거나 기준값이 유효하지 않으면 계산값은 결측이다.

물가의 0.42%·3.45%는 [10월 8일 INPC 발표문](https://www.inegi.org.mx/contenidos/saladeprensa/boletines/2026/inpc/inpc_2q2026_10.pdf)의 월간·연간 수치와 각각 일치한다. 지수 기준은 2018년 7월 하반월=100이며, 비교 기준과 가중치 갱신을 구분한다. 발표문은 2022년 가계조사로 구성한 가중치를 설명한다. 이를 2018년 가계 구성비가 이후 한 번도 수정되지 않았다는 뜻으로 확대하지 않는다.

### 기존 경로에 연결한 방식

`질문·출처 선택 → 명시적 INEGI 로컬 조회 → 허용 필드 추출·정의 확인 → 기존 선택 출처 수집 → 기존 근거 범위 카드 검토`

- 정의 등록부는 `scripts/currency-report/inegi-report-indicators.js`의 `inegi-report-definitions/1`이다. 계열·전국 범위·단위·비교·실질/명목·조정·기준년·공식 확인 경로와 정의 해시를 묶는다.
- 기존 일반 공개 수집기는 토큰을 읽지 않는다. 전용 `inegi-report-local.js`만 명시적 `live` 모드에서 로컬 키를 읽고, 선택한 세 계열 이내에서 각 1회 조회한다. 요청당 20초, 자동 재시도·모델·유료 호출 없음이다. 브라우저용 실행 경로가 아니다.
- 저장 모드는 키 파일과 외부 API를 읽지 않는다. 저장된 응답·계열 정의를 재검사해 같은 수집·검토 경로로 넘긴다. 재생으로 상태판 성공 시각을 갱신하지 않는다.
- 최대 최근 25개 월 관측을 남긴다. 더 오래된 요청 월이 없으면 `period_mismatch`, 전년 비교값이 없으면 결측으로 구분한다. 별도 과거 원본 보관소를 확보한 것처럼 취급하지 않는다.
- `retail`의 지수와 계산한 연간 변화율, `consumer_prices`의 월간·연간 변화율을 정확한 범위로 매칭한다. 현재 미선정한 계절조정 지표·가전 세부 업종·근원물가를 임의로 대신 채우지 않는다.
- 원본 전체의 해시라고 주장하지 않고 **비밀값을 제거한 응답 투영 해시**와 정의 해시를 남긴다. 카드와 검토 기록이 다른 계열·기간에 재사용되지 않도록 묶는다. 해시는 출처가 문장을 지지한다는 의미 판단을 대신하지 않는다.
