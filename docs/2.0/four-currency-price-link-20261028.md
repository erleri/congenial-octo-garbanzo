# BRL·COP·PEN·ARS 가격 기준 연결 결과

2026-10-28 · Sol High 로컬 연결 작업 · 저장 자료 재사용 · 원고·운영 변경 없음

## 무엇을 연결했나

기존 국가별 자료 준비 입력에 **기사 가격과 공식 가격의 대조 결과**를 연결했다. 이전의 ‘가격 검증 필요’라는 한 줄 대신, 날짜·가격 종류·매수/매도 구분·적용 기간·원문 버전·숫자 일치 범위를 저장한다.

**가격 대조와 혼용 차단은 연결했다. 네 통화의 동일 기준 전후 가격과 환율 원인 집필 자격이 모두 완성된 것은 아니다.** 통과하지 못한 항목은 보류를 유지하고 다음 통화로 넘어갔다. 새 유료 호출·외부 조회·운영 변경 없이 기존 원본을 재생했다.

### 재사용한 검증 자료

- BRL: [BCB PTAX 조회](https://ptax.bcb.gov.br/ptax_internet/consultarUltimaCotacaoDolar.do), 기존 PTAX 정의 검토, Agência Brasil 저장 원문.
- COP: [SFC 공식 데이터](https://www.datos.gov.co/resource/32sa-8pi3.json), 기존 공식 적용 기간·규정 대조 및 미국 휴일 사례. [기존 날짜 검증 기록](pen-ars-cop-basis-verification-20261027.md)의 미확정 거래일을 인증된 날짜로 승격하지 않았다.
- PEN: [BCRP 계열 API 설명](https://estadisticas.bcrp.gob.pe/estadisticas/series/ayuda/api), PD04645PD·PD04646PD의 정상 저장 JSON과 후속 오류 응답, Gestión 원문.
- ARS: [BCRA v4 변수 5](https://api.bcra.gob.ar/estadisticas/v4.0/monetarias?idVariable=5), 기존 A8359 방법론 검토와 Infobae 원문. 계열의 마지막 날짜를 실제 단일 호가 관측시각으로 표시하지 않았다.

이 링크의 기관 자료를 이번에 새로 조회한 것은 아니다. 이용 범위·외부 모델 전송·공개 서비스 허가는 이전 검토 상태를 유지한다. 가격 대조 성공이 그 승인을 대신하지 않는다.

## 공통 코드에 반영한 기준

1. **원본을 다시 읽어 검사한다.** 저장 응답의 해시·HTTP 상태·요청 출처를 확인한다. 호출자가 `통과`라고 적은 결과만 재사용하지 않는다.
2. **전체 응답을 해석한다.** JSON 뒤 오류 HTML을 잘라내 가격만 건져 쓰지 않는다. 정상 과거 응답과 후속 실패는 별도 기록으로 남긴다.
3. **공식 가격을 종류별로 읽는다.** PTAX 매수·매도 열 순서, TRM 유효 구간, BCRP 매수·매도 계열과 결측, BCRA 변수 5 정의를 검사한다.
4. **기사의 선택된 본문과 날짜를 대조한다.** 원문 해시·본문 위치·기사 URL 날짜·원문 게시/수정 시각을 확인한다. 숫자가 다른 문단의 은행 소매·금융 환율과 섞이지 않게 등록된 문장을 읽는다. 원문이 바뀌면 다시 검토해야 한다.
5. **현지 날짜와 시각의 의미를 구분한다.** BRL·COP·PEN·ARS도 해당 현지 날짜로 기사 게시 시점을 비교한다. UTC 자정 직후의 브라질 게시물이 전날 현지 거래일을 보도하는 경우를 검증했다. 게시·수집 시각은 가격 관측시각이 아니다.
6. **비교 결과를 구분한다.** ‘같은 적용 TRM 일치’, ‘숫자만 일치·가격 종류 미확인’, ‘가격 종류 다름’, ‘해당 날짜 공식값 없음’을 따로 기록한다. 변동률을 계산할 자격과 별개다.
7. **생성 요청으로 자동 승격하지 않는다.** `generationMovement=null`, `caseDailyChange=null`, `request=null`을 유지한다. 기존 엄격한 환율 원인 검사와 이용 범위 검토를 우회하지 않았다.

`country-price-connection.js`는 원문을 읽고 위 대조를 수행한다. `country-material-preparation.js`가 이를 기존 준비 입력에 붙이고 가격별 보류 사유를 공통 결과에 포함한다. 기존 CLP·MXN 가격 검사 경로는 유지한다.

일치 여부는 자동으로 재생할 수 있지만, 기사 문장이 어느 거래일·가격을 뜻하는지에 대한 최초 판단은 원문을 직접 대조한 검토 기록이다. 이를 독립적인 내용 검토나 시장 원인 입증으로 부르지 않는다.

## 저장·재현

Git 제외 작업 폴더: `.local-reports/private/four-currency-price-link-20261028/`.

- `before.json`: 기존 소스·문서·원고·환율·비용 파일의 변경 전 해시.
- `replay-saved.mjs`: 기존 원본의 해시를 확인하고 국가별로 새 입력과 대조 결과를 저장하는 오프라인 재생.
- `verified-*/BRL-input.json` 등: 원본을 복사해 가격 대조 입력을 추가한 **새 사본**. 기존 국가 입력은 덮어쓰지 않는다.
- 같은 폴더의 국가별 `prepared.json`, `summary.json`: 실제 원문 연결·보류 사유.
- `regression-CLP-MXN.json`: 기존 두 통화의 준비 상태 회귀 확인.

국가별 새 입력은 기존 로컬 명령으로 다시 검증할 수 있다.

```powershell
node scripts/currency-report/country-material-preparation-local.mjs --input .local-reports/private/four-currency-price-link-20261028/verified-결과폴더/BRL-input.json
```

매번 새 비공개 결과 폴더가 생기며, 네트워크·환경 키·DB·유료 모델을 사용하지 않는다. 입력 원문은 비공개 저장소 안에 두며 대조 결과에는 원문 전체를 복사하지 않는다.

## 검증

실제 저장 원문 4개와 공식 응답의 대조·새 사본 저장을 확인했다. 합성 검사는 별도로 원본 변조, 날짜 이동, 열 순서 변경, TRM 기간 겹침·주말 적용, PEN 결측·오류 HTML, ARS 가격 종류 및 역산 방지, 현지 날짜를 검증한다. 첫 재생에서 발견한 COP 숫자 뒤 문장부호 처리 오류는 추출식을 고치고 정상 문장 회귀에 포함했다.

전체 검사 112파일·811실행 사례가 통과했다. 선언 653개·매개변수 확장 158개이며 정확한 이름/본문 중복·자기 자신 비교는 0이다. 의미상 중복이 전혀 없거나 실제 원고 품질이 통과했다는 뜻은 아니다. 타입·린트·운영/기존 앱 로컬/리포트 3종 빌드·번들 경계 검사도 통과했다. 기존 500kB 경고는 유지하며 운영 진입 번들은 610,348바이트다.

최종 저장 재생은 `verified-ZjmKcR/`에 있다. 이전 실패·재생 기록도 보존했다. 기존 파일 보존 대조는 `preservation.json`, 전체 검사와 정확 중복 감사는 `unit-tests.json`, `test-inventory.json`에 기록한다. 새 외부 조회·유료 모델 호출·API 비용·운영 변경은 모두 0이다.
