# 코드 조립 적용 후 Gemini 생성 비교

같은 칠레 2026년 10월 5일 근거로 Gemini 3.8 Flash를 한 번 다시 호출했다. 정책 신호와 관찰 조건은 더 명확해졌고 기존 관측·장부·조달 압박 표현은 사라졌다. 분석가 해석의 귀속 보완 한 문장과 문장별 근거 대응표 오류 네 위치가 남아 있어 채택하지 않았다. 실제 원문은 A안의 미채택 비교본으로 표시한다.

## 비용과 조건

사용자의 신규 최대 $0.084 승인에 따라 2026년 10월 7일 실행했다. 추론 medium, Vertex Flex, ZDR·데이터 수집 금지, 자동 제공 경로 전환 없음, 재시도 없음이다. 실행 직전 가격·모델 지원·개인정보 보호 조건을 확인했다. 이전 네 단계 시험의 호출 승인을 재사용하지 않았다.

| 항목 | 이전 | 이번 |

| 생성 단계 실제 비용 | $0.011263500 | **$0.009462375** |
| 입력 토큰 | 6,896 | 6,568 |
| 출력 토큰 및 포함된 추론 | 4,628 / 1,780 | 3,733 / 1,351 |

이번 비용은 `usage.cost`로 확인했고 미확인 예약은 0이다. 응답 ID는 `gen-1791383129-QsY0Sf3Bbp3vn7K3DAU7`이다. 생성끼리 비교하면 약 15.99% 저렴하다. 이번 내용 검토는 에이전트가 수행했으므로 이전 네 단계 전체 비용과 비교해 같은 작업이 그만큼 싸졌다고 주장하지 않는다. 이전 조사·집필 포함 관련 누계 $0.154288225에 이번 비용을 더하면 $0.163750600이며, 더 오래된 별도 미확인 예약은 포함하지 않는다.

환율·차트·기사 원문·승인된 USD 환산 조건은 같은 packet이다. 사전에 저장한 요청과 현재 생성 요청의 해시를 대조했고, 모델에 이번 오프라인 검토의 정답이나 실패 문장을 추가하지 않았다. 새 작성 규칙의 효과를 보는 단일 비교이며 반복·블라인드 실험은 아니다.

## 내용 대조

| 구분 | 결과 |
| --- | --- |
| 관측시각·공식성 | 본문에서 ‘공식 관측 이후’가 사라졌다. 시각·출처는 코드가 미기록 여부까지 표시한다. |
| 환산 범위 | 승인된 동일 USD·미헤지 문구를 코드가 조립했다. 장부 평가를 주장하지 않는다. |
| 정책 신호 | 매각 규모보다 정책 신호를 중요하게 본 분석가 설명이 앞에 나왔다. 규모 변경 조건도 보존했다. |
| 관찰 조건 | 실제 집행·포지션 조정 여부에 따라 앞선 설명이 강화·약화될 수 있음을 제시했다. 이를 확정 예측으로 차단하지 않았다. |
| 원자재 명칭 | 본문에 구리를 명시했다. 제목의 ‘주요 원자재’는 이 문맥에서 구리를 지칭하므로 명칭 구체화 권고로 남겼다. 원자재 전체 상승으로 확대했던 이전 문장과 구분한다. |
| 남은 본문 교정 | ‘현지 보도는 … 시장 내 가용 외화가 늘어난 점’을 확인된 공급 사실처럼 읽을 수 있다. DF p5의 XTB 해석에 직접 귀속해야 한다. 실제 공급 집행 자료를 확보한 것은 아니다. |

문제 문장이 사실과 정반대라고 판정한 것은 아니다. DF p5에는 해당 분석가의 공급 해석이 있다. 다만 허용 범위는 출처에 귀속한 해석이며 ‘보도가 확인한 실제 공급 증가’로 넓히지 않는 것이 중요하다. 이어지는 문장은 분석가에게 직접 귀속했고 구리 문맥이 명시돼 있어 선택적 구체화 권고로 남겼다.

총 16개 제목·문장을 원문 및 승인 원리와 대조했다. 필수 교정 한 문장, 선택적 편집 네 문장이다. 코드 환산과 타당한 조건부 관찰은 유지했다. 구조·기본 본문 안전 검사는 통과했지만 생성 대응표가 요약·배경 두 곳·관찰의 문장을 각각 나누지 않아 R10 네 위치가 보류됐다. 과거 사례의 관측시각 부재에 따른 R09 게시 차단도 유지한다. 대응표를 고쳐 과거 자동 판정을 덮어쓰거나 원고를 자동 재작성하지 않았다.
