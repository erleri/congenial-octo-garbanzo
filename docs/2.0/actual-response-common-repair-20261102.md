# 실제 저장 응답에 기반한 공통 경로 보완 — 2026-11-02

이번 작업은 실제 6통화 실행의 원문·입력·24개 응답을 다시 검사하고 알려진 처리 결함을 고친 로컬 작업이다. 새 모델 요청, 수동 원고 교정, 운영 반영은 없다. **전체 자동 리포트 품질 합격이나 6개 원고 생성 완료를 뜻하지 않는다.**

## 수정과 검증

| 문제 | 공통 수정 | 확인 결과 |
|---|---|---|
| 마지막 결과 저장이 64KB를 초과 | 국가별 상세 기록과 고정 입력은 기존 위치에 보존하고 배치 체크포인트에는 요약·참조·해시 저장 | 설치된 격리 DB 함수에서 기존 97,942바이트 거절 → 새 10,351바이트 저장. 호출24·비용0.2511376·국가6 보존. 시험 전체 롤백 |
| `Nesta sexta-feira (30)` 날짜 표현 과잉 차단 | 현재 세션의 요일·일 숫자·발행 현지 날짜가 모두 맞는 표현만 허용 | 실제 BRL 응답은 추출 검사 통과. 틀린 일·요일·연도·발행일·회고 문구는 차단. 사건 의미는 별도 원문 대조 대상 |
| 대조가 발언 문단만 지목하면 발언자 소개 참조 누락으로 중단 | 별도 대조가 모든 주장·귀속·조건을 지지하고, 바로 앞 문단의 이름/기관과 이어지는 발언이 확인되는 제한된 경우 소개 문단을 함께 보존 | CLP 실제 응답으로 기존 근거 카드·이용 범위·집필 입력까지 연결. 조건 문단 누락·다른 발언자·불충분 대조는 계속 차단 |
| 무관 스포츠/기간 밖 기사를 유료 처리 | 공통 탐색에서 명확한 비경제 섹션 제외. 계획·실행 모두 현지 발표/수정일이 조사 세션 이전인 시장 전용 후보 제외 | 실제 후보 중 MXN 오래된 기사6건·ARS 스포츠1건을 유료 요청 전 선별할 수 있음. 수정된 기사·별도 월간 배경·날짜 미상은 자동 승인/일괄 제외하지 않음 |
| 보류인데 claims가 있어 기술 고장처럼 표시 | 새 지침에 보류/무관은 빈 claims 명시, 불일치는 모델 출력 문제로 분류 | 기존 응답은 그대로 보류. 자동 재작성/재시도 없음, 대체 근거 탐색에 연결 |
| 구버전 보류를 새로 판단한 기록이 과거 기록과 충돌 | 재검토 준비 시 이전 판단의 키를 명시해 후속 서비스 기록에 대체 관계 전달 | 과거 판단은 보존하고 하나의 새 유효 판단으로 연결하는 합성 회귀 통과. 실제 과거 기록을 덮어쓰지 않음 |

저장 요약에서는 전체 오류 분류를 별도로 보존한다. 긴 진단 목록을 줄였다는 이유로 기술 오류가 정상/대기로 바뀌지 않는다. 상세 국가 결과는 `operating_cases`, 입력은 기존 batch payload에서 찾는다. 추가 수집 진단 전체는 실행 반환값에 남으며 요약에는 해시만 남긴다. 모든 세부 진단을 DB에 중복 저장했다고 주장하지 않는다.

## 실제 6통화 재생 결과

후속 [4통화 자료 공백 재점검](four-country-evidence-gap-audit-20261102.md)에서 아래 ‘원인 자료 부족’은 **선택·검토를 통과한 자료의 부족**이며 실제 뉴스 부재를 뜻하지 않음을 확인했다. 특히 PEN은 저장 목록의 해설 기사가 이전 보류 피드백 때문에 선택에서 빠지는 현상을 재현했고, MXN에는 월간 약세 해설이 이미 있었다. 아래 표는 당시 저장 응답 재생 결과로 보존한다.

| 통화 | 저장 응답으로 확인한 진전 | 아직 없는 것/보류 사유 |
|---|---|---|
| BRL | 실제 날짜 표현 검사 통과 | 지난 실행에 독립 대조 요청이 없었으므로 대조 응답도 없음. 집필 허용하지 않음 |
| MXN | 가격 관측 카드 유지, 오래된 후보 무료 선별 | 적합한 세션의 환율 원인 설명 부족. 기존 보류+주장 모순 출력도 그대로 보류 |
| COP | 신규 후보 날짜 미확인과 기존 보류 구분 | 새 날짜 대조 근거 부족. 지난 실행에서 재사용한 두 보류의 원응답은 이번24응답에 없음 |
| PEN | RPP 가격 관측 두 건은 카드 검토 유지 | 가격 보도만으로 원인을 만들지 않음. 선택 세션의 원인 자료 부족 |
| CLP | 카드 → 사용 범위 → 공통 집필 입력 준비 통과 | 실제 집필·원고 품질 검증은 이번에 수행하지 않음 |
| ARS | 무관 기사 무료 제외, 날짜/기간 보류 유지 | 현재 세션 원인 근거 부족. 예산 초과로 이전에 전송되지 않은 자료의 응답은 없음 |

누락된 대조나 원문 응답을 합성 응답으로 채우지 않았다. 실제 원응답 24개를 모두 원래 요청 해시와 대조했으며, 기존 `/4` 입력 재구성 해시도 일치한다. `/5` 지침으로 모델이 새로 답한 것처럼 표시하지 않는다. CLP 집필 입력은 메모리에서만 등록했고 운영/로컬 원고 DB에는 추가하지 않았다.

## 검증 수준과 증거

- **실제 저장 재평가:** `replay-operating-records-local.mjs`가 6통화 원본 계획·응답24개와 현재 근거 연결 코드를 실행. 새 외부 모델/네트워크 요청0, 추가 비용$0. 원본 분석 파일 전후 SHA-256 동일.
- **실제 DB 경계:** 고정 실패 결과를 설치된 격리 SQL 함수에 전달해 크기 오류 재현. 요약 저장 성공·완료/소유권 거절 유지. BEGIN/ROLLBACK 전후 원배치·국가 기록·제어 상태 해시 동일. 함수 정의·마이그레이션·권한 변경0.
- **합성 통합 회귀:** 6통화 전체 절차에 큰 수집 진단을 넣어 종료/재진입 중복 호출 없음 확인. 무관 자료는 계획/실행 모두0회, 다른 국가 정상 진행. 실제 AI 품질 표본으로 세지 않음.
- 전체169파일·1,247실행 통과. 선언1,064+매개변수확장183. 이름·동일 본문·자기 비교 중복 검사 통과는 의미적 중복/AI 품질 증명이 아님.
- 타입·전체 린트·운영/앱 로컬/리포트 빌드·번들 경계 확인. 기존 `dbClient.ts` 정적/동적 import 경고는 별개로 남아 있다.
- 초기 전체 테스트의 하드링크 EPERM은 정상 권한으로 같은 검사를 실행해 해소. 추가 지침으로 긴 입력의 비용 상한이 넘어가는 회귀도 발견해 새 날짜 지침의 중복을 줄였고, 입력을 자르거나 예산 한도를 올리지 않았다.

재현 명령(저장 자료만 읽음):

```powershell

```

모델 원문/기사 원문/실행 기록은 비공개 제외 경로에 유지한다.

## 다음 실행의 전제

이 수정으로 해결한 것은 처리 오류와 불필요한 유료 후보다. **원인 기사 부족이 코드 수정만으로 해결됐다고 말하지 않는다.** 다음은 6통화 무료 수집을 같은 선별 규칙으로 실행해 대체 후보·남은 대조 요청·집필 가능성을 하나의 준비표로 확인하는 단계다. 새 유료 요청은 그 입력과 비용을 확인한 별도 승인 범위에서만 실행한다. 근거가 없는 국가는 그 이유와 자동 대체 탐색 경로를 남기며 다른 통화의 작업을 막지 않는다.

Supabase 함수 사용 방식은 [공식 함수 문서](https://supabase.com/docs/guides/database/functions)와 [변경 기록](https://supabase.com/changelog)을 확인했다. 이번 수정은 기존 함수의 입력 축소이며 SDK/DB 버전·권한을 바꾸지 않았다.
