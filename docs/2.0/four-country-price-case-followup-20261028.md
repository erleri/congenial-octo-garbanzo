# BRL·ARS 공식 가격 쌍과 COP·PEN 다른 변동일 확인

2026-10-28 · Sol 로컬 구현·비맹검 내용 검토 · 유료 생성/운영 변경 없음

## 이번에 달라진 것

**BRL·ARS는 공식 기간 응답에서 전후 기준값을 확보해 기존 가격 검사에 연결했다. COP는 다른 날짜에서 현지 달러 수급과 상승 압력을 연결한 귀속 설명을 찾았다. PEN은 사전 선정한 두 날짜도 설명 근거가 부족했다.**

이전 원고·환율·입력·비용·승인 기록은 보존했다. 새 모델 호출·원고·게시 승인은 만들지 않았다. 새 결과도 아직 여섯 통화 집필 가능 또는 출시 완료를 뜻하지 않는다.

## BRL — ‘마감’ 유형이 명시된 공식 두 관측

등록된 BCB PTAX 경로에서 통화별 기간 API를 조회했다. [공식 정의 문서](https://www.bcb.gov.br/conteudo/dadosabertos/BCBDepin/gnastportal-dados-abertostaxas-de-cambio---todos-os-boletins-diarios.pdf)는 기간 조회와 공표 유형을 설명하고, [해당 데이터셋](https://dadosabertos.bcb.gov.br/dataset/taxas-de-cambio-todos-os-boletins-diarios)은 PTAX 마감을 네 차례 조사값의 평균으로 정의한다. 해당 데이터셋의 ODbL 표기도 확인했으며 다른 기관 자료의 조건으로 대체하지 않았다.

| 공급자 기준일 | 매수 BRL/USD | 매도 BRL/USD | 원응답 유형 |
| --- | ---: | ---: | --- |
| 2026-10-23 | 5.0371 | 5.0377 | Fechamento |
| 2026-10-26 | 5.4998 | 5.5007 | Fechamento |

기준값 사이의 변화는 매수 +9.18584%, 매도 +9.19070%다. 기사 현물 마감 5.403·+8.21%와 동일한 가격이 아니다. 한쪽을 틀렸다고 바꾸거나 두 기준을 합치지 않는다.

`country-price-connection`의 새 판독 경로는 USD·조회 범위·전체 응답·공표 유형·중복·페이지 잘림을 검사한다. 날짜별 개장 1건/중간 3건과 마감 1건을 구분하고 네 조사값 평균과 마감값의 일치도 확인한다. 단지 마지막 행이나 오후 시각이라는 이유로 마감으로 선택하지 않는다. 시간대 없는 공급자 문자열은 그대로 보존하며 개별 현물 체결시각으로 바꾸지 않는다.

처음 조회한 달러 기간 API의 값도 일치했으나 공표 유형이 없는 응답만으로 마감을 승인하지 않고, 유형을 제공하는 통화별 기간 응답을 추가 확인했다. OData 메타데이터 500 실패도 보존했다. 공식 PDF·실제 응답을 대조한 범위이지 서버 메타데이터 조회 성공으로 기록하지 않는다.

## ARS — 최신 요약 대신 변수 5의 기간별 관측

[공식 API 문서 페이지](https://www.bcra.gob.ar/documentacion-apis/?fileName=estadisticas-monetarias-v4)가 지정한 로더와 JSON 명세를 확인했다. 옛 PDF 주소는 404였고, 실제 연결된 [공식 명세](https://www.bcra.gob.ar/archivos/Catalogo/Content/files/json/estadisticas-monetarias-v4.json)와 `monetarias/5` 기간 응답을 사용했다. 비공식 예제의 URL만으로 구조를 확정하지 않았다.

| 공급자 기준일 | 변수 5 공식 참조값 ARS/USD |
| --- | ---: |
| 2026-10-23 | 1528.2630 |
| 2026-10-26 | 1540.4751 |

기준값 사이 변화는 +0.7990837%다. 기사 도매 종가 1541과 별도이며, 기사 상승폭 11.50을 빼서 이전 관측을 만든 것이 아니다. 요청 기간 전체에 6개 원관측이 있고 그중 해당 두 기준일을 연결했다.

판독기는 변수 ID·날짜 범위·중복·응답 건수/페이지·값을 확인한다. 중간 오류 HTML이 붙은 응답을 잘라 쓰지 않는다. 기존의 BCRA 용도별 이용 판단은 그대로 남아 있으며 기술적 조회 성공으로 외부 전송·공개 상태를 허용으로 바꾸지 않았다.

### 두 통화의 다음 연결 경계

기존 `pairPreparation`에 두 원관측과 출처 해시, **기준값 간 변화**를 연결했다. 가격 쌍이 없다는 보류는 사라졌지만, `reference_session_mapping_and_fx_cause_review_required`를 유지한다. 공급자의 기준일·공표 시각이 해당 기사 거래 구간과 어떻게 연결되는지와 설명 지지를 검토해야 한다.

`localSessionDate`, `observedAt`는 미확인 상태를 보존한다. 엄격한 집필 검사 `verifiedFxMovement`의 지원 범위는 아직 CLP·MXN이다. 이번 결과를 검증된 거래일 기반 가격 입력으로 가장해 연결하지 않았다. 새 사본은 여전히 `request=null`, `publicationApproved=false`, 집필 보류다.

## COP·PEN — 기사보다 먼저 날짜 선택

검색 전에 `preselected-cases.json`을 고정했다. 저장된 수치 범위에서 절대 변화가 큰 두 구간씩 선정했다. 새 날짜가 안 맞는다고 성공 기사가 있는 날짜로 바꾸지 않았다.

| 통화 | 사전 선정 기준 | 기사 조사 날짜 | 주의 |
| --- | --- | --- | --- |
| COP | 저장 25개 TRM 구간 중 9/25 적용 시작 +1.997923%, 10/6 적용 시작 -1.946241% | 거래 구간 후보 9/24·10/5 | TRM 적용일을 당일 시장 관측일로 바꾸지 않음. 기반 거래일 매핑은 검토 전 |
| PEN | 저장 정상 관측 중 10/22 매도 +0.291121%, 10/20 -0.290951% | 공급자 기준일 10/22·10/20 | 시각의 시간대 미확인 유지. PEN 발행 2% 임계값을 새로 정한 것이 아님 |

COP 1.997923%를 반올림해 2% 발행 통과로 처리하지 않았다. 이는 연속 기준값의 조사 후보이고 마지막 실제 발행본 대비 누적 변화 시험도 아니다. 기존 10/26 실패 사례를 지우지 않았다.

### COP 9/24 — 현지 수급에 연결한 귀속 설명 확보

[La República 원문](https://www.larepublica.co/finanzas/precio-del-dolar-y-petroleo-hoy-24-de-septiembre-4489258)을 실제 저장·추출했다. Corficolombiana의 Mauricio Acevedo는 금리 배경과 함께 현지 금융기관의 달러 잔고 부족이 결제용 달러 매수를 유발하는 상승 압력이라고 설명한다. 이를 짧은 자체 사실·귀속 견해 카드로 작성해 기존 자료 준비 함수에 연결했다.

원고나 번역문은 만들지 않았다. 경고를 요지마다 반복하지 않고 사용 범위 카드에 모았다. 같은 기사에 전일 통계, 당일 현물/TRM 비교, 혼합 소수점 표기, 수출업체 업무 제안이 있어 그 부분은 분리·제외했다. 지속된 수급 배경을 당일 요인별 기여도나 공식 확정 원인으로 쓰지 않는다.

현재 본문 수정은 9/25 05:49:31Z, 최초 게시 9/24 13:12:44Z다. 수정된 마감 내용을 오전에 확보한 자료처럼 소급하지 않는다. 새 카드의 외부/공개 사용은 pending으로 남겨 내용 확인과 이용 판단을 분리했다. 같은 기준 가격/거래일 원인 검토도 남는다.

### COP 10/5 — 조건부 지지 요인과 당일 원인을 구분

[Infobae 원문](https://www.infobae.com/colombia/2026/10/05/precio-del-dolar-hoy-en-colombia-cotizacion-de-cierre-del-5-de-octubre/)도 확보했다. 상대금리·지역 배경은 페소 지지 요인의 귀속 해석으로 검토할 수 있지만, DXY/유로 설명과 브라질 제목만으로 당일 하락 이유를 확정하지 않았다. USD/COP 하락을 페소 약세라고 표현한 본문 오류와 미래 예상 범위도 제외했다. 새 원인 입력으로 자동 채택하지 않았다.

따라서 COP 수집 경로 전체가 설명을 얻을 수 없는 것은 아니다. 이번 두 날짜 중 하나에서 현지 설명을 확보했지만, 이를 상시 자동 수집 성공률이나 발행 승인으로 확대하지 않는다.

### PEN 10/22·10/20 — 가격 안내·일반 배경만으로 원인을 채우지 않음

등록 RPP 목록의 실제 HTML에서 해당 날짜 링크를 찾아 [10/22 원문](https://rpp.pe/economia/economia/precio-del-dolar-peru-y-tipo-de-cambio-hoy-22-de-octubre-del-2026-noticia-1713852)과 [10/20 원문](https://rpp.pe/economia/economia/precio-del-dolar-peru-y-tipo-de-cambio-hoy-20-de-octubre-del-2026-noticia-1713475)을 확보했다. 가격 방향과 반올림 변화는 맞지만 전자는 일반 소비 영향·중앙은행 역할, 후자는 일반 수급 원리 설명이다. 당일 자금 흐름의 원인으로 채택하지 않았다.

[Macroconsult 10/22](https://sim.macroconsult.pe/reporte-diario-del-22-de-octubre-de-2026/)·[10/20](https://sim.macroconsult.pe/reporte-diario-del-20-de-octubre-de-2026/) 공개 브리프도 확인했다. 가격·비개입과 별도 사건은 있으나 직접적인 당일 PEN 연결은 부족하다. 기존 추출기의 목록 누락은 부분 추출로 유지하고, 본문을 수동 읽은 범위와 자동 추출을 구분했다.

Gestión 목록에서 두 날짜 원문을 찾지 못했고, 10/22 주소 규칙으로 만든 후보는 404였다. 해당 기사가 실제로 없다고 일반화하지 않는다. RPP 웹 도구가 반환한 오래된 목록 캐시와 직접 받은 현재 HTML도 구분했다.

기존 10/26과 새 두 날짜의 확인 범위에서는 **원인 집필 보류**다. 단순 가격 안내 페이지를 더 모으는 대신 현지 딜러 수급·기업 달러 수요·정책 반응을 취재한 자료가 필요한 것으로 조사 초점을 좁혔다. PEN 전체 지원 불가나 소비 통계로 원인을 대체하는 결정은 하지 않았다.

## 종료 상태와 남은 작업

| 통화 | 이번에 해소한 공백 | 남은 필수 조건 |
| --- | --- | --- |
| BRL | 실제 PTAX 마감 두 관측과 판독 경로 | 기준일/기사 구간·원인 지지·가격 이용/표시 검토 후 엄격한 집필 연결 |
| ARS | 변수 5 실제 역사 두 관측과 판독 경로 | 참조 계열/기사 구간, BCRA 용도, 엄격한 집필 연결 |
| COP | 다른 날짜의 현지 달러 수급 귀속 설명과 로컬 카드 | 해당 사례 가격·거래일·이용/내용 최종 검토 |
| PEN | 다른 두 날짜의 수집 가능/설명 부족 구분 | 현지 수급을 설명하는 취재 근거. 일반 가격 안내만으로 원인 승인하지 않음 |
| CLP·MXN | 기존 저장 준비 상태 재생 유지 | 반복 최신 조사·실제 품질·공개/UI/출시 검증은 별도 |

원래 4단계의 마지막 연결 작업으로 **확보한 BRL·ARS 가격과 COP 원인 카드의 구간/내용 검토(Astra High 권장)**를 수행한 뒤, 확인한 범위만 **Sol High로 엄격한 공통 입력에 연결**한다. PEN은 남은 취재 근거 공백을 유지한다. 새 네 통화의 실제 집필 지원을 끝냈다고 보고하지 않는다. 준비 통과 이후에만 5단계 별도 유료 품질 시험으로 이동한다. 6단계 UI/공개, 7단계 파일럿/출시 순서는 유지한다.

## 검증·재현·비용

- 비공개 폴더 `.local-reports/private/four-country-price-case-followup-20261028/`. `preselected-cases.json`, 원본/영수증, 추출 결과, `content-review.json`, `replay.mjs`를 보존한다.
- 최종 입력/결과: `verified-yf2ht9/`. 초기 사본과 카드도 덮어쓰지 않고 보존했다. 마지막 재생은 요지의 사실/견해와 사용 한계를 분리했다.
- 자동 공개 수집 시도 23건, 저장 원본 16건. 처음 제한된 연결 실패 4건·메타데이터 500·옛 매뉴얼 404·미확인 기사 후보 404를 모두 보존했다. 별도 웹 검색/읽기는 이 시도 수에 합산하지 않는다. 차단 우회·로그인·구독·유료 검색은 하지 않았다.
- 기존 검사에 합성 경계 6개 추가: 명시적 마감 선택, 조사 평균 검증, 페이지/통화/중복 거부, ARS 역사/기준 분리, 변수/범위/오염 응답 거부, 서로 다른 저장 관측 충돌. 실제 자료 재생과 합성 검사를 구분한다.
- 113파일 834사례·타입·린트·3종 빌드·번들 경계 통과. 정확한 이름/본문 중복·자기 비교 0. 원고 품질 표본 834건이 아니다. 기존 번들 크기 경고 유지.
- 첫 부분 검사는 임시 폴더 접근 문제로 실행되지 않았고, 프로젝트 내부 임시 폴더로 재실행한 결과와 전체 통과를 기록했다. 이를 제품 실패 또는 최초 성공으로 숨기지 않는다.
- UI/DB 변경이 없어 새 화면·pgTAP 검증은 수행하지 않았다. 기존 보호 파일은 `before.json`/`preservation.json`으로 대조한다.
- 새 원고·AI 호출·API 비용·운영 DB·메일·정기 작업·배포·push 변경 0. 자격증명을 읽지 않았다.
