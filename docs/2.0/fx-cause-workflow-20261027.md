## 가격부터 달랐다

10월 15일 기존 원고의 985.5324 CLP/USD, 전 관측 대비 +0.37%는 공급자 날짜 기반 값이다. 실제 현지 거래일과 관측시각이 확인되지 않았다.

공식 BCCh 비교는 **14일 거래 평균 987.03 → 15일 거래 평균 984.09, 약 -0.30%**다. 고시 적용일은 각각 15일과 16일이다. 15일의 Emol 매도호가 하락 보도와 방향은 같지만, 평균값과 마감 호가는 대체 가능한 가격이 아니다. 공급자 차트의 날짜를 임의로 하루 옮기지도 않았다.

별도 검토가 끝난 작성 후보는 **22→23일 거래 평균 986.58 → 990.35, +0.38%**, 보고서 기준일 26일이다. 이 역시 27일의 최신 시장 보고서로 표시하지 않는다. 기존 15일 사례와 혼합하지 않는다.

## 근거의 역할

- 당일 달러·미국 금리 해석은 해당 시간의 출처 귀속 시장 배경이다. 하루 전체 가중평균의 정량적 원인이나 기여도로 바꾸지 않는다.
- 구리는 실제 보고 방향을 확인해 지지 또는 반대 압력으로 배치한다. 항상 페소 하락의 원인으로 넣지 않는다.
- 장중 기사와 마감 보도의 달러지수 방향 차이는 시각과 비교 기준을 보존한다. 한쪽을 골라 하루 전체가 같았다고 쓰지 않는다.
- 8월 소매·시간당 보수는 별도 소비 배경이다. 10월 환율 원인 질문의 답으로 승인하지 않는다.
- 기사 뒤의 기술적 목표·예측·회사 실적·가격 업무 지시는 입력에 채택하지 않는다.

자료와 반대 근거를 찾았다는 사실, 사용 권한, 설명의 의미적 지지, 생성 비용 승인, 게시 승인은 서로 다른 상태다.

## 코드 경로

1. 기존 공식 가격 어댑터와 `researchTimeScope`가 가격 종류·공급자·실제 거래일을 확정한다.
2. 기존 `inspectDossier`와 `inspectSourceUses`가 원문 구절·채택 카드·사용 범위의 일치를 검사한다.
3. `fx-cause-input.js`가 가격/차트/수치의 일치, 시장 사실, 출처 귀속 환율 연결, 반대 근거 검토, 새 설명의 가치 검토를 요구한다.
4. `prepareEventTrial`이 같은 기존 집필·스키마·예산 경로에 환율 설명 구조를 삽입한다. 경제 업데이트로 자동 전환하지 않는다.
5. `executeApprovedEventTrial`이 전송 직전에 가격·원문·검토·사용 범위와 요청 본문을 다시 확인한다. 검토 내용이 바뀌어도 기존 승인을 재사용하지 않는다.

순서는 **무엇이 달라졌나 → 왜 움직였나 → 근거 있는 사업 환경 → 설명을 바꿀 변수**다. 기사와의 연결은 검토자가 판단하며 해시나 정규식이 인과를 증명하지 않는다.

현재 공식 가격 검증은 CLP 어댑터에 한정한다. BRL/MXN의 거래일·가격 종류 검증이 완료됐다는 의미가 아니다. 기존 연구 도구의 로컬 재생·역사 기록은 보존하며, 새 FX 생성의 구체 실행 경로에 검사를 적용했다.

## 실제 생성이 막힌 이유

[Emol의 현재 약관](https://www.emol.com/terminos/terminosycondiciones.aspx)은 엄격한 개인·비상업적 이용 범위와 그 밖의 재사용에 대한 사전 서면 허가를 규정한다. 기존 검토에서 미확인이었던 기사 이용 범위를 허용으로 바꾸지 않았다. 원문을 읽을 수 있다는 사실만으로 서비스의 외부 집필·공개 이용을 승인하지 않는다.

대체 후보인 [Alpha Vantage 약관](https://www.alphavantage.co/terms_of_service/)도 개인·사적인 연구와 다른 사용자에게 정보를 제공하는 이용을 구분한다. API 키가 있다는 사실만으로 계획된 공개 서비스의 이용 권리를 확인한 것으로 기록하지 않았다. 실제 사용자 계약의 추가 권한 여부는 이번에 확인하지 않았다.

이는 이번 확인한 범위의 운영 판단이며 법률 의견이 아니다. 기존 허용 조건·기록·원문을 삭제하거나 사용 범위를 낮추는 우회는 하지 않는다. 기사 이용 범위가 해결되지 않으면 새 집필과 실제 모델 품질 시험을 보류한다. 같은 소비 원고의 재생성을 대체 성공으로 삼지 않는다.
