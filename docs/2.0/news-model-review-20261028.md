## 검토 대상을 두 가지로 구분

### 새로 수집한 기사 원문 19건

원문/카드 바인딩을 확인하고 기존 `inspectSourceUses`에 실제 원문 리소스를 대입했다. 해당 원문을 외부 모델에 보낼 수 있는 정확한 이용 기록이 없어 **19건 모두 외부 전송 보류**다. 무료 접근·추출 성공·robots 안내를 모델 전송 허가로 바꾸지 않았다.

이전의 검토 입력 준비와 이번 모델 검토를 같은 성공 기록으로 합치지 않는다. 새 원문 내용 판단은 계속 미완료이며 사용자에게 수동 검토 작업을 넘기지 않는다.

### 기존의 독립 작성된 사실·귀속 견해 카드 10건

CLP 4건, MXN 1건, BRL 2건, COP 1건, PEN 1건, ARS 1건이다. 정확한 카드 원본/검토 기록과 범위 바인딩을 검사했다. 외부 입력에 대해 기존에 기록한 제한적 프로젝트 판단 및 실제 출처 표시 조건을 통과하는 카드만 모델 요청에 투영한다. 이는 출판사가 기사 원문의 AI 이용을 허가했다는 뜻이 아니다.

모델 입력은 **카드의 요지·귀속·허용 범위·가격 메타데이터·출처 표시**다. 기사 본문·번역·원문 HTML·비공개 검토자 기록·키는 보내지 않는다. 내부 저장 파일 전체를 메시지로 직렬화하지 않는다.

**중요한 한계:** 이 모델은 ‘제공된 카드 안에서의 설명 일관성’을 점검한다. 기사 원문을 받지 않으므로 ‘카드의 모든 주장이 원문에서 지지되는지’를 새로 독립 확인했다고 기록할 수 없다. 코드와 결과에 `originalEntailmentVerified=false`를 유지한다. 기존 원문 확인 기록은 보존하지만 이를 무인 원문 검토 구현이라고 부르지 않는다.

## 자동 실행과 결과 검사

`news-model-review.js`와 `news-model-review-local.js`가 기존 카드/범위/출처 이용/전재·귀속 메타데이터와 스트리밍·비용 조회 도구를 재사용한다. 별도의 자료 허가 엔진이나 공개 승인 경로를 만들지 않았다.

1. 국가별 저장 입력에서 검토된 뉴스 카드만 선택한다. 통계 원문은 해당 카드 검토 요청에 몰래 포함하지 않는다.
2. 카드 바인딩·허용 범위와 `external_model` 이용 상태를 확인한다. 필수 출처 표시가 실제 전송 자료에 없으면 보류한다.
3. Sol/Azure·medium·엄격한 구조화 응답·ZDR·데이터 수집 금지·백업 없음으로 요청한다. 요청별 최대 120초, 출력 상한 4,096토큰이며 추론 토큰도 이 상한에 포함한다.
4. 모든 카드와 요지 문장의 식별자가 정확히 한 번씩 반환되어야 한다. 역할은 원인 설명/가격 정보/글로벌 배경/소비 배경/정책 배경/무관으로 구분한다.
5. 이미 구조화된 보도 가격이 있으면 해당 가격 기준을 누락하거나 종가·장중·매도 호가를 바꿀 수 없다. 관측시각 미상은 그대로 미상이다. 발행시각·수집시각을 가격 시각으로 채우면 거부한다.
6. 원인 설명과 글로벌 배경, 정책·소비 맥락을 구분한다. 모델의 판단은 검토 결과로 저장하며 집필/공개 승인으로 승격하지 않는다. 내용상 타당성은 별도 평가가 필요하다.
7. 요청 전에 예산을 예약하고 원본/규칙/모델 기반 중복 키를 잠근다. 실행시각만 바꿔 같은 자료를 반복 호출할 수 없다. 동시 실행도 막는다.
8. 사용량·실제 비용·응답 ID·모델·지연을 보존한다. 비용 누락·초과는 다음 통화 호출을 멈추며 예약액을 유지한다. 잘못된 출력도 비용을 기록하고 자동 재작성/재시도하지 않는다.

실제 실행 직전 원래 입력에서 계획을 다시 만들어 바인딩을 대조한다. 수집 원문·허용 범위·가격/모델 설정이 바뀌면 이전 승인 계획을 그대로 사용하지 않는다.

## 비용 확인과 시험 제안

[OpenAI 공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-6.1-sol)를 열어 모델과 구조화 출력 지원을 확인했다. 실제 OpenRouter 요청에 대해서는 [공개 엔드포인트 정보](https://openrouter.ai/api/v1/models/openai/gpt-6.1-sol/endpoints)와 [ZDR 목록](https://openrouter.ai/api/v1/endpoints/zdr)을 별도로 읽어 Azure의 현재 지원·가격·상태를 검사했다. OpenAI 직접 요금을 OpenRouter의 실제 청구액으로 대체하지 않았다.

## 실제 6회 실행과 저장 응답 재검사

요청·실제 반환 모델은 모두 `openai/gpt-6.1-sol`이었다. 통화별 1회씩 총 6회, 자동 재시도·백업·추가 생성은 없었다. 실제 비용은 OpenRouter가 반환한 `usage.cost`를 기록했으며 미확인 비용/예약 잔액은 0이다.

| 통화 | 카드 / 요지 수 | 모델이 구분한 내용 | 카드 안의 현지 설명 자료 수 | 실제 비용 |
| --- | ---: | --- | ---: | ---: |
| CLP | 4 / 6 | DF·Emol의 현지 해석과 Pulso·Yahoo/Reuters의 글로벌 배경 구분 | 2 | $0.0244785 |

‘요지 19개’와 앞서 새로 수집한 ‘기사 원문 19건’은 별개의 자료다. 이번 전송은 전자뿐이다. 모델은 모든 요지를 제공된 카드 범위 안에서 지지되는 것으로 판단했으며, 위 현지 설명 수는 원문 직접 지지·독립 검증 횟수·실제 인과 입증 수가 아니다.

### 실제 시험에서 발견한 검사 오탐과 수정

최초 실행 기록에서는 CLP·COP가 `output_hold`, 나머지 4통화는 검토 결과가 기록됐다. 두 보류의 응답은 정상 완결 JSON이며 모델이 글로벌 해석을 `global_context + reported_link`로 표현한 것이 원인이었다. 기존 지침은 명시된 시장 해석을 reported_link로 부르게 하면서 검사는 현지 원인에만 이 값을 허용해 의미가 충돌했다.

원래 응답·최초 실패·비용은 보존했다. 원고나 카드 문장을 손으로 바꾸지 않고 검사 버전 `news-notes-model-review-check/2`로 구분했다.

- 글로벌 배경의 보도된 해석 연결은 허용하지만 **`localCauseSupport=false`**다. 현지 설명 후보는 국가 자료·명시적 귀속 요지·채택 범위가 함께 있는 경우만 카드 내부 판단으로 표시한다. 이 표시도 집필 승인과 다르다.
- 모든 요지가 카드 안에서 지지되지만 관측시각 미상 등 한계가 있으면 `notes_consistency_checked_with_limitations`다. 실제 범위 초과/미검증 요지는 `scope_review_needed`로 유지한다. 공통 한계가 있다는 이유와 내용 오류를 합치지 않는다.
- 가격 정보/소비 배경을 현지 원인으로 승격하는 조합, 원문 위치/요지 누락, 가격 시각 발명 등은 계속 거부한다.

추가 유료 호출 없이 저장 응답 6건을 새 버전으로 재검사했다. 모두 **한계가 있는 카드 일관성 검사 통과**이며 `originalEntailmentVerified=false`, 집필 미판정·게시 미승인 상태다. 최초 결과에 성공을 소급 덮어쓰지 않았다.

### 에이전트의 별도 내용 대조

저장된 카드 19개 요지와 모델의 문장별 판단을 대조했다. 관측시각을 새로 만들거나 TRM 차이를 전일비로 바꾸거나, 기대를 실현된 정책으로 바꾸는 오류는 이 표본에서 발견하지 못했다. COP/PEN의 현지 원인 부재, BRL의 조건부 재정 평가, ARS의 전문가 해석과 공식 발표 구분도 기존 채택 범위와 맞았다.

이는 동일 자료를 이미 본 에이전트의 카드 대조이며 독립 원문/사람 승인/맹검 평가가 아니다. 이미 검토한 정상 카드 중심 표본이므로 오보·악성 입력·잘못 작성한 카드의 모델 검출률을 실측한 시험도 아니다. 새 리포트 품질 점수를 부여하거나 운영 자동 승인 근거로 사용하지 않는다.

| ARS | 한계 포함 일관성 확인 | 보류 | 가중 참조환율과 도매 마지막 가격 구분, 같은 기준 가격 쌍·직접 원인 연결 |

카드 검토가 통과해도 부족한 원인·공식 가격 쌍·외부 이용 조건을 만들어내지 않는다. 같은 이유로 승인되지 않은 국가는 사유를 남기고 다른 국가의 검증을 계속한다.

### PEN의 저장 가격 연결 보강

이번 재생에서 기존 Gestión 캡처에 `isAccessibleForFree=false`가 있어 공통 접근 검사가 작동했다. 표시를 우회하거나 저장 시세를 대신 사용하지 않았다. `prepareCountryPriceConnection`이 이 확인된 접근 제한만 `article_access_review_required`로 반환하도록 보강했다. 원문/검토 해시 오류 같은 다른 예외는 여전히 숨기지 않는다.

따라서 PEN은 이유가 있는 집필 보류가 되고, 국가별 처리 전체가 예외로 멈추지 않는다. 실제 원본과 기존 카드·환율은 수정하지 않았다. 이 접근 표시만으로 기존에 따로 작성한 최소 사실 카드의 모든 이용 판단을 소급 취소하거나 기사 자체가 무료였다고 재승인하지 않았다.
