보강한 출처가 수집 후 대기열에만 남던 연결을 마감했다. `country-news` 선택은 현재 등록부에서 해당 국가의 활성 뉴스 경로를 모두 고른다. 매번 선호 신문 이름을 입력하거나 한 매체가 해결될 때까지 전체 작업을 멈추는 방식이 아니다. 출처별 실패/미시도/후보 부족/원문 검토 대기/카드 이용 대기를 나누고, 다른 적격 근거가 있으면 공통 준비로 이어진다. 판정·출처 이용·게시 승인 기준은 낮추지 않았다. 아래 10/28의 “다음 작업”과 미연결 상태는 당시 기록이다.

### 반복 실행에 적용되는 공통 동작

1. **국가 전체 선택:** 기존 수집 명령의 `--sources country-news`가 등록된 활성 뉴스 경로를 자동 선택한다. 여섯 통화에 같은 선택 함수를 사용하며 국가별 자료 내용 검토를 여섯 번 수행했다는 뜻은 아니다.
2. **조회 예산 분리:** 전체 상한16회 안에서 출처별 한도를 나눈다. 복수 매체를 포함하는 기존 수집 그룹은 구성 매체 수를 반영한다. 앞 출처가 모든 요청을 쓰지 않도록 하며 부족한 요청은 실패/미시도로 기록한다.
3. **대상 날짜 탐색:** 목록에 다른 날짜 기사만 있어도 등록 뉴스 색인을 확인한다. URL 날짜는 후보 우선순위 단서일 뿐 발표일/거래일 증거가 아니다. 이동 목록에서 사라진 링크는 명시적으로 전달된 저장 URL에서 복원할 수 있으며 본문·시점·접근 검사는 그대로 수행한다.
4. **저장 재사용:** 이전 HTML을 재사용하면 원래 수집시각을 보존한다. 페이지 부가 요소만 바뀐 raw SHA와 실제 본문/게시·수정 정보의 판본 변경을 구분한다. 내용이 다른 판본은 순서로 선택하거나 이전 검토를 물려주지 않는다. 독립 기사 본문이 완전히 같은 전재는 중복으로 기록한다.
5. **검토 연결:** 기존 `prepareSelectedReviewBatch`·`reviewSelectedNewsMaterial`의 정확한 원문/카드/응답 바인딩을 검사한다. 역할 입력의 사실·범위 카드가 검토 결과와 다르면 거부한다. 가격 전용/글로벌 판단을 현지 직접 원인으로 승격하지 않는다. 검토 응답이 없으면 자동 검토 대기다.
6. **집필 준비:** 기존 공통 기준환율 스냅샷과 `reconnectReferenceMaterials`·`material-selection/2`를 재사용한다. 새 카드의 역할·기간·이용/표시 조건이 모두 맞아야 합친다. 제외 자료의 의존 주장도 제거하고 필수 관측·원인이 없으면 보류한다. 이전 승인·유료 권한을 상속하지 않고 요청/게시 승인을 만들지 않는다.
7. **원문/카드 구분:** 원문 외부 처리 허가와 정확한 자체 사실·귀속 카드의 제한된 운영 판단은 별개다. BioBio 원문 이용 조건 미확정은 유지했다. 이번 두 자체 요지만 기존 카드 범위로 개별 판단했으며 원문 전송·번역·기사 구성 복제·공개 허가를 부여하지 않았다. 공개 표시는 대기다.

### 검증 범위와 남은 경계

BioBio 두 요지는 **현재 Codex 에이전트가 저장 원문을 직접 대조해 작성한 검토 기록**이다. 기존 카드만 모델에 반복 보내 원문 대조로 이름을 바꾼 결과가 아니다. 별도 유료/독립 검토 모델과 상시 무인 의미 검토의 실제 성능은 이번에 시험하지 않았다. 새 미검토 기사는 계속 대기한다. 원문 처리 범위가 맞지 않는 자료를 외부 모델에 보내는 대체 경로도 만들지 않았다.

실제 공개 읽기는 최초 환경 내 전송 실패4회를 보존한 뒤 정상 공개 읽기12회, 수정 후 저장 응답을 재사용한 추가 읽기6회로 확인했다. 마지막 무네트워크 재생은 기존 10/27 BioBio 기사도 후보로 복원했다. 모델/API 유료 호출0, 신규 비용$0이다. 출처 한 곳 실패·검토 누락·역할/용도 대기·다른 날짜·변조/수정본·전재·HTML 부가 변경·한도 분배·색인/캐시 후보 복원을 검사했다. 새 계약11개 선언을 추가했고 전체129파일990실행 사례(815선언 +175매개변수 확장), 타입·린트·3빌드·번들 경계를 통과했다. 정확한 테스트 이름/본문 중복·자기 비교 단정은 없었으며 실제 원고 품질 표본 수가 아니다. 기존615,654바이트 묶음 경고는 유지한다.

보호 자료315개의 변경/누락0, 세 빌드 산출물56파일에서 로컬 비밀값·검사 대상 기사 원문 문단 발견0을 확인했다. 기존 환율·원고·과거 비용·운영 DB·배포·메일은 보존했다. 새 리포트 생성/공개/운영 반영은 없다. [결과 기록](clp-source-pool-20261029.json).

재현 명령은 다음과 같다. 첫 명령의 `saved`는 자료 수집 성공이 아닌, 명시한 저장 응답을 사용하는 모드다. 실제 무료 공개 조회는 `live`를 명시한다. 두 번째 명령은 어떤 경우에도 네트워크·모델 호출이나 키 읽기를 하지 않는다.

```text
npm run report:research:collect-selected -- --input <비공개 조사 입력.json> --sources country-news --mode saved --saved <비공개 캡처 목록.json>
npm run report:news:pool -- --input .local-reports/private/clp-source-pool-20261029/final-manifest-v2.json
```

출처별로 매번 수동 확인을 사용자에게 요청하지 않는다. 상시 자동 의미 검토의 실제 시험은 처리 범위가 맞는 원문과 실행 경로·별도 예산이 준비된 경우에 진행하며, 카드 일관성 재시험으로 대체하지 않는다. 이 공통 연결 완료와 실제 집필 품질·승인/UI·파일럿·출시는 분리한다.

## 공통 수집기 보강

1. **접근 규칙:** 새 출처는 각 실행에서 저장/실제 robots 응답을 먼저 확인한다. 해당 URL이 차단되거나 정책을 확인하지 못하면 본문 요청을 하지 않는다. 다른 봇의 규칙을 현재 수집기에 적용하거나 검색 도구의 접근을 허가로 대신하지 않는다. 지연 정책이 있으면 처리 가능한 실행기가 생길 때까지 보류한다.
2. **유료벽:** `isAccessibleForFree=false`와 숨겨진 premium 본문을 차단한다. JSON-LD가 free라고 적혀 있어도 숨긴 premium 표시를 우선한다. 일반 구독 링크만 있다고 무료 본문을 차단하지 않는다.
3. **본문 영역:** Forbes·Valora·BioBio·Cooperativa·iProfesional·El Financiero·Andina의 확인된 본문 영역을 읽는다. 경계가 사라지거나 복수이면 전체 페이지로 대체하지 않는다. El Financiero의 중간 추천 article 뒤 본문도 끝까지 보존한다.
4. **목록 형식:** HTML 외에 BioBio 공개 목록 JSON과 공식 뉴스 sitemap/RSS의 제목·URL을 탐색한다. 목록 JSON의 기사 내용 필드는 원문 증거로 쓰지 않고 개별 기사 요청으로 이어간다. Andina는 관측한 뉴스 sitemap, Infobae Perú는 robots에 명시된 국가별 뉴스 색인을 보조 경로로 사용한다.
5. **탐색 우선순위:** 국가·현지 통화와 직접 연결된 해설을 일반 금/글로벌 달러 기사보다 우선한다. 새 경로는 출처당 후보 최대 3개다. 제목·URL의 날짜는 근거 승인이나 발표시각으로 사용하지 않는다.
6. **기존 도구 연결:** 같은 출처·기간의 반복 질문은 요청/원문을 재사용한다. 여섯 통화의 확장 목록을 한 국가 단위로 선택해도 질문별 내부 요청 수 때문에 거부되지 않도록 범위를 조정했다. 실제 네트워크 요청 한도는 최대 16회라는 기존 제한을 유지한다.
7. **전재:** 확인된 Reuters/EFE/AFP 등 credit을 단서로 보존한다. 이는 자동 독립성 판정이 아니다. 출처 수나 기사 수를 독립 확인 횟수로 계산하지 않는다.
