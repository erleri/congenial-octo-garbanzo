## 1. PEN 정상 응답과 오류 처리 기준

[공식 API 안내](https://estadisticas.bcrp.gob.pe/estadisticas/series/ayuda/api)는 JSON·CSV와 언어 매개변수를 설명하며 기본 언어를 스페인어로 안내한다. 같은 PD04646PD 시리즈와 2026-10-19~23 구간을 비교했다.

| 요청 | 결과 |
| --- | --- |
| JSON, 끝에 `/esp` 명시 | 전체 JSON 파싱 성공, 오류 HTML 없음 |
| 이전과 같은 언어 생략 URL | 이번에는 정상. 위 응답과 내용·SHA-256 동일 |
| CSV, `/esp` | HTML 줄바꿈이 섞인 CSV 표시 형식. 행을 별도로 대조했을 때 5개 값 일치 |
| 매입 PD04645PD·매도 PD04646PD, 10월 19~26일 | 5개 유효 관측, 10월 26일 `n.d.`, 24·25일 행 없음 |

따라서 **언어를 명시하면 오류가 해결된다는 원인 판단은 하지 않는다.** 앞선 조회의 오류와 이번 정상 결과를 함께 보존한다. 서버 상태가 일시적으로 달랐을 가능성이 있으나 확정 원인은 아니다.

PD04646PD의 이름은 13:30 마감 매도, 단위는 1 USD당 PEN이다. 13:30은 시리즈 정의이고 수집·발표 시각이 아니다. 응답에 없는 관측 타임스탬프와 시간대는 채워 넣지 않았다. 이번 유효 자료의 마지막 날짜는 10월 23일이며, 요청 종료일 26일을 최신 관측일로 표시하지 않는다.

향후 수집에 반영할 기준:

- 형식을 JSON으로 요청하고 **응답 전체**를 파싱한다. 뒤에 서버 오류 HTML이 붙으면 일부 값만 잘라 채택하지 않는다.
- 이번 서버는 정상 JSON에도 `text/html`을 반환했다. MIME을 단독 합격·실패 기준으로 삼지 않고 전체 파싱·스키마·시리즈·기간·값을 함께 검사한다.
- `n.d.`는 결측이다. 0·전일 값·변화 없음으로 바꾸지 않는다.
- 매입·매도를 구분하고 동일 기간 단일·복수 시리즈 응답을 대조한다.
- CSV는 공식 대조 경로다. 이번 HTML 줄바꿈을 허용한 연구용 대조를 운영용 CSV 파서 완성으로 취급하지 않는다.

원본은 `.local-reports/private/pen-ars-cop-basis-20261027/pen-*.body`와 메타데이터에 보관했다. 기존 실패 기록은 [이전 출처 등록부](six-currency-source-register-20261027.json)의 `publicApiProbes`에 남아 있다.

## 2. ARS 이용 범위

[BCRA API 목록](https://www.bcra.gob.ar/apis-banco-central/)은 웹사이트·기업 서비스 활용을 안내하고 통계 API별 이용 안내를 [일반 법적 고지](https://www.bcra.gob.ar/aviso-legal/)로 연결한다. 확인한 목록과 v4 기술 설명서에서는 통계에 적용할 별도의 무제한 라이선스를 찾지 못했다.

| 이용 방식 | 확인한 조건과 이번 판단 |
| --- | --- |
| 로컬 공개 통계 조사·정보 분석 | 정보 제공 목적의 출처·맥락 보존 조건으로 진행할 범위 |
| 공개 정보 리포트의 수치·자체 분석 | 허용된 정보 제공 목적에 맞는지 서비스의 실제 제공 방식과 대조. BCRA 출처와 LATAM FX 가공 책임 표시 |
| 상업·광고·캠페인 목적 | 사전 명시 허가 대상으로 안내됨. 별도 확인 없이 허용으로 등록하지 않음 |
| 외부 AI에 공개 수치·정의 입력 | AI 전용 허용·금지 조항은 확인하지 못함. 이를 포괄적 금지나 허가로 바꾸지 않음. 수치 최소 입력과 이용 목적 검토 필요 |
| 원 데이터베이스 전체 배포·로고·제3자 콘텐츠 | 위 정보 제공 허용을 자동 확대하지 않음 |

무료 API라는 사실과 무료 정보 서비스의 이용 목적은 별도다. 현재 개발·검증을 중단할 사유는 없으며, 공개 연결 전에 **순수 정보 제공인지, 상품·광고·유료 업무 서비스와 연결되는지**를 기록해야 한다. 필요할 경우 해당 범위로 BCRA에 확인할 수 있지만 이번에 문의를 보내거나 허가를 받지는 않았다.

대체 경로 조사에서는 Datos Argentina의 과거 환율 및 CC BY 자료가 발견됐지만, 최신 도매 기준환율의 동일성·현재 기간을 확인하지 못했다. 오래된 역사 자료·실질환율 지수·은행 소매 시리즈를 현재 BCRA 도매 환율의 대체로 채택하지 않았다.

2026-01-02 산식 변경과 도매·은행 소매·MEP·CCL·blue 분리 기준은 [기존 준비 현황](six-currency-readiness-20261027.md)을 유지한다. 이번 이용 조건 확인이 가격 종류를 바꾸는 이유는 아니다.

## 3. COP 거래일과 적용일

### 공식 규정 확인

[DOAM-146 원문 PDF](https://www.banrep.gov.co/sites/default/files/reglamentacion/archivos/bjd_94_2020.pdf)는 2020-11-04 발행, 2021-02-01 시행으로 표시된다. 8-1·8-2쪽에서 거래액 가중평균, 현지 07:30~13:00 거래 구간, 다음 날 적용, 미국 은행 휴일 및 주말 처리를 확인했다. 8-2쪽의 표와 마지막 문장은 PDF를 로컬 이미지로 렌더링해 직접 대조했다.

주말 설명에는 공식 자료 간 차이가 있다. 규정은 다음 영업일에 유효한 TRM을 주말에 적용한다고 쓰지만 [2021년 설명문](https://www.banrep.gov.co/es/node/57129/printable/print)은 이전 영업일로 표현한다. 이 차이를 숨기거나 설명문만으로 자동 이월 규칙을 만들지 않는다. **실제 SFC의 유효기간을 우선 보존하고 규정과 대조**한다. 모든 후속 개정·예외를 전수 확인한 것으로 보고하지 않는다.

### 공식 데이터 확인

SFC가 발행한 [TRM 원본 데이터셋](https://www.datos.gov.co/resource/32sa-8pi3.json)과 [메타데이터](https://www.datos.gov.co/api/views/32sa-8pi3.json)를 확인했다. 조회 화면 `mcec-87by`는 원본 `32sa-8pi3`의 정렬된 보기다. 두 메타데이터 모두 발행기관 SFC, 공식 자료, CC BY-SA 4.0을 표시한다.

제공 필드는 `valor`, `unidad`, `vigenciadesde`, `vigenciahasta`다. 날짜는 자정 형태의 **시간대 없는 달력 값**이며 실제 자정 관측이나 UTC 시각을 뜻하지 않는다. 거래일·개별 관측시각 필드는 없다.

[연준 은행 휴일 안내](https://www.federalreserve.gov/aboutthefed/k8.htm)에서 2026-06-19와 10-12 휴일을 확인했다. 같은 안내는 2026-07-03에 이사회는 쉬지만 연준 은행은 연다는 차이도 명시한다. 일반 미국 공휴일 목록으로 은행 결제 휴일을 대신하지 않는다.

이번 실제 자료는 최근 25개 유효기간과 6월 휴일 주변 4개 구간이다. 10월 24·25·26일 조회는 같은 인증 구간을 반환해야 한다. 이를 세 번의 새 거래·새 수익률·새 발행 계기로 세지 않는다. 다음 유효기간이 없으면 마지막 구간을 임의 연장하지 않는다. 가격이 우연히 같은 두 독립 구간을 값만으로 합치지도 않는다.

기사와 연결할 때는 다음을 구분한다.

- **TRM:** 인증된 적용 구간과 그 기초 거래 구간.
- **현물 종가·장중 가격:** 기사에 표시된 거래일·시각·비교 기준.
- **이번 추론 거래일:** API 필드처럼 표시하지 않으며 공식 현지·미국 은행·CUD 달력과 예외 확인이 남아 있음.

예를 들어 10월 26일 기사에서 ‘당일 TRM 대비’를 말하면 24~26일에 적용된 기준과의 비교다. 기사 종가의 전일 대비 수익률이나 26일 거래로 형성된 27일 TRM과 같은 계산이 아니다.

CC BY-SA 4.0의 출처·라이선스·변경 표시와 파생 자료 적용 범위는 공개 출력 설계에 반영해야 한다. 이번 확인을 앱 코드 전체의 라이선스 변경이나 운영 재배포 완료로 해석하지 않는다.

## 4. 저장 응답 검증

새 공개 응답 11건은 원본·수집시각·최종 URL·HTTP 상태·SHA-256으로 보존했다. 이후 외부 연결 없이 다음을 검증했다.

- PEN 전체 JSON 파싱, 두 요청의 동일 응답, CSV와 5개 값 일치, 매입≤매도, 결측 26일과 마지막 유효일 23일 구분.
- COP 공식 원본·보기 연결, 라이선스·4개 필드, 29개 구간의 단위·값·역전·중복·겹침 검사.
- 실제 주말·미국 휴일 구간 조회와 미제공 날짜의 조회 실패 유지.
- 합성 변형 8개 거부: 오류 HTML 접미부, `n.d.` 숫자화, 빈 문자열, 0 가격, 잘못된 통화, 중복 구간, 역전 구간, 겹친 구간.

합성 변형은 재발 방지용이며 실제 장애 8건이나 원고 품질 표본 8건으로 세지 않는다. ARS 약관의 의미 판단은 원문 검토이며 정규식·이 검사의 통과로 법적 허가를 자동 승인하지 않는다.

최종 재생에서도 위 결과를 재현했다. 원본 응답 11건의 해시와 이전 출처 등록부의 모든 원래 필드·실패 기록이 유지됨을 대조했다. 문서 정리 전후 보존 대상 26,952개 파일은 내용 변경·누락이 없었다. 앱·자료 수집 실행 코드는 수정하지 않았으므로 전체 앱 테스트·빌드는 다시 실행하지 않았다.
