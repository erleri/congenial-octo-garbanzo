# 칠레 공통 범위 카드 실제 생성 시험

같은 칠레 자료를 공통 범위 카드로 다시 생성했다. 자동 검사와 출처 연결은 통과했고, 이전 원고의 최대 순위·가구 부담 확대·자료 부재 단정은 새 원고에서 발견되지 않았다. 그러나 반복 경고와 새 변수가 없는 관찰 항목 때문에 전체 읽기 품질은 합격 기준에 미달했다. 본문을 수동으로 고치지 않고 미채택 비교본으로 보존했다.

## 호출과 비용

사용자가 선택한 3번의 승인 범위는 Sonnet 한 번, 신규 최대 $0.15, 재시도와 백업 없음이다. 요청 모델과 실제 반환 모델은 모두 `anthropic/claude-sonnet-5.5`이고 추론 설정은 medium이다. Google Vertex global 경로의 가격·구조화 출력 지원·ZDR를 호출 전에 확인하고 데이터 수집 금지, 다른 경로 대체 금지, 120초 제한을 유지했다. 검색 추가 기능은 사용하지 않았다.

입력과 출력 상한으로 예약한 비용은 $0.144936, 실제 OpenRouter `usage.cost`는 **$0.030218**이다. 입력 5,224토큰·출력 1,977토큰이며 응답에 보고된 추론 토큰은 0이다. medium 설정이 별도 추론 토큰 발생을 보장하지는 않는다. 이번 호출은 성공했고 미확인 비용 예약은 없다.

| 입력 | 자동 검사 | 당시 잠정 품질 | 실제 생성 비용 | 채택 |
| --- | --- | --- | --- | --- |
| 첫 입력 | 미통과 | 3.4/5 | $0.039662 | 미채택 |
| 수정 입력 | 출처 대응 미통과 | 3.6/5 | $0.022112 | 미채택 |
| 공통 범위 카드 | 통과 | 3.4/5 | $0.030218 | 미채택 |

세 건의 확인된 합계는 **$0.091992**다. 과거 검색 비용은 이 합계에 포함하지 않는다. 과거 점수는 당시 평가로 보존했다. 세 번의 독립 생성은 모델의 통계적 품질 비교나 사람 독자 평가가 아니다.

## 같은 자료와 새 입력의 경계

기준일·환율 관측일은 2026-10-09다. INE의 9월 IPC 발표와 8월 실질보수 발표를 사용했고, 환율·차트·사실·출처 패킷은 수정 입력 시험과 해시가 같음을 확인했다. 실제 관측시각은 미제공이며 수집시각으로 대체하지 않았다. 경제·소비 환경 업데이트이지 저장 환율의 원인을 검증한 보고서가 아니다.

새 입력은 `economic-update/3`, `evidence-scope/1`을 사용했다. 원문이 강조한 항목을 전체 최대 순위로 바꾸지 않고, 지수 기여와 가구별 부담을 구분하며, 서로 다른 월의 물가와 실질보수를 직접 차감하지 않도록 범위를 명시했다. 원문은 현재 페이지를 보존한 자료로서 당시 페이지의 아카이브라고 표시하지 않는다.

## 보존과 로컬 화면

실행 기록은 `.local-reports/private/event-trials/run-cv5X5k`, 승인된 입력은 `.local-reports/private/economic-scoped-trial-3-Je1ZbM`에 있다. 최종 문장 검토는 `content-review-detailed.json`이다. 앞선 두 실행·평가·원문·보고서 등 열 파일의 해시가 유지됐다. 새 초안의 최초 공개 투영도 private에 복사한 후 검토 상태만 변경했으며 AI 본문은 바꾸지 않았다. 비교 목록의 이전 파일도 보존했다.

로컬 A안은 실행 `CLP-2026-10-09-1791718402206`을 명시해 연다. 화면에는 과거 사례·미채택·운영 미게시를 표시하고, 접는 비교표에서 세 원고를 각각 선택할 수 있다. 기존에는 현재 사례로 표시된 과거 원고로 전환하면 비교표가 사라졌다. 과거 표시와 표 표시를 분리하고 해당 manifest에 속한 실행에만 표를 유지하도록 보완해 이전 원고에서 새 원고로 복귀를 확인했다. 과거 원고의 당시 메타데이터는 수정하지 않았다.

새로고침과 화면 전환은 API를 호출하지 않는다. PC와 390px 모바일에서 원고·차트·출처를 확인했다. 모바일 문서 폭은 375px로 viewport 390px을 넘지 않았다. 화면 캡처는 `.local-reports/reviewable/clp-economic-scoped-3-20261011-pc.jpg`와 동일 이름의 `-mobile.jpg`다.

## 안전장치와 회귀 검증

기존 한 번의 교정 재시험 경로를 전체 실패 이력에 결합된 세 번째 승인으로 확장했다. 세 번째에는 앞선 요청 해시의 순서·비용 확정·연속된 재시험 연결·모든 입력의 차이·별도 신규 예산을 요구한다. 미확인 비용이나 다른 미해결 실패를 우회하지 못하며 캠페인의 최대 세 번 제한은 유지한다. 승인 기록이나 새 입력이 이후 추가 호출 권한은 아니다.

관련 안전장치 12개, 전체 67파일·374개 선언·468개 실행 사례가 통과했다. 타입·린트·운영 빌드·리포트 빌드·번들 경계도 통과했고 기존 804,454바이트 진입 번들 경고는 남아 있다. 정확히 같은 이름·본문·자기 비교 감사에서는 항목이 없었으나 의미적 중복이 전혀 없다는 보장은 아니다. 이 수를 실제 원고 품질 표본으로 계산하지 않는다.

두 빌드와 로컬 검토 자료 60개 파일에서 실제 키의 유출이 없음을 확인했다. 정제된 보고서 응답은 HTTP 200이고 생성 원문 경로는 HTTP 403이다. 내부 카드·원문 구절·문장 대응표는 공개 응답에 포함하지 않았다. DB 변경이 없어 pgTAP은 재실행하지 않았다. 운영·원격 push·DB·메일은 변경하지 않았다.

## 다음 판단

공통 범위 계약과 출처 누락 차단은 유지한다. 다음 개선은 규칙 추가나 재호출보다, 긍정적 새 정보와 필요한 조건을 분리하는 편집 설계다. 특히 요약의 비교 제한 범위를 정확히 쓰고, 이미 설명한 공통 한계는 한 번 모으며, 별도 관찰 변수가 없으면 해당 항목을 만들지 않는 대조 예시를 저장 원고로 먼저 평가한다. 권장 작업 모델은 내용·입력 판단 Astra High, 구현이 필요한 경우 Sol High다.

이후 유료 재시험은 새 승인 대상이다. 세 번의 사후 시험은 실시간 파일럿 관찰일이나 사람 승인 표본에 합산하지 않으며 2.0 출시는 계속 보류한다.
