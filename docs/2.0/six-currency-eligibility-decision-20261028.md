# 6개 통화 집필 자격 검토 — 필수 자료와 선택 배경

2026-10-28 · 저장 자료와 기존 코드 확인 · 로컬 검토, 추가 호출·운영 변경 없음

## 이번에 끝낸 판단

**현재 네 통화의 보류를 모두 ‘뉴스가 부족하다’로 묶으면 안 된다.** COP·PEN은 해당 사례의 설명 근거 부족과 일부 수집 결함이 함께 있다. BRL·ARS는 귀속된 설명이 있으나 가격 연결과 공통 원인 검사 확장이 남는다. 별도의 소비 배경 미확인까지 환율 원고의 필수 조건으로 만드는 것은 불필요하다.

이 문서는 기존 자료에 대한 비맹검 에이전트 검토다. 별도 Astra 실행·독립 심사·새 법률 판단·실제 모델 품질 시험은 아니다. 기존 이용 판단과 원고는 바꾸지 않았다. 아래 입력 선택 원칙은 **다음 구현의 기준**이며, 실제 집필 허용이나 배포 승인으로 적용한 것은 아니다.

## 1. 필수 자료와 선택 자료

대상은 ‘왜 환율이 움직였나’를 설명하는 원고다. 별도 정기 점검본·정책 업데이트에는 해당 목적의 기존 기준을 적용한다. 원인 근거가 없다는 이유로 목적을 자동 변경하지 않는다.

| 항목 | 필수 여부와 정확한 범위 | 부족할 때 |
| --- | --- | --- |
| 움직임과 가격 기준 | 필수. 비교에 쓸 전후 관측은 같은 계열·단위·가격 종류이며 실제 거래일/집계 구간을 식별해야 한다 | 숫자를 역산하거나 현물·공식 평균·TRM·FIX를 혼합하지 않고 집필 보류 |
| 해당 통화와 요인을 연결한 설명 | 필수. 같은 구간의 시장 보도 또는 귀속된 견해와 그 설명을 지지하는 내용 검토 | 가격 보도·달러 일반론만 있으면 원인 집필 보류. 기여도를 정밀 계산하거나 두 매체를 확보해야 한다는 추가 요건은 없음 |
| 반대 근거와 중요한 조건 | 조사·검토가 필수. 실제 발견한 반대 압력과 범위를 바꾸는 조건은 유지 | 유리한 자료만 남기려고 삭제하지 않음. 별도 반대 의견을 억지로 만들어 개수를 채우지도 않음 |
| 소매·물가·임금·소비금융 | 독립적인 영업 환경 배경일 때 선택. 그 지표를 제목·원인·요약·영업 문장에 사용하면 해당 주장에는 필수 근거가 됨 | 미확인 자료와 이에 의존한 문장을 함께 제외. 실제 판매나 구매력 개선을 일반론으로 대신 쓰지 않음 |
| 정책 자료 | 과거 금리 수준을 설명하는 배경은 선택. 새 정책을 환율 원인으로 채택하거나 중요한 반대 근거로 쓰면 필수 | 역할에 따라 해당 주장 또는 집필을 보류. ‘정책’이라는 이름만으로 일괄 제외 금지 |
| 출처·시점·사용 범위·표시 | 최종 입력에 포함하는 모든 자료에 필수. 공개 표시는 별도 확인 | 선택 자료라도 입력에 남아 있으면 기존 검사 유지. 출처 표시만으로 미확인 이용 범위를 허용으로 바꾸지 않음 |
| 게시 승인과 유료 예산 | 자료 자격과 별개 | 입력 준비 통과가 호출·게시 승인으로 전환되지 않음 |

공식 평균값과 기사 현물값이 반드시 같을 필요는 없다. CLP 사례처럼 **같은 거래 구간의 다른 가격 기준을 분리해서** 해석할 수 있다. 그러나 공식 값 두 개를 비교한다고 하면서 다른 날짜나 다른 호가를 끼워 넣거나, 장중 해석으로 전체 종가 변동을 입증했다고 하면 안 된다. 분 단위 관측시각을 모르는 모든 자료를 일괄 탈락시키는 것이 아니라, 해당 주장에 필요한 거래일·집계 구간과 순서를 확인한다.

소비 자료를 생략한 환율 원고는 가능하나 영업 관련성 점수가 자동으로 높아지는 것은 아니다. 품질 기준을 낮추거나 빈 영업 항목을 만들어 통과시키지 않는다.

### 선택 배경 제외를 안전하게 구현할 조건

1. 목적·주장별 필수/선택 역할을 먼저 기록한다. 같은 자료 안에 원인·반대 근거가 함께 있으면 통째로 제외하지 않는다.
2. 원본은 유지하고 별도의 선택 결과를 만든다. 제외 사유, 의존하는 주장, 자료 상태를 남긴다.
3. 제외 자료의 본문·카드·수치·표시·참조 ID가 최종 모델 입력에 남지 않게 한다. 감사 기록은 비공개 원본에 유지한다.
4. 남긴 자료의 범위·이용·시점 검사를 다시 실행한다. 바뀐 패킷의 바인딩과 내용 검토도 새로 확인한다. 과거 승인을 그대로 복사하지 않는다.
5. 필수 자료가 빠졌거나 조건이 미확인이면 보류한다. 선택 경로가 기존 검사를 우회하는 허용 목록이 되어서는 안 된다.

## 2. 저장 사본으로 확인한 실제 효과

기존 `prepareCountryMaterials`를 그대로 사용했다. BRL의 소매·과거 Selic 배경, PEN의 INEI 생산 배경을 실험 사본에서만 제외했다. COP·ARS는 동일 입력 대조군으로 유지했다. 자료별 이용 상태를 allowed로 바꾸거나 가격을 수정하지 않았다.

| 통화 | 제외 실험으로 사라진 보류 | 그대로 남은 필수 보류 | 결과 |
| --- | --- | --- | --- |
| BRL | 소매 외부 이용 미확인, Selic 발표일 미확인 | PTAX와 기사 현물 종가 차이, 같은 기준 전후 공식 가격 쌍, 원인 검토 연결 | 여전히 보류 |
| COP | 없음 | 해당 COP 움직임에 연결한 설명, TRM 적용일/거래일, 현물−TRM 비교, 가격 쌍과 원인 검토 | 여전히 보류 |
| PEN | INEI 배경 외부 이용 미확인 | 직접 설명, 공식 당일 값/호가면, 선언된 시각의 시간대, 가격 쌍과 원인 검토 | 여전히 보류 |
| ARS | 없음 | 도매 종가와 가중 참조값 구분, 최신 요약값 대신 전후 계열, 원인 검토 | 여전히 보류 |

남긴 근거·반대 견해·가격 연결 결과는 동일했고, 모든 공개 이용 상태는 pending을 유지했다. 제외 항목의 ID·URL이 실험 입력에 남지 않은 것도 확인했다. **이 실험은 집필 요청을 만들지 않았으며 선택 기능의 제품 구현 완료도 아니다.** 이후 실제 선택 기능은 다른 입력 구조에 존재하는 수치·주장·카드 의존성까지 검사해야 한다.

CLP 저장 사례(기준일 9/10), MXN 저장 사례(보고서 기준일 10/28, 시장 거래 구간 10/26)의 기존 준비 상태도 유지했다. 둘의 실제 최신 리포트 또는 6개 통화 서비스가 완성됐다는 뜻은 아니다.

## 3. COP·PEN: 하루의 문제인가, 수집 경로의 문제인가

**둘 중 하나로 단정할 수 없다.** 저장 기록은 해당일 근거 부족과 특정 수집 결함을 구분할 만큼 충분하지만, 여러 날짜에 걸친 경로의 유용성을 입증하지는 못한다.

| 통화·경로 | 확인된 사실 | 판단 |
| --- | --- | --- |
| COP La República·Infobae 10/26 | 본문 확보·추출 가능. 현지 가격 보도와 DXY 해석은 있으나 같은 구간 COP 직접 설명으로 채택할 연결이 부족 | 이번 날짜의 내용 부족. 사이트 전체에 설명이 없다는 결론은 아님 |
| COP Portafolio | HTML 확보, 기존 추출기의 본문 식별 실패. 이용 검토도 미해결 | 별도 수집/사용 경로 문제. 이 기사를 읽었다거나 원인이 없다고 세지 않음 |
| PEN Gestión·RPP 10/26 | 원문 확보. 가격과 국제 일정·일반 영향 설명은 있으나 당일 PEN 연결이 부족 | 이번 날짜의 내용 부족. 같은 BCRP 가격 인용을 독립 원인 두 건으로 세지 않음 |
| PEN Macroconsult | 공개 브리프의 가격·비개입 설명은 확인. 목록 일부를 기존 추출기가 누락. 확인한 전체 내용에도 직접 하락 이유는 없음 | 부분 추출 결함과 내용 부족이 함께 있음. 추출을 고쳐도 이번 원인 공백이 자동 해결되지는 않음 |

Infobae 저장 본문은 DXY 설명, 전주 COP 흐름, BRL 전망, 향후 정책 시나리오가 섞여 있다. 한 기사 안에 있다는 이유로 전부 10/26 COP 원인으로 묶지 않는다. Macroconsult의 도표 기초 출처와 공개 브리프는 새로운 자유 재사용 데이터 피드가 아니다. 기존 이용 기록을 변경하지 않았다.

### 이 날짜를 끝내는 기준과 다른 날짜 검증

- **10/26 COP·PEN 원인 집필은 현재 자료 기준 보류로 닫는다.** 같은 일반 시황을 더 읽는 작업을 반복하지 않는다. 나중에 실제 새 관련 근거가 도착했을 때만 해당 기록을 다시 연다.
- 반복 수집 경로 검증은 별도 사례로 한다. 결과가 좋아 보이는 기사를 먼저 고르지 않고, 검증된 가격/사건 기록에서 조사 날짜를 먼저 정한다. COP는 합의한 누적 2% 후보를 활용할 수 있다. PEN에는 아직 확정하지 않은 2% 발행 기준을 임의 적용하지 않는다.
- 제한된 다음 검증안: 통화당 다른 날짜 최대 2개, 기존 등록 무료 경로 우선, 날짜별 후보 원문 최대 3건. 기존에 읽은 원문은 재조회하지 않고, 로그인·유료·접근 제한 우회 없이 실패를 기록한다. 이는 새 발행량 규칙이 아닌 조사 범위 제안이다.
- 가격 날짜를 확인할 수 없으면 날짜 선택부터 보류한다. 다른 날짜가 현재 저장 자료에 검토돼 있지 않으면 성공 사례로 계산하지 않는다.
- 평가 결과는 `원문 확보/추출 실패/내용 부족/주장 연결 가능/이용 검토 보류`로 분리한다. 최초 실패 날짜도 분모와 이력에 보존한다. 1건 성공만으로 상시 자동 수집 완료라 하지 않는다.

이번에는 이 추가 날짜 조회를 실행하지 않았다. 저장 자료만으로 확인 가능한 판단을 끝냈으며, 새 원문 확인 결과를 만들어 보고하지 않는다.

## 4. 6개 통화 준비표와 다음 구현 범위

| 통화 | 현재 사례의 원인 설명 | 다음 필수 작업 | 선택 배경/독립적인 출시 조건 |
| --- | --- | --- | --- |
| CLP | 9/10 저장 입력 준비 유지 | 공통 선택·표시 계약 적용 시 회귀 확인 | 새 거래일 반복 수집·실제 공개 표시 검증 |
| MXN | 기존 10/26 거래 구간 입력 준비 유지 | 종가/FIX 구분과 원인/소비 분리 유지, 공통 변경 회귀 | 실제 품질 시험·희소 가격 차트 F02·공개 검증 |
| BRL | 현지 현물 급등·되돌림 관련 귀속 설명 있음 | 같은 기준 전후 가격과 설명 구간 대조, 엄격한 원인 검사 확장 | IBGE 이용 범위·Selic 발표일은 독립 배경을 포함할 때 해결. 미해결 자료를 전송하지 않음 |
| ARS | 도매시장 귀속 해석 있음 | 도매/참조 계열 구분, 같은 기준 전후 가격, 채택 가격 출처의 용도 검토, 원인 검사 확장 | INDEC 반복 수집은 배경 제공 범위의 조건. 과거 수동 확인과 자동 성공을 구분 |
| COP | 10/26은 내용 부족 | 현재 사례 보류. 다른 사전 선정 날짜로 경로 유용성 검증, 같은 기준 가격 쌍 | DANE 소비 배경과 출처 조건은 확보 상태 보존 |
| PEN | 10/26은 내용 부족 | 현재 사례 보류. 다른 날짜 검증, 공식 결측/호가면·가격 기간 연결 | INEI 사용 범위·Macroconsult 부분 추출, 발행 임계값 미확정 |

**확인한 구현 공백:** `verifiedFxMovement`는 CLP·MXN만 허용한다. 새 네 통화의 `country-price-connection`은 차이를 설명하고 보류를 남기는 연결이며, 엄격한 가격 검증을 끝낸 결과가 아니다. 이 상태에서 자료만 더 수집하면 `verified_price_pair_and_fx_cause_review_required`는 계속 남는다. 통화 문자열 허용 목록만 늘리지 말고, 확인된 계열별 검증과 거래 구간 검토를 연결해야 한다.

원래 계획 4단계의 다음 작업을 다음 두 묶음으로 제한한다.

1. **Sol High — 필수/선택 입력 선택과 BRL·ARS 가격·원인 연결.** 먼저 기존 도구에 새 사본 선택·제외 의존성 검사를 연결한다. 이어서 확보한 가격 쌍이 있는 경우에만 해당 통화 검증을 확장하고, 없으면 정확한 계열/날짜 부족으로 종료한다. 새 선택으로 부정확한 가격이 통과하거나 공개 승인이 생기면 실패다.
2. **Astra High — COP·PEN 다른 사례의 설명 지지 검토.** 위 제한된 경로 검증과 가격 작업을 함께 묶어 수행하고, 준비·보류를 통화별 한 번에 정리한다. 먼저 선택한 날짜와 실패까지 기록한다. 국가 지원 범위는 줄이지 않는다.
