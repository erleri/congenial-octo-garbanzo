# 칠레·브라질·멕시코 최신 거래일 리포트 준비

2026-10-28 기준. 사용자 요청에 따라 칠레 한 건에서 BRL·MXN을 포함한 세 건의 로컬 비교 준비로 범위를 넓혔다. **신규 유료 호출은 아직 없고 합산 예산 승인 대기다.** 이전 칠레 단독 제안이나 종료된 카드 검토 예산을 이번 세 건의 승인으로 사용하지 않는다.

## 확정된 경계

- 대시보드의 기존 환율 경로는 유지한다. 리포트는 별도로 검증한 가격과 거래일을 사용하고 종류·공급자를 표시한다.
- 기존 원고·환율·비용 기록은 보존한다. 운영 배포·DB·메일·원격 push는 하지 않는다.
- 이 준비는 사용자가 요청한 최신 완료 거래일 초안이다. 누적 2% 자동 발행 자격이나 공개 승인을 의미하지 않는다.
- 한국 오전 대시보드 값의 종가 정합성은 [후속 필수 점검](release-backlog.md)에 별도 기록했다. 수집 시각만으로 종가를 보장하지 않는다.

## 공통 경로 변경

- `prepareNewsNotesInput`의 CLP 고정 설명을 실제 통화로 표시한다. CLP의 기존 전송 본문은 동일하게 유지됐다.
- MXN의 공식 가격과 다른 장중 기사 해설을 같은 거래일의 **다른 가격 기준**으로 명시할 수 있게 했다. 다른 거래일·알 수 없는 연결 유형은 계속 차단한다. 원문이 당일 종가를 뒷받침한다고 승인한 것은 아니다.
- BRL은 별도 작은 가격 어댑터에서 지정 발행처·거래일·원문 해시·전후 명시 가격·반올림 변동률을 검사한다. 검토 기록과 가격 스냅샷을 결합하며 PTAX 대입·추정 전일 값·인위적 관측시각·추가 API 이력은 거부한다.
- 기존 A안 메타데이터에는 평균·공식 종가 기준·매체 종가 보도값을 구분하는 출처 라벨을 연결했다. 원래 공개 타입·URL·대시보드 값은 유지한다.
- 구조·참조 검사와 실제 내용 품질·게시 승인은 구분한다. 일반 소비 원리로 비어 있는 원인을 채우지 않는다.

조회 실패도 보존했다. 최초 Banxico 응답의 문자 인코딩 손실은 원시 바이트를 다시 받아 해결했다. PTAX 요청의 공백 인코딩 오류도 수정해 공식 응답을 확인했으나, PTAX를 시장 종가로 채택하지 않았다. CNN 가격 뒤 문장부호의 쉼표를 숫자로 읽은 초기 추출 실패는 숫자 형식을 제한하고 실제 저장 본문과 합성 문장으로 재검증했다.
