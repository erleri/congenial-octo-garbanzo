외부 컴포넌트의 코드나 글꼴을 복사하지 않고 기존 CSS로 표현했다. 새 패키지·새 차트 라이브러리·새 유료 템플릿·Figma 파일을 도입하지 않았다. 금융 데이터와 한국어 본문을 유지하는 실제 웹 렌더링이 이번 비교의 기준이다.

## 바뀐 표현

- 전체는 푸른 회색 배경과 흰 카드, 네이비 강조를 사용한다.
- USD/KRW 기준환율 영역과 현재 선택된 메뉴를 네이비로 표시한다. 영역 안의 설명은 밝은 보조색을 사용한다.
- 통화명·핵심 숫자의 굵기, 보조 설명의 명암, 카드 테두리·모서리·그림자를 정리한다.
- 보고서의 제목·통계 영역·국가 선택·본문·출처 링크를 같은 네이비 계열로 연결한다.
- 가격 강약 의미색, 경고/자료 상태 표시, 통화별 차트 색은 유지한다.

글꼴 크기·줄 간격·카드 수·섹션 순서·열 구성·원고·숫자·기간·차트 경로는 변경하지 않았다. 글자의 굵기·일부 자간은 변경했으며, 측정한 주요 영역의 좌표와 크기는 기존 안과 일치했다. 이를 전체 DOM의 모든 픽셀 동일성으로 확대 해석하지 않는다.

| 실제 앱 | 비교 theme 속성 없음, 보호한 앱 13파일과 기존 비교 4파일의 해시 일치 |

모바일 차트는 크기 전환 직후 측정에서 차이가 있었으나, ResponsiveContainer 재계산 후 동일해짐을 확인했다. iframe 내부 버튼의 Playwright 클릭 위치 탐색이 실패한 경우 실제 접근성 버튼 클릭으로 갱신/관리자 차단을 확인했다. 이는 제품 기능 실패나 외부 API 호출 실패로 기록하지 않는다.

새 팔레트 대비는 공통 배경의 보조 글자, 네이비 영역의 흰색/보조 글자, 보고서 본문과 출처 링크를 계산해 확인했다. 전체 앱의 모든 상태에 대한 접근성 인증은 아니다. 실제 iPhone Safari·A4 프린터·다른 관리자 화면의 시각 검증은 이번 범위에 포함하지 않았다.

JS 구문·공백 검사 통과. 앱 소스·로직·DB를 수정하지 않아 기존 전체 단위/DB 시험을 재실행하지 않았다. 상세 브라우저 결과는 `.local-reports/private/ui2-refined-20261031/browser-verification.json`, 보호 기준은 같은 폴더 `source-baseline.json`에 보관한다. 추가 AI 호출·유료 비용·운영 변경은 모두 0이다.
