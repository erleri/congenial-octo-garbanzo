**연결 코드가 구현됐지만 실제 기사에 대한 AI 추출·대조 품질은 아직 검증하지 않았다.** 기존 카드 6묶음을 검사한 [이전 시험](news-model-review-20261028.md)의 비용 $0.085461과도 다른 작업이다. 이전 총 $0.46 승인을 이번 원문 시험에 재사용하지 않았다.

## 구현한 흐름

```text
등록된 기사 URL / 기존 자동 탐색 결과
  → 기존 수집기: 접근 규칙·유료벽·원문 영역·메타데이터 보존
  → 출처 + 원문 자료 형태에 맞는 사용 정책 적용
      미확정/전재 예외/조건 누락이면 사유와 함께 보류
  → Sol 추출 요청: 전체 추출 원문을 읽고 짧은 사실·귀속 견해 후보 생성
  → 코드 검사: 문단 참조·발언자·사건일·중복·길이·현지/글로벌 범위
  → 별도 Sol 대조 요청: 같은 원문과 후보 문장, 추출자의 이유는 제외
  → 문장 전체의 지지·귀속·범위·조건을 검사하고 오류와 공통 한계를 구분
  → 기존 근거 카드/범위 계약으로 변환하거나 보류
  → 카드의 후속 사용·집필·게시 자격은 별도로 판정
```

두 요청은 같은 Sol 모델을 사용하지만 추출 응답을 검토 응답으로 재사용하지 않는다. 서로 다른 요청 해시/응답 ID를 요구하고 두 번째 입력에는 추출자의 해설·자기점수를 넣지 않는다. 이것은 추출과 대조의 분리이며 독립된 사람·맹검 평가나 사실의 진실성 입증은 아니다.

원문은 등록된 수집 영역 전체를 동일하게 전달한다. 모델 예산을 맞추려고 조건이 있는 뒷부분을 잘라내지 않는다. 최대 크기의 후보를 넣었을 때 대조 요청이 예산 안에 들어오는지도 추출 전에 확인한다.

## 재사용한 코드와 새 연결

- `selected-source-collection.js` / `selected-source-collection-local.js`: 새 `articleUrls` / `--url`. 등록된 출처 하나의 기사 URL을 직접 요청할 수 있다. 같은 출처의 목록 URL·국가 경로·정확한 호스트를 검사하고, 직접 URL이어도 접근 규칙과 유료벽을 우회하지 않는다. 기존 목록 탐색 기본값은 유지한다.
- `original-news-pipeline.js`: 원문 전용 추출·대조 계약, 후보/검토 응답 검사, 기존 `reviewSelectedNewsMaterial` 영수증/범위 카드 생성 연결.
- `original-news-use-policy.js`: 기존 `inspectSourceUses`를 재사용해 검토한 출처 정책을 새 원문 리소스에 바인딩한다. 매 기사마다 사용자가 정책을 다시 입력하게 하는 운영 경로를 만들지 않는다.
- `original-news-pipeline-local.js`: `plan / replay / execute`. 준비/재생은 키를 읽거나 모델을 호출하지 않는다. 결과·원문·응답은 새 비공개 폴더에만 기록한다.
- 실제 전송은 기존 `callOpenRouterStream`, 비용 보완 조회, Sol 프로필, 엔드포인트 검사를 재사용한다. 운영 워크플로·DB·메일·브라우저 화면에는 연결하지 않았다.

## 원문과 이전 요지 카드의 사용 범위

[출처 정책 자료](original-news-source-policy-20261028.json)는 `publisher_article_text` 전용이다. `reviewer_authored_notes`에 대한 기존 허용 기록으로 원문을 허용할 수 없다.

검토가 끝난 정책만 출처 ID·국가·호스트·기사 경로와 대조해 적용한다. 원문 해시가 다른 새 자료에는 새 리소스 바인딩을 만들어 기존 정책의 범위만 적용한다. 정책 변경·중복 매칭·전재 표시 등은 보류한다. 해시는 권리나 법률 판단의 정확성을 증명하지 않는다.

정책이 요구하는 출처 링크 등의 표시도 실제 모델 입력에 포함한다. 발표일 미상이나 지표 대상 기간 미상은 출처 표시를 완성하려고 임의로 채우지 않는다. 외부 모델 전달 표시와 공개 화면 표시도 별도로 다룬다.

현재 등록한 11개 원문 정책은 모두 `pending`이다. 이는 전부 이용 금지라는 결론이 아니라, 해당 원문 용도의 적용 판단이 미확정이라는 기록이다. 접근 안내인 robots를 재사용 허가로 기록하지 않았다.

Agência Brasil의 [현행 소개/재현 정책](https://agenciabrasil.ebc.com.br/sobre)과 [EBC FAQ](https://acessoainformacao.ebc.com.br/perguntas-frequentes)를 실제로 확인했다. 자체 보도물의 보도 목적 이용, 상업 목적, 제휴/국제통신사 전재 예외를 구분한다. 과거의 일반적인 CC 설명이나 기존 자체 요지 카드의 판단만으로 모든 원문을 일괄 허용하지 않았다. 이용 조건을 법률상 허가/금지로 새로 확정하거나 기관에 연락하지 않았다.

## 검사와 실패 처리

- 추출은 최대 4개 짧은 요지이며 숫자는 새로 계산하지 않는다. 가격 관측시각/보도 수치 검증을 이 단계에서 만들어내지 않고 `reportedPrice=null`로 둔다. 실제 가격은 기존 별도 연결 절차를 거쳐야 한다.
- 사실과 귀속 견해를 구분하고 발언자·기관이 인용 문단에 실제 있는지 검사한다. 인과·대상·기간의 의미는 모델 대조의 판단이며 문자 일치만으로 승인하지 않는다.
- 대조가 후보의 중요 문맥 참조를 빠뜨리거나 조건 보존을 확인하지 못하면 카드로 변환하지 않는다. 긴 한계/조건을 잘라내서 범위 카드 제한에 맞추지 않고 보류한다.
- 글로벌 배경을 현지 통화 원인으로 승격하지 않는다. 실제 범위 오류와 관측시각 미상 같은 공통 한계는 구분한다. 한계가 있다는 이유만으로 모두 실패로 만들지는 않는다.
- 모델은 사용 허가·집필 자격·게시 승인 값을 만들 수 없다. 원문 대조는 모델의 지지 판단이며 실제 원인의 입증이나 사실 자체의 진실성 보증이 아니다.
- 같은 추출 응답을 대조로 다시 사용하거나 다른 자료의 응답을 끼우면 거부한다. 원문/카드/정책이 변경되면 이전 결과를 그대로 적용하지 않는다.
- 실제 실행은 정확한 원문 계획과 두 호출의 예산에 대한 새 승인을 요구한다. 한 기사에 최대 추출 1회·대조 1회, 요청별 120초, 재시도/백업 없다. 원문 처리 허용이 없으면 예산 승인이 있어도 전송하지 않는다.
- 사용량/비용/실패는 비공개로 보존한다. 비용 미확인은 예약액을 유지하고 다음 호출을 막는다. 같은 URL/동일 원문/버전의 중복 실행도 막는다.

## 로컬 명령

기존 수집 명령에서 등록 출처의 기사 URL을 직접 지정할 수 있다. `input`은 기존 질문 계획 입력이며 기사 원문이나 API 키가 아니다.

```powershell
npm run report:research:collect-selected -- --input ".local-reports/private/query.json" --sources "cop-valora" --url "검증할 등록 매체의 기사 URL" --mode live
```

그 수집 결과의 `result.json`을 원문 처리 준비에 전달한다.

```powershell
npm run report:research:original-pipeline -- --collection ".local-reports/private/수집결과/result.json" --mode plan
```

기본 출처 정책은 위 고정된 로컬 정책 파일이다. 검토한 별도 정책이나 저장 응답을 사용할 때는 비공개 파일을 명시적으로 지정한다. 준비 명령이 승인을 생성하거나 실행으로 자동 전환하지 않는다. 현재 19건은 준비 명령에서 보류된다.

`replay`는 원문/요청 해시가 맞는 저장된 추출·대조 응답을 재생한다. 새 모델 검토라고 기록하지 않는다. `execute`는 원문 처리 가능 판정과 별도 승인 파일을 함께 요구하고 그때만 Node가 기존 로컬 OpenRouter 키를 읽는다. 코드의 $0.25 제한은 한 기사 시험의 안전 상한이며 이번 실행 승인이 아니다.

## 검증과 보존

- 원문 흐름 8개 행동 검사와 정책 적용 3개: URL/매체 경계, 전체 문맥의 두 단계 분리, 조건/하위 주장 누락, 없는 발언자/다른 사건일/복사/범위 확대, 응답 바인딩, 예산·비용 유실, 출처 표시, 새로운 기사에 정책 적용, 전재·정책 변경/중복 보류를 검사했다.
- 실제 저장 19건의 수집 재생과 합성 전체 흐름은 별도 기록이다. 단위/모의 시험은 실제 모델 생성 품질을 보장하지 않는다.
- 전체 회귀 119파일/882실행 사례, 타입·린트·운영/앱 리포트/별도 리포트 빌드·번들 경계 검사 통과. 이후 ID 반환 지침의 명료화는 관련 28개 실행 사례와 실제 저장 재생으로 재검사했다. 기존 500kB 묶음 경고 유지. 검사 수는 원고 품질 표본 수가 아니다.
- 기존 원고·환율·근거·입력·비용 등 보호 파일 **13,225개**의 작업 전 해시와 대조해 변경·누락 0을 확인했다.
- 원문/검토/실행 자료는 Git 제외 비공개 폴더에만 저장한다. 새 키 발급/값 출력·운영 변경·유료 호출은 없었다. 공개 정책 페이지의 무료 검색/읽기는 수행했으며, 기사 재생·모의 검증은 네트워크를 사용하지 않았다.
- UI/DB 변경은 없으며 이번에 실제 브라우저·DB 검증을 새로 완료했다고 보고하지 않는다.

구현/저장 검증은 이번 범위에서 진행했다. 남은 것은 **원문 처리 범위가 확정된 실제 자료로 새 추출·대조 요청을 한 번씩 실행하는 품질 시험**과, 아직 미확정인 출처 정책의 적용 판단이다. 외부 전송 범위가 해결되지 않으면 해당 자료를 보류하고 처리 가능한 출처/자료 형태를 검토한다. 이전 카드 검토 성공·합성 결과·무료 열람을 실제 원문 검토 성공으로 바꾸지 않는다.

이 조건을 통과한 자료가 생겨야 국가별 집필 자격을 다시 평가한다. COP/PEN 직접 원인과 BRL/ARS 가격 구간 등의 기존 공백은 그대로 관리하며, 원래 4단계를 마감한 뒤 5단계 실제 원고 품질 시험으로 이동한다.
