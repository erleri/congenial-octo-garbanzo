# 공통 기사 선택·기간 해설·보류 분류 보완 — 2026-11-02

## 결론과 범위

MXN·COP·PEN·ARS가 모두 ‘쓸 뉴스가 없어 정상적으로 미작성’이었다는 설명은 유지할 수 없다. [앞선 실제 자료 감사](four-country-evidence-gap-audit-20261102.md)에서 확인한 선택·기간·진단 문제를 공통 경로에 반영했다. 국가별 면제나 수동 원고 교정은 추가하지 않았다.

이번 작업은 로컬 코드·저장 재생·합성 경계 검증이다. 외부 수집·모델 호출·신규 비용·DB 변경·운영 반영은 모두 0이다. 기존 원고·기사 캡처·모델 응답·비용 기록을 덮어쓰지 않았다. 새 실제 리포트가 생성됐거나 6개 통화의 집필 자격이 모두 확보됐다는 뜻은 아니다.

새 버전: `news-selection/1`, `news-period/1`, `research-continuation/3`, `original-news-pipeline/6`, `shared-input-policy/4`. 과거 원문 요청 버전의 생성 방식은 보존했으며 실제 저장 요청 해시로 확인했다. 구버전 보류는 기존 재검증 경로로 이동하며, 이전 승인·비용을 지우거나 새 비용 검사를 우회하지 않는다.

요청 예약은 단일 사건일 증빙과 기간 증빙 중 더 큰 유효 요청을 기준으로 한다. 둘을 동시에 갖는 불가능한 후보를 상한으로 삼지 않는다. 기사당 추출·대조 예약 한도 $0.25는 올리지 않았다. 본문이 한도를 넘으면 원문을 자르지 않고 필요한 비용과 용량 보류를 반환한다.

### 페루 후보 누락

같은 RPP 저장 목록, 후보 2개 제한, 같은 과거 보류 URL 목록을 사용했다. 기존에는 시세 기사 1714970·1715142만 선택됐으나 수정 후에는 원인 해설 1715079가 첫 번째로 선택된다. 보류 이력을 삭제하지 않고도 선택 문제가 해결됐다.

원실행에는 1715079의 본문 캡처가 없다. 따라서 이번 결과는 **선택 개선의 재현**이며 원문 수집 성공·독립 대조 통과를 뜻하지 않는다.

- 원 감사와 결과는 보존: `.local-reports/private/audit-four-country-selection-20261102.mjs`, `four-country-selection-proof-20261102.json`.
- 새 재생과 결과: `.local-reports/private/verify-fixed-selection-20261102.mjs`, `selection-period-fixed-proof-20261102.json`.
- 네 가지 단언 통과, 원본 4개 파일 전후 SHA-256 동일. 네트워크·모델·DB 접근 0.

## 합성 경계와 회귀 검사

`news-selection-period.test.ts`의 네 검사는 선택/피드백, 사유 분류, 원문→독립 대조→카드→공통 집필 입력의 기간 연결, 잘못된 기간·가격 결합 차단을 각각 담당한다. 실제 기사와 구분한 합성 자료이며 실제 모델의 품질 점수가 아니다. 월말 경계, 미래·원문 인용 불일치, 독립 대조의 기간 불일치, 일간 트리거에서 기간 해설 사용 차단, 원문 인용의 집필 요청 제외를 포함한다.

타입·린트·전체 170파일/1,251개 실행·테스트 메타데이터 중복 검사·운영 빌드·번들 경계·앱 리포트 빌드·리포트 빌드 통과. 마지막 미확정 가격 식별 방어 추가 후 담당 4개 검사와 린트를 다시 통과했다. Windows 임시 캐시 권한 오류는 테스트 실행 환경을 조정해 재검사했다. 리포트 빌드에는 `dbClient.ts`의 정적/동적 import 혼용 경고가 남아 있으며 이번 수집·기간 로직과 별개의 번들 구성 항목이다.

긴 본문 정상 처리 검사 두 건은 변경된 요청 길이에서도 기존 예약 한도 안에 들도록 합성 본문 길이만 조정했다. 128개 초과 문단·말미 근거 보존·24,000 초과 입력 상한 확인은 유지하며, 50,000자 초과 본문의 무손실 예산 보류 검사는 별도로 통과했다. 실제 기사를 잘라 통과시킨 것이 아니다.
