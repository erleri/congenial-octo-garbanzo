## 저장·권한·캐시

기존 `currency_reports`는 현재 유효 본문, runs/reviews는 비공개 원고·감사 이력으로 유지한다. 새 `currency_report_public_states`에는 공개됐던 ID·통화·기준일·상태·시각·버전·확인된 유형만 둔다. 과거 원문·요약·검토자·내부 사유·비용을 공개 상태 표에 복사하지 않는다. 옛 판본의 본문을 모두 공개하는 저장소를 만들지 않았다.

같은 통화·기준일의 유효 상태는 partial unique index로 하나만 허용한다. 승인·교체·철회는 같은 트랜잭션이며 기존 advisory lock을 재사용한다. 최초 승인/반려/철회의 기존 RPC는 유지하고, 기존 공개본을 조용히 교체하는 호출은 재확인을 요구한다. 새 `review_currency_report_version` 경로에서 예상 공개 ID와 교체 유형을 받는다.

공개 요약 view는 `security_invoker`다. anon/authenticated의 상태 조회만 허용하며 일반 사용자의 쓰기 권한은 추가하지 않았다. 초안 ID는 공개 상태 조회에서도 미존재다. 이미 공개됐다는 확인이 없는 과거 private run을 이관하지 않았다.

본문10개·목록 페이지12개·기타 조회 결과12개의 캐시를 최근 사용 순으로 제한하고 합계 UTF-8 JSON5MiB를 적용한다. 알려진 철회/교체 ID의 최소 차단 정보는 세션에 별도로 유지하며 본문 캐시 퇴출로 없애지 않는다. 기존24시간 만료·15분 확인은 **로컬 시험값**이다. 완전 오프라인에서 아직 수신하지 않은 철회의 즉시 반영은 보장하지 않는다. 실제 원고의 보존 기간/DB 자동 삭제는 적용하지 않는다.

신규 migration: `20261031023526_currency_report_public_history.sql`. CLI로 파일을 만들고 격리 DB에서 직접 검증 후, 해당 버전 하나만 로컬 적용 이력에 기록했다. 기존 migration 파일은 수정하지 않았다. 다른 포트의 DB와 운영 DB는 사용하지 않았다.

| DB 보안 진단 | 지정 격리 프로젝트의 CLI security advisors 경고 이상 이슈 없음 |

최초 Windows sandbox 실행은 임시 파일 rename/EPERM으로 시험 시작 전에 실패했다. 동일 검사를 호스트에서 실행해 통과했으며 검사를 완화하지 않았다. 구현 중 합성 구분의 후속 갱신, 날짜 철회와 RLS, 캐시 상태 전달 오류를 발견해 수정하고 회귀 사례에 반영했다. DB 시험 날짜는 UI 합성 이력과 충돌하지 않도록 별도2074~2075년을 사용한다.

원래 >500kB 번들 경고는 남아 있다. entry815,792bytes, initial JS816,858bytes로 기존 경계 검사 통과, xlsx는 lazy 상태다. 운영 산출물에 로컬 DB 주소 설정·비공개 원고 경로·신규 이력 API 모듈이 포함되지 않는 것도 확인했다. 기존 환율 화면의 기준일9월12일을 현재 시장 자료로 갱신하지 않았다.

검증 표본65개는 **합성 탐색 자료**다. 실제 발행/AI 품질 표본65건으로 계산하지 않는다. 추가 모델 호출0·신규 AI 비용$0·운영 변경0이다.

## 남은 범위

이번 기능은 기존 앱의 **로컬 승인·조회 연결**에서 완료했다. 운영의 새 provider 연결, 신규 migration의 테스트/프리뷰 이관, 기존 운영 데이터와의 최종 비교·배포/복구 승인·파일럿·전체2.0 출시는 별도다. 과거에 공개됐던 모든 판본의 관계를 복원했다고 주장하지 않는다. 정확한 A4 PDF 출력과 실제 iPhone Safari는 이번 화면 폭/기존 인쇄 경로 보존 검사와 구분한다.

다음은 사용자가 로컬 이력·상세 이동을 확인한 뒤 남은 관리자 화면/색상·톤을 순서대로 검토한다. 이메일과 운영 반영은 그다음이며 새 집필 시험으로 되돌아가지 않는다.
