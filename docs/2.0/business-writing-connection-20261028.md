# 영업 환경 본문·당일 달러 흐름 연결

2026-10-28 · 로컬 저장 자료 재생 · 신규 외부/모델 호출 0

## 누락 원인

최근 3개국 생성은 `prepareNewsNotesInput`을 사용했다. 이 경로는 기사 카드의 소비 배경을 조사 결과에는 남겼지만, 집필용 `fxWritingBackground`를 만들지 않았다. 기존 MXN 전용 경로에서 검토한 INEGI 자료도 이 경로로 합쳐지지 않았다.

`draftSchemaForPacket`은 해당 배경이 없으면 `implications.maxItems=0`, 전송 형식은 영업 환경 슬롯 0개를 요구한다. 조립도 이 경우 코드 소유 설명만 허용했고, 이번 패킷에는 그 설명도 없었다. 빈 본문은 모델이 자료를 무시한 결과로만 볼 수 없다.

MXN에는 당일 오전·정오판의 달러지수 상승 관측이 있었지만, 집필 우선순위와 설명 누락 검토가 명시되지 않았다. 기존 출력은 최근 금리차·캐리와 앞선 물가 발표 설명에 집중했다. 같은 기사 ID를 인용했다는 사실만으로 그 안의 달러 관측도 설명했다고 판단하면 안 된다.

## 공통 경로 변경

| 연결 | 구현·범위 |
| --- | --- |
| 검토된 소비 통계 | `prepareNewsNotesInput(...,{consumer})`에서 기존 INEGI 준비·기간·약관·출처 검사로 다시 조립. 새 패킷에 맞는 바인딩을 만들며 과거 컨텍스트를 복사하지 않는다. |
| 검토된 정성 소비 카드 | `consumerBackground`가 선택한 소비 구절·대상 기간·검토 기록을 연결. watch 전용·미지원·혼합된 원인/배경 출처는 자동 채택하지 않는다. |
| 실제 출력 | 승인된 배경이 있으면 영업 환경 0~2개와 문장별 출처 연결을 허용. 2개는 상한이며 내용을 채우기 위한 의무 개수가 아니다. 배경을 FX 원인 항목에 쓰는 것은 계속 차단한다. |
| MXN 당일 달러 | `marketFocus`가 검토한 당일 관측 카드·구절·장중/종가 구분을 연결. 당일 관측을 먼저 설명하고 이전 캐리 배경을 뒤에 연결하도록 한다. 장중 동행을 종가 인과·기여도로 승격하지 않는다. |
| 내용 검토 | `writingCoverageRequirements`와 필수 `writingCoverage` 응답으로 소비 본문·달러 연결의 누락을 별도 확인. 미응답은 미검증, 설명 누락은 편집 보완, 실제 기간·인과 오류는 교정 대상으로 구분한다. |
| 기록·호환성 | 기존 원고·점수·리뷰·비용·가격 파일을 바꾸지 않는다. 새 입력은 별도 저장. `currency-input/12`, `fx-background-writing/3`, `fx-writing-focus/1`로 식별한다. 기존 배경 기록과 기본 URL은 유지한다. |

생성 입력에는 필요한 설명 지시만 전달한다. 검토용 질문을 생성 모델에 다시 자기 평가 계약으로 전달하거나 같은 지시를 여러 위치에 복제하지 않는다. 원리·출처가 없는 판매 영향이나 업무 지시를 새로 허용하지 않는다.

## 저장 자료 재생 결과

| 통화 | 연결한 영업 환경 | 당일 시장 맥락 | 남은 제한 |
| --- | --- | --- | --- |
| CLP | BCCh가 발표한 **3분기 소비·투자 평가** 중 검토된 소비 구절. 발표일과 대상 분기를 분리 | 기존 가격·기사 기준 유지 | 새 모델 출력의 품질은 시험하지 않음 |
| MXN | INEGI **8월 실질 소매 연간 변화**, **9월 소비자물가 월간·연간 변화**. 검토한 발표일·비교 기준·표시 조건 유지 | El Economista 당일 **장중 달러지수 상승·페소 약세 관측**. 미래 중앙은행 일정과 최근 금리차 견해는 별도 | 새 모델 출력의 품질은 시험하지 않음 |
| BRL | 현재 선택된 저장 기사에는 검토된 소비·소매 자료 없음 | 기존 시장·포지션 해석 유지 | 재정·인선 관찰을 소비 자료로 승격하지 않음. 영업 환경 슬롯 0개 유지 |

기존 CLP/MXN 원고는 영업 환경 블록이 비어 있어 새 자료 연결 기준상 보완 대상이다. MXN의 기존 달러 설명 누락도 재확인했다. 이는 새 생성본의 점수나 승인으로 대체되지 않는다. BRL은 설명 누락과 자료 미확보를 구분한다.

처음 멕시코의 검토된 통계 4개를 모두 넣었을 때 기존 보수적 입력 길이 상한에 걸렸다. 금액 상한 초과와 구분해 보류 이유를 기록한다. 현재는 소비 흐름 질문에 필요한 소매 연간 변화와 물가 월간·연간 변화를 명시적으로 선택하고, 같은 소매 발표의 지수 수준은 보내지 않는다. 원본 4개·검토·이용 기록은 보존하며 선택한 3개에 연결된 약관·기간 검사를 재실행했다. 최종 입력은 한도 변경 없이 준비된다. 미선택은 자료 부재나 검토 불합격을 뜻하지 않는다.

## 재현·검증

오프라인 명령:

```powershell
node scripts/currency-report/replay-fx-writing-local.js --input .local-reports/private/business-writing-connection-20261028/question-selected-input.json
```

새 결과 폴더에 입력·실행 준비 결과·보류 미리보기·범위/출력 슬롯 요약을 저장한다. 원고와 기존 비용 장부는 읽기 전후 동일성을 확인한다. 실행 허가와 게시 승인은 항상 false이며 자격증명·네트워크·DB를 읽지 않는다. 입력 상한 보류는 그대로 보류로 저장하고 미리보기를 실행 승인으로 바꾸지 않는다.

검증은 출력 슬롯·소비/원인 역할·기간/범위 변조·미승인 용도·중복/다른 역할의 시장 관측·기존 입력 재생과 검토 응답 누락을 대상으로 한다. 저장 원고 재검토와 합성 경계 테스트는 구분한다. 새 생성 품질 및 운영 승인·게시·실제 유료 호출은 이번 완료 범위가 아니다.
