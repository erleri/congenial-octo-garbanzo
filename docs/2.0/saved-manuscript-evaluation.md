# 저장 원고의 오류와 조건부 설명 검증

2026년 10월 5일 칠레 저장 원고를 같은 DF·La Tercera 원문 선택본 및 승인된 달러 환산 원리와 대조했다. 원본에는 필수 교정 네 문장이 있고, 달러 환산 부분을 코드로 교체한 예시에는 세 문장이 남는다. 조건과 출처를 지킨 설명은 유지한다. 이번 판정은 에이전트의 오프라인 내용 검토이며 Gemini의 새로운 검토 결과나 게시 승인이 아니다.

## 판정 결과

| 표현 | 판정 | 원문 대조와 교정 범위 |
| --- | --- | --- |
| 공식 관측 이후 | 필수 교정 | 실제 관측시각과 공식 제공기관 기록이 없다. DF p0·p3의 기사 속 장중 전환을 설명할 수 있으나 저장 환율과의 선후관계까지 확정할 수 없다. |
| 외화 확보 압박이 일부 완화되고 | 필수 교정 | DF p4는 비거주자 포지션 압력, p5는 발표와 공급에 관한 분석가 해석이다. 외화 조달 압박의 실제 완화 및 그 전문가 귀속까지 확인되지 않는다. 공급 발표와 페소 반응으로 좁힌다. |
| 주요 원자재 가격이 연속 상승세 | 필수 교정 | DF p10은 구리의 두 거래일 상승이다. 같은 기사 p9는 유가 하락을 기록한다. 구리를 주요 원자재 전반으로 확대하지 않는다. |
| 장부상 현지통화 환산 부담 | 필수 교정 | 승인 범위는 같은 USD 결제금액의 조건부 환산이다. 기업 장부의 평가 방법·실제 거래는 확인되지 않았다. 현재 코드 조립 예시에서는 교체했다. |
| 추상적 제목과 대외 통화 여건 | 편집 권고 | 정책 신호와 국제 달러 강세의 대비는 근거가 있다. 명칭을 구체화하면 이해하기 쉽지만 추상성 자체를 사실 오류로 세지 않는다. |
| 실제 매각 규모의 변경 조건 | 유지 | La Tercera p10의 재정 필요·시장 조건에 따른 변경 가능성을 보존했다. |
| 포지션 조정 여부 및 조건부 관찰 | 유지 | DF p3의 향후 조정 여부를 관찰한다는 발언에 연결된다. 실제 청산·집행이 완료됐다는 진술이 아니다. |
| 같은 USD 금액·미헤지 조건의 환산 | 유지 | 승인된 단위와 적용 조건을 지킨 산술 관계다. 헤지·선결제·고정 계약 환율의 예외를 보존한다. |

이전 [쟁점 재분류](review-error-and-style-policy.md)의 두 문장은 당시 지정된 쟁점이었다. 이번에는 전체 문장을 대조해 조달 압박과 원자재 범위의 문제를 추가했다. 과거 점수·본문·승인·비용 기록은 변경하지 않는다. ‘외화’는 앞 문맥에서 USD를 가리키면 허용하고, ‘원자재’라는 범주 제목도 그 자체로 전반 상승을 뜻하지 않으면 구체화 권고로 남긴다.

기사 속 장중 반응은 저장된 환율 변화의 직접 원인으로 확정하지 않는다. 자료는 수집 당시 페이지이며 최초 발행 판본을 보장하는 아카이브는 아니다. XTB 인용 두 건을 독립된 두 기관의 검증으로 계산하지 않는다.

## 과도한 차단 여부

실제 저장 원고와 코드 조립 예시를 각각 17문장으로 평가했다. 공통 14문장을 한 번만 세므로 고유 원고 문장은 20개다. 합성 대조 사례 10개는 별도로 두었고 역사 사례로 세지 않았다.

| 합성 대조 사례 | 판정 |
| --- | --- |
| 보도에 귀속한 달러 매각 계획 발표 | 유지 |
| 달러 매각이 이미 완료됐다는 단정 | 필수 교정 |
| 비거주자가 포지션을 줄인다면이라는 관찰 조건 | 유지 |
| 비거주자가 이미 포지션을 줄였다는 단정 | 필수 교정 |
| 구리의 두 거래일 상승 | 유지 |
| 주요 원자재 전반의 장기 상승 확정 | 필수 교정 |
| 동일 달러 대금·미헤지 조건의 페소 환산 | 유지 |
| 그 환산으로 업체 실제 마진 개선을 단정 | 필수 교정 |
| 달러라고 먼저 명시한 뒤 이 외화 대금으로 지칭 | 유지 |
| 제공되지 않은 별도 정부 원문의 집행 결과 | 확인 대기 |

유지 다섯 건·필수 교정 네 건·확인 대기 한 건의 판정이 의도한 경로로 전달됐다. 선택적 문체 권고 다섯 문장은 기본 교정 계획에서 제외됐고 코드 작성 환산 세 문장은 유지됐다. 에이전트가 내린 판단을 검사 코드가 올바르게 처리한다는 결과이며 AI의 자동 오류 발견율이나 모든 통화에서의 오탐률을 뜻하지 않는다.

## 검사 한계

검토 기록은 문장 전체를 덮는 세부 주장, 원문 위치·해시, 적용 원리, 이유를 포함한다. 기존 검사로 교정 대상과 편집 권고의 일관성 및 인용의 실재 여부를 확인했다.

반례도 실행했다. 실제 구리 원문을 인용한 채 ‘주요 원자재 상승’을 지지한다고 잘못 판정하면 참조 검사는 이를 의미 오류로 잡지 못한다. 원문 ID가 유효하다는 것과 원문이 모든 주장을 뒷받침한다는 것은 별개의 조건이다. 자동 검사는 이 판정을 게시 승인으로 올리지 않지만 내용 판정 자체를 대신하지도 않는다. 다음 실제 생성본은 원문을 다시 대조해야 한다.

## 재현과 보존

`node scripts/currency-report/evaluate-saved-claims-local.js`는 원고·입력·비용 SHA256을 확인한 뒤 별도 비공개 결과 폴더를 만든다. 키·환경 파일·네트워크를 사용하지 않는다. 공개 보고서·현재 화면·과거 승인·점수는 쓰지 않는다.

- 판정 정의: `scripts/currency-report/saved-review-cases.js`
- 이번 결과: `.local-reports/private/saved-claims-evaluation-vKmGXm/`
- `legacy.json`, `assembly.json`: 전체 입력·판정·검사 결과
- `contrasts.json`: 합성 사례의 문장별 판정
- `result.json`: 필수 교정·편집 권고·한계·다음 요청 상한
- `generation-request.json`: 같은 근거를 사용하는 다음 생성 요청

원본 원고·snapshot·비용 기록 해시는 [기존 분류 기록](review-error-and-style-policy.md)과 같다. 신규 호출·비용은 0이다. 린트와 기존 생성·문장 검토 담당 검사 60개가 통과했다. 생산 코드나 UI 변경이 없어 전체 빌드·화면 검사는 반복하지 않았다. 20문장·10개 합성 사례를 단위 테스트 수에 추가하지 않는다.

## 같은 근거의 다음 생성 시험

Gemini 3.8 Flash·medium으로 생성 한 번, 재시도 없이 준비했다. 입력·스키마의 보수적 상한은 28,877토큰, 추론 포함 출력 상한은 16,384토큰이다. 단가 상한 입력 $0.75/M·출력 $3.75/M를 적용하면 신규 상한은 $0.083097750이며 제시 한도는 $0.084다. 공개 목록에서 Vertex Flex 가용성·ZDR·구조화 출력 지원을 확인했다. 현재 Flex 입력 $0.375/M·출력 $1.875/M는 위 상한보다 낮지만 실제 청구는 응답에서 확인한다. 실행 직전 조건을 재확인한다.

환율·차트·원문·원리 적용은 같은 packet으로 유지한다. 작성 규칙 변경 효과를 비교하며 이번 실패 표현이나 정답 원고를 생성 입력에 추가하지 않는다. 생성 뒤 근거 검토는 에이전트가 수행하고 추가 유료 검토·교정 호출은 포함하지 않는다. 이전 생성 단계 비용 $0.011263500와 새 생성 비용을 직접 비교하며 이전 네 단계 전체 비용 $0.044439750은 별도로 표시한다.

기존 시험의 네 호출 승인은 사용이 끝났다. 이후 새 상한 $0.084를 승인받아 [실제 한 번의 생성 비교](owned-content-trial-results.md)를 완료했다. 이 오프라인 결과 자체는 보존한다. 같은 근거의 단일 비교로 전반적인 모델 우월성이나 다른 통화의 품질 합격을 확정하지 않는다.
