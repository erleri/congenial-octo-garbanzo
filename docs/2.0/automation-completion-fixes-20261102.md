# 자동 처리 독립 점검 A1~A5 보완 — 2026-11-02

## 완료 범위

[독립 점검](automation-independent-audit-20261102.md)의 다섯 문제를 국가 공통 실행·저장·근거 재사용 경로에서 보완했다. BRL·MXN·COP·PEN·CLP·ARS 모두 같은 코드와 상태 정의를 사용한다. 국가/매체/특정 숫자를 조건으로 한 승인 예외는 추가하지 않았다.

이번 결과는 **코드·저장 자료·합성 장애·격리 DB 검증**이다. 실제 새 모델 응답의 품질 합격이나 2.0 출시 승인은 아니다. 외부 모델/뉴스 호출 0, 신규 비용 $0, 원고 수동 교정 0, 운영/메일/대시보드 환율 변경 0이다.

새 근거가 없거나 실제 내용 반려인 경우에는 자동 재작성하지 않는다. 재개는 기존 요청의 미완료 단계에 한정된다. 새 요청은 출처 사용 범위·현재 정책·실제 비용 장부·허용 예산을 다시 검사한다. 새 시험 예산을 이전 승인에서 가져오지 않는다.

## 검토 버전과 과거 자료

- `research-continuation/2`: 단계 대기와 오류 목록을 명시한다.
- `source-review-validity/1`: 현재 판정과 과거 기록의 대체 관계를 저장한다.
- `original-news-pipeline/4`: 재검토 이유와 이전 판단 ID를 요청에 묶는다. 모델은 새 원문 대조를 수행하며 이전 성공을 현재 승인으로 사용하지 않는다.
- 과거 `/2`·`/3` 요청은 재현 가능하게 유지했다. 실제 저장된 `/3` 요청 21건을 재구성한 해시가 이전과 같았다.
- 현재 검토 버전이 없는 성공 기록은 현재 지침 준수를 입증하지 못하므로 재검토 대상으로 둔다. 이는 원문 오류 확정이나 과거 기록 삭제가 아니다. 현재 버전의 영향 없는 정상 기록은 무과금 재사용한다.
- 알려진 MXN 기사 가격 문제는 과거 비교 응답을 고치지 않고, 그 옛 성공 기록이 현재 사용 자격을 자동으로 부여하지 못하도록 확인했다. 새 모델이 가격 모순을 실제로 잡는지는 별도 실제 품질 시험 사항이다.

## 저장·권한·비용

마이그레이션 `20261101222538_currency_report_continuation_completion.sql`을 로컬 파일로 준비했다. 새 함수는 서비스 역할 전용이며 익명/일반 로그인 실행 권한은 없다. 기존 공개 테이블·관리자 승인 정책·정기 워크플로 파일은 이번에 변경하지 않았다. 함수 설계에는 [Supabase Database Functions 공식 문서](https://supabase.com/docs/guides/database/functions)의 실행 권한/보안 컨텍스트 지침을 확인했다.

`supabase_db_latamfx-2x-isolated:56322`에서 함수 정의와 합성 쓰기를 트랜잭션에 넣어 검사한 뒤 전부 롤백했다. 그 뒤 **비활성·검토 비활성·예산 0을 확인하고 함수 정의만 이 격리 로컬 DB에 설치**했다. 코드가 요구하는 조회/종료/중복 저장 함수와 로컬 DB를 맞추기 위한 처리다. 운영 DB 및 기존 원고·환율·비용·실행 제어는 변경하지 않았다. DB의 기존 행/제어 해시를 전후 비교했다. 운영 마이그레이션 적용과 실행 활성화는 후속 운영 승인 범위다.

미확인 비용·진행 중 요청이 있으면 새 배치로 바꾸어 지출하지 못한다. 동일 최종 저장 재호출도 원래 비용을 덮어쓰지 않는다. 모델/경로 자동 교체·전송 재시도·자동 게시는 추가하지 않았다.

## 검증과 재현

1. 전체 자동 회귀 1,213건 통과. 수정한 장애 경계는 별도의 `continuation-recovery.test.ts`로 확인했다. 6통화별 반복 검증도 포함하며 경제 원고 품질 표본 수로 세지 않는다.
2. 타입·린트·운영 빌드·앱 리포트 빌드·리포트 전용 빌드·브라우저 번들 경계 검사 통과. 기존 `dbClient.ts` 정적/동적 import 혼용 경고는 유지된다.
3. 실제 격리 DB 23개 합성 SQL 검사 통과: 전용 권한, lease, 원래 배치 재개, 미확인 비용 차단, 명시적 대체, 원래 장부 보존, 최종 저장 중복/내용 변경 방지.
4. 실제 격리 DB에 6통화 반려/성공/독립 재검토 합성 기록 18개를 저장·조회하고 전부 롤백. 불변 이력·중복 방지·재검토 후 유효 판정 선택 확인.
5. 실제 저장 기사/응답을 읽어 과거 판단과 현재 재사용 자격을 분리했다. 원본 입력/실행/비용 파일 4개의 해시가 같다. 새 모델 호출 0.

재현 명령은 Node 20 환경에서 실행한다. DB 명령은 고정 격리 컨테이너/포트를 확인한다.
