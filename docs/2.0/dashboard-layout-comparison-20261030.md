## 사용자 검토 후 — 두 안 보류 / 기존 대시보드 유지

사용자 판단: 기존 실행 버전이 의미와 편의성에서 더 낫고 새 시안은 정보가 많이 빠졌다. 이에 **아래의 A 기본 추천을 철회한다.** A/B는 미채택 비교 기록으로 보존하며 다음 구현의 기본으로 사용하지 않는다.

실제 `Dashboard.tsx`와 기존 화면 캡처를 대조한 결과, 이번 시안은 단순 배치 비교가 아니었다. 기존의 당월 누적 평균 중심을 기준일 값 중심으로 바꾸고 MoM을 전일 대비로 대체했다. 오늘의 주목 포인트, USD/KRW의 평균/MoM/52주 위치, 통화별 52주 위치와 출처 표시, 30일/24개월 평균선·평균 대비 설명을 누락했다. 단기/월간 차트를 동시에 보던 흐름을 전환식으로 바꾸고 6열 정렬을 3열 또는 선택식으로 바꿨다. 원본 파일과 A/B 값이 같다는 검증은 **기존 화면과 지표의 의미·정보량·사용 흐름이 같다는 검증이 아니다.**

새 기준: 기존 대시보드의 지표·산식·정보 우선순위·6통화 순서·단기와 장기 동시 비교를 보존하고 그 위에서 메뉴 통합/관리 분리/리포트 이동을 설계한다. 계획 대비 메뉴 통합이 대시보드의 기존 계획 편차나 평균 정보를 삭제할 승인은 아니다. 모바일은 실제 기존 배치와 나란히 비교하며 읽기 편의를 검증한다. 다음 시안은 기존 컴포넌트를 재사용하는 사본에서 필요한 변화만 보여준다. 먼저 합의한 3메뉴는 유지하며 색상·톤·이메일은 기존 순서대로 별도 검토한다.

이번 조치는 설계 기록 정정이다. 기존 앱의 대시보드 코드는 그대로이며 A/B로 교체되지 않았다. 아래 비교·검증은 당시의 시안 기록이다.

## 어떤 판단을 위한 시안인가

| 관점 | A · 통화별 카드+작은 차트 | B · 요약 목록+큰 차트 |
|---|---|---|
| 여러 나라 흐름 동시 파악 | 여섯 선의 방향을 바로 훑을 수 있음 | 숫자는 동시에 보이나 나머지 다섯 흐름은 선택해야 보임 |
| 한 통화 자세히 읽기 | 상세 추이로 이동 | 대시보드에서 통화 선택만으로 확대 |
| 모바일 | 2열×3행 차트, 전체 흐름 확인에 스크롤 필요 | 3열×2행 숫자+선택 차트, 요약이 짧음 |
| 월별 장기 흐름 | 여섯 통화 동시 전환 | 선택 통화만 크게 전환 |
| 공간 사용 | 여러 작은 차트에 분배 | 한 차트에 집중 |

**제안:** 다국가 흐름을 빠르게 확인하는 업무에는 A를 대시보드 기본으로 추천한다. B의 큰 차트·통화 전환은 환율 추이 화면의 기본으로 재사용할 수 있다. 모바일은 B 요약의 장점도 있지만, 자동으로 기기별 다른 안을 확정하지 않는다. 사용자 선택 전이며 색상·폰트·최종 톤의 검토는 다음 순서다.

## 같은 자료와 범위

`public/data.json`의 저장 기준일 **2026-09-12**를 두 안에서 동일하게 사용한다. `scripts/ui2-dashboard-snapshot.mjs`가 공개 가격만 투영하며 기존 `getDashboardDaily/getDashboardPreviousDaily/getDashboardDailyChange`를 재사용한다. 원본 SHA256 `c7d75391561af63d4fc67cf05cd991cf12c7acbb6d1175ab56b5dbcfa35c3f9e`를 대조했다.

- 두 안의 6통화 현재 표시값과 전일 대비 계산 동일. 최신 API 재수집·종가 추정 없음.
- 30/90일은 저장 기준일에서 거슬러 올라간 달력 범위이며, 월별은 저장된 최근24개월 값이다. 당월 진행 중을 표시한다. 월별 tooltip을 해당 월 1일의 관측값처럼 보이지 않도록 월 단위로 표시했다.
- 보정값·관측 간격의 점선, 단위, 현지통화 강약 방향과 통화별 독립 축을 안내한다. 실제 시각 미확보를 종가로 표시하지 않는다.
- 리포트 진입은 **2026-10-09 CLP 기존 승인 과거본 캡처**로 연결한다. 동일 화면을 두 안에서 사용한다. 다른 통화는 미발행 상태 예시이며 실제 최신 발행 현황을 대체하지 않는다.
- 리포트 본문은 보존 이미지다. 근거·과거 이력의 완성된 새 UI를 구현한 결과가 아니다.
- 계획값을 임의 입력하지 않았다. 관리자 버튼은 메뉴 구성 예시이며 인증·편집·승인 기능을 붙이지 않았다.
- 이용 현황 수집도 미연결이다. 시안을 누르는 행동이 독자 통계나 모델 호출로 이어지지 않는다.

- 실제 브라우저에서 PC A/B 숫자 일치, 모바일390px 컨테이너 2열 카드/3열 요약과 가로 넘침 없음 확인.
- 30/90일·월별 전환, 월별24행 표, MXN 선택·기간·표 상태의 새로고침 보존, 대시보드→상세→뒤로가기 확인.
- 초기 브라우저 이력에는 여러 시험 단계가 섞여 이전 추이 화면으로 돌아간 기록도 보존했다. 별도 고정 동선으로 대시보드 복귀를 재확인했다.
- 초기 화면의 작은 주석 글자를 최소11px로 올리고 모바일 ‘오른쪽’ 표현과 월별 날짜 표시를 보완했다. 차트 값은 바꾸지 않았다.
- 원본자료 해시/공통계산 일치, 민감 경로404·POST405, 외부 연결 금지 CSP 확인. 시안은 고정된 공개 파일만 제공한다.
- 오류/경고 콘솔 기록 없음. 기존 앱 전체 회귀·실제 iPhone Safari·A4·접근성 전체 심사는 이번 결과가 아니다. 모바일 내 키보드/스크린리더 전체 품질도 아직 별도 검증 범위다.
- 관리자 연결/운영 provider/리포트 상태 오류 U01~U06은 이 시안에서 해결했다고 하지 않는다.

## 재현과 다음 작업

```powershell
node scripts/ui2-dashboard-snapshot.mjs
node scripts/ui2-dashboard-server.mjs
node scripts/verify-ui2-dashboard.mjs
```

서버는 loopback4180·고정 파일 허용 목록·GET/HEAD만 지원한다. 운영 env/메일/DB를 읽지 않는다. 원본을 갱신하면 새 시안 자료 버전으로 기록하고 A/B 둘 다 같은 스냅샷으로 비교해야 한다.

**다음:** 사용자가 두 배치의 읽기 편의성을 확인 → 기본 배치 선택 → 통합 추이·리포트 상세·관리 이동 설계 → 색상/톤 → 로컬 제품 적용. 앱 출시 조건과 이메일 상세 설계는 기존 순서를 유지한다.
