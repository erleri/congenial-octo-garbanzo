# 남은 4건과 반복 발생 처리 기준 / 2026-11-01

## 요약

멕시코 2건의 날짜는 원문에 있었다. 시간대 없는 Open Graph 값과 UTC가 붙은 JSON-LD 값이 함께 있을 때 모두 충돌로 처리한 수집기 문제였다. 같은 저장 HTML에서 실제 UTC 값을 복구했다.

브라질 2건은 EBC 포털의 일반 안내를 근거로 사이트 전체의 외부 본문 분석을 보류한 내부 설정이었다. Agência Brasil의 자체 제작 보도·제휴 자료·사진 조건과 실제 LATAM FX의 처리 행위를 나눠 다시 기록했다. 공통 비공개 분석 경로를 적용하되, 이를 출판사의 AI 허가로 표시하지 않는다. 원문·사진의 공개 복제는 계속 허용하지 않는다.

기존 수집 파일 6개와 원고·환율·비용을 보존했다. 새 사본으로 재생해 24개 후보 모두 모델 검토 입력을 준비했다. **이는 당일 환율 원인 근거 24건의 채택이나 실제 AI 검토 합격이 아니다.** 유료 호출·운영/DB 변경은 없다.

## 1. 날짜 2건: 추측 대신 명시된 시각 사용

| 자료 | 원문에서 확인한 발표시각 | 보존할 구분 |
|---|---|---|
| Expansión José Cuervo 기사 | 2026-10-29T21:48:37.659Z | 10월29일 기사. 조사 목표 30일로 바꾸지 않음 |
| Expansión 브라질 헤알 기사 | 2026-10-26T14:36:42.226Z | 10월26일 기사. 멕시코 기사라고 현지 페소 원인으로 자동 채택하지 않음 |

공통 파서는 JSON-LD·Open Graph·microdata의 발표/수정 필드를 읽는다. 명시된 시간대가 있는 값과 시간대 없는 값의 날짜·시·분·초·소수초가 같은 경우, 미해결 필드의 시간대를 추정하지 않고 명시된 값만 사용한다. 원래 값과 미사용 사유는 `publicationResolution`에 보존한다.

등록된 출판사 시간대가 있는 값은 기존 정규화 경로를 유지한다. 실제 두 시각이 다르거나, 날짜가 다르거나, 시간대 없는 값만 있으면 계속 미확정/충돌로 남긴다. URL·검색 노출·수집시각·수정시각을 발표시각으로 대신 쓰지 않는다.

수집기 코드에 연결했으므로 다음 수집부터 같은 구조의 기사에 적용된다. 이번 저장 재생은 원래 HTML·본문·수집시각을 그대로 사용하고 메타데이터를 새 사본에서 재추출했다. 카드 binding이 달라져 과거 응답을 새 판단으로 재사용할 수 없다.

## 2. ‘이용 범위’의 뜻과 브라질 설정 교정

무료 열람 여부, 기사·사진을 그대로 다시 싣는 행위, 자체 사실·전문가 견해 분석은 각각 다른 용도다. 이번에 검토한 공식 안내는 주로 복제/재배포 범위를 설명한다.

- [EBC 공식 FAQ](https://acessoainformacao.ebc.com.br/perguntas-frequentes): 자체 제작 보도는 출처 표시 조건으로 다른 매체의 보도 목적 이용이 가능하다고 안내하며, 국제 통신사 자료는 일반 허용 범위에 자동 포함하지 않는다.
- [EBC 언론 안내](https://www.ebc.com.br/sobre/sala-de-imprensa): 비상업 목적/출처 표시와 상업적 복제 문의, 외부 제공 자료의 예외를 안내한다.
- [EBC 포털 일반 약관](https://www.ebc.com.br/termos-de-uso-e-condicoes-gerais-do-portal-da-ebc): 일반 포털 목적과 출처 표시 조건을 담고 있다. 이 문구만으로 Agência Brasil 전체의 비공개 AI 분석 금지를 확정하지 않는다.

저장된 브라질 두 기사에는 Reuters 정보 사용 표시가 있다. 사진의 Reuters 복제 제한을 기사 속 모든 사실에 대한 분석 금지로 확대하지 않는다. 반대로 EBC 자체 보도의 재배포 안내를 Reuters 자료·사진의 사용 허가로 확대하지도 않는다.

**수정한 운영 판단**: 출처 안내와 실제 차단 규칙을 별도 데이터로 관리한다. EBC 전체의 `all_external_text` 보류를 제거하고, 출처의 재배포 범위·제휴 예외·AI 용도 미언급을 `sourceNotices`로 기록했다. `grantsUse=false`, `aiPermission=not_explicitly_addressed`를 유지한다. 비공개 수집 본문 분석에는 다른 출처와 같은 공통 프로젝트 기준을 적용한다. 출판사 허가증이나 법적 판단을 생성하는 기능이 아니다.

실제 처리 제한이 확인된 경우에는 기존 `restrictions`가 우선한다. 단순 권리 안내가 모든 용도의 금지로 바뀌거나, 권리 안내가 허가증으로 바뀌지 않도록 구분했다.

## 3. 요청·카드·공개에 연결한 통제

| 행위 | 공통 처리 |
|---|---|
| 수집 본문 비공개 분석 | 본문 결합/접근 검사·전체 입력·승인 예산·제공 경로/ZDR·학습/수집 금지 검사 |
| 출처 전달 | 원출판사·URL·Reuters 등 본문에 표시된 제공 출처·독립 분석 용도를 실제 요청에 전달. 표시가 빠지면 조건 미충족으로 차단 |
| 자체 사실/귀속 견해 카드 | 별도 원문 대조·모든 하위 주장·독립 표현·발언자·기간·조건 검사 후 기존 경로로 연결 |
| 리포트 공개 | 정제된 콘텐츠·출처 표시·별도 내용 검토·관리자 승인. 원문/사진/기사 대체물은 공개하지 않음 |
| 명시적 접근/이용 제한 | 해당 자료·용도만 보류하고 다른 등록 후보를 계속 처리 |

이번에 원문 요청의 URL·출처/제공 출처·변환 목적을 실제 전달 조건으로 묶었다. `sourceCredits`를 누락해도 허용 판단만 남는 공백도 막았다. 자체 카드의 공개 출처 조건과 게시 승인은 기존 별도 경로를 유지한다.

## 4. 다음에도 같은 사례가 나오면

1. **자동 날짜 복구**: 표준 메타데이터를 모으고 동일/충돌/시간대 미확정을 구분한다. 근거 없는 시간대 보정은 하지 않는다.
2. **출처 안내 분류**: 사이트 이름이나 무료 여부 대신 자료 종류·행위·원권리자·목적·표시 조건을 기록한다. 일반 안내와 확인된 금지를 분리한다.
3. **범위별 적용**: 사진/원문 복제의 조건을 자체 사실 분석 전체의 차단으로 자동 확대하지 않는다. 확인된 AI/외부 전송 금지도 다른 행위의 허용으로 우회하지 않는다.
4. **대체 후보 계속 처리**: 복구하지 못한 날짜·접근·제한은 이유와 `nextAction=continue_other_registered_candidates`를 반환한다. 이미 준비된 다른 출처가 계속 진행한다. 기사별로 사용자에게 수동 확인을 요청하는 경로를 운영 기본값으로 만들지 않는다.
5. **부족하면 이전 발행본 유지**: 같은 거래일의 필수 관측/설명이 끝내 없으면 집필 자격에서 보류한다. 과거 기사 날짜를 바꾸거나 통계로 환율 원인을 만들어 채우지 않는다.
6. **정책 변경 이력 유지**: 출처 등록·조건 변경 시 공식 근거 URL·확인일·정책 hash를 갱신한다. 과거 원고/승인·이용 판단은 덮어쓰지 않는다. 외부 약관 변경을 자동으로 법률 해석해 허가/금지를 생성하는 기능은 이번에 추가하지 않았다.

출처 안내를 AI에게 매 기사 다시 판단시키지 않는다. 반복 실행은 확인한 구조화 정책으로 동일하게 처리하고, 범위 변경이 필요한 경우 자료/정책 단위로 관리한다.

## 5. 검증과 남은 경계

동일 24후보에서 날짜 재추출2건·출처 범위 교정2건을 반영해 입력 준비24/보류0을 재현했다. 원본6묶음의 해시 일치, 기사 본문/원래 날짜 보존, 새 카드 결합을 확인했다. 실제 모델 의미 검토는 하지 않았다.

검사에는 명시 UTC+동일 미지정 값 복구, 실제 시각 충돌 유지, 미지정 값만 있을 때 보류, 알려진 출판사 시간대 충돌 유지, microdata 보완, 출처/Reuters 표시 누락 차단, 실제 금지가 안내보다 우선하는 경우를 포함한다.

전체150파일·1,112사례, 타입·lint·운영/로컬 앱/리포트 빌드·번들 검사를 통과했다. 운영 산출물/새 검증표 텍스트35파일의 실제 비공개 키 값·비공개 경로 노출0을 확인했다. DB 구조·권한은 변경하지 않았다. 기존 스튜디오의 동적 import 최적화 경고1건은 남았다.

다음 순서는 기존대로 한 사례의 자료 역할·전체 비용 확인→별도 승인 범위의 실제 자동 추출/대조·집필·내용 검토→격리 승인/공개 조회→이메일2.0이다. 이번 결과를 6개국 당일 원인 근거/원고/출시 준비 완료로 표시하지 않는다.
