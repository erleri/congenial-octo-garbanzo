# LATAM FX 통화별 리포트 편집 기준

2026-11-02 현재 자동 생성 편집 우선순위: [환율 중심 공통 기준](fx-first-generation-20261102.md). 제목·요약·본문은 환율 움직임과 해설이 중심이며, 영업 환경은 직접 관련될 때만 한 항목·180자 이내의 선택적 보조 설명이다. 기존 통계 단독 최초 점검 예외는 폐기한다. 아래 날짜별 실험은 보존 기록이다.

현재 신규 생성은 [공통 생성·편집·검증 규칙](common-report-rules.md)의 2026-10-27 역할 분리 기준을 따른다. `currency-editorial/9`이며 집필과 내용 검토를 구분한다. 아래 `currency-editorial/2` 기준과 칠레 예시는 기존 실험의 기록으로 보존한다. 칠레 설명 카드는 공통 규칙의 필수 입력이 아니다.

내구재 영업 독자가 공개 정보를 통해 환율 변화의 배경과 소비환경을 이해하도록 돕는다. 문장의 안전성만으로 좋은 리포트라고 평가하지 않는다. 각 문장이 독자의 이해를 진전시키는지 별도로 확인한다.

## 적용 범위와 상태

- 편집 기준 버전은 `currency-editorial/2`다. 로컬 통화별 생성의 무료 모델 경로와 유료 비교 경로에 동일하게 적용한다.
- 기존 보고서, 원문 응답, 입력 스냅샷, 비용, 잠정 점수는 수정하지 않는다. 이전 점수는 새 편집 기준 통과를 의미하지 않는다.
- 최초 기준 변경에서는 API를 호출하지 않았다. 이후 사용자 승인 재생성 1회 결과는 아래 실험 기록에 별도로 남긴다. 기존 기본 결과와 운영은 유지한다.
- 공개 콘텐츠의 필드와 URL은 유지한다. 비공개 실행 기록에 편집 버전, 자동 검사 결과를 추가한다.

## 독자가 따라갈 설명 순서

‘왜 움직였나’는 항목당 두세 문장을 기본으로 한다. 첫 문장은 새 사실이나 출처에 귀속한 해석, 다음 문장은 왜 중요한지와 전달 경로, 마지막 문장은 해당 통화와의 연결을 설명한다. 제목을 문장으로 다시 쓰거나 같은 주의사항을 반복하지 않는다.

| 항목 | 필요한 내용 | 불합격 예시 |
|---|---|---|
| 무엇이 달라졌나 | 사건과 기존 기대의 차이. 기대가 확인되지 않으면 사건만 설명 | 미확인 예상치나 실제 반응을 만들어 서술 |
| 왜 중요한가 | 근거가 지지하는 금리 기대·달러·원자재 등 전달 경로 | ‘여러 요인이 복합 작용’으로 설명을 종료 |
| 왜 해당 통화인가 | 공통 달러 요인과 국가 요인의 차이 | 나라 이름만 바꾸면 그대로 사용 가능한 해설 |
| 영업 환경의 의미 | 조건을 밝힌 구매력·수입환산·금융 여건의 경로 | 회사 판매·마진·재고 추정, 가격·판촉 업무 지시 |
| 다음 관찰 변수 | 제공된 사건·지표의 반응이 어느 해석을 강화하거나 약화하는지 | 미확인 일정·예측, ‘관심 있게 지켜보자’만 반복 |

배경 세 개는 상한이지 할당량이 아니다. 근거가 두 개면 두 개만 쓴다. 설명 경로를 뒷받침할 자료가 없으면 항목을 줄인다. 원인 설명을 모두 확보하지 못하면 발행을 보류하며, 주의사항을 원인 대신 쓰지 않는다.

## 사실과 해석의 표현

확인한 사실은 직접 쓴다. 보도에 담긴 분석가 해석은 출처를 밝힌다. 일반 경로는 조건을 앞에 둔다. ‘조건부’라는 말만 붙여 실제 움직임의 원인으로 승격하지 않는다.

공통 한계는 본문 뒤의 한계 영역에 한 번 둔다. ‘유일한 원인은 아니다’ 같은 범용 면책을 매 문단에 붙이지 않는다. 그러나 특정 해석을 바꾸는 반대 근거, 가격 기준 불일치, 중요한 조건은 해당 설명 옆에 남긴다. 자동 검사도 문장을 삭제하지 않는다.

사실 요약과 근거의 채택 범위를 입력에서 분리한다. `summary`에는 관측·출처 귀속 설명을, `admittedScope`에는 원문 검토에서 허용한 범위를 담는다. `sharedLimitations`는 코드가 표시할 공통 한계다. 범위를 분리했다고 제한을 해제한 것은 아니다.

## 칠레 기준 문장

아래는 기존 원문 검토 기록에서 허용한 내용으로 작성한 편집 예시다. 새 API 결과나 발행 승인본이 아니며, 과거 보고서를 덮어쓰지 않는다. 근거의 상세화가 필요한 지점을 드러내기 위한 기준 원고다.

### 미국 물가의 구성과 달러 해석

Emol이 인용한 분석가는 일반 물가가 예상에 부합했어도 근원물가의 압력이 끈질겼다는 점에 주목했다. 기사 속 해석의 연결은 근원물가 압력에서 미국 금리 기대를 거쳐 달러 지지 가능성으로 이어진다. 칠레 내부의 경기 소식과 구분해서 읽을 공통 달러 배경이다.

근거: `emol-morning`. 실제 미국 금리·달러 지수의 등락이나 공식 물가 수치는 이 입력으로 확인하지 않았다. 더 깊은 ‘예상과 무엇이 달랐나’를 쓰려면 실제치·예상치·이전치와 발표 시각을 추가 확인해야 한다. 위 문단은 그 확인을 대신하지 않는다.

### 구리와 국내 경기 배경

Emol 마감 보도는 구리 조정과 취약한 국내 거시 여건을 함께 거론했다. 인용된 분석가가 덧붙인 내용은 국내 물가의 예상 밖 결과와 성장 전망 약화였다. 미국발 달러 해석과 함께 칠레 내부의 경기·물가 평가도 시장 설명에 포함됐다는 점이 다르다.

근거: `emol-close`. 이 문단은 허용된 요약의 범위를 보여주지만 전달 경로 설명은 아직 얕다. 구리와 페소 사이의 경로 및 해당 시점의 반응을 뒷받침하는 근거가 보강되기 전에는 ‘설명 충실도’ 만점을 줄 수 없다. 교과서적 경로를 당일 관측으로 바꾸지 않는다.

### 구매력과 큰 구매의 시점

Reporte Minero가 인용한 경제학자는 물가 부담이 가계 구매력을 약화시키고 불확실성이 큰 구매를 늦추는 경로를 설명했다. 구매력과 구매 시점을 나누어 보면 내구재 소비환경을 이해하는 데 도움이 된다.

근거: `rm-inflation`. 일반 경로로 표시한다. 실제 판매나 할부조건 자료가 없다는 사실을 변화가 없었다는 증거로 사용하지 않는다.

## 검사와 평가

자동 안전 검사는 기존 수치·출처 ID·통화·업무 권고·개인정보 제한을 유지한다. 별도의 편집 검사는 한계만을 제목으로 삼은 배경과 동일한 배경 본문을 차단한다. 반복 문장, 설명이 한 문장뿐인 항목, 주의 문구 비중은 검토 신호로 기록한다. 주의 문구로 추정되는 문장이 둘 이상이며 본문 문장의 사분의 일을 초과하면 신호를 남긴다. 이는 한국어 패턴 휴리스틱이며 참·거짓이나 설명 품질 판정이 아니다.

검토자는 아래 여섯 항목에 각각 통과 여부와 구체적 이유를 기록한다. 이유에는 실제 문장과 근거, 자동 경고가 있다면 수용·수정 판단을 포함한다.

1. 새 정보가 있으며 제목을 반복하지 않는다 (`newInformation`).
2. 사건에서 시장 해석으로 이어지는 연결을 설명한다 (`explainedTransmission`).
3. 해당 통화와의 관계가 설명된다 (`currencyRelevance`).
4. 각 항목의 역할이 다르고 반복 경고로 지면을 채우지 않는다 (`distinctInsights`).
5. 근거가 실제 설명을 뒷받침하며 자료 부재를 변화 부재로 바꾸지 않는다 (`evidenceFidelity`).
6. 중요한 반대 근거·조건을 숨기지 않는다 (`materialCaveatsPreserved`).

유료 비교 결과 선정은 기존 평균·근거 점수·오류 기준 외에 이 여섯 항목과 편집 차단 항목 없음도 요구한다. 검토 기록의 `version`, 각 `checks`의 `passed`·`reason`, 실제 콘텐츠의 `contentHash`를 확인한다. 자동 검사를 통과하거나 AI가 스스로 점수를 주는 것만으로 내용 검토나 사용자 승인이 완료되지 않는다. 기존 고정 캠페인은 재호출·재최종화하지 않는다.

다음은 추가 호출이 아니라 **근거 패킷 상세화와 기준 원고의 오프라인 대조**다. 원문에서 확인한 사건/기대 차이/전달 경로/통화 연결/허용하지 않은 주장 각각을 분리하고, 관찰 변수 중복과 확인되지 않은 효과 우선순위를 검토한다. 프롬프트만 강화해 빈 근거를 채우거나 미채택 문장을 조용히 수정한 뒤 실제 AI 원고로 표시하지 않는다.

## 설명 근거 분리와 목표 원고 — 2026-10-05 후속

사용자 승인에 따라 세 원문을 다시 읽고 `source-explanations/1`을 추가했다. 기사 요약만 전달하던 입력에 사건, 기대와의 차이, 출처가 설명한 전달 경로, 통화/소비 연결, 귀속, 원문 문단 위치, 제외할 주장을 나눈 세 카드를 **명시적으로 붙인 패킷에만** 제공한다. 근거 없는 연결을 보충하는 기능이 아니다.

카드는 원문 확인 기록 및 출처의 URL·발행일·사건일·대상 기간·요약·채택 범위 해시와 연결한다. 오래된 카드/불명 출처/잘못된 사례/판매 맥락의 원인 승격/중복 ID/추가 필드를 차단한다. 자유 텍스트 전체는 기존 개인정보·명령문 검사도 거친다. 이 구조 검사가 연결의 경제적 타당성을 자동 보증하지는 않는다.

`attachClpExplanations(packet)`으로 선택하고 무료·유료 요청 빌더가 같은 정제 카드를 사용한다. 모델·요금·기본 생성 경로 및 이전 캠페인은 변경하지 않았다. 다음 실제 실험은 준비된 입력을 명시적으로 선택해야 하며 **이번에는 어떤 생성 API도 호출하지 않았다**. API 키 파일도 읽지 않는 오프라인 준비 명령은 `node scripts/currency-report/prepare-clp-reference.js`다. 고정 예시를 덮어쓰지 않도록 배타적 저장을 사용한다.
