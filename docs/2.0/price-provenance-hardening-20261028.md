## 코드 연결

1. `api.ts`가 기존 반환값에 선택적 `priceSource`를 추가한다. 과거 스냅샷·Alpha Vantage 이력은 기존 반환 형식을 유지하면서 선택적 기록 콜백을 제공한다.
2. `price-provenance.ts`가 비밀값 없는 고정된 출처 주소, 응답 해시, 수집/공급자 시각을 만든다. 인증 URL·키·원응답은 기록하지 않는다. 기록 해시를 만들 수 없는 환경에서도 가격 자체의 수집을 실패시키지 않으며 출처 검증은 미확인으로 남는다.
3. `merger.ts`가 실제 대입과 같은 위치에서 출처를 갱신한다. 전체 날짜 묶음을 교체하면 기존 출처도 지운다. 다른 공급자가 같은 값으로 덮어써도 최종 단계의 기록을 남긴다.
4. 기존 캐시가 주입 자료보다 우선하는 수치 선택은 이번에 변경하지 않았다. 캐시에 원수집 기록이 없으면 주입 자료의 새 기록을 빌려 붙이지 않는다. 그 결과를 검증할 수 있도록 origin을 미확인으로 남긴다.
5. 생성 스크립트의 Alpha Vantage 캐시도 선택적 출처 기록을 읽고 보존한다. 기존 캐시와 호환된다. 생성 명령은 실제 운영/로컬 환율 파일을 갱신하므로 이번에는 실행하지 않았다.
6. JSON 전체 이력에는 새 기록이 포함될 수 있고, 경량 폴백은 제공 날짜·현재 값과 일치하는 출처 기록만 유지한다. 보간·Excel 변경·다른 값에 원 API 기록을 재사용하지 않는다.
7. `shared-price-contract.js`가 기록 버전·가격 일치·공급자/주소·시각·해시·상태를 검사한다. 기록된 공급자와 가격 성격은 읽되, 거래일 검증까지 자동 통과시키지 않는다. 기록이 바뀌면 새 스냅샷 식별값이 나온다.

인증 요청의 공개 프록시 차단은 보안 보완이다. 공개 자료의 기존 프록시 폴백은 유지한다. 브라우저에서 인증 API 직접 연결이 실패하는 경우 공개 프록시로 키를 우회 전송하지 않으며 해당 수집 실패를 드러낸다. 기존 VITE 키 설정 구조 전체를 교체한 작업은 아니다.
