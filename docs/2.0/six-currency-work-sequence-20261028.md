### 별도 승인·예산·저장 연결

기존 `executeEventTrial`·`runLocalTrial`·스트림 전송/비용 조회를 재사용한다. 새 공통 버전은 `shared-paid-trial-consent/1`으로 **전체 계획·요청·기준환율 사본·현재 저널 해시·추가1회·신규 예산**을 묶어야 한다. 과거의 카드 승인/원고 승인/다른 호출 승인은 통과하지 않는다. 기본 유료 경로가 비활성이면 그대로 보류하고, 실제 요청 전 새 제공 경로 검사를 수행한다.

예산과 기존 기록 검사 → 새 제공 조건 확인 → 비공개 저널/중복 방지 파일에 예약 저장 → 단1회 전송 → 원래 응답/실제 비용/검사 결과를 비공개 저장 순서다. 기존 요청당$0.25·캠페인$0.75 정책 상한은 자동으로 올리지 않았다. 추가 비교의 같은 날짜 재실행은 마지막 요청을 가리키는 새 승인도 필요하며 같은 요청은 재실행하지 않는다.

시간 초과·비용 미확인은 예약을 유지해 후속 호출을 막는다. 잘못된 출력은 보존하되 재작성/재시도/다른 모델 전환을 하지 않는다. 새 초안은 로컬 공개용 원고 목록에 자동으로 넣지 않고 비공개 결과에만 남긴다. 원래 `event-trials`와 비용 기록은 보존하며 새 공통 시험 저널은 별도 `shared-reference-trials`에 기록한다. 이는 기존 미확인 비용을 해결/삭제했다는 뜻이 아니다. 향후 예산 제안에도 이전 확정/미확인 비용을 별도로 명시해야 한다.

**최신 완료/다음 행동:** [현재 공급자의 종가 정의 판단](provider-close-definition-review-20261028.md)을 마쳤다. 현재 6통화 가격은 현지 종가로 인증되지 않는다. 참고환율의 정의와 종가 미확인을 구분했으며 숫자/운영은 보존했다. 다음은 **대시보드·리포트 공동 가격 정의 계약과 교체 전 비교 설계(Astra High)**다. 정의가 확정된 뒤 로컬 연결·기사 기간 대조·저장 전달(Sol High)로 간다. 아래 ‘다음 종가 판단’ 기록은 이번 조사 이전 이력이다.

**수집 기록 보강 후 현재 작업:** [가격 계보·공통 검사2·검증과 남은 조건](price-provenance-hardening-20261028.md). 기록/JSON/캐시 연결은 완료했다. 다음은 이 기록이 말하는 공급자 날짜와 가격이 현지 종가/어느 거래일을 뜻하는지 판단하는 공통 검토(Astra High)다. 그 뒤 같은 가격의 기사 기간 연결과 운영 전달 설계(Sol High)를 진행한다. 과거 기사 종가 확보 과제로 돌아가지 않는다. 실제 모델 생성/운영 반영 승인은 만들지 않았다.

**원문 연결 후 현재 작업:** [원문 추출·대조 구현과 실제/합성 검증 구분](original-news-pipeline-20261028.md). 카드 검토 앞단인 기사 URL 수집·원문 추출·별도 원문 대조·기존 카드 생성 경로를 구현했다. 출처 정책을 새 원문에 자동 적용하되 현재 11개 정책은 미확정이며 실제 저장19건은 전송 전 보류됐다. 합성 전체 흐름은 통과했지만 실제 원문 AI 품질 시험은 아직 하지 않았다. 원래4단계의 원문 사용 범위와 실제 자료 검증·국가별 가격/직접 원인 공백을 계속 관리한다. 연결 코드 완료를 4단계/출시 완료로 계산하지 않는다.

**실제 모델 검토 후 현재 작업:** [Sol 6통화 카드 검토·비용·준비표](news-model-review-20261028.md). 카드 전용 GPT Sol 연결·기존 사용/표시 조건 검사·실제 6회 검토·준비표 갱신을 진행했다. 실제 $0.085461이며 최초 오탐은 응답 보존 후 검사 버전2로 재검사했다. 신규 원문19건의 외부 전송/무인 지지 검토와 COP/PEN 현지 원인·BRL/ARS 가격 연결 등 **4단계의 남은 조건**은 유지한다. 카드 일관성 검토를 새 원고 품질·집필/게시 승인으로 처리하지 않는다.

**검토 연결 후 현재 작업:** [뉴스 검토 입력·응답 연결 결과](news-review-connection-20261028.md). 19건의 원문/시간/전재/사용 상태를 비공개 검토 입력으로 준비하고 기존 카드 검사를 재사용하는 연결부를 구현했다. 저장/모의 응답 검증은 통과했으나 실제 무인 검토기는 아직 연결하지 않아 새 19건의 내용 판단은 미수행이다. 4단계의 실제 내용 검토와 사용 범위·가격/원인 연결이 남았다. 수집·연결 검사 통과를 5단계 품질 또는 출시 합격으로 계산하지 않는다.

**뉴스 보강 후 현재 작업:** [무료 출처 확인·자동 수집 연결](free-news-expansion-20261028.md). 10개 신규/재활성화 경로의 실제 탐색과 저장 재생에서 19원문을 확보했다. 수집은 통과했고 자동 내용·사용 범위 검토는 대기다. 다음은 원래 **4단계의 국가별 가격·기간·직접 원인 연결과 자동 검토**다. 자료가 늘었다는 이유로 집필/게시를 승인하지 않는다. 아래 첫 ‘현재 기준’은 이번 출처 보강 전의 연속 작업 결과로 보존한다.

### 이전 진행 이력

**최신 네 통화 후속:** [BRL/ARS 가격 쌍·COP/PEN 다른 변동일](four-country-price-case-followup-20261028.md). BRL·ARS 공식 역사 원관측 두 개를 확보해 기존 판독 경로에 연결했다. COP는 사전 선정한 9/24에서 현지 달러 수급 귀속 설명을 로컬 카드로 확보했다. PEN 두 새 날짜도 직접 원인 부족으로 유지했다. 아직 엄격한 집필 자격은 아니다. 다음 고정 작업은 **확보한 BRL·ARS 가격과 COP 카드의 기준일/구간·설명 지지·이용 검토(Astra High)**, 이어서 **확인한 범위의 엄격한 공통 입력 연결(Sol High)**이다. PEN은 일반 시세 기사 반복 대신 현지 수급 취재 근거가 필요한 공백으로 남긴다. 아래 계획·상태는 과거 이력이다.

**최신 구현 결과:** [필수/선택 입력 구현·가격 연결 경계](material-selection-implementation-20261028.md). 선택 기능과 저장 재생을 완료했다. **최신 필수/선택 판단:** [집필 자격·사례와 수집 경로 구분](six-currency-eligibility-decision-20261028.md). COP·PEN의 10/26 원인 집필은 현재 자료 기준 보류로 닫고 다른 사전 선정 날짜로 반복 경로를 검증한다. BRL·ARS는 직접 설명이 있으나 가격 쌍과 CLP·MXN에 한정된 엄격한 원인 검사 확장이 남는다. 독립 소비·정책 배경은 선택할 수 있으나 실제 입력에서 완전히 제외하고 필수 근거·반대 조건을 보존해야 한다. 이번은 저장 사본 실험/판단이며 제품 선택 기능이나 집필 승인은 아니다. 다음은 **Sol High의 필수/선택 입력 선택 + BRL·ARS 가격·원인 연결**, 이어서 **COP·PEN 다른 사례의 제한된 경로/내용 검증**이다. 아래 ‘최신’ 표기는 당시 이력이다.

**최신 2026-10-28 후속:** [6개국 자료 준비·집필 입력·저장 검증](six-currency-preparation-20261028.md)을 마쳤다. BRL→COP→PEN→ARS의 자료 인계 및 CLP·MXN 저장 사례 재생을 같은 기준으로 기록했다. ## 다음 작업은 하나의 제한된 묶음

**완료한 묶음: 3단계 공통 집필 경로 마감 — Sol High.**

1. MXN F01: 정성적 집필과 코드의 수치·기간 표시 역할을 일치시킨다. 별도 경제 업데이트의 정상 계약은 보존한다.
2. E01: 소비 배경이 이미 첨부된 경우 하위 시장 조사 상태의 missing을 전체 자료 부재로 읽지 않게 한다.
3. 실제 사용하는 생성 진입점의 모델 선택을 점검한다. 사용자 확정 기본은 Sol이며, 구형 무료/Sonnet 시험 기본값과 운영용 기본 선택을 구분한다. 코드 전체 문자열을 일괄 치환하지 않는다.
4. 기존 입력·원고를 바꾸지 않고 요청 미리보기와 저장/합성 출력으로 확인한다. API 호출·출처 재조사·원고 재편집·UI 개편을 이 묶음에 넣지 않는다.

종료 조건은 **입력 지침·출력 검사·코드 표시가 모순 없이 맞고, 선택 모델 변경에도 공통 검토·예산 경계가 유지되는 것**이다. 이 조건을 충족하면 멕시코 미세 개선을 더 제안하지 않고 4단계 BRL로 이동한다. 근거·보안·권한 오류가 실제 발견될 때만 해당 경계를 다시 연다.
