# 공통 로컬 집필 경로 마감

2026-10-28 · 3단계 마감 · 저장 입력/합성 출력 검증 · 실제 모델 호출 없음

## 마감한 범위

MXN 최종 검토의 F01 지침 충돌과 E01 소비 배경 상태를 해소하고, 로컬 공통 집필의 기본 모델을 **GPT Sol**로 연결했다. 모델 선택은 `sol | sonnet | argon`의 등록된 프로필로 명시한다. 선택을 바꿔도 근거·검토·예산·개인정보 보호 경계는 유지한다. F02 요약 관측 차트는 원래 6단계 화면 작업으로 남긴다.

제품 운영 설정이나 GitHub 변수·워크플로·배포를 변경하지 않았다. 과거 무료/단일 모델 시험 도구와 v1 비용·승인 기록은 재현을 위해 보존했다. 이 로컬 경로 마감은 새 실제 원고 품질 통과 또는 유료 호출 승인이 아니다.

## 하나의 수치·기간 계약

- 환율 원인과 소비/정책 배경을 함께 쓰는 경로에서는 모델이 **정성적 문장과 근거 ID만** 제출한다. 숫자·날짜·자리표시자 금지는 유지한다.
- 연결된 소비/정책 근거에서 코드가 `factIds`를 고른다. A안은 기존 사실 레이블을 이용해 대상 월·단위·비교 기준·값을 설명 옆에 표시한다. 모델 문장은 그대로 유지한다.
- 기존 경제 업데이트 경로의 `{{fact_id}}` 계약은 보존하고, 목적별 지침을 분리했다. 전체 공유 지침에서 자리표시자를 무조건 삭제하지 않았다.
- 소비 근거를 환율 drivers로 사용한 출력은 계속 거부한다. 수치·기간 표시와 의미적 주장 검토는 별개다.
- 소비 배경이 첨부되면 최종 brief의 consumer 상태는 `reviewed_background_available`이다. 시장 조사 하위 계획의 기존 missing은 `sourcePlanUnresolved`로 명확히 보존하며, 실제 배경 첨부를 무시하거나 조사 성공으로 위장하지 않는다.

입력 버전은 `currency-input/11`, 배경 집필 지침은 `fx-background-writing/2`다. 기존 `CurrencyReport` 구조·URL·원고 파일·평가·비용 기록은 바꾸지 않았다.

## Sol 기본과 교체 경로

`writer-policy.js`가 로컬 프로필·제공 경로·출력 필드·가격 예약 상한을 관리한다. 새 `prepareEventTrial`은 `event-trial/2`로 Sol을 기본 선택하고 프로필을 요청·승인 해시에 묶는다. MXN 입력 미리보기와 정기 점검 준비도 같은 정책을 사용한다.

| 선택 | 저장 시험에서 재사용한 모델/경로 | 출력 상한 | 성격 |
| --- | --- | --- | --- |
| 기본 `sol` | `openai/gpt-6.1-sol` / Azure | 추론 포함 8,192토큰 | 로컬 기본. 현재 제공자 가용성 확인이나 운영 채택 완료를 뜻하지 않음 |
| 명시 `sonnet` | `anthropic/claude-sonnet-5.5` / Vertex global | 동일 | 자동 백업 아님. 새 예산·지원/가격·데이터 보호 확인 필요 |
| 명시 `argon` | `google/gemini-4-argon` / Vertex us | 동일 | 자동 백업 아님. 위와 동일한 경계 |

모델 ID·경로·단가는 기존 저장 시험의 정책 상한을 재사용했다. 현재 광고 가격·가용성을 새로 조회하거나 확정하지 않았다. 실제 호출 직전에는 제공자 지원, ZDR, 데이터 수집 금지, 추론 및 캐시 쓰기 포함 가격, 요청 수수료·가격 구간을 다시 확인한다. 등록 외 모델·다른 경로·보호 조건 완화는 거부한다.

실행은 기존 예약·중복·미확인 비용·요청별 120초·재시도 0·백업 0·별도 승인 경계를 유지한다. 모델이 바뀐 요청에는 이전 승인 해시가 맞지 않는다. v1 Sonnet 기록은 별도 동결 정책으로 남기며 새로운 기본으로 사용하지 않는다. 배포된 무료 optional-AI 도구의 기본·워크플로 변수는 변경하지 않았다.

전송은 같은 닫힌 슬롯 계약으로 변환하고, 응답은 무손실 복원 후 전체 로컬 스키마·출처·문장 검토 계약으로 검사한다. 구조화 출력의 스키마 준수와 내용 정확성을 별도로 검토하는 방식은 [공식 OpenAI 문서](https://developers.openai.com/api/docs/guides/structured-outputs)를 참고했다. 이번 공식 문서 열람 외에 자료 수집·카탈로그/API·모델 호출은 없었다.
