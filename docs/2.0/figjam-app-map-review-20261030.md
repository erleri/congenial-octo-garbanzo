## 확정과 제안 구분

확정: 기존 기준환율과 같은 스냅샷. 뉴스 가격은 대표값 대체에 사용하지 않음. 환율 원인과 소비 배경 분리. 기존 정상 보고서를 유지하되 철회된 원고를 다시 정상으로 노출하지 않음. 6개 통화 모두 누적±2% 및 유효 발행 후 14일이 지난 첫 한국 월요일 점검. PEN/ARS도 10월 29일 정책/코드에서 확정됐으며 이번에 과거 미결정 표시를 정정했다. [재생·정책 재확인](pre-ui-policy-review-20261030.md)과 [상태·행동표](report-state-actions-20261030.md)를 UI 검토 기준으로 사용한다.

검토 제안: Q1 독자 목적에 따른 메뉴 단순화와 계획 대비/관리 통합 범위. Q2 숫자 카드의 해석 읽기와 별도 목록 병행. Q3 관리자 승인 대기·API 상태·실행 비용을 모은 작업 공간. 아직 UI 확정·구현 승인이 아니다.

## 검증과 남은 범위

FigJam 도형 트리와 세 영역의 실제 렌더링을 확인했다. 철회 연결선의 경로와 한국어 글자 생략을 발견해 수정했다. 비밀값·수신자·원문 응답은 보드에 포함하지 않았다. 앱 코드 변경이 없어 전체 자동 테스트는 재실행하지 않았다. 링크 클릭의 사용자 브라우저 로그인·접근 상태는 별도이며, 도구의 보드 생성·수정과 렌더링만 확인했다.

다음 순서: 전체 지도와 R1–R8 검토 → Q1–Q3 구조 결정 → 리포트 기능 확인 → UI 2.0 검토·구현 → 분리된 PR·프리뷰·파일럿·운영 전환 승인. 권장 검토 모델 Astra High, 확정 후 구현 Sol High.

## 보강 03 · 외부 연결과 실제 화면 상세

사용자 요청에 따라 같은 보드에 두 영역을 추가했다. 전체 지도 상단에 C 상세 및 외부 연결로 이동하는 링크와 서비스 역할 요약을 넣었다. 기존 A–G·R1–R8 번호는 유지했다.

| 화면 번호 | 현재 메뉴 | 표시한 기능 |
| --- | --- | --- |
| C1 | 대시보드 | 기준환율·MoM·52주 위치, 최근 30일·월간 추이 |
| C2 | 월별 이력 | Local per USD·KRW 환산 월별표, 통화·연도 선택 |
| C3 | 일별 추이 | 통화·기간별 차트·일별표, 보간·범위 안내 |
| C4 | 계획 대비 | 이동·선행 평균·실제·계획 편차, 관리자 계획값 저장·변경 이력 |
| C5 | 관리 | 기존 관리: 비상 Excel·원본 자료·데이터 상태·메일링·기존 리포트 검토; 로컬 분기: API 상태·새 원고 승인 |
| F | 리포트 | 운영의 기존 리포트 경로와 로컬의 새 A안 경로 구분 |

관리자 계획환율 수정은 현재 C4에 있다. 로컬 새 관리 분기는 기존 Admin을 그대로 감싸는 형태가 아니라 별도 분기다. 화면 통합이 이미 구현됐다고 표시하지 않았다.

추가 근거: `src/App.tsx` 메뉴·렌더 분기, `src/components/{Dashboard,MonthlySummary,CurrencyDetail,MovingComparison,Admin}.tsx`, `src/lib/api.ts`, `src/lib/exchangeRateRepository.ts`, `netlify.toml`, `.github/workflows/generate-data.yml`을 읽었다. 계정·키·토큰·수신자 내용은 읽거나 보드에 포함하지 않았다. 현재 소스의 연결을 설명하며 API 실시간 인증·공급자 가용성 재시험은 하지 않았다.

두 새 영역과 갱신한 전체 지도를 실제 FigJam 렌더링으로 확인했다. 이번에도 제품 코드·환율·원고·운영 설정은 변경하지 않았다.
