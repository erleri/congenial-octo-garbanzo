# 기존 앱 리포트 동선 로컬 검증

2026-10-30 · Sol 단계 · 로컬 실제 화면/격리 DB · 신규 유료 호출 $0

## 판단

**UI2.0 구조 검토로 넘어갈 수 있다.** 승인·공개 조회·로그아웃·조회 장애·철회의 핵심 접근 경계는 이번 로컬 시험에서 확인했다. 공개·관리자 화면에 남은 상태 표현과 연결 항목을 UI 구현 요구사항으로 고정한다. 운영 전환·전체 출시·원고 품질 승인은 아니다.

**이번에는 제품 코드를 수정하지 않았다.** 실패 문구가 복구 후에도 남는 문제와 미발행/없는 날짜/철회 주소의 안내 혼동을 실제로 재현했다. 이들을 검증 통과로 숨기거나 국가별 예외로 해결하지 않는다.

## 환경과 자료

- 기존 앱: `http://127.0.0.1:4176/`, `vite.app-local.config.ts`. 꺼져 있던 서버를 다시 실행했다. 브라우저가 접근 가능한 호스트에서 loopback으로만 실행했다.
- 격리 Supabase: `latamfx-2x-isolated`, API 56321/DB 56322. 54322·55322의 다른 로컬 환경과 운영 환경은 변경하지 않았다.
- 시작 상태: 기존 원고 44건, 현재 공개본 2건. 실제 CLP 승인 과거본 2026-10-09와 기존 합성 BRL 공개본이 있다. 최근 실제 MXN/CLP 검토 원고를 자동 승인하지 않았다.
- 승인/철회 시험: 별도 PEN 합성 사본 한 건, 가상 기준일 2098-11-27. 화면 제목·본문·표시에 합성 시험임을 명시했다. 입력의 4점은 승인 경로 시험을 위한 합성 값이며 실제 AI 평가가 아니다.
- 로컬 대시보드 고정 자료는 2026-09-12다. 화면 확인을 위해 운영 최신값으로 교체하지 않았다. 기존 승인 과거 보고서는 발행 당시 수치·차트를 유지한다.

## 검사와 보존

- 기존 자동 검사 4파일 **17개 통과**: 공개 선택, 공개 캐시/철회 우선, 승인 준비, 연결 제한 시간. 새 테스트 수를 늘리지 않았다.

- 기존 DB 원고·검토 기록·공개본·관리자·계획 관련 행을 전후 해시로 대조했다. **기존 행 변경 0**. 추가 합성 사본과 승인/철회 두 감사 기록은 삭제하지 않고 보존했다.
- 코드·환율·원고·공개 파일·DB migration·workflow·package/Vite 설정 **617개 파일 동일**. 제품 코드 수정이 없어서 전체 빌드/설치/전체 테스트를 다시 돌리지는 않았다.
