# 통화별 한 장 — 디자인 검토 패킷

## 결정 전제

React 화면이 최종 렌더링 기준이다. **2026-09-13 사용자 결정: A안을 기준으로 진행한다.** B안은 비교 기록으로 보존한다. 같은 BRL/MXN 콘텐츠·차트·수치로 비교하며 모델 비교와 혼합하지 않는다. 본문 길이는 제목/소제목 포함 BRL 약 946자, MXN 약 902자(출처·추가 한계 제외, placeholder 치환 전).

Figma/Canva 관련 스킬은 있지만 이번 세션의 호출 가능한 도구 검색 결과는 모두 비어 있었다. **외부 Figma/Canva 파일을 만들거나 편집하지 않았다.** 아래 자료로 연결 복구 후 이어간다. 공개 환율·정제 문장·토큰·화면 이미지만 전달한다. `.env*`, private 실행 폴더, 사용자 계정·이메일은 전달 금지.

## 비교

| | A · 편집형 | B · 분석 브리프 |
|---|---|---|
| 첫인상 | 결론형 큰 제목, 넉넉한 여백 | 제목·요약 병렬, 카드로 구역 구분 |
| 강조 | 흐름을 읽는 기사형 | 변화와 배경을 비교하는 브리프 |
| 기본색 | warm ivory + deep teal | cool gray + navy |
| 동일한 요소 | 동일 사실·출처·관측값·구조 | 동일 사실·출처·관측값·구조 |
| 모바일 | 제목 → 요약 → 값 → 차트 → 배경 | 같은 순서, 구역 카드 강조 |

메인 숫자 카드에는 작은 독립 링크와 보고서 날짜만 추가한다. 카드 전체를 링크로 바꾸거나 숫자의 기존 기능을 대체하지 않는다. 별도 목록도 제공하여 최초 진입과 통화 비교를 모두 지원한다. 과거 보고서 날짜는 대시보드 데이터 날짜와 따로 표시한다.

## 토큰과 반복 컴포넌트

구현 기준 파일: `src/local-report/report.css`.

- Font: 기존 앱 Inter/Noto Sans KR 계열 우선, Segoe UI/sans-serif 대체. 숫자 tabular-nums. 추가 폰트 서비스 계약/업로드 없음.
- Ink `#192e30`, muted `#526567`, paper `#fffefa`, rule `#dce3df`, BRL accent `#147564`.
- B ink `#203145`, paper `#ffffff`, background `#edf1f6`, accent `#355c91`.
- MXN accent `#86523a`.
- Desktop 1240px content max; paper padding48px. 850/520px 반응형 기준.
- 공통: masthead, country mark, conclusion header, fixed-stat row, observation chart, claim with provenance kind, business-context band, watch item, evidence disclosure, status/empty/cache notice.
- 상태는 색만으로 표현하지 않는다: 현지통화 강/약세 방향 문구, 사실/해석/일반 경로 배지, 과거 사례/로컬 초안 명시.
- 차트 기본3개월, 1개월/1년 선택. 발행 스냅샷의 관측값만 사용. 보간된 차트를 새 사실로 표시하지 않음.

Figma 연결 후 권장 프레임: A/B 각각 desktop1240과 mobile390, 목록·숫자카드 진입·상세·근거 펼침·미발행/오류/캐시 상태. 기존 변수/컴포넌트부터 확인하고 토큰을 코드와 일치시킨다.

Canva 연결 후 동일 본문의 A4 편집 시안을 만든다. 디자인은 사람이 읽을 수 있는 활자 크기를 우선하며 자동 축소로 한 장에 억지로 넣지 않는다. 인쇄 CSS는 준비했으나 실제 A4 페이지 수/가독성 검증은 남아 있다.

## 사용자 검토 질문

1. A/B 중 어느 쪽에서 제목·배경·영업 의미를 더 빠르게 찾는가? 혼합한다면 무엇을 유지할 것인가?
2. 문장이 '원론적인 설명'을 넘어 읽을 가치가 있는가? 특히 단일 중앙은행 발표만으로 만든 시안은 근거 다양성이 부족하다.
3. 공개정보 도우미의 범위를 넘는 업무 지시나 회사 실적 추정이 없는가?

기준 디자인은 A로 선택됐다. 콘텐츠 방향에 대한 긍정적 검토는 실제 AI 품질·개별 보고서 발행·2.0 출시 승인과 구분한다. 발행 정책과 출시 승인은 여전히 별도다.

## 급변일의 읽기 흐름 — 사용자 피드백 반영

평시의 거시 배경 설명만으로 급변일을 통과시키지 않는다. A안의 큰 제목과 요약에서 독자가 “무슨 일이 있었기에 이렇게 움직였나”를 먼저 파악하도록 한다.

1. **무슨 변화인가:** 기준 시각/비교 시각, 변동폭, USD당 현지통화 호가와 현지통화 강약을 코드로 표시한다. 현지통화 급락은 해당 호가 상승과 구별해 표현한다.
2. **이번 움직임의 촉발 요인은 무엇인가:** 당일 사건·발표를 우선한다. 환율과 사건의 시간 순서, 해당 통화의 반응을 뒷받침하는 출처를 연결한다. 단순 동시 발생은 원인 확정이 아니다.
3. **공통 요인인가, 국가 요인인가:** 달러·다른 통화와의 비교, 해당 국가 정책·시장 뉴스 등 확보한 근거에 한해 분리한다. 특정 국가에 흔히 연결되는 요인을 자동 정답으로 넣지 않는다.
4. **어디까지 확인됐나:** 직접 확인된 사건/자료, 출처가 제시한 해석, 추가 확인 필요를 분리한다. 발표 시각·대상 기간이 없는 일반적 설명을 당일 원인처럼 쓰지 않는다.
5. **확인되지 않을 때:** “변동은 확인됐으나 촉발 요인은 확인 중”임을 분명히 한다. 원인을 만들어내거나 단정하지 않고 발행 품질 기준을 충족하지 못하면 이전 보고서를 유지한다.

사용자가 언급한 칠레 페소 급락은 다음 **급변 사례 검증 후보**로 기록한다. 이 문서는 해당 날짜·변동폭·원인을 확인한 시장 분석이 아니다. 실제 기준일과 자료를 확인한 뒤 사례를 선정한다. CLP 상시 생성이나 API 호출 한도의 확대를 승인받은 것으로 해석하지 않는다.

검증 합격 조건: 독자가 첫 화면에서 변화의 크기와 방향, 가장 근거가 강한 설명, 아직 모르는 부분을 구분할 수 있어야 한다. 큰 변동 자체가 원인을 명확하게 해 주는 것은 아니므로 원인 설명의 질을 별도로 검토한다.
