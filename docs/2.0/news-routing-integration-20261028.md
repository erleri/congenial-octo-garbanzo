# 6개국 뉴스 선택 연결 — 수동 수집에 의존하지 않는 경로

2026-10-28 · 로컬 구현 · 외부 조회·유료 호출·운영 변경 없음

**후속 결과:** [무료 뉴스 출처 보강](free-news-expansion-20261028.md)에서 실제 공개 요청으로 10개 신규/재활성화 경로를 추가했다. 아래 실행 대상/제외 표와 838사례는 초기 연결 당시 이력이다. 현재 출처는 등록부와 후속 문서의 표를 따른다. El Financiero는 부분 공개 경로가 재활성화됐고 Yahoo 등의 제외는 유지한다.

## 확정한 경계

사용자의 “수동확인 안돼” 지시에 따라, 수동 검색·열람을 해야 진행되는 출처는 자동 수집 요청에서 제외한다. 제외 사유는 기록하지만 사용자에게 수동 확인 작업을 만들거나 그 작업을 기다리지 않는다. 기존 원고·환율·근거 승인·비용 기록은 보존한다.

이는 **수집 경로의 연결**이다. 기사 확보 성공과 원문이 주장을 지지하는지에 대한 내용 검토, 이용 범위 확인, 게시 승인은 여전히 별개다. 아직 연결되지 않은 자동 내용 검토를 완성했다고 보고하지 않는다. 검토 기준을 없애거나 검색 제목만으로 근거를 승인하지 않는다.

## 국가별 실행 대상

| 통화 | 기존 수집 도구로 선택하는 순서 | 조사 등록부에는 남기되 자동 실행에서 제외 |
|---|---|---|
| BRL | InfoMoney → Agência Brasil | Valor Econômico, Yahoo |
| MXN | El Economista → Expansión | El Financiero, Yahoo |
| COP | La República | Portafolio, Yahoo |
| PEN | Gestión → RPP | Yahoo |
| CLP | 기존 Emol·Reporte Minero 수집기 | DF, Pulso, Yahoo |
| ARS | Infobae | El Cronista, Ámbito, Yahoo |

표의 실행 대상은 기존 어댑터에 연결된 범위다. 모든 날짜의 무료 본문 확보나 자동 사용 허가가 검증됐다는 뜻이 아니다. 개별 조회에서 유료벽·접근 오류·추출 실패·기간 불일치가 나타나면 기존 실패 상태로 남기며, 다른 출처의 확보 결과를 처리한다. 어느 출처가 막혔다고 조회 권한을 우회하지 않는다.

CLP의 과거 `clp-existing-four-outlets` 식별자는 과거 검토 기록의 호환성을 위해 보존한다. 이 식별자가 실행하는 기존 수집기는 Emol·Reporte Minero이며, DF·Pulso·Yahoo 자동 연결이 완료됐다는 의미가 아니다.

경제 전문지 후보는 우선순위 등록부에 보존한다. 이번에 새로 조사한 전문지와 Portafolio·El Cronista는 자동 접근 조건/수집 연결이 완료되지 않은 상태이므로 실행에서 제외했다. 후보의 순위와 실제 실행 가능성을 혼동하지 않는다. 매체 성격과 조사 근거는 [기존 조사](six-country-news-outlets-yahoo-review-20261028.md)를 따른다.

## 연결한 동작

1. 기존 질문·기간·국가 판정 결과를 받는다.
2. 국가별 등록 순서를 유지하며 경제 전문 → 보완 보도 → 전재 매체 순으로 후보를 정렬한다.
3. `excluded` 출처는 제외 사유만 남기고 수집 요청을 만들지 않는다. 자동 연결된 출처만 기존 수집기로 전달한다.
4. 기존 수집기는 저장 원문 재사용 또는 제한된 실제 조회를 수행한다. 날짜·통화·원문 해시·조회/추출 실패를 기존 방식으로 보존한다.
5. 확보 자료는 기존 근거 카드 검토 경로로 전달한다. 수집 자체로 집필·게시를 승인하지 않는다.

기사 탐색용 국가·언어·기간 검색어도 요청 메타데이터에 연결했다. 검색어를 생성한 것을 검색 서비스 호출 또는 기사 수집 성공으로 기록하지 않는다. 실제 목록 조회/칠레 수집기는 기존 도구를 그대로 사용한다.

### 자료가 없거나 실패했을 때

- 실행 가능한 출처가 전혀 없음: `no_automatic_source` 또는 미등록이면 `no_registered_source`.
- 실행 대상의 저장 응답이 없음: `not_attempted / saved_capture_missing`.
- 조회 실패와 본문 추출 실패: 기존 `access_failed`, `extraction_failed`를 유지.
- 확인한 출처에서 해당 자료가 없음: `missing_in_checked_sources`. 시장 전체에 관련 기사가 없다는 뜻이 아니다.
- 자동 경로가 부족해도 수동 작업이나 임의의 AI 원인 추정을 대안으로 만들지 않는다.

소비 통계 질문에 뉴스 출처를 끼워 넣지 않고, 소비 배경을 당일 환율 원인으로 승인하지 않는다. 기존 준비 상태의 CLP·MXN을 다른 네 통화 전체의 준비 완료로 확대하지 않는다.

## Yahoo 처리

Yahoo는 여섯 통화 모두 검색 후보로 등록했지만 자동 수집에서는 제외한다. 이전 조사에서 직접 읽기 6건의 429와 자동 접근 조건 미해결이 확인됐다. Yahoo를 일반 수집 허용 목록에 추가하지 않았다. 메타데이터를 삭제하거나 `existing_adapter`로 바꾸는 것만으로 실행이 가능해지지 않도록 검사한다.

향후 합법적이고 안정적인 무료 자동 경로가 확보되면 별도 연결 검증을 거쳐 활성화할 수 있다. 현재는 사용자가 직접 기사를 찾아 전달하는 흐름을 요구하지 않는다. 기존에 검토된 Yahoo 기사 카드와 원고는 삭제하거나 재승인하지 않는다.

## 검증 결과

- 관련 두 파일 35사례 통과: 여섯 국가별 순서, 제외 대상 미전송, 모두 제외된 경우의 공백, 이전 요청 ID로 우회 차단, 기존 저장 자료→카드 흐름, 조회 실패/추출 실패 구분.
- 전체 회귀: 113파일 838사례 통과. 정확한 이름/본문 중복 및 자기 비교 감사에서 검출 없음. 의미적 테스트 중복이나 실제 리포트 품질을 보증하는 수치가 아니다.
- 타입 검사·린트·운영 빌드·기존 앱 리포트 빌드·A안 리포트 빌드·번들 경계 검사 통과. 기존 500 kB 번들 경고 유지.
- 별도 재생: 합성 질문 6개 + 변경 전 저장 등록부를 현재 도구에 다시 넣어 호환성을 확인했다. 실제 새로운 기사 수집 시험이나 원고 품질 시험은 아니다.
- 보호 파일 11,661개 대조: 검사 실행이 갱신한 `test-inventory.json` 외 변경 없음. 원고·원문·비용·환율 보존.
- 이번 외부 조회 0, 모델 호출 0, 신규 비용 $0. 운영 반영 없음.

## 남은 작업

현재 연결은 자동 수집 가능한 기존 도구만 선택하는 단계까지다. 무료 접근이 막히는 전문지의 대체 경로와 국가별 실제 수집 범위, 확보 원문을 문장별 근거 카드로 자동 검토하는 반복 실행은 별도 검증이 필요하다. 사용자 수동 수집을 그 공백의 해법으로 사용하지 않는다. 유료 호출이나 운영 연결부터 진행하지 않는다.
