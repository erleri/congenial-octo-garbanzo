# Gemini 연결 진단 — 비용 없는 준비 (2026-10-05)

## 이번 변경과 경계

기존 두 실패 기록·요청 해시·비용 예약·GPT 원고·A안·공통 리포트 규칙은 보존한다. 이번 작업의 신규 생성 호출은 **0회**다. 운영·DB·메일·원격 push 변경도 없다.

`npm run report:diagnose:plan`은 고정 칠레 입력을 검사하고 Git 제외된 `.local-reports/private`에 계획만 저장한다. 키를 읽거나 인터넷에 접속하지 않는다. `run` 인수를 지원하지 않는다. 동일 계획 재실행은 기존 기록을 확인하고 재사용하며 덮어쓰지 않는다.

## 단계별 진단 계획

| 단계 | 확인 대상 | 출력/추론 토큰 상한 | 보수적 예약 USD |
|---|---|---:|---:|
| connection | 짧은 공개 문장과 status 한 필드로 라우팅/첫 응답 확인 | 256 | 0.00428700 |
| structure | 근거·시장 분석 없이 리포트 본문 구조 수락 확인 | 2,048 | 0.01269900 |
| evidence | 고정 공개 자료와 본문 구조의 응답 확인 | 4,096 | 0.02858025 |
| full-ledger | 동일 자료·공통 규칙·전체 주장 대응표 확인 | 8,192 | 0.04468350 |

위 가격은 기존 Gemini 가격 상한(입력 $0.75/백만, 출력·추론 $3.75/백만)으로 산정한 **예약**이며 실제 요금이나 실행 승인이 아니다. 모두 별도 승인했을 때만 합계 최대 $0.09024975다. 자동 단계 진행·재시도·모델 교체는 없다. 다음 실제 실행은 최신 endpoint의 모델·ZDR·데이터 수집 금지·구조화/stream 지원·가격/요청 수수료를 다시 확인한 뒤 **connection 한 건부터** 진행한다.

진단 응답은 전부 공개·승인 불가다. full-ledger가 끝까지 왔더라도 기존 `parsePaidResponse(..., true)`의 구조·안전·공통 규칙 검사와 독립 내용 검토를 별도로 통과해야 보고서 후보로 취급한다. 짧은 연결 시험 성공은 리포트 품질 성공이 아니다.

## 스트리밍 전송과 기록

- `openrouter-stream.js`: 한 요청만 전송, 헤더 수신/첫 이벤트/첫 본문 시간, ID·모델·종료 상태·사용량·실제 비용 보존. 타임아웃 기본 총 240초/무응답 60초, 수신 상한 500,000바이트. 처리 중 댓글은 본문 도착으로 계산하지 않는다.
- UTF-8 분할, CRLF/CR/LF, 여러 data 줄, 반복 종료 사유와 마지막 usage, HTTP JSON 오류/HTTP 200 안의 SSE 오류를 구분한다.
- `[DONE]`와 정상 stop·일치하는 모델을 모두 확인해야 완전한 payload를 반환한다. 중간 종료·잘림·잘못된 ID·민감값 응답은 후보를 만들지 않는다. JSON 보정·자동 재작성으로 우회하지 않는다.
- `stream-journal.js`: 실행 ID별 전용 private 폴더를 한 번만 생성하고 순번 파일로 체크포인트 저장. 헤더 ID를 본문 읽기 전에 기록하므로 이후 프로세스가 종료되어도 조회 단서가 남는다. 완성/부분 원문 모두 브라우저·공개 캐시·번들·Git에 넣지 않는다.
- 이 전송기는 **아직 기존 유료 runner에 연결하지 않았다**. 승인 없는 지출이나 이전 실행 재시도를 막기 위해 실제 실행 명령을 추가하지 않았다.

[OpenRouter 스트리밍 문서](https://openrouter.ai/docs/api_reference/streaming)는 헤더의 X-Generation-Id, 마지막 usage chunk 및 중간 오류를 설명한다. Google은 취소에 따른 처리·과금 중단 지원 목록에 없으므로 타임아웃을 무과금으로 간주하지 않는다. 일부 응답을 받았다는 이유로 예약을 해제하지도 않는다.

## 과거 비용과 이후 조회

기존 최초 HTTP 400: 비용 미확인·예약 $0.04536825. 형식 단순화 후 timeout: 비용 미확인·예약 $0.04468350. **합계 미확인 예약 $0.09005175 유지**. 두 기록 모두 generation ID가 없어 요청별 조회를 실행하지 않았다. 계정 활동 기록 없이 추정 비용을 확정값으로 바꾸지 않는다.

향후에는 마지막 `usage.cost`를 우선 사용한다. ID가 남고 비용이 없으면 `reconcileGenerationCost`로 해당 ID 하나만 읽기 조회할 수 있다. 다른 ID·아직 종료되지 않은 처리·조회 실패·미확인 비용은 null로 남기고 기존 예약을 유지한다. 과거 기록을 덮어쓰지 않고 별도 정산 기록을 추가해야 한다. [사용량·비용 공식 안내](https://openrouter.ai/docs/cookbook/administration/usage-accounting).

## 검증 범위

합성 SSE 응답으로 프로토콜·타임아웃·ID/비용·민감값 경계를 검사한다. 단계 계획은 입력 보존·출력 상한·예약·진단 결과의 비공개를 검사한다. 기존 전체 테스트·중복 감사·타입·린트·운영/리포트 빌드·입력/비밀값 경계도 재검증한다.

**미검증:** 실제 Gemini 구조 수락, 스트리밍 지원/속도, 완성된 원고, 실제 과금, 내용 품질. 실제 시험은 별도 호출 수·예산 승인 후 진행한다.
