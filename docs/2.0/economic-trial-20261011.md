모델만의 실패로 분류하지 않는다. 경제 업데이트에 환율 인과 설명용 지침을 덧붙이던 부분을 제거했다. 공급자 전송용으로 단순화한 스키마를 로컬 검증에도 사용하던 연결을 끊고, 길이·개수·대응표 주소를 전체 로컬 계약으로 검사한다. 전송 스키마에도 유지되는 주소 열거형을 사용한다. 완성형 수치 라벨의 사용 위치와 조사 범위 제한도 명시했다.
